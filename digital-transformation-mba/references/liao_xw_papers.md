## 二、综合：商业分析方法论索引（可复用模型 → 业务场景）

### A. 偏好学习与多准则决策（MCDA × ML）
- **加性价值函数 / 边际价值函数**：把"决策逻辑"拆成各准则的贡献曲线，是连接管理直觉与算法的桥梁（01/03/04/07 共用）。
- **偏好解聚（Preference Disaggregation）**：从"结果"（某客户被评为高价值）反推"各准则权重与价值曲线"——课程"需求倒推"的算法化实现。
- **valued / 软标签**：对临界客户给多档可信度而非硬切（04），更贴近经营实际。
- **可应用场景**：信用评级、供应商分级、客户分层、风险档位、科研/门店/项目评估。

### B. 可解释 AI（XAI）在管理决策中的落地
- **XOFM（02）/ NN-MCDA（03）**：用"属性贡献曲线 + 交互热力图 + 边际价值函数"让人看懂模型，满足高风险、强监管场景（信贷、医疗、风控）的可审计需求。
- **核心原则**：在管理决策中"可解释性至少与精度同等重要"；部署 AI 不应盲目追求黑箱高准确率。

### C. 智能风控（金融 / 交易 / 保险）
- **DBDT（05）**：软决策树 + 提升 + 组合式 AUC 最大化，算法级处理样本不平衡，免重采样、契合实时风控；用 AUC/H-measure 而非 accuracy 作 KPI。
- **落地前提**：类别编码、数值归一化等**数据治理**功课做不好，再强算法也会变"邪恶大模型"。

### D. 个性化推荐与客户偏好挖掘
- **偏好构建（06）**：变分贝叶斯 + MCTS 主动提问，在最少交互内收敛用户真实偏好——推荐系统从"被动观察"升级为"主动对话式挖掘"。
- **BABOR（07）**：响应时间、注意力时长等行为信号融入贝叶斯偏好学习，挖掘客户自己都说不清的隐性需求——呼应"数据驱动精细化管理"。

## 四、可直接套用的分析框架（汇总）

1. **数据驱动多准则排序七步法**（01）：定类别体系 → 治理准则口径 → 采带标签标杆样本 → 检验单调性 → 训价值函数（正则化）→ 选分类器验证 → 解读落地。
2. **XOFM 可解释序数建模七步法**（02）：界定序数问题 → 离散化 → 设主效+交互结构 → 成对比较损失+SGD → 注入单调性先验 → 输出贡献曲线/热力图/区间 → 专家校验迭代。
3. **NN-MCDA 人类决策建模七步法**（03）：定义问题与属性 → 构造样本 → 设多项式阶数(默认3) → 联合训练 → 诊断 α 与复杂度 → 提取边际价值函数 → 落地迭代。
4. **偏好学习排序框架八步法**（04）：界定分层 → 准备软标签 → 选型价值函数 → 标定超参 → ADMM 学模型 → 新对象指派 → 类别优先级调优 → 评估复盘。
5. **DBDT 风控落地九步法**（05）：定义成本 → 数据治理 → 不平衡诊断 → 可解释基线 → 部署 DBDT → 组合式 AUC 优化 → 不平衡友好评估 → 可解释交付 → 持续监控。
6. **MCTS 偏好构建八步法**（06）：定模型与信息形式 → 设先验似然 → 变分贝叶斯更新(RT) → 量化问题价值 → MCTS 选下一题 → 收回答迭代 → 输出校验 → 可选增强。
7. **BABOR 行为偏好学习八步法**（07）：界定问题 → 采多源信号(选择/RT/注意力) → 设偏好模型 → 构建联合似然 → 贝叶斯推断(HMC) → 收敛诊断 → 输出洞察 → 分群干预。
