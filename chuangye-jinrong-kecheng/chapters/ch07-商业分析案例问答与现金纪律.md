# Chapter 7：商业分析案例问答与现金纪律（来源：33）

## Core Idea

课堂问答把商业模式从“收入增长”推进到“现金是否健康、竞争优势是否可持续”。尤其对 B2B、硬件和项目制企业，收入确认与现金回收之间可能相隔很久。

## Frameworks Introduced

- **DIO/DSO/DPO/CCC**：DIO 是库存变现所需天数，DSO 是应收回款天数，DPO 是对供应商付款天数；CCC = DIO + DSO − DPO。CCC 越大，增长越消耗现金。
- **双边飞轮**：客户、供给、数据和服务相互增强才是真飞轮；单纯广告带来的流量不是网络效应。
- **直销/分销边界**：头部和战略客户可直销，中小客户可渠道覆盖，但要清晰划分客户归属、利益和冲突。

## Case Applications

- **极视角**：标准算法、长尾场景、开放工程师生态和交付速度可能构成优势，但现金少、回款周期长和定制化依赖是高风险。
- **白鸽在线**：牌照、场景嵌入和风控数据可能形成壁垒；若收入主要来自一次性佣金和流量投放，可能出现增收不增利。
- **宇树科技**：高校/科研采购能带来收入、数据和品牌，但不能直接证明工业刚需和重复购买。

## Worked Example

如果 DSO 达到数百天，即使收入和毛利增长，也必须先问账上现金、供应商账期、库存投入和融资能力。将销售增长情景与回款延迟放入现金跑道；如果增长越快需要垫付越多，企业可能在盈利前耗尽现金。

## Anti-patterns

- 只看利润表，不看现金流和回款。
- 把牌照、曝光或客户数量直接当作护城河。
- 把中介佣金模式自动称作网络效应。

## Key Takeaways

1. 高增长企业首先要证明能活下来。
2. 护城河必须带来定价权、留存、转换成本或可复制收入。
3. 问答质量取决于能否从宏观数据追到具体客户、现金和机制。
