# Chapter 5：市场分析与波特五力（来源：24）

## Core Idea

市场分析不是背行业数字，而是用多维框架理解需求、竞争、替代、供应、渠道和制度环境，并判断某家公司在具体细分市场中是否能取得收入。

## Frameworks Introduced

- **波特五力**：现有竞争者、潜在进入者、供应商议价力、买方议价力、替代品威胁；应结合公司所处垂直领域，而非只写宏观行业。
- **三层市场**：总市场说明方向，可服务市场说明能力边界，可获取市场说明现实收入；每层要有口径和假设。
- **市场动态**：政策、技术、资本、供需、用户行为和竞争者行动会改变市场结构。

## How to Apply

1. 定义产品/解决方案、地理范围、客户类型和收费单位。
2. 识别现有解决方案与替代品，包括“不解决”的选择。
3. 分析供应商、渠道和关键资源的集中度。
4. 估算进入壁垒、转换成本、网络效应、牌照、数据与规模经济。
5. 将结论落到毛利、获客成本、定价权和可获得收入。

## Anti-patterns

- 把全国/全球总交易额直接当成公司的收入空间。
- 只说竞争激烈或蓝海，不说明竞争发生在哪个客户、渠道和利润池。
- 用一张五力图替代证据和动态判断。

## Key Takeaways

1. 市场边界必须与公司的方案和收费机制一致。
2. 五力分析的结论要能解释谁拿走利润、谁承担成本。
3. 细分越准确，估值和增长假设越可检验。
