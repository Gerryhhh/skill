# Chapter 8：投资案例与商业化验证（来源：34）

## Core Idea

投资案例讨论将 AICV/AI 视觉、白鸽在线和宇树科技放进同一套框架：先看真实客户与收入机制，再看市场、竞争、壁垒和现金，最后区分长期趋势与当前可投资回报。

## Frameworks Introduced

- **AI 视觉商业化**：标准化算法、定制项目、模型能力和软硬一体化必须分别看收入、毛利、交付周期和现金。
- **保险科技平台化**：场景保险的价值在于嵌入用户工作/消费流程；牌照、数据、风控和系统转换成本需要共同形成壁垒。
- **机器人商业化阶梯**：曝光 → 采购 → 场景使用 → 重复采购 → 工业生产力/持续利润，不能跳级。
- **长期故事—短期现金双时间框**：长期趋势可解释期权价值，但投资仍需检查未来数年的客户、收入、现金和融资需求。

## Case Applications

- **AICV/极视角**：不要用行业巨头收入证明小公司空间；要细分垂直场景、长尾客户、交付周期和标准化程度，并检查 DSO/CCC。
- **白鸽在线**：把场景保险、保险中介、数字营销分开估算；判断数据是否能反哺风控/SaaS，而不是只带来佣金。
- **宇树科技**：人形适合既有人的环境，但不等于所有场景经济；比较人工、专用机器人和人形机器人的回本、维护、安全与部署成本。

## Worked Example

若机器人售价约 16 万元，而客户用约 200 元即可获得人工搬运，机器人必须证明效率、安全、连续运行或长期总成本优势。高校采购可验证研发与教育场景，却不能自动证明工业规模化；需估算潜在客户数、已购数量、重复采购率和服务收入。

## Anti-patterns

- 把春晚/媒体曝光、融资或政府采购当作商业闭环。
- 把人形设计当作所有场景的最优形态。
- 用 AI 热潮替代 B2B/C2C 的具体需求验证。

## Key Takeaways

1. 投资人买的是可持续的客户结果，不是技术展示。
2. 机器人等硬件业务要特别审视交付、适配、维护、回款和现金。
3. 长期趋势可以提高研究优先级，但不能免除短期现金和估值纪律。
