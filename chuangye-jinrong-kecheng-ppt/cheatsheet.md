# 决策速查表

## BP 先问五个问题

| 问题 | 必须说清 |
|---|---|
| What | 做什么、解决什么问题、产生什么结果 |
| Why | 为什么现在、为什么客户需要、为什么方案成立 |
| Who | 创始团队、使用者、决策者、付款者、竞争者 |
| When | 市场窗口、产品阶段、验证节点、融资时点 |
| How | 如何创造、交付、获客、收费、留存和扩张 |

## 看到这些说法时追问

| 说法 | 追问 |
|---|---|
| “市场很大” | 公司服务哪一层？在价值链中拿多少收入？ |
| “用户很多” | 谁付款？转化/留存/复购如何证明？ |
| “技术领先” | 客户结果比替代方案好多少？部署和交付成本是多少？ |
| “平台有网络效应” | 哪些参与者互相增强？数据是否反哺？换平台是否困难？ |
| “需要 Pivot” | 转什么？为什么转？何时转？触发证据是什么？ |
| “公司已融资/上市” | 融资买来了什么？估值、稀释、控制权和现金跑道如何变化？ |

## 五层价值检查

1. **创造**：客户是否有真实痛点？
2. **潜力**：市场规模、结构、动态是否支持增长？
3. **获取**：商业模式和收费机制是否成立？
4. **执行**：团队、产品、渠道、交付是否能落地？
5. **资本**：融资时点、估值、稀释、控制权和回报是否匹配？

## 创业阶段侧重点

| 阶段 | 优先验证 |
|---|---|
| Idea/早期 | 问题、客户、方案、时机、团队和最小验证 |
| 产品验证期 | 产品—市场匹配、使用行为、付款、GTM 和转型触发点 |
| 扩张期 | 可获得收入、单位经济、渠道、网络效应、现金和组织能力 |
| 融资/上市期 | 估值、Cap Table、稀释、控制权、盈利/现金流和市场价格 |

## 课堂路演底线

不要照搬课件或招股书的结论。每个数字注明课件页/案例来源和核验状态；每个结论同时写出支持证据、关键假设和可能推翻它的条件。
