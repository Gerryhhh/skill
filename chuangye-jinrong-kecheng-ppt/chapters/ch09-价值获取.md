# Chapter 9：价值获取（课件 41）

## Core Idea

价值获取是“如何赚钱、获客和转化客户”。课件通过多种商业模式、平台案例和 GTM 图示说明：创造价值并不等于拥有收入，企业还要让客户发现、购买、使用、留存并持续为价值付费。

## Frameworks Introduced

- **商业模式分类**：广告、联盟、订阅、免费增值、交易费、佣金/平台抽成、授权、加盟、租赁、硬件销售、SaaS/LaaS、Marketplace 等。
- **GTM 客户转化链**：客户获取 → 激活/试用 → 转化 → 留存 → 复购/推荐 → 客户终身价值。
- **产品与服务收费**：直接对产品/服务收费，或通过平台、数据、广告、交易和生态获取价值。
- **渠道与客户关系**：直销、分销、平台和生态的选择影响获客成本、控制力和利润分配。

## Key Concepts

商业模式的核心不是名称，而是收费对象、收费单位、收费时点、成本承担者、交付方式和规模化条件。平台交易额、广告曝光和免费用户只有在能转化为可持续现金时才构成价值获取。

## Worked Example

对一个 B2B SaaS 项目画完整链条：谁发现产品、谁试用、谁决策采购、谁部署、谁日常使用、谁续费、谁付款；同时记录销售周期、实施成本、服务成本、留存率和回款周期。若价值主张很好但转化环节断裂，问题在价值获取而不一定在产品。

## Anti-patterns

- 用“先做大用户量、以后再变现”替代商业模式。
- 只说收入来源，不说获客、交付和留存成本。
- 把一次性交易误当作持续性收入，把流量误当作现金。

## Key Takeaways

1. 价值获取是从客户触达到现金回收的完整链条。
2. 不同商业模式需要不同的增长、估值和现金分析方法。
3. GTM 不是营销口号，而是可测量的客户行为和经济模型。
