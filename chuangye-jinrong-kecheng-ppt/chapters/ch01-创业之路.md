# Chapter 1：创业之路（课件 11）

## Core Idea

创业不是遍地黄金的标准流程，而是高投入、高不确定性、需要长期重复执行的价值创造过程。成功经验可以借鉴，但通常无法复制；创业者更应学习失败、问题定义、团队和执行。

## Frameworks Introduced

- **创业现实检验**：创业者需要面对个人资金、时间、家庭资源、融资周期、收入不确定和失败概率。
- **BP 五问**：What、Why、Who、When、How；BP 既是融资沟通工具，也是创业者检查逻辑的工具。
- **Learn / Think / Apply / Question**：学习框架、用不同角度思考、在项目中应用、在提问前检验假设。

## Mental Models

- 经验可借鉴，但路径不可复制；时机、资源、团队和环境不同。
- “有 idea”不是“有机会”；机会要经过客户、市场、方案和执行验证。
- 创业者必须把故事讲清楚，但表达不能替代真实能力。

## Worked Example

课件将创业者梦想描述为烧钱、投入和长期坚持，而不是遍地黄金。用 BP 五问把抽象梦想改成可检查的计划：做什么、为什么做、谁来做/谁买单、什么时候进入、如何创造和获取价值。

## Anti-patterns

- 只因为上市、热门或估值高就判断公司优秀。
- 把创业者辛苦本身当作投资理由。
- 认为一次成功经验可以照搬到另一家公司。

## Key Takeaways

1. 先建立问题和验证框架，再讨论融资。
2. 研究失败原因比模仿成功故事更可迁移。
3. 创业判断必须把个人投入、团队关系、时机和现金一起考虑。
