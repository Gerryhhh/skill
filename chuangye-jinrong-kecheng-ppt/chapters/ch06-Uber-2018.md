# Chapter 6：Uber 2018（课件 16）

## Core Idea

Uber 2018 课件把早期创业故事推进到融资、估值、Cap Table、股东价值和控制权分析。重点不是记住某个估值，而是理解融资如何改变公司总价值、持股比例、投票权和投资回报。

## Frameworks Introduced

- **投前/投后估值**：投资金额、投前估值和投后估值共同决定新旧股东比例。
- **Cap Table 分析**：跟踪创始人、员工、不同轮次投资者的股权变化和稀释。
- **经济权益 vs 控制权**：持股比例、财富和投票权不必相同；双重股权和协议安排可能分离三者。
- **市场价格 vs 估值**：估值是交易和预期的结果，需要结合增长、收入、风险和市场环境。

## Key Concepts

课件包含 Uber 历史融资、估值变化、融资轮次、股权结构、增长曲线、Cap Table 和不同阶段价格比较。具体数字应以课件页和原始资料核验，不应脱离时间点使用。

## Worked Example

新投资进入后，原股东的比例会下降，但如果公司总价值增长，原股东绝对财富仍可能上升。判断融资是否值得，不看“稀释是否发生”，而看融资换来的增长、资源、控制权让渡和未来回报是否匹配。

## Anti-patterns

- 认为持股比例下降必然意味着财富下降。
- 把 2018 年估值直接当作今天的内在价值。
- 只看融资金额，不看资本用途、增长质量和治理权利。

## Key Takeaways

1. 投资分析要同时看估值、股权、投票权和回报。
2. 资本结构是商业模式和执行能力之外的重要风险层。
3. 任何估值数字都必须带时间点、交易背景和数据来源。
