- 想理解某个机器学习概念/模型的定义、思想、适用边界。

- 复习西瓜书某章要点、术语、金句。

## 关键原则（来自全书）

1. **没有免费午餐（NFL）**：脱离具体问题谈"哪种学习算法最好"毫无意义，必须结合任务与数据。
2. **泛化优于记忆**：目标是泛化误差小，不是训练误差小；过拟合是核心敌人。
3. **先评估再选型**：用留出/交叉验证/Bootstrap 客观评估，用偏差-方差权衡解释现象。
4. **线性模型是基础**：多数复杂模型可视为其推广（核、基函数、神经网络）。
5. **集成通常更强**：好而不同的个体结合，往往胜过单一强模型。
6. **数据假设决定方法**：贝叶斯依赖生成假设，SVM 依赖间隔最大化，聚类依赖"相似"定义。
7. **trade-off 无处不在**：偏差↔方差、精度↔召回、探索↔利用、稀疏↔保真。
