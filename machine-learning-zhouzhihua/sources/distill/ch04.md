# 第4章 决策树

## 1. 章节核心摘要

- 决策树是一类基于树结构进行决策的机器学习方法，遵循“分而治之”（divide-and-conquer）的直观策略：从根结点（样本全集）出发，在每个结点对某一属性进行测试，按测试结果将样本划分到子结点，直至叶结点给出决策结果。其学习目标是产生一棵泛化能力强（能处理未见示例）的树。
- 决策树学习的关键是“如何选择最优划分属性”。本章给出三种经典纯度准则：信息增益（ID3）、增益率（C4.5）、基尼指数（CART）。它们都试图让分支结点所包含的样本尽可能属于同一类别（纯度越来越高）。
- 为避免过拟合，剪枝是主要手段：预剪枝在划分前估计、禁止不能提升泛化性能的划分；后剪枝先生成完整树再自底向上剪枝。一般后剪枝欠拟合风险更小、泛化往往更优，但训练开销更大。
- 现实数据常含连续属性与缺失值：连续属性用二分法（候选划分点为相邻取值中点）处理，且连续属性划分后还可作为后代结点的划分属性；缺失值通过样本权重机制在划分属性选择与样本划分两方面处理（C4.5 方案）。
- 标准决策树形成轴平行（axis-parallel）的分类边界；当真实边界复杂时需很多段划分，可改用多变量决策树（斜决策树）以线性组合测试实现“斜划分”，大幅简化模型。

## 2. 关键术语表

- 决策树（decision tree）/ 判定树 — 基于树结构进行决策的模型；有时指学习方法，有时指学得的树。
- 分而治之（divide-and-conquer）— 决策树生成的基本递归策略：不断按属性划分样本子集。
- 纯度（purity）— 结点所包含样本属于同一类别的程度；划分过程使纯度越来越高。
- 信息熵（information entropy）— 度量样本集合纯度最常用的指标；值越小纯度越高。
- 信息增益（information gain）— 用某属性划分后纯度的提升量；ID3 选择信息增益最大的属性。
- 增益率（gain ratio）— C4.5 使用的准则，用“固有值”对信息增益做除数以抑制对多值属性的偏好。
- 固有值（intrinsic value）— 属性 a 的取值数目越多（V 越大）通常越大的量，用于修正信息增益。
- 基尼指数 / 基尼值（Gini index / Gini）— CART 使用的纯度度量，反映随机抽取两样本类别不一致的概率；越小纯度越高。
- 剪枝（pruning）— 对付过拟合的主要手段，去掉一些分支降低过拟合风险。
- 预剪枝（prepruning）— 生成过程中，划分前估计若不能提升泛化性能则停止划分并标记为叶结点。
- 后剪枝（postpruning）— 先生成完整树，再自底向上考察，若用叶结点替换子树能提升泛化则剪枝。
- 决策树桩（decision stump）— 仅有一层划分（一个划分结点）的决策树，是预剪枝常见结果。
- 连续值处理 / 二分法（bi-partition）— 对连续属性取相邻取值中点为候选划分点，进行二分。
- 缺失值处理 — 用样本权重机制处理属性值缺失下的划分选择与被划分问题。
- 轴平行（axis-parallel）— 标准决策树分类边界由若干与坐标轴平行的分段组成。
- 单变量决策树（univariate decision tree）— 每个非叶结点仅测试单个属性的传统决策树。
- 多变量决策树（multivariate decision tree）/ 斜决策树（oblique decision tree）— 非叶结点对属性线性组合进行测试，实现“斜划分”。
- 增量学习（incremental learning）— 接收新样本后仅局部调整模型而不重训全部；ID4/ID5R/ITI 等为代表。

## 3. 关键模型与算法

### 决策树基本生成算法（分而治之）
- 核心思想：递归地选择最优划分属性，把结点样本集按属性测试划分到子结点，直到满足递归返回条件。
- 数学形式/公式：算法以属性集 A 与训练集 D 为输入，对每个结点执行：若样本全属同一类则标记为叶（返回情形1）；若 A 为空或所有样本在所有属性取值相同则标记为叶、类别取该结点样本最多类（返回情形2）；若样本集为空则标记为叶、类别取父结点样本最多类（返回情形3）；否则选最优属性 a*，对每个取值分支递归。注意情形2用当前结点后验分布，情形3用父结点先验分布。
- 适用场景：分类与回归任务的白盒模型，需要可解释的规则。
- 慎用情形/局限：若不剪枝易过拟合；属性选择准则不同会影响树尺寸与泛化；分支过多时预测时间开销大。

### 信息增益（ID3 准则）
- 核心思想：用属性划分后信息熵的加权平均下降量衡量“纯度提升”，选信息增益最大的属性。
- 数学形式/公式：数据集 D 的信息熵 Ent(D)=−Σₖ pₖ·log₂pₖ（pₖ 为第 k 类样本比例；约定 p=0 时 p log₂p=0；最小值为0、最大值为 log₂|y|）。用属性 a（V 个取值）划分的信息增益 Gain(D,a)=Ent(D)−Σᵥ(|Dᵛ|/|D|)·Ent(Dᵛ)，其中 Dᵛ 为在 a 上取值 aᵛ 的子集，权重为样本数占比。
- 适用场景：特征取值数目不多、希望树偏向信息增益大的属性时。
- 慎用情形/局限：对可取数目较多的属性有偏好（如“编号”会得极大信息增益却无泛化能力），故 C4.5 改用增益率。

### 增益率（C4.5 准则）
- 核心思想：用属性的“固有值”对信息增益做归一，减弱对多值属性的偏好；但增益率又偏好取值少的属性，故 C4.5 先筛选信息增益高于平均者，再从中选增益率最高。
- 数学形式/公式：增益率 Gain_ratio(D,a)=Gain(D,a)/IV(a)；固有值 IV(a)=−Σᵥ(|Dᵛ|/|D|)·log₂(|Dᵛ|/|D|)，取值数目 V 越大通常 IV(a) 越大（例：触感 V=2 时 0.874，色泽 V=3 时 1.580，编号 V=17 时 4.088）。
- 适用场景：属性取值数目差异大、需避免被多值属性误导时（C4.5 默认准则）。
- 慎用情形/局限：单独使用会偏好取值少的属性，需配合“信息增益高于平均”的启发式筛选。

### 基尼指数（CART 准则）
- 核心思想：用基尼值度量纯度，选划分后基尼指数最小的属性；CART 可用于分类与回归。
- 数学形式/公式：数据集 D 的基尼值 Gini(D)=1−Σₖ pₖ²，反映随机抽取两样本类别不一致的概率，越小纯度越高。属性 a 的基尼指数 Gini_index(D,a)=Σᵥ(|Dᵛ|/|D|)·Gini(Dᵛ)；在候选集 A 中选使该值最小的属性。
- 适用场景：需要同时支持分类与回归的统一决策树算法（CART）；实证中信息增益与基尼指数仅在约 2% 情况下结果不同。
- 慎用情形/局限：与信息增益、增益率一样只是启发式准则，对泛化性能影响有限，真正影响大的是剪枝。

### 剪枝（预剪枝 / 后剪枝）
- 核心思想：主动去掉分支以降低过拟合风险；用留出法划分验证集评估泛化性能是否提升。
- 数学形式/公式：以验证集精度为评估。预剪枝：划分前若验证精度不提升则停止划分（得“决策树桩”）。后剪枝：完整树生成后自底向上，若把某子树替换为叶结点（类别取所含训练样本最多类）能提升验证精度则剪枝。
- 适用场景：任何已生成、可能过拟合的决策树。
- 慎用情形/局限：预剪枝基于贪心、可能禁止后续能显著提升性能的分支（欠拟合风险），但省时；后剪枝保留更多分支、泛化常更优但训练时间开销大。

### 连续值与缺失值处理（C4.5 机制）
- 核心思想：连续属性用二分法找最优划分点；缺失值用样本权重同时解决“如何选属性”与“如何划分样本”。
- 数学形式/公式：
  - 连续：排序后候选划分点集为相邻取值中点 T_a={ (aⁱ+aⁱ⁺¹)/2 }，选使二分后信息增益最大的点；与离散不同，连续属性划分后仍可作后代结点划分属性。
  - 缺失：为样本赋权重 w_x（根结点初始为1），定义无缺失子集占比 ρ、各类占比与取值占比；将信息增益推广为带 ρ 与权重的形式，仅用无缺失样本判断属性优劣；样本在某属性值缺失时，按各取值分支的占比概率同时划入所有子结点（权重相应乘占比）。
- 适用场景：含连续属性或缺失值的真实数据（如医疗数据）。
- 慎用情形/局限：连续属性的候选点随样本量线性增长；缺失值处理下同一样本以不同概率进入多分支，增加计算复杂度。

### 多变量决策树（斜决策树）
- 核心思想：非叶结点不再测试单个属性，而是对属性的线性组合进行测试（形如 w₁a₁+…+w_d a_d ≤ t 的线性分类器），实现“斜划分”，简化复杂边界的模型。
- 数学形式/公式：每个非叶结点学得一组权重 wᵢ 与阈值 t（在结点所含样本与属性上学得），即一个线性分类器；由此突破轴平行边界限制。
- 适用场景：真实分类边界复杂、用轴平行分段需要极多划分时。
- 慎用情形/局限：可解释性下降（每段不再直接对应单一属性取值）；代表性算法 OC1 先贪心求各属性权值再做随机扰动，或引入最小二乘（Brodley & Utgoff）。

## 4. 应用与决策框架

选择划分准则与剪枝方式的决策步骤：

1. 确定任务与可解释性需求：需要清晰规则、白盒模型 → 决策树（而非黑盒如神经网络）。
2. 选择划分准则：
   - 属性取值数目较均衡、追求简洁 → 信息增益（ID3）。
   - 属性取值数目差异大、怕被多值属性误导 → 增益率（C4.5，先筛信息增益高于平均）。
   - 需要统一支持分类与回归 → 基尼指数（CART）。
3. 处理数据特性：
   - 有连续属性 → 二分法找最优划分点。
   - 有缺失值 → 采用样本权重机制（C4.5 方案）。
4. 设定防过拟合策略：
   - 资源紧张、可接受略欠拟合 → 预剪枝。
   - 追求更优泛化、可接受更大训练开销 → 后剪枝（通常更优）。
5. 边界复杂度：若分类边界明显非轴平行且传统树过深过慢 → 考虑多变量（斜）决策树。
6. 对照表：

| 需求 | 准则/策略 | 代表算法 |
|---|---|---|
| 简洁、取值均衡 | 信息增益 | ID3 |
| 抗多值偏好 | 增益率 | C4.5 |
| 分类+回归 | 基尼指数 | CART |
| 省时防过拟合 | 预剪枝 | — |
| 更优泛化 | 后剪枝 | — |
| 复杂斜边界 | 多变量/斜划分 | OC1 等 |

## 5. 典型案例/例题要点

- 西瓜数据集2.0（17样例）：根结点信息熵 Ent(D)=−(8/17 log₂ 8/17 + 9/17 log₂ 9/17)≈0.998；各属性信息增益：纹理0.381（最大，选为根划分）、脐部0.289、触蒂0.143、敲声0.141、色泽0.109、触感0.006。基于“纹理”划分后递归，最终得图4.4决策树。
- 信息增益偏好陷阱：把“编号”作候选属性时信息增益约0.998，远大于其他，但产生17个单样本分支、无泛化能力——说明不能把标识列当划分属性。
- 预剪枝实例（留出法划分训练/验证集）：用“脐部”划分后验证精度由42.9%升至71.4%故保留；但结点②用“色泽”划分会使精度降至57.1%被禁止；结点③“根蒂”划分精度不提升亦被禁止；最终仅一层划分（决策树桩），验证精度71.4%。
- 后剪枝实例：完整树验证精度42.9%；剪除结点⑥→57.1%，剪除结点②→71.4%均保留；结点⑤、③、①剪枝未提升故保留；最终后剪枝树验证精度71.4%，但保留更多分支、欠拟合风险更小。
- 连续属性（西瓜数据集3.0 加入密度、含糖率）：密度候选划分点16个，信息增益0.262对应划分点0.381；含糖率信息增益0.349对应0.126；根仍为“纹理”。连续属性划分后还可再作为后代结点划分属性。
- 缺失值（西瓜数据集2.0a）：仅4样本无缺失时若弃用浪费大；用权重机制得信息增益：纹理0.424（最大，作根划分），色泽0.252、脐部0.289等；缺失样本（如编号8）按占比同时进入三个分支（权重7/15、5/15、3/15）。
- 多变量决策树（西瓜数据集3.0a）：标准树产生轴平行边界、需大量段；斜决策树以线性组合测试，分类边界大幅简化。

## 6. 金句与重要结论

- 决策树“分类边界的特点是轴平行，即由若干个与坐标轴平行的分段组成”。
- “信息增益准则对可取值数目较多的属性有所偏好”，增益率则“对可取值数目较少的属性有所偏好”。
- C4.5 并不直接选增益率最大者，而是“先从候选划分属性中找出信息增益高于平均水平的属性，再从中选择增益率最高的”。
- 基尼值“反映了从数据集D中随机抽取两个样本，其类别标记不一致的概率；Gini(D)越小，纯度越高”。
- 预剪枝“基于贪心本质禁止这些分支展开，给预剪枝决策树带来了欠拟合的风险”。
- 后剪枝决策树“通常比预剪枝决策树保留了更多的分支……泛化性能往往优于预剪枝决策树”，但训练时间开销大得多。
- 与离散属性不同，连续属性作当前结点划分属性后“还可作为其后代结点的划分属性”。
- 各种特征选择方法本质上均可用于决策树划分选择；不同准则“仅对决策树的尺寸有较大影响，但对泛化性能的影响很有限”，而剪枝对泛化影响显著（噪声数据下剪枝可提升约25%）。
- 多变量决策树亦称“斜决策树”；传统 vs 多变量的区别在于非叶结点测试单属性还是属性线性组合。

## 7. 与其他章节的关联

- 第2章：经验误差与过拟合（2.1）是剪枝的理论依据；性能评估（留出法/2.2）用于判断剪枝是否提升泛化。
- 第3章：多变量决策树的每个非叶结点是形如线性组合测试的线性分类器，与线性模型（第3章）直接相通。
- 第5章：感知机树（Perceptron tree）在叶结点嵌入感知机、或在叶结点嵌多层神经网络，结合决策树与神经网络；增量学习与第5章神经网络训练思路呼应。
- 第8章：集成学习（如随机森林、AdaBoost）常以决策树为基学习器。
- 第11章：本质上各种特征选择方法均可用于决策树划分属性选择（特征选择与稀疏学习）。
- 多变量决策树、斜划分与线性模型联系紧密；决策树可转化为符号规则（C4.5Rule），与规则学习衔接。
