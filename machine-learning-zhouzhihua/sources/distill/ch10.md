# 第10章 降维与度量学习

## 1. 章节核心摘要
- 本章处理"维数灾难"：高维下样本稀疏、距离计算困难，所需样本数随维数指数增长（d=20 时密采样需约 10^60 个样本，现实不可达）。缓解途径主要有二——降维（本章主线）与特征选择（第11章）。
- 降维（维数约简）通过数学变换把原始高维属性空间映射到低维子空间，使样本密度提高、距离计算变易；其理论依据是：与学习任务密切相关的往往是高维空间中的一个低维"嵌入"（embedding）。
- k近邻（kNN）是"懒惰学习"代表，没有显式训练过程；最近邻分类器泛化错误率不超过贝叶斯最优分类器的两倍，但性能高度依赖"距离计算恰当"与"密采样"假设。
- 线性降维统一形式为 Z=WᵀX（W 为变换矩阵）。PCA 是最常用的无监督线性降维，源自"最近重构性"与"最大可分性"两种等价推导；核化（KPCA）处理非线性。
- 流形学习（Isomap、LLE）借"局部与欧氏空间同胚"的流形概念做非线性降维；度量学习则干脆直接学习一个合适的距离度量矩阵 M，并可衍生降维矩阵。

## 2. 关键术语表
- k近邻（kNN）— 基于距离找 k 个最近训练样本、用投票/平均预测的监督学习方法。
- 懒惰学习（lazy learning）/ 急切学习（eager learning）— kNN 仅保存样本、测试时才计算（前者）；训练阶段即学习模型（后者）。
- 密采样（dense sample）— 任意测试样本附近任意小范围内都能找到训练样本，是 kNN 良好性能的假设前提。
- 维数灾难（curse of dimensionality）— 高维下样本稀疏、距离计算困难的现象。
- 降维 / 维数约简（dimension reduction）— 将高维空间经变换映射到低维子空间。
- 嵌入（embedding）— 高维空间中与学习任务相关的低维分布结构。
- 子空间（subspace）— 降维后样本所处的低维空间。
- 多维缩放（MDS）— 保持原始空间样本距离的低维表示方法。
- 线性降维 — 符合 Z=WᵀX 的降维，W 为变换矩阵。
- 主成分分析（PCA）— 最常用的无监督线性降维，取方差最大方向。
- 最近重构性 / 最大可分性 — PCA 的两种等价优化视角（投影重构误差最小 / 投影后方差最大）。
- 核化（kernelized）— 借核技巧将线性降维推广到非线性（如 KPCA）。
- 本真（intrinsic）低维空间 — 样本最初被采样的低维空间（区别于降维后的空间）。
- 流形学习（manifold learning）— 借拓扑流形概念、保持局部结构做非线性降维。
- 等度量映射（Isomap）— 用近邻图上的最短路径逼近流形测地线距离再做 MDS。
- 局部线性嵌入（LLE）— 保持邻域内样本线性重构关系的非线性降维。
- 测地线距离（geodesic）— 流形表面上两点间的最短路径距离（本真距离）。
- 度量学习（metric learning）/ 距离度量学习 — 直接从数据学习合适的距离度量。
- 马氏距离（Mahalanobis distance）— 以半正定对称矩阵 M（度量矩阵）参数化的距离。
- 近邻成分分析（NCA）— 以最大化近邻分类器留一法正确率为目标的度量学习。
- 必连（must-link）/ 勿连（cannot-link）— 度量学习中"样本应相似/不相似"的约束。

## 3. 关键模型与算法

### k近邻学习（kNN）
- 核心思想：给定测试样本，按距离找训练集中最近的 k 个邻居，分类用投票法（或距离加权投票）、回归用平均法（或加权平均）。
- 数学形式：最近邻（1NN）分类器出错概率 = P(x 与最近邻 z 类别不同)；在密采样假设下，其泛化错误率 err ≤ 2·err*（err* 为贝叶斯最优分类器错误率）。
- 适用场景：小样本、决策边界复杂、无需显式训练的场景；是懒惰学习典型。
- 慎用情形：性能强烈依赖距离计算的恰当性与 k 的取值；高维下因维数灾难而失效；测试时需扫描全训练集，计算开销随样本量增长。

### 多维缩放（MDS）
- 核心思想：保持原始空间样本间距离，求低维表示 Z，使 ‖z_i−z_j‖ = dist_ij。
- 数学形式：由距离矩阵 D 求内积矩阵 B=ZᵀZ，B 中心化后各行、列和为零；对 B 做特征值分解 B=VΛVᵀ，取前 d' 个最大特征值及其特征向量得 Z = Λ*^{1/2} V*ᵀ（严格保持取全部非零特征值；近似降维取 d'≪d 个最大特征值）。
- 适用场景：需保持样本间距离结构的可视化或作为其他降维的基础（Isomap 用之）。
- 慎用情形：严格 MDS 要求距离精确保持；近一步常只需"尽可能接近"而非相等。

### 主成分分析（PCA）
- 核心思想：对中心化样本，找一组标准正交基，将维度降至 d' 时使"投影重构误差最小（最近重构性）"或"投影后方差最大（最大可分性）"，二者等价。
- 数学形式：对协方差矩阵 XXᵀ 做特征值分解，特征值 λ_1≥…≥λ_d，取前 d' 个对应特征向量构成 W*=(w_1,…,w_d')，低维表示 Z=W*ᵀX；d' 可按累计方差占比（如阈值 95%）或交叉验证选定；新样本用保存的 W* 与均值向量投影。
- 适用场景：无监督线性降维首选，去除噪声、提高采样密度、便于可视化。
- 慎用情形：仅捕捉线性结构；舍弃最小特征值对应方向虽能去噪，但也会损失信息；对非线性流形需核化或流形学习。

### 核主成分分析（KPCA）
- 核心思想：将样本经核映射 φ 投射到高维特征空间，再在该空间做 PCA；用核技巧避免显式写出 φ。
- 数学形式：引入核函数 κ(x_i,x_j)=φ(x_i)ᵀφ(x_j)，对应核矩阵 K；在特征空间中对 K 做特征值分解，取最大 d' 个特征值对应特征向量；新样本第 j 维坐标需对所有训练样本求和（计算开销较大）。
- 适用场景：低维结构呈非线性、线性 PCA 会丢失本真结构（如 S 形曲面嵌入三维）的数据。
- 慎用情形：新样本投影需遍历全部训练样本，计算量大；核函数与参数需选择。

### 等度量映射（Isomap）
- 核心思想：流形上两点本真距离是测地线距离，高维直线距离有误导性。利用流形局部同胚欧氏空间，建近邻连接图，用 Dijkstra/Floyd 算法算图上最短路径逼近测地线，再对测地距离矩阵做 MDS。
- 数学形式：近邻图可用 k 近邻图或 ε 近邻图构建；图上最短路径距离近似测地线；后续同 MDS 求低维坐标。
- 适用场景：数据本真位于低维流形、且流形上"沿曲面"的距离才有意义的情况。
- 慎用情形：近邻图构建不当会出现"短路"（远点误连）或"断路"（区域不连通）；新样本需另训回归器映射，仅为权宜之计；需密采样。

### 局部线性嵌入（LLE）
- 核心思想：保持邻域内样本的线性重构关系。先为每个样本找邻域并用线性组合系数 w_i 重构它，再在低维空间保持 w_i 不变求坐标 z_i。
- 数学形式：重构权重 w_i 由最小化 Σ_i ‖x_i − Σ_{j∈Q_i} w_{ij}x_j‖² 求得（有闭式解，依赖 C_{jk}=(x_i−x_j)ᵀ(x_i−x_k)）；低维坐标由最小化 Σ_i ‖z_i − Σ_{j∈Q_i} w_{ij}z_j‖² 求得，等价于对 M=(I−W)ᵀ(I−W) 取最小 d' 个特征值对应特征向量（组成 Zᵀ）。
- 适用场景：保持局部线性结构的非线性降维与可视化。
- 慎用情形：重构关系仅为局部，全局结构靠拼合；同样依赖密采样；新样本映射无解析直接解。

### 度量学习（马氏距离与 NCA）
- 核心思想：每个空间对应一个距离度量，寻找合适空间等价于学习合适距离。将平方欧氏距离推广到带权重 W=diag(w)（加权距离），再推广到半正定对称度量矩阵 M，得到马氏距离；M 可通过优化近邻分类器性能（如 NCA 最大化留一法正确率）或满足必连/勿连约束来学习。
- 数学形式：
  - 马氏距离 dist²(x_i,x_j) = (x_i−x_j)ᵀ M (x_i−x_j)，M 半正定对称（可写为 M=PPᵀ）；
  - NCA：样本 x_j 影响 x_i 的概率 p_{ij} ∝ exp(−‖x_i−x_j‖²_M)（i≠j），优化 Σ_i P(y_i=正确类 | x_i) 最大化；
  - 必连/勿连约束下的凸优化：min Σ_{(i,j)∈ℳ} ‖x_i−x_j‖²_M，s.t. Σ_{(i,j)∈𝒞} ‖x_i−x_j‖²_M ≥ 1 且 M⪰0。
- 适用场景：已知相似/不相似先验、或希望为特定学习器"量身定做"距离时；若 M 低秩，可从其分解得到降维矩阵 P（rank(M)<d）。
- 慎用情形：M 学习需设定目标与约束；监督目标（如错误率）或领域约束（必连/勿连）的质量决定效果；全局度量学习对所有样本同时作用。

## 4. 应用与决策框架
选择降维/度量方法的决策思路：
1. 任务是否依赖监督信息且目标是"学得距离"？
   - 是 → 度量学习（NCA 提近邻性能；必连/勿连约束法用领域知识）。
   - 否 → 进入降维。
2. 数据的主要结构是线性还是非线性？
   - 线性/近似线性、追求简单快速 → PCA（无监督线性降维首选）。
   - 非线性、本真流形结构 → 核化方法（KPCA）或流形学习（Isomap / LLE）。
3. 降维目标侧重什么？
   - 保持全局距离结构 → MDS / Isomap。
   - 保持局部邻域结构 → LLE（及 LE、LPP 等）。
4. 是否需可视化或先定 d'？
   - 降维到 2/3 维便于可视化；d' 可交叉验证或按累计方差阈值（如 95%）选定。
5. 评估方式：比较降维前后学习器性能，性能提升则降维有效；2/3 维时直接可视化判断。

## 5. 典型案例/例题要点
- 最近邻错误率证明思路（10.2）：在密采样假设下，测试样本 x 总能在其任意近邻找到训练样本 z，最近邻分类器出错概率 = x 与 z 类标不同概率；推导得 err ≤ 2·err*，即"简单的最近邻分类器泛化错误率不超过贝叶斯最优的两倍"。
- 维数灾难数值例：单属性 δ=0.001 需约 1000 样本密采样；20 维则需 (10³)²⁰=10⁶⁰ 个样本，现实不可达——说明降维必要。
- MDS 推导：由距离矩阵 D 经中心化求内积矩阵 B，再特征值分解取前 d' 个最大特征值对应向量得低维坐标。
- PCA 双视角等价：最近重构性导出最小化 Σ‖x_i−x̂_i‖²，最大可分性导出最大化投影方差 Σ Wᵀx_ixᵀW，二者等价，解为 XXᵀ 前 d' 个最大特征值对应特征向量。
- KPCA 新样本坐标需对全部训练样本求和（式10.25），揭示其计算开销大。
- Isomap 近邻图"短路/断路"问题：近邻范围过大误连远点（短路），过小致区域不连通（断路），都会误导最短路径计算。

## 6. 金句与重要结论
- 高维下"样本稀疏、距离计算困难"即维数灾难；降维的根本依据是"与学习相关的仅是某个低维嵌入"。
- 懒惰学习（kNN）训练时间开销为零，收到测试样本才处理；与之相对的是急切学习。
- 最近邻分类器虽简单，泛化错误率不超过贝叶斯最优分类器的两倍。
- PCA 的"最近重构性"与"最大可分性"两种推导完全等价。
- 降维舍弃最小特征值对应方向虽损失信息，但能提高采样密度、并常起到去噪作用。
- 线性降维都符合 Z=WᵀX，区别仅在于对低维子空间性质的不同约束（即对 W 的不同要求）。
- 流形学习依赖"局部与欧氏空间同胚"，但同样需要密采样，故实践中降维性能常不如预期；不过"邻域保持"思想深刻影响了半监督学习（流形假设、流形正则化）。
- 度量学习学得半正定对称矩阵 M；若 M 低秩，可衍生降维矩阵，将"学距离"与"降维"统一。
