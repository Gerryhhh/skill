# 第14章 概率图模型

## 1. 章节核心摘要

概率图模型是用图表达变量相关关系的概率模型：以结点表示随机变量、边表示变量间概率相关关系。根据边是否有向，分为有向图模型（贝叶斯网）与无向图模型（马尔可夫网）。本章先从时序数据的最简单动态贝叶斯网——隐马尔可夫模型（HMM）入手，再讲无向图代表马尔可夫随机场（MRF）与判别式模型条件随机场（CRF），然后系统梳理学习与推断方法（变量消去、信念传播、MCMC、变分推断），最后介绍生成式话题模型 LDA。

主线是：问题归结为"推断"——由可观测变量推测未知变量（含隐变量）的条件分布；为高效推断与学习，需要图结构来表达条件独立性，把联合分布分解为因子乘积，从而把指数级的计算降到局部可解。

最重要结论：有显式因果用贝叶斯网、难获因果但有关联用马尔可夫网；精确推断（变量消去、信念传播）复杂度随极大团规模指数增长，故现实多用近似推断（MCMC 采样、变分推断）；LDA 等话题模型把文本等离散数据建模为"词—话题—文档"的生成过程。

## 2. 关键术语表

- **概率模型（probabilistic model）**：把学习任务归结为计算变量概率分布的框架。
- **推断（inference）**：由可观测变量推测未知变量（含隐变量）的条件分布。
- **生成式模型**：对联合分布 P(Y,O,R) 建模。
- **判别式模型**：对条件分布 P(Y,R|O) 建模。
- **概率图模型（probabilistic graphical model）**：用图表达变量相关关系；分有向（贝叶斯网）与无向（马尔可夫网）。
- **隐马尔可夫模型（HMM）**：结构最简单的动态贝叶斯网，有向图，用于时序数据；含隐藏状态变量与观测变量。
- **状态变量 y_t / 观测变量 x_t**：HMM 中第 t 时刻的隐状态与可观测值。
- **马尔可夫链（Markov chain）**：下一时刻状态仅由当前状态决定，与以往无关。
- **状态转移概率矩阵 A**：a_ij 表示从状态 s_i 转移到 s_j 的概率。
- **输出观测概率矩阵 B**：b_ij 表示在状态 s_i 下观测到 o_j 的概率。
- **初始状态概率 π**：初始时刻各状态出现概率。
- **马尔可夫随机场（MRF）**：典型无向图模型；用势函数（因子）定义联合分布。
- **团（clique）/ 极大团（maximal clique）**：任意两结点有边相连的结点子集；极大团是不能再被包含的团。
- **势函数（potential function）/ 因子**：定义在团上的非负实函数，刻画变量间相关关系。
- **规范化因子 Z**：使联合分布为合法概率的归一化常数（常难精确计算）。
- **全局/局部/成对马尔可夫性**：给定分离集/邻接变量/其他所有变量时条件独立的三条性质。
- **马尔可夫毯（Markov blanket）**：某变量的所有邻接变量集合，给定它该变量条件独立于其余变量。
- **条件随机场（CRF）**：判别式无向图模型，对条件分布 P(y|x) 建模；链式 CRF 最常用。
- **特征函数（转移/状态）**：CRF 中刻画相邻标记关系、观测对标记影响的实值函数。
- **变量消去（variable elimination）**：精确推断，利用条件独立性按序求和消去变量（动态规划）。
- **信念传播（Belief Propagation）/ Sum-Product**：把变量消去看作消息传递，避免重复计算；无环图两趟完成。
- **近似推断**：采样（MCMC）与确定性近似（变分推断）两类。
- **MCMC（马尔可夫链蒙特卡罗）**：构造平稳分布为目标分布的马尔可夫链产生样本。
- **Metropolis-Hastings（MH）算法**：基于拒绝采样逼近平稳分布的 MCMC。
- **吉布斯采样（Gibbs sampling）**：MH 特例，逐变量按条件概率采样。
- **变分推断（variational inference）**：用简单分布逼近复杂后验，常结合平均场（mean field）假设。
- **盘式记法（plate notation）**：用方框表示由相同机制独立生成的重复变量，使图简洁。
- **话题模型（topic model）**：生成式有向图模型，处理离散数据（文本等）；代表为 LDA。
- **LDA（隐狄利克雷分配）**：每篇文档含多个话题、每个词来自某话题的词频分布。
- **词 / 文档 / 话题 / 词袋（bag-of-words）**：话题模型的基本概念。

## 3. 关键模型与算法

### 隐马尔可夫模型 HMM（14.1）

- **核心思想**：用两个变量组（隐藏状态序列 y、观测序列 x）建模时序数据；状态仅依赖前一状态（马尔可夫链），观测仅依赖当前状态。联合分布可分解为初始概率×转移概率×观测概率的乘积。
- **数学形式/公式**：指定状态空间 Y={s_1..s_N}、观测空间 X={o_1..o_M} 与三组参数 λ=[A,B,π]。联合分布 P(y,x)=π_{y1}·Π_t P(x_t|y_t)·Π_t P(y_t|y_{t−1})（以转移与输出概率表示）。产生观测序列：按 π 选初态 → 按 B 出观测 → 按 A 转移 → 重复。三个基本问题：① 计算 P(x|λ)（评估，前向算法）；② 求最优状态序列（解码，Viterbi）；③ 训练参数 λ 使 P(x|λ) 最大（Baum-Welch/EM）。
- **适用场景**：语音识别、自然语言处理等时序数据；观测为离散（本书讨论）或连续。
- **慎用情形/局限**：强马尔可夫与观测独立性假设；状态数/阶数需事先设定；仅建模一阶依赖。

### 马尔可夫随机场 MRF（14.2）

- **核心思想**：无向图模型，联合分布基于极大团的势函数乘积定义；用"分离"概念得到条件独立性。
- **数学形式/公式**：联合分布 P(x)= (1/Z) Π_{Q∈C*} ψ_Q(x_Q)，Z=Σ_x Π ψ_Q 为规范化因子；势函数常取指数形式 ψ_Q=exp(−H_Q(x_Q))，H_Q 为实值（含单结点项 β_v 与成对项 α_uv）。条件独立性由全局马尔可夫性（分离集）推出，等价于局部/成对马尔可夫性。
- **适用场景**：变量间有关联但难获显式因果时；图像、空间数据等。
- **慎用情形/局限**：Z 精确计算困难；势函数设计依赖领域知识。

### 条件随机场 CRF（14.3）

- **核心思想**：判别式无向图模型，直接对条件分布 P(y|x) 建模（可看作给定观测的 MRF 或对率回归扩展）；链式 CRF 用于序列标注。
- **数学形式/公式**：链式 CRF 条件概率 P(y|x)= (1/Z) exp( Σ_j λ_j t_j(y_{i+1},y_i,x,i) + Σ_k μ_k s_k(y_i,x,i) )，其中 t_j 为转移特征函数（相邻标记关系及观测影响）、s_k 为状态特征函数（观测对标记影响），Z 为规范化因子。图 G 中每个标记变量满足马尔可夫性即构成 CRF。
- **适用场景**：词性标注、语法分析等序列/结构化预测（比 HMM 更灵活，可包含任意观测特征）。
- **慎用情形/局限**：特征函数与参数需设计；训练计算量较大；Z 同样需处理归一化。

### 变量消去与信念传播（14.4）

- **核心思想**：精确推断利用条件独立性削减计算量。变量消去按序求和消去无关变量（动态规划）；信念传播把求和看作消息传递，避免重复计算多个边际分布。
- **数学形式/公式**：变量消去通过对联合分布交替求积与求和（如 m_ij(x_j)=Σ_{x_i} ...）得到边际 P(x_5)。信念传播中结点仅在收齐邻接消息后才发消息，结点边际分布正比于所收消息乘积；无环图经"叶→根、根→叶"两趟完成。
- **适用场景**：中小规模、无环或近无环图上的精确推断。
- **慎用情形/局限**：变量消去对多边际分布有冗余；信念传播在有环图上需改为 Loopy BP，理论性质不完全清楚；复杂度随极大团规模指数增长。

### MCMC 采样（14.5.1）

- **核心思想**：近似推断——构造平稳分布恰为目标分布的马尔可夫链，收敛后产出的样本近似服从目标分布，用样本均值估计期望。判别平稳用细致平稳条件 P(x)T(x'|x)=P(x')T(x|x')。
- **数学形式/公式**：目标期望 E_{P}[f(x)]≈(1/N)Σ f(x_n)。MH 算法按候选转移 Q(x*|x_{t−1})，以接受率 A(x*|x_{t−1})=min(1, [P(x*)Q(x_{t−1}|x*)]/[P(x_{t−1})Q(x*|x_{t−1})] ) 决定是否接受（拒绝采样）。吉布斯采样为 MH 特例：逐变量按条件分布 P(x_i|x_{−i}) 采样（无拒绝），更简洁。
- **适用场景**：目标分布复杂、难以直接积分时；贝叶斯推断常用。
- **慎用情形/局限**：需足够长 burn-in（丢弃初段样本）；收敛诊断困难；高维下混合可能慢。

### 变分推断（14.5.2）

- **核心思想**：用已知简单分布逼近复杂后验，限制近似分布类型得到确定性近似解。结合盘式记法与平均场假设。
- **数学形式/公式**：对数似然下界 ELBO = E_q[ln p(x,z)] − KL(q(z)‖p(z|x))；平均场假设 q(z)=Π_i q_i(z_i)，在固定 q_{i≠j} 下最大化 ELBO 得最优 q*_j ∝ exp( E_{i≠j}[ln p(x,z)] )。与 EM 结合：E 步推断隐变量分布、M 步最大化参数。
- **适用场景**：E 步后验推断困难时（如 LDA），求近似后验与参数。
- **慎用情形/局限**：结果依赖隐变量拆解方式与子集分布假设（如指数族）；假设不当则效率低、效果差。

### 话题模型 LDA（14.6）

- **核心思想**：生成式有向图模型，每篇文档以一定比例包含 K 个话题，每个词由某话题的词频分布生成；词袋表示。
- **数学形式/公式**：文档生成：① 按狄利克雷(α) 采话题分布 Θ_t；② 对每个词：按 Θ_t 指派话题 z_{t,n}，再按该话题词频 β_k 采词。联合分布 p(W,Θ,Z,β|α,η)=Π_t p(Θ_t|α) Π_n p(z_{t,n}|Θ_t) p(w_{t,n}|z_{t,n},β) Π_k p(β_k|η)。参数 α,η 用极大似然（变分近似）估计；已知参数后推断话题结构用吉布斯采样或变分法。
- **适用场景**：文本集合、词袋表示的离散数据（亦可用于图像小块等）。
- **慎用情形/局限**：话题数 K 需事先指定（可用非参数化 HDP 等改进）；变分/吉布斯推断均为近似。

## 4. 应用与决策框架

按任务选择概率图模型的决策步骤：

1. **变量间关系是因果还是仅相关**？
   - 有显式因果、需建模生成过程 → 有向图（贝叶斯网 / HMM / 话题模型）。
   - 只有关联、难获因果 → 无向图（MRF / CRF）。
2. **是否时序/序列数据**？
   - 是 → HMM（生成式）或 链式 CRF（判别式，可含丰富观测特征）。
3. **建模目标是联合分布还是条件分布**？
   - 联合（生成式，如分类+生成）→ HMM/MRF/贝叶斯网。
   - 条件（判别式，序列标注）→ CRF（优于 HMM，避免独立观测假设）。
4. **推断/学习算法选择**：
   - 小图、需精确 → 变量消去 / 信念传播。
   - 大模型、近似可接受 → MCMC（MH/吉布斯）或 变分推断（平均场）。
5. **文本/离散数据建模** → 话题模型 LDA（生成式）。

**模型对照表**

| 任务特征 | 推荐模型 | 类型 |
|---|---|---|
| 时序、生成式 | HMM | 有向/动态贝叶斯网 |
| 序列标注、判别式 | 链式 CRF | 无向/判别式 |
| 关联无向、图像 | MRF | 无向/生成式 |
| 文本主题 | LDA | 有向/生成式 |
| 需条件分布 | CRF | 判别式 |

## 5. 典型案例/例题要点

- **HMM 三个基本问题**：评估 P(x|λ)（前向算法）、解码最优状态序列（Viterbi）、训练 λ（Baum-Welch/EM）——均因式(14.1) 的条件独立性可高效求解。
- **MRF 图14.2 实例**：团如 {x1,x2}、{x2,x5,x6}（极大团）；{x1,x2,x3} 不构成团（缺 x2–x3 边）；联合分布可仅基于极大团势函数定义，势函数 ψ256 体现 x2,x5,x6 相关，免为子团另建势函数。
- **全局马尔可夫性验证（图14.4）**：A、B 被 C 分离时，由联合分布与条件概率定义可推出 P(x_A|x_C,x_B)=P(x_A|x_C)，即 x_A⊥x_B|x_C。
- **势函数偏好示例**：二值变量下若 ψ(x_A,x_C,x_B) 在 x_A=x_C 且 x_B≠x_C 时最大，则模型偏好 x_A 与 x_C 正相关、x_B 与 x_C 负相关。
- **CRF 词性标注**：转移特征 t_j 可在 x_i="knock" 时偏好标记 [V]→[P]；状态特征 s_k 可在 x_i="knock" 时偏好标记 [V]。
- **LDA 生成与推断**：文档按 Θ_t（狄利克雷）含多话题，词由话题词频 β 生成；训练估 α,η（变分），推断话题结构用吉布斯/变分。

## 6. 金句与重要结论

- 推断远超出"预测"：由果溯因逆推隐变量状态也是推断。
- 有显式因果关系常用贝叶斯网；变量间相关但难获因果则用马尔可夫网。
- HMM 的"马尔可夫链"指系统下一时刻状态仅由当前状态决定，与以往无关（"现在决定未来"）。
- 联合分布可基于极大团定义：非极大团的关系已包含在其所属极大团的势函数中，故只需对极大团定义势函数。
- 全局/局部/成对马尔可夫性等价地刻画 MRF 的条件独立性。
- 条件随机场与 MRF 形式相近，但 CRF 处理条件概率、MRF 处理联合概率；CRF 是判别式模型。
- 精确推断复杂度随极大团规模指数增长，故现实多用近似推断（MCMC、变分）。
- 信念传播把变量消去的求和视为消息传递，解决了多边际分布的重复计算；无环图两趟完成。
- MCMC 通过构造"平稳分布恰为目标分布"的马尔可夫链获取样本；吉布斯采样是 MH 的特例且无需拒绝，更简洁。
- 变分推断用平均场假设（q(z)=Π q_i(z_i)）把复杂后验拆为可解子集，与 EM 结合做推断与参数估计。
- LDA 认为每篇文档含多个话题、每个词来自一个话题；参数与话题结构常需变分或吉布斯近似推断。
