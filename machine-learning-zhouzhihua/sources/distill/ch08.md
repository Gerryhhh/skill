# 第8章 集成学习

## 1. 章节核心摘要
本章研究如何通过构建并结合多个学习器（集成）来获得比单一学习器显著更优的泛化性能。集成可由同质个体学习器（基学习器）或异质个体学习器（组件学习器）构成。

核心结论是：好集成要求个体学习器"好而不同"——既要有一定准确性，又要有足够多样性（差异）。理论上在基学习器误差相互独立时，集成错误率随个体数 T 指数级下降；但现实中个体由同一任务训练、不可能独立，因此"如何产生并结合好而不同的个体"是集成学习的研究核心。

按个体生成方式分两大类：串行、强依赖的 Boosting（代表 AdaBoost，主要降低偏差）与并行、弱依赖的 Bagging/随机森林（主要降低方差）。结合策略有平均法、投票法、学习法（Stacking）。最后从误差-分歧分解、多样性度量与多样性增强三方面深化理论。

## 2. 关键术语表
- 集成学习（ensemble learning）— 构建并结合多个学习器完成学习任务；亦称多分类器系统、基于委员会的学习。
- 个体学习器（individual learner）/基学习器（base learner）— 由单个学习算法从训练数据产生；同质集成的个体称基学习器。
- 基学习算法（base learning algorithm）/组件学习器（component learner）— 同质用基学习算法；异质集成中不同算法产生的个体称组件学习器。
- 同质（homogeneous）/异质（heterogeneous）— 集成中个体是否同为一种学习算法。
- 弱学习器（weak learner）— 泛化性能略优于随机猜测的学习器（如二分类精度略高于 50%）。
- 多样性（diversity）— 个体学习器间的差异；与"准确性"共同决定集成好坏。
- 好而不同— 集成对个体的核心要求：既准确又多样。
- Boosting— 串行、强依赖的集成族，将弱学习器提升为强学习器，关注降低偏差。
- Bagging— 基于自助采样（bootstrap）的并行集成代表，关注降低方差。
- 随机森林（Random Forest, RF）— Bagging 的扩展：在决策树训练中进一步引入随机属性选择。
- AdaBoost— Boosting 最著名代表；迭代调整样本分布、加权结合基分类器。
- 加性模型（additive model）— 基学习器的线性组合 H(x)=Σα_t h_t(x)，AdaBoost 可由此推导。
- 指数损失函数（exponential loss）— AdaBoost 优化的目标 ℓ_exp=exp(−f(x)H(x))，是 0/1 损失的一致替代。
- 重赋权法 / 重采样法— Boosting 中让基学习器关注不同数据分布的两种实现（权重 vs 重新采样）。
- 自助采样（bootstrap sampling）— 有放回采样 m 次，约 63.2% 样本被采中。
- 包外估计（out-of-bag estimate）— 用未被某基学习器采中的约 36.8% 样本估计其泛化误差。
- 结合策略— 把个体输出组合成集成输出的方法：平均法、投票法、学习法。
- 平均法（averaging）— 简单平均 / 加权平均（回归数值输出）。
- 投票法（voting）— 绝对多数/相对多数/加权投票（分类）；硬投票（类标记）/软投票（类概率）。
- Stacking（学习法）— 用次级学习器（元学习器）结合初级学习器输出；次级集由交叉验证生成防过拟合。
- 误差-分歧分解（error-ambiguity decomposition）— E = 加权平均误差 − 加权平均分歧，揭示准确性与多样性的权衡。
- 多样性度量（diversity measure）— 估算个体分类器多样化程度，如不合度量、相关系数、Q-统计量、κ-统计量。
- 多样性增强— 通过数据样本/输入属性/输出表示/算法参数扰动引入随机性。
- 稳定基学习器（stable base learner）— 对样本扰动不敏感的学习器（线性、SVM、朴素贝叶斯、k 近邻），需靠属性扰动等增强多样性。

## 3. 关键模型与算法
### 集成学习的错误率分析（理论）
- 核心思想：二分类、基分类器错误率 ε 且相互独立时，简单投票集成的错误率随 T 指数级趋于 0。
- 数学形式/公式：每个基分类器 P(h_i(x)≠f(x))=ε；集成通过多数投票，正确当且仅当超过半数基分类器正确。由 Hoeffding 不等式，集成错误率 P(H(x)≠f(x)) ≤ exp(−½T(1−2ε)²)（即误差指数下降）。前提"独立"现实中不成立——个体为同任务训练，不可能独立；准确性与多样性存在冲突。
- 适用场景：说明为何集成能远超单一学习器、论证弱学习器集成的理论可行性。
- 慎用情形/局限：独立假设过强，仅为理论上界；实际性能取决于能制造多少真实多样性。

### AdaBoost（Boosting 代表）
- 核心思想：串行训练——每轮依样本分布训出基分类器，提高其前一集成犯错样本的权重，最终加权结合。基分类器权重由误差决定（误差越小权重越大）。
- 数学形式/公式：H(x)=sign(Σ_t α_t h_t(x))，其中 α_t=½ ln((1−ε_t)/ε_t)，ε_t 为第 t 个基分类器在分布 D_t 下的误差。样本分布更新为 D_{t+1}∝D_t·exp(−α_t y h_t(x))（规范化因子 Z_t 保证是分布）。可从"加性模型 + 最小化指数损失"严格推导：指数损失 ℓ=exp(−f(x)H(x)) 最小化等价于贝叶斯最优；sign(H) 达贝叶斯最优错误率，故指数损失是 0/1 损失的一致替代。
- 适用场景：二分类（可推广到多分类）；基学习器可为决策树桩等弱学习器。
- 慎用情形/局限：仅二分类原生；对噪声/异常敏感（不断加权错分样本）；每轮须检查基分类器是否优于随机猜测，否则抛弃并可能过早停止（重采样法可重启）。从偏差-方差看主要降偏差。

### Bagging（并行集成代表）
- 核心思想：对训练集自助采样得 T 个有交叠子集，各训一个基学习器再结合；用自助采样制造差异，又保留足够样本保准确性。
- 数学形式/公式：自助采样 m 次（有放回），约 63.2% 样本进入采样集；分类用简单投票、回归用简单平均结合。复杂度约 T·O(m)，与单学习器同阶。包外估计：H_oob(x) 仅用未训练 x 的基学习器预测，泛化误差用包外样本估计。
- 适用场景：多分类/回归均可（不经修改）；对不稳定基学习器（决策树、神经网络）尤有效；可用包外样本辅助剪枝/早停。
- 慎用情形/局限：对稳定基学习器（线性、SVM、朴素贝叶斯、k 近邻）提升有限（扰动不敏感）；主要降方差，对偏差高的弱学习器帮助小。

### 随机森林（Random Forest）
- 核心思想：在 Bagging 的基础上，对每棵决策树每个结点的属性选择再做随机——仅从随机选择的大小为 k 的属性子集中挑最优属性。
- 数学形式/公式：k 控制随机性；k=d 即传统决策树，k=1 即随机选属性，推荐 k=log₂d。其起始性能常较差（个体性能被降），但随 T 增加收敛到更低泛化误差；训练更快（只需考察属性子集）。
- 适用场景：高维、大量冗余属性的分类/回归；常作为强基准模型。
- 慎用情形/局限：属性少/冗余少时不宜；属 Bagging 变体，对稳定学习器本身无效，靠"样本+属性"双重扰动。

### 结合策略：平均法 / 投票法 / 学习法
- 核心思想：把 T 个个体输出 h_i(x) 组合成最终输出。
- 数学形式/公式：
  - 平均法：简单平均 H(x)=Σh_i(x)/T；加权平均 H(x)=Σw_i h_i(x)（w_i≥0,Σw_i=1）。性能相近用简单平均，相差大用加权平均。
  - 投票法：绝对多数投票（过半才预测，否则拒判，可靠性高）/相对多数投票（最高票，平局随机）/加权投票。硬投票用类标记 {0,1}，软投票用类概率（结合常更好，但类概率需校准如 Platt 缩放）。
  - 学习法（Stacking）：初级学习器输出作次级学习器的输入特征，原标记作标记；次级集用 k 折交叉验证生成防过拟合；次级常用多响应线性回归（MLR）。
- 适用场景：平均用于回归，投票用于分类，Stacking 用于追求更强性能（尤其异质集成）。
- 慎用情形/局限：加权平均权重从噪声数据学得易过拟合；异质学习器类概率不可直接比较（需转类标记）；Stacking 易过拟合，须用未参与初级训练的样本。

### 误差-分歧分解与多样性增强
- 核心思想：理论证明集成泛化误差 = 个体加权误差均值 − 个体加权分歧均值；故个体越准、越多样越好。多样性可通过数据/属性/输出/参数四类扰动增强。
- 数学形式/公式（回归）：分歧 A(h_i|x)=(h_i(x)−H(x))²；集成泛化误差 E = E_bar − A_bar（E_bar 为个体误差加权平均，A_bar 为分歧加权平均）。多样性度量（二分类列联表 a/b/c/d）：不合度量 dis=(b+c)/m；相关系数 ρ=(ad−bc)/√((a+b)(c+d)(a+c)(b+d))；Q-统计 Q=(ad−bc)/(ad+bc)；κ-统计量 κ=(p−p_e)/(1−p_e)（p 一致概率、p_e 偶然一致概率）。增强机制：数据样本扰动（Bagging 自助采样、AdaBoost 序列采样）、输入属性扰动（随机子空间）、输出表示扰动（翻转法、ECOC）、算法参数扰动（负相关法）。
- 适用场景：诊断与改进集成（分析"好而不同"程度、设计更优集成）。
- 慎用情形/局限：误差-分歧分解仅严格适用于回归、难推广到分类；现有多样性度量均有显著缺陷，理解多样性被誉为集成学习的"圣杯问题"。

## 4. 应用与决策框架
- 选 Boosting 还是 Bagging：
  - 想降低偏差、基学习器较弱（如决策树桩）→ Boosting（AdaBoost）。
  - 想降低方差、用不稳定且较强的学习器（不剪枝决策树、神经网络）→ Bagging/随机森林。
- 基学习器类型决策：
  - 不稳定（决策树、神经网络）：数据样本扰动（Bagging）有效。
  - 稳定（线性、SVM、朴素贝叶斯、k 近邻）：数据扰动无效，需输入属性扰动（随机森林、随机子空间）或算法参数扰动。
- 任务类型：二分类用 AdaBoost；多分类/回归优先 Bagging（不经修改）。
- 结合策略选择：回归用平均（性能近则简单平均）；分类用投票（可靠性要求高用绝对多数拒判）；追求极致用 Stacking（须交叉验证防过拟合）。
- 多样性增强：并行集成优先数据+属性双重扰动（随机森林范式）；可用输出/参数扰动进一步增益。
- 性能诊断：用 κ-误差图观察个体准确性（点云高度）与多样性（点云右移程度），指导是否需要更多样化。

## 6. 金句与重要结论
- 集成获得比单一学习器显著优越的泛化性能，对弱学习器尤为明显。
- 要获得好的集成，个体学习器应"好而不同"——既准确又有多样性；但准确性与多样性本身存在冲突。
- 若基学习器误差相互独立，集成错误率随 T 增大指数级下降，最终趋于零（但现实中不可能独立）。
- 从偏差-方差分解看：Boosting 主要关注降低偏差，Bagging 主要关注降低方差。
- 指数损失是 0/1 损失的一致替代；最小化它即最小化分类错误率（AdaBoost 因此理论上达贝叶斯最优）。
- Bagging 复杂度与训练单学习器同阶，是高效的集成算法；且能不经修改用于多分类/回归。
- 大约 63.2% 样本进入自助采样集，约 36.8% 可作包外估计。
- 随机森林起始性能常较差，但随个体数增加收敛到更低泛化误差，且训练比 Bagging 更快。
- 加权平均法未必优于简单平均；个体性能相近宜用简单平均，相差大宜用加权。
- 基于类概率结合常比基于类标记结合更好；但异质学习器类概率不可直接比较。
- 误差-分歧分解：个体越准确、多样性越大，集成越好——由 Krogh & Vedelsby 给出。
- 集成学习是黑箱模型；即便个体可解释，集成仍难解释。理解多样性是集成学习的"圣杯问题"。
