# 第5章 神经网络

## 1. 章节核心摘要

- 神经网络是由具有适应性的简单单元（神经元）组成的广泛并行互连网络，其学习即“神经网络学习”。最基本的成分是神经元模型，本书采用一直沿用的 M-P 神经元模型：接收带权输入、与阈值比较、经激活函数产生输出。
- 感知机（两层神经元）只能解决线性可分问题（与/或/非），无法解决异或等非线性可分问题；引入隐层（多层功能神经元）后即可解决非线性问题，形成多层前馈神经网络。神经网络“学”到的东西蕴涵在连接权与阈值中。
- 训练多层网络最杰出的算法是误差逆传播（BP）算法：基于梯度下降，信号前传、误差逆传，逐层调整连接权与阈值。BP 既可是标准（逐样本更新）也可是累积（整批更新）形式；因其强大表示能力常遭遇过拟合，可用早停与正则化缓解。
- 参数寻优存在局部极小与全局最小之分；基于梯度的 BP 易陷局部极小，常用多组初始化、模拟退火、随机梯度下降、遗传算法等启发式策略跳出（理论缺乏保障）。
- 本章还简介 RBF、ART、SOM、级联相关、Elman、Boltzmann/RBM 等常见网络，并讨论深度学习：通过增加隐层、无监督逐层预训练+微调、权共享（CNN）等提升模型容量，把学习理解为“特征学习/表示学习”，减少对人工特征工程的依赖。

## 2. 关键术语表

- 神经网络（neural networks）/ 神经网络学习 — 由适应性简单单元并行互连组成的网络及其学习过程。
- 神经元（neuron）/ 单元（unit）— 网络最基本成分，即 M-P 模型中的“简单单元”。
- M-P 神经元模型 — 1943 年 McCulloch & Pitts 提出的模型：带权输入与阈值比较后经激活函数输出。
- 阈值（threshold）/ 偏差（bias）— 神经元激活的判断界限；常把阈值看作固定输入−1.0 的哑结点连接权。
- 激活函数（activation function）/ 响应函数 — 对神经元总输入做非线性变换产生输出；理想阶跃函数不连续，实际常用 Sigmoid。
- Sigmoid 函数 / 挤压函数（squashing function）— 把大范围输入挤压到 (0,1) 的单调可微函数；对数几率函数是其典型代表。
- 感知机（Perceptron）/ 阈值逻辑单元 — 两层神经元，输出层为 M-P 神经元；可学逻辑与/或/非。
- 线性可分（linearly separable）— 存在线性超平面能分开两类模式；感知机对此必收敛。
- 隐层 / 隐含层（hidden layer）— 输入层与输出层之间的层，其神经元拥有激活函数，是功能神经元。
- 多层前馈神经网络（multi-layer feedforward neural networks）/ 单隐层网络 — 层级全互连、无同层/跨层连接；含隐层即多层，“单隐层”指仅一个隐层。
- 连接权（connection weight）— 神经元之间的权重，是神经网络学习的核心参数。
- 误差逆传播（BP, error BackPropagation）/ 反向传播 — 训练多层网络最成功的算法，基于梯度下降。
- 标准 BP / 累积 BP（accumulated error backpropagation）— 前者逐样本更新，后者读完整个训练集后才更新参数。
- 早停（early stopping）/ 正则化（regularization）— 缓解 BP 过拟合的两类策略；正则化在误差目标中加连接权与阈值平方和项。
- 局部极小（local minimum）/ 全局最小（global minimum）— 参数空间中邻域/全体误差最小的解；全局最小必为局部极小，反之不然。
- 梯度下降（gradient descent）/ 随机梯度下降（SGD）— 沿负梯度方向寻优；SGD 在梯度中加随机性，有助跳出局部极小。
- 模拟退火（simulated annealing）— 以一定概率接受次优解以跳出局部极小的技术。
- 径向基函数网络（RBF 网络）— 单隐层前馈网络，隐层用径向基函数、输出层线性组合隐层输出。
- ART 网络 / 竞争型学习 / 胜者通吃（winner-take-all）— 识别层神经元竞争获胜、可增量/在线学习，缓解可塑性-稳定性窘境。
- SOM 网络 / 自组织映射（Self-Organizing Map）— 竞争型无监督网络，将高维数据映射到低维并保持拓扑结构。
- 级联相关网络（Cascade-Correlation）— 结构自适应网络，训练中新隐结点逐渐加入、输入端权冻结。
- 递归神经网络（recurrent neural networks）/ Elman 网络 — 允许环形连接、输出反馈作输入，可处理时序动态；Elman 是常用代表。
- Boltzmann 机 / 受限 Boltzmann 机（RBM）/ 能量模型 — 以“能量”定义网络状态，RBM 仅保留显层-隐层连接，用对比散度（CD）训练。
- 深度学习（deep learning）— 很深层的神经网络；通过增加隐层提升容量。
- 预训练（pre-training）/ 微调（fine-tuning）— 无监督逐层训练后再全局训练的多隐层训练策略。
- 权共享（weight sharing）/ 卷积神经网络（CNN）— 一组神经元用相同连接权；CNN 用卷积层+采样(汇合)层，大幅减少参数量。
- 特征学习 / 表示学习（feature learning / representation learning）— 深度学习通过多层加工把低层特征转化为高层特征，替代人工特征工程。
- 特征工程（feature engineering）— 由人类专家设计样本特征；深度学习旨在减少其依赖。

## 3. 关键模型与算法

### M-P 神经元与感知机
- 核心思想：神经元接收 n 个带权输入，总输入与阈值比较，经激活函数输出；感知机通过学习权重与阈值实现逻辑与/或/非。
- 数学形式/公式：输出 y = f(Σᵢ wᵢxᵢ − θ)（f 为阶跃/Sigmoid）；阈值 θ 可视为固定输入−1.0 的哑结点权 w_{n+1}，从而权重与阈值统一为权重学习。感知机学习规则：对样例 (x,y)，若当前输出 ŷ，则权重增量 Δwᵢ = η(y−ŷ)xᵢ，η∈(0,1) 为学习率（常取0.1）；预测正确则不变。
- 适用场景：线性可分的二分类（与/或/非等）；单层功能神经元即可。
- 慎用情形/局限：仅有一层功能神经元，学习能力有限；对非线性可分（如异或）会振荡、无法收敛（Minsky & Papert, 1969）。

### 多层前馈神经网络
- 核心思想：增加隐层使网络具备处理非线性可分问题的能力；每层与下层全互连、无同层/跨层连接，拓扑无环（前馈）。
- 数学形式/公式：输入层仅接收、不处理函数；隐层与输出层含功能神经元。网络“学”到的内容蕴涵在连接权 w 与阈值 θ 中。单隐层网络已具强大学习能力（Hornik 等证明：含足够多神经元的单隐层可任意精度逼近任意连续函数），但隐层神经元个数常靠试错法设定。
- 适用场景：复杂非线性映射、分类与回归；需比感知机更强的表示能力时。
- 慎用情形/局限：多隐层直接用经典 BP 难训练（误差逆传易发散）；易过拟合；参数多、训练效率低。

### 误差逆传播算法（BP）
- 核心思想：基于梯度下降，信号从输入层逐层前传至输出，计算输出误差后逆向传播到隐层，据误差调整连接权与阈值；是训练多层前馈网络最成功的算法（也适用于递归网络）。
- 数学形式/公式：对训练例 (xₖ,yₖ)，网络输出 ŷₖ，均方误差 Eₖ=½Σⱼ(ŷₖⱼ−yₖⱼ)²（1/2 为求导便利）。任一参数 v 的更新通式 Δv = −η·∂Eₖ/∂v。以隐层→输出层权 wₕⱼ 为例，利用链式法则得 Δwₕⱼ = η·gⱼ·bₕ（其中 gⱼ = ŷₖⱼ(1−ŷₖⱼ)(yₖⱼ−ŷₖⱼ) 为输出层误差项，bₕ 为隐层输出）；隐层阈值、输入层→隐层权与隐层阈值有类似更新式（含隐层误差项 eₕ = bₕ(1−bₕ)Σⱼ wₕⱼ gⱼ）。Sigmoid 性质 f'(x)=f(x)(1−f(x)) 简化推导。学习率 η∈(0,1) 控制步长（太大振荡、太小收敛慢，常设0.1；可对不同层用不同 η）。
- 适用场景：绝大多数现实神经网络训练（默认即 BP）；标准 BP 与累积 BP 皆常用。
- 慎用情形/局限：标准 BP 单样本更新频繁、不同样例更新可能抵消，需更多迭代；累积 BP 读取整批后才更新、频率低，但误差降到一定程度后下降缓慢；两者区别类似 SGD 与标准梯度下降。
- 缓解过拟合：①早停（训练集算梯度、验证集估误差，验证误差升则停并返回最小验证误差的参数）；②正则化（目标加 λ·Σwᵢ²，偏好小权重使输出更光滑，λ 用交叉验证估计）。

### 全局最小与跳出局部极小
- 核心思想：训练即参数寻优，希望找到全局最小；但误差函数常有多局部极小，基于梯度的方法易陷其中。
- 数学形式/公式：若存在 ε>0 使邻域内误差均不小于该点，则为局部极小；若参数空间任意点误差均不小于该点则为全局最小。负梯度方向是下降最快方向，梯度为零处更新量为零、迭代停止。跳出策略：多组不同初始化取最优；模拟退火（按概率接受次优解、概率随时间降）；随机梯度下降（梯度含随机性，陷局部极小时梯度仍可能非零）；遗传算法。以上多为启发式、理论缺保障。
- 适用场景：任何基于梯度的神经网络训练。
- 慎用情形/局限：局部极小非所愿；上述跳出技术无法保证全局最优。

### RBF 网络
- 核心思想：单隐层前馈网络，隐层用径向基函数（沿径向对称的标量函数，常以样本到中心的欧氏距离为自变量），输出层线性组合隐层输出。
- 数学形式/公式：输出为 Σᵢ wᵢ·ρ(x,cᵢ)，ρ 常用高斯径向基函数 exp(−‖x−cᵢ‖²/某宽度参数)。训练通常两步：先定中心 cᵢ（随机采样/聚类），再用 BP 等定 wᵢ 与宽度。足够多隐层神经元可任意精度逼近连续函数（Park & Sandberg, 1991）。
- 适用场景：函数逼近、插值；可作为单隐层的高效替代。
- 慎用情形/局限：常见为单隐层；中心与宽度的选取影响性能。

### ART / SOM / 级联相关 / Elman / Boltzmann-RBM
- ART 网络：竞争型无监督，比较层+识别层+阈值+重置模块；识别阈值高则模式类多而精细、低则粗略；可增量/在线学习，缓解可塑性-稳定性窘境。
- SOM 网络：竞争型无监督，将高维输入映射到低维（常二维）并保持拓扑结构；输出层神经元矩阵排列，最佳匹配单元及其邻域权向量向输入靠拢；用于聚类、可视化、图像分割。
- 级联相关网络：结构自适应，训练中新隐结点逐渐加入（输入端权冻结），通过最大化新结点输出与网络误差的相关性训练；无需预设层数与隐结点数、训练快，但数据少时易过拟合。
- Elman 网络：递归神经网络，隐层输出反馈作下一时刻输入，可处理时序；常用 Sigmoid、推广 BP 训练。
- Boltzmann 机 / RBM：基于能量模型，状态为0/1；标准 Boltzmann 机全连接、训练复杂，现实用 RBM（仅显层-隐层连接，二部图），用对比散度（CD）算法训练（由显层采隐层、再生显层、再采隐层，据差异更新连接权）。
- 适用场景：ART/SOM 用于无监督/聚类；Elman 用于时序；RBM 用于深度信念网络预训练。
- 慎用情形/局限：多为特定结构，训练复杂度或数据量要求各异；Boltzmann 机全连接训练代价高。

### 深度学习（DBN / CNN）
- 核心思想：增加隐层数提升模型容量；多隐层难直接用标准 BP（误差逆传发散），故用无监督逐层预训练+微调，或 CNN 权共享。
- 数学形式/公式：预训练——每层作为一个 RBM，上一层隐结点输出作下一层输入，逐层训练后用 BP 微调。权共享——一组神经元用相同连接权（如 CNN 每个特征映射平面共用权），大幅减少参数量。CNN 复合卷积层（多个特征映射，用卷积滤波器提局部特征）与采样/汇合层（亚采样保留信息），最后连接层映射输出；常用修正线性单元 ReLU 替代 Sigmoid。深度学习可理解为逐层特征/表示学习。
- 适用场景：图像（CNN）、语音、时序等大数据复杂任务；大数据+强算力下优势显著。
- 慎用情形/局限：参数巨多、训练开销大；需大数据降过拟合、强算力缓解低效；黑箱难解释（可从网络抽取符号规则改善）。

## 4. 应用与决策框架

选择网络类型的决策步骤：

1. 明确问题性质：
   - 线性可分二分类 → 感知机即可。
   - 非线性可分 / 一般分类回归 → 多层前馈网络 + BP。
   - 时序/动态 → 递归网络（Elman）或更复杂 RNN。
   - 聚类/可视化/无监督 → SOM、ART。
   - 图像 → CNN（权共享）。
   - 需深层表示、大数据 → 深度学习（DBN/CNN）。
2. 确定训练算法：默认 BP；权衡标准 BP（大数据时常更快得较好解）与累积 BP（整批稳定）。
3. 防过拟合：早停（简单有效）或正则化（偏好小权重）；两者可结合。
4. 缓解局部极小：多组初始化、模拟退火、SGD、遗传算法（启发式）。
5. 对照表：

| 任务 | 推荐网络 | 训练要点 |
|---|---|---|
| 线性可分 | 感知机 | 感知机学习规则 |
| 一般非线性 | 多层前馈（单隐层） | BP（标准/累积） |
| 时序 | Elman/递归 | 推广 BP |
| 聚类/可视化 | SOM/ART | 竞争学习、无监督 |
| 图像 | CNN | 权共享、BP |
| 深层表示 | DBN/CNN | 逐层预训练+微调 |

## 5. 典型案例/例题要点

- 感知机实现逻辑运算：与（w₁=w₂=1, θ=2，仅 x₁=x₂=1 时 y=1）；或（θ=0.5，任一为1即 y=1）；非（w₁=−0.6, w₂=0, θ=−0.5，x₁=1 时 y=0）。
- 异或问题：单层感知机无法解决（非线性可分、会振荡）；图5.5 两层感知机（含隐层）即可解决——说明隐层的必要性。
- BP 西瓜示例：在 2 属性、5 样本的西瓜数据上，随训练轮数增加网络参数与分类边界逐步演化（图5.9）。
- 通用逼近定理（Hornik 等, 1989）：单隐层、足够多神经元即可任意精度逼近任意连续函数；隐层神经元数通常靠试错。
- 标准 vs 累积 BP：标准 BP 逐样本更新频繁、效果可能抵消，需更多迭代；累积 BP 整批后更新、频率低，但误差降到位后变慢；标准 BP 在大数据时常更快得好解。
- RBF 解异或（习题5.7）：单层 RBF 网络可构造解决异或；高斯径向基函数的中心与宽度需合理设置。
- 深度学习示例：CNN 手写数字识别（LeCun 等, 1998），32×32 图像经卷积层（6 个 28×28 特征映射，5×5 局部滤波）、采样/汇合层（6 个 14×14）、连接层（84 神经元）到输出，权共享大幅减参。
- 小故事：神经网络三起三落——40-50 年代起步（M-P、感知机）、1969 年 Minsky《感知机》致冰河期、80 年代 Hopfield+BP 复兴、90 年代中因 SVM 再低谷、2010 前后深度学习借算力与大数据第三次崛起。

## 6. 金句与重要结论

- 神经网络“学”到的东西，“蕴涵在连接权与阈值中”。
- “前馈”指网络拓扑结构上不存在环或回路，并非信号不能向后传。
- 感知机：若两类模式线性可分则学习必收敛；否则会振荡、不能求得合适解（连异或都解决不了）。
- 误差逆传播（BP）算法“是迄今最成功的神经网络学习算法”，现实任务大多用 BP 训练。
- “只需一个包含足够多神经元的隐层，多层前馈网络就能以任意精度逼近任意复杂度的连续函数”（Hornik 等, 1989）。
- 标准 BP 与累积 BP 的区别“类似于随机梯度下降与标准梯度下降之间的区别”。
- “全局最小一定是局部极小，反之则不成立。”
- 缓解 BP 过拟合两策略：早停与正则化；“增加连接权与阈值平方和这一项后……使网络输出更加光滑，从而对过拟合有所缓解”。
- ART“比较好地缓解了竞争型学习中的可塑性-稳定性窘境”，可进行增量/在线学习。
- 深度学习可理解为“特征学习/表示学习”：多层加工把“低层”特征转化为“高层”特征后，用“简单模型”即可完成复杂任务。
- 以往特征需人类专家设计（特征工程），“特征学习则通过机器学习技术自身来产生好特征，这使机器学习向全自动数据分析又前进了一步”。
- 神经网络是难解释的“黑箱模型”，但可从网络抽取符号规则改善可解释性。

## 7. 与其他章节的关联

- 第3章：Sigmoid 激活函数即对数几率函数，与对数几率回归（3.3）直接相通；神经元用线性组合+阈值即线性模型；多变量决策树（第4章）的每个结点也是一个线性分类器。
- 第6章：引入正则化的神经网络与 SVM 已非常相似（书中明言）。
- 第8章：集成学习思路在 CNN 汇合层（最大/平均）中有所体现（参见 8.4 结合策略）。
- 第11章：加入 L1 正则的神经网络对应特征选择与稀疏学习。
- 第12章：深度学习模型容量/复杂度与计算学习理论衔接。
- BP 算法实质是 LMS（最小均方）算法的推广，亦称广义 δ 规则；反向传播也可用于递归网络（Elman）。
