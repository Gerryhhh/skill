# 第9章 聚类

## 1. 章节核心摘要
- 聚类是无监督学习中最主要、应用最广的任务：在训练样本标记未知的情况下，将数据集划分为若干个通常不相交的子集（簇），以揭示数据的内在结构与分布规律，簇所对应的语义需由使用者把握与命名。聚类既可作为独立过程（探寻数据分布），也可作为分类等任务的前驱（先聚类、再依簇定义类、训练分类器）。
- 聚类算法种类繁多、缺乏统一客观标准，本章采用"列举式"叙述，按学习策略将算法分为四类：原型聚类、密度聚类、层次聚类（外加性能度量与距离计算两大基础问题）。
- 性能度量的核心是"簇内相似度高、簇间相似度低"；距离计算是几乎所有聚类算法的底层依赖，闵可夫斯基距离是连续/有序属性的通用形式，VDM 处理无序属性，二者可结合处理混合属性。
- 原型聚类假设簇结构可由一组"原型"刻画，代表算法有 k均值（无监督、贪心最小化平方误差）、LVQ（带类别标记的监督式原型学习）、高斯混合聚类（用概率模型—高斯分布—表达原型，借 EM 算法求解）。
- 密度聚类（DBSCAN）假设簇由样本分布紧密程度决定，能发现任意形状的簇并标记噪声；层次聚类（AGNES）在不同层次做树形划分，可借树状图在任意层次切割得到不同粒度的簇。

## 2. 关键术语表
- 聚类（clustering）— 将无标记样本划分为若干不相交子集（簇）的无监督学习任务。
- 簇（cluster）— 聚类得到的样本子集，亦称"类"。
- 簇标记（cluster label）— 样本所属簇的编号 λ_j∈{1,…,k}。
- 性能度量 / 有效性指标（validity index）— 评估聚类结果好坏的指标，也可作为聚类过程的优化目标。
- 外部指标（external index）— 将聚类结果与参考模型（如专家划分）比较的指标。
- 内部指标（internal index）— 不依赖任何参考模型、直接考察聚类结果的指标。
- 簇内相似度 / 簇间相似度（intra-/inter-cluster similarity）— 同一簇内样本彼此相似、不同簇样本彼此相异的程度。
- 距离度量（distance measure）— 满足非负性、同一性、对称性、直递性（三角不等式）的函数。
- 闵可夫斯基距离（Minkowski distance）— 连续属性的通用距离 ‖x_i−x_j‖_p。
- 欧氏距离 / 曼哈顿距离 / 切比雪夫距离 — 闵氏距离在 p=2、p=1、p→∞ 时的特例。
- 有序属性（ordinal）/ 无序属性（non-ordinal）— 属性值是否定义了"序"关系，决定能否直接算距离。
- VDM（Value Difference Metric）— 针对无序离散属性的距离度量。
- 非度量距离（non-metric distance）— 不满足直递性的相似度距离（如"人""马"与"人马"的例子）。
- 距离度量学习（distance metric learning）— 基于数据样本学习合适的距离计算式。
- 原型聚类（prototype-based clustering）— 用一组"代表性点（原型）"刻画簇结构的聚类。
- k均值（k-means）— 最小化簇内平方误差的原型聚类，贪心迭代求解。
- 学习向量量化（LVQ）— 利用样本类别标记辅助学习的监督式原型聚类。
- 高斯混合聚类（Mixture-of-Gaussian）— 用 k 个高斯分布混合模型表达簇、借 EM 算法求解的原型聚类。
- 密度聚类（density-based clustering）— 从样本密度/可连接性出发的聚类，典型为 DBSCAN。
- 核心对象（core object）— ε-邻域内样本数不少于 MinPts 的样本。
- 密度直达 / 密度可达 / 密度相连 — DBSCAN 中描述样本可连接性的三种关系。
- 噪声 / 异常（noise/anomaly）— 不属于任何簇的样本。
- 层次聚类（hierarchical clustering）— 在不同层次做树形划分，可自底向上聚合或自顶向下分拆。
- AGNES — 自底向上聚合的层次聚类算法；按簇间距离计算方式分单链接、全链接、均链接。
- Voronoi 剖分 — 由一组原型向量定义的样本空间划分（每个样本归入最近原型）。

## 3. 关键模型与算法

### 聚类性能度量（外部指标）
- 核心思想：将聚类结果 C 与参考划分 C* 比较，统计样本对（i<j）的归属情况，定义 a（两簇均同属）、b（C 同属、C* 异属）、c（C 异属、C* 同属）、d（两簇均异属），且 a+b+c+d = m(m−1)/2。
- 数学形式：
  - Jaccard 系数 JC = a / (a+b+c)，取值 [0,1]，越大越好；
  - FM 指数 FMI = √[ a/(a+b) · a/(a+c) ]，取值 [0,1]，越大越好；
  - Rand 指数 RI = 2(a+d) / (m(m−1))，取值 [0,1]，越大越好。
- 适用场景：有专家参考划分、需横向比较不同聚类算法结果时。
- 慎用情形：现实任务往往没有可靠参考模型，外部指标不可用，须改用内部指标。

### 聚类性能度量（内部指标）
- 核心思想：直接考察聚类结果本身。定义簇内平均距离 avg(C)、簇内最远距离 diam(C)、簇间最近样本距离 d_min(C_i,C_j)、簇间中心点距离 d_cen(C_i,C_j)。
- 数学形式：
  - DB 指数 DBI = (1/k)·Σ_i max_{j≠i} [ (avg(C_i)+avg(C_j)) / d_cen(C_i,C_j) ]，值越小越好；
  - Dunn 指数 DI = min_{i≠j} [ d_min(C_i,C_j) / max_k diam(C_k) ]，值越大越好。
- 适用场景：无参考模型、仅依据簇内紧凑度与簇间分离度评估聚类质量。
- 慎用情形：DBI 受中心点距离影响，对形状异常的簇未必敏感；内部指标仅作辅助，并非绝对标准。

### 距离计算：闵可夫斯基与变体
- 核心思想：对有序/连续属性，以 ‖x_i−x_j‖_p 度量距离；p=2 为欧氏距离（最常用）、p=1 为曼哈顿距离（街区距离）、p→∞ 为切比雪夫距离。距离度量须满足非负性、同一性、对称性、直递性（三角不等式）。
- 数学形式：dist(x_i,x_j) = (Σ_n |x_{it}−x_{jt}|^p)^{1/p}，对 p≥1 满足距离四性质；p<1 时不满足直递性。
- 适用场景：属性为连续或有"序"关系的离散属性。
- 慎用情形：无序属性（如{飞机,火车,轮船}）不能直接用闵氏距离，须改用 VDM；不同属性重要性不同时用加权距离。

### 距离计算：VDM 与混合/加权距离
- 核心思想：无序属性用 VDM 度量两个离散值的差异，再与闵氏距离结合处理混合属性；属性重要性不同则用加权距离（权重 w_t≥0）。
- 数学形式：
  - VDM：VDM(a,b) = Σ_{i=1}^k | (m_{u,a,i}/m_{u,a}) − (m_{u,b,i}/m_{u,b}) |（m_{u,a} 为属性 u 取值 a 的样本数，m_{u,a,i} 为其中属第 i 簇者）；
  - 混合属性距离 = [ Σ_{有序} |x_{it}−x_{jt}|^p + Σ_{无序} VDM(x_{it},x_{jt}) ]^{1/p}；
  - 加权闵氏距离在求和项引入权重 w_t。
- 适用场景：含无序或混合属性、属性重要性不等的数据。
- 慎用情形：权重需先验或学习得到；非度量距离（不满足直递性）用于特定语义相似度，不能直接当严格距离用。

### k均值算法（k-means）
- 核心思想：假设簇结构可由 k 个均值向量（原型）刻画，最小化所有样本到其所属簇均值向量的平方误差和；因最优解为 NP 难，采用贪心迭代：初始化均值向量→按最近均值划簇→重算均值→反复至不变。
- 数学形式：最小化 E = Σ_{i=1}^k Σ_{x∈C_i} ‖x−μ_i‖²，其中 μ_i = (1/|C_i|)Σ_{x∈C_i} x 为簇均值向量；E 越小簇内越紧密。
- 适用场景：簇近似"凸形"（椭球状）、样本量适中、需快速得到明确硬划分的场景；西瓜数据集4.0 上以 k=3 演示可见清晰迭代收敛。
- 慎用情形：仅在凸形簇结构效果好；k 需用户给定；对初始中心敏感、易陷局部最优；常设最大轮数或最小调整阈值防止过长运行。

### 学习向量量化（LVQ）
- 核心思想：与 k均值类似但利用样本类别标记（监督信息）。学一组原型向量 {p_1,…,p_q}，每轮取最近原型 p_{i*}，若与样本同类则令 p_{i*} 向样本靠拢（新向量 = p_{i*} + η(x_j−p_{i*})，η∈(0,1)），异类则推远；最终每个样本归入最近原型所在簇（Voronoi 剖分）。
- 数学形式：同类更新后距离缩小为 (1−η)·‖p_{i*}−x_j‖；异类更新后距离增大为 (1+η)·‖p_{i*}−x_j‖。
- 适用场景：有类别标记、希望簇与已知类语义对齐（形成类的"子类"结构）的监督式聚类/向量量化（有损压缩）。
- 慎用情形：需类别标记；每轮仅更新最近的一个原型（LVQ2/LVQ3 改为多原型更新以加速收敛）。

### 高斯混合聚类（Mixture-of-Gaussian）
- 核心思想：以概率模型（k 个高斯分布混合）表达原型。样本由"先按混合系数 α_i 选成分、再按对应高斯密度采样"生成；用 EM 算法估计参数 {α_i, μ_i, Σ_i}，簇标记由后验概率最大者决定（x_j 归入使 γ_{ji}=p_M(z_j=i|x_j) 最大的成分）。
- 数学形式：p_M(x) = Σ_{i=1}^k α_i·N(x|μ_i, Σ_i)，Σ_i α_i = 1；E 步算 γ_{ji}，M 步更新 μ_i = Σ_j γ_{ji} x_j / Σ_j γ_{ji}、Σ_i 类似加权平均、α_i = (1/m)Σ_j γ_{ji}。
- 适用场景：簇呈椭球形且允许"软"概率隶属、需给出生成概率模型的场景；k均值可视为其"方差相等且每样本仅属一成分"的特例。
- 慎用情形：需先定成分数 k；对初值敏感；协方差矩阵估计在高维/小样本下不稳定。

### DBSCAN（密度聚类）
- 核心思想：基于邻域参数 (ε, MinPts) 刻画紧密程度。簇定义为"由密度可达关系导出的最大密度相连样本集合"。先找所有核心对象，再以任一核心对象为种子扩展出由其密度可达的所有样本构成簇，直至核心对象耗尽；未归入任何簇者为噪声。
- 数学形式：ε-邻域 N_ε(x_j) = {x_i : dist(x_i,x_j)≤ε}；若 |N_ε(x_j)|≥MinPts 则 x_j 为核心对象；密度直达/可达/相连按定义递推；簇 C 满足连接性（任意两样本密度相连）与最大性（不能再扩展）。
- 适用场景：簇形状任意、含噪声/异常点、密度不均的数据；西瓜数据集4.0 上 (ε=0.11, MinPts=5) 得到 4 个簇。
- 慎用情形：对 (ε, MinPts) 敏感；密度差异过大时难用统一参数；默认距离多为欧氏距离。

### AGNES（层次聚类）
- 核心思想：自底向上聚合——初始每样本一簇，每步合并距离最近的两个簇，直至达到预设簇数。簇间距离由集合距离决定，决定链接方式。
- 数学形式：簇间距离 d(C_i,C_j) 可取 d_min（最近样本距离，单链接 single-linkage）、d_max（最远样本距离，全链接 complete-linkage）、d_avg（平均距离，均链接 average-linkage）。算法输出树状图（dendrogram），在指定层次切割即得分簇。
- 适用场景：需层次化/多粒度簇结构、想直观查看簇合并过程的数据；西瓜数据集4.0 用 d_max 得 k=7…4 的多种划分。
- 慎用情形：合并后不可回溯调整；大规模数据计算/存储开销大（BIRCH、ROCK 等对此改进）。

## 4. 应用与决策框架
选择聚类方法的决策思路：
1. 是否有类别标记？
   - 有标记且希望簇对齐语义 → LVQ（监督式原型聚类）。
   - 无标记 → 其余均为无监督聚类。
2. 簇形状是否近似凸/椭球，且需明确硬划分、追求速度与简单？
   - 是 → k均值（或高斯混合若需概率/软隶属）。
   - 否，簇形状任意或含噪声/异常 → DBSCAN 等密度聚类。
3. 是否需要层次化、多粒度结果，或想可视化合并过程？
   - 是 → AGNES 等层次聚类，借树状图按需切割。
4. 数据属性类型？
   - 连续/有序 → 闵可夫斯基（欧氏最常用）。
   - 含无序属性 → VDM 或混合距离。
   - 属性重要性不均 → 加权距离；语义上需非度量相似度 → 非度量距离/度量学习。
5. 如何评估结果？
   - 有参考划分 → 外部指标（JC/FMI/RI）。
   - 无参考划分 → 内部指标（DBI 越小越好、DI 越大越好）。
- 簇数 k 通常由用户指定；可用不同 k 多次运行取最佳，或用 X-means、gap statistic 等启发式自动确定。

## 5. 典型案例/例题要点
- 西瓜数据集 4.0（密度、含糖率二维）：k均值 k=3，随机选 x6/x12/x24 为初值，第 5 轮与第 4 轮结果相同即停；LVQ 令 9–21 号标 c2、其余 c1，q=5，η=0.1，演示 Voronoi 剖分形成；高斯混合 k=3 用 EM 迭代；DBSCAN (ε=0.11, MinPts=5) 得核心对象集及 4 个簇（C1…C4）；AGNES 用 d_max 生成树状图，切割得 7 个簇再逐步合并为 4 个。
- 非度量距离示意（图9.1）："人""马"分别与"人马"距离小，但"人"与"马"距离大，违反直递性，说明相似度距离未必是严格距离。
- 习题要点：9.3 指出 k均值贪心不能保证找到式(9.24)最优解（NP难）；9.5 证明核心对象密度可达集满足连接性与最大性；9.7 区分仅能产生凸聚类的算法（k均值、LVQ、高斯混合、AGNES 用 d_min/d_max/d_avg 均凸）与能产生非凸聚类的算法（DBSCAN 等密度聚类）。

## 6. 金句与重要结论
- "物以类聚"——聚类希望同一簇样本尽可能相似、不同簇样本尽可能不同（簇内相似度高且簇间相似度低）。
- 聚类结果的好坏评估可转化为"与参考模型比（外部指标）"或"直接考察结果（内部指标）"两类。
- k均值最小化平方误差是 NP 难问题，故采用贪心迭代近似求解；k均值类算法仅在凸形簇结构上效果较好。
- k均值可看作高斯混合聚类在"各成分方差相等且每样本仅指派给一个成分"时的特例。
- 密度聚类中簇定义为"由密度可达关系导出的最大密度相连样本集合"，能自然处理噪声/异常。
- LVQ 可看作 SOM（自组织映射）基于监督信息的扩展，用的是竞争学习"胜者为王"策略。
- 距离度量未必满足所有基本性质（尤其直递性），为特定语义可设计非度量距离；合适的距离也可通过度量学习从数据中学得。
- 聚类不存在客观标准，故新算法层出不穷；异常检测常借助聚类或距离计算（远离所有簇中心或密度极低处即为异常点）。
