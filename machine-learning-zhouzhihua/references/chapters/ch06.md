# 第6章 支持向量机

## 1. 章节核心摘要
本章讨论二分类任务中如何找到"最好"的划分超平面。直观上应取位于两类训练样本"正中间"的超平面，因为该平面对训练局部扰动容忍度最高、最鲁棒，对未见样本的泛化能力最强。这条思路被形式化为"最大间隔"（maximum margin）准则。

核心主线是：先得到硬间隔下的基本型（一个凸二次规划问题），再用拉格朗日乘子法导出对偶问题，从而揭示"支持向量"——只有少量落在间隔边界上的样本决定最终模型，大部分训练样本可丢弃。为处理非线性可分，引入特征空间映射与"核技巧"，将高维内积转化为核函数；为处理线性不可分与噪声，引入软间隔与替代损失，使模型稀疏且容错。

本章还把思想推广到回归任务（支持向量回归 SVR）和一般学习器（核方法、表示定理），并指出核函数选择是 SVM 性能的最大变数，而正则化把"间隔大小"与"训练误差"统一到一个可折中的框架中。

## 2. 关键术语表
- 划分超平面（separating hyperplane）— 在样本空间中将不同类别分开的线性方程 wᵀx + b = 0 所描述的平面；w 为法向量决定方向，b 为位移项决定与原点距离。
- 间隔（margin）— 两个异类支持向量到超平面距离之和，等于 2/‖w‖；最大化间隔是 SVM 的目标。
- 支持向量（support vector）— 距离超平面最近、使间隔约束等号成立的训练样本；最终模型仅由它们决定。
- 最大间隔（maximum margin）— 在正确分类约束下使间隔最大化的准则。
- 基本型（SVM 基本型）— 最小化 1/2‖w‖²、约束为 yᵢ(wᵀxᵢ+b)≥1 的凸二次规划问题。
- 对偶问题（dual problem）— 由拉格朗日乘子法从基本型导出的等价优化问题，变量为样本对应的乘子 aᵢ。
- KKT 条件— 带不等式约束优化问题取最优解需满足的互补松弛等条件；SVM 中体现为 aᵢ=0 或 yᵢf(xᵢ)=1。
- 核函数（kernel function）— 满足 k(xᵢ,xⱼ)=φ(xᵢ)ᵀφ(xⱼ) 的函数，隐式定义高维特征空间，免去直接计算高维内积。
- 核技巧（kernel trick）— 用核函数代替特征空间内积，使算法只需在原空间计算 k(·,·) 即可获得非线性能力。
- 再生核希尔伯特空间（RKHS）— 任一核函数隐式定义的特征空间。
- 半正定核矩阵（kernel matrix）— 以 k(xᵢ,xⱼ) 为元素的矩阵；定理6.1 要求它对任意数据都半正定，这样的对称函数才能作核函数。
- 硬间隔（hard margin）— 要求所有样本都被正确分类、满足间隔约束。
- 软间隔（soft margin）— 允许部分样本不满足间隔约束，以提升容错与泛化。
- 替代损失（surrogate loss）— 用凸、连续且是 0/1 损失上界的函数替代不可微的 0/1 损失，如 hinge、指数、对率损失。
- 松弛变量（slack variable）ξᵢ— 表征第 i 个样本不满足间隔约束程度的非负变量。
- 正则化（regularization）— 在经验风险之外加入结构风险项 Ω(f) 以控制模型复杂度、抑制过拟合；C 为正则化常数。
- 结构风险 / 经验风险— 描述模型性质的项 / 描述与训练数据契合程度的项。
- 支持向量回归（SVR）— 回归版 SVM，允许预测值与真实值有 ε 以内的偏差而不计损失。
- ε-不敏感损失（ε-insensitive loss）— SVR 的损失：仅当 |f(x)−y|>ε 时才计算损失，形成宽度为 2ε 的间隔带。
- 表示定理（representer theorem）— 一大类正则化风险最小化问题的最优解总可写为核函数的线性组合。
- 核方法（kernel methods）— 基于核函数的一系列学习方法统称；"核化"即引入核函数把线性学习器拓展为非线性。
- SMO（Sequential Minimal Optimization）— 高效求解 SVM 对偶的算法：每步只优化两个乘子，有闭式解。

## 3. 关键模型与算法
### 最大间隔划分超平面（硬间隔 SVM 基本型）
- 核心思想：在能正确分类的训练集中，找使两类支持向量到超平面距离之和（间隔）最大的超平面，等价于最小化 ‖w‖²。
- 数学形式/公式：超平面为 wᵀx + b = 0；样本 x 到超平面的距离为 |wᵀx + b|/‖w‖；最大化间隔等价于求解
  min ½‖w‖²，s.t. ∀i，yᵢ(wᵀxᵢ + b) ≥ 1。
  （约束说明：对正类 yᵢ=+1 要求 wᵀxᵢ+b≥1，负类则 ≤−1，间隔为 2/‖w‖。）
- 适用场景：训练样本在原始空间线性可分且噪声较少的二分类。
- 慎用情形/局限：现实数据往往不可分；此时基本型无解，需转用软间隔或核方法。

### 对偶问题与支持向量
- 核心思想：对基本型每条约束加拉格朗日乘子 aᵢ≥0，令 L 对 w、b 偏导为零消去 w、b，得到仅含 aᵢ 的对偶问题。
- 数学形式/公式：对偶为
  max Σaᵢ − ½ΣΣaᵢaⱼyᵢyⱼ(xᵢᵀxⱼ)，
  s.t. aᵢ≥0，Σaᵢyᵢ=0。
  解出 a 后，w=Σaᵢyᵢxᵢ，模型 f(x)=Σaᵢyᵢ(xᵢᵀx)+b。由 KKT 条件：aᵢ=0 的样本对模型无贡献，aᵢ>0 的样本恰落在间隔边界上、是支持向量。
- 适用场景：理论分析与中小规模数据；揭示解仅依赖支持向量。
- 慎用情形/局限：对偶问题规模正比于样本数，通用二次规划开销大，需 SMO 等高效算法；大规模数据仍是瓶颈。

### SMO 算法
- 核心思想：固定除两个乘子 aᵢ、aⱼ 外的所有变量，因等式约束 aᵢ 可由 aⱼ 表出，该两变量优化有闭式解；反复选违背 KKT 最严重的变量对更新直至收敛。
- 数学形式/公式：选一对变量求解单变量二次规划（仅约束 aᵢ>0），b 取所有支持向量求出的均值以更鲁棒。
- 适用场景：高效训练 SVM，尤其是大规模线性/非线性核。
- 慎用情形/局限：非线性核 SVM 时间复杂度理论上不低于 O(m²)，仍受样本量制约。

### 核函数与核技巧
- 核心思想：把样本从原空间映射到高维特征空间使线性可分，但高维内积难算；核技巧用 k(xᵢ,xⱼ)=φ(xᵢ)ᵀφ(xⱼ) 在原空间直接算，模型变为 f(x)=Σaᵢyᵢk(xᵢ,x)+b（支持向量展式）。
- 数学形式/公式：核函数合法性由定理6.1 保证——对称函数 k 是核函数当且仅当对任意数据其核矩阵 K（Kᵢⱼ=k(xᵢ,xⱼ)）总是半正定。常用核：线性核 k=xᵢᵀxⱼ；多项式核 (xᵢᵀxⱼ+1)ᵈ（d=1 退化为线性核）；高斯核/RBF 核 exp(−‖xᵢ−xⱼ‖²/2σ²)；拉普拉斯核；Sigmoid 核。核函数可经线性组合、直积、与函数 g 组合而仍是核。
- 适用场景：原空间线性不可分、需非线性决策边界；文本常用线性核，不明时先试高斯核。
- 慎用情形/局限：核函数选择是最大变数；选错等于把样本映射到不合适的特征空间，性能会显著下降；核矩阵需半正定。

### 软间隔支持向量机
- 核心思想：允许部分样本不满足硬间隔约束，在最大化间隔与最小化违例数之间用常数 C 折中，用替代损失代替 0/1 损失。
- 数学形式/公式：引入松弛变量 ξᵢ≥0，优化目标
  min ½‖w‖² + C·Σξᵢ，
  s.t. yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ，ξᵢ≥0。
  C→∞ 等价硬间隔；C 有限则容错。常用替代损失：hinge ℓ(z)=max(0,1−z)；指数 ℓ(z)=exp(−z)；对率 ℓ(z)=log(1+exp(−z))。其 KKT：aᵢ=C 且 ξᵢ>1 的样本被错分；用 hinge 损失仍保持稀疏性（仅支持向量参与）。
- 适用场景：含噪声或近似线性可分的数据。
- 慎用情形/局限：hinge 损失给出的是无概率意义的判别输出；对率损失则接近对率回归（有概率输出但解不稀疏）。

### 支持向量回归 SVR
- 核心思想：容忍预测值与真实值最多 ε 的偏差，仅当偏差超出 ε 才计损失，形成 2ε 宽的间隔带。
- 数学形式/公式：损失为 ε-不敏感损失（|y−f(x)|−ε 的正部，即 max(0, |y−f(x)|−ε)）；目标
  min ½‖w‖² + C·Σ(ξᵢ+ξᵢ*)，
  s.t. f(xᵢ)−yᵢ ≤ ε+ξᵢ，yᵢ−f(xᵢ) ≤ ε+ξᵢ*，ξ,ξ*≥0。
  解 f(x)=Σ(aᵢ−aᵢ*)k(xᵢ,x)+b；仅落在 ε 带外的样本（支持向量）贡献非零。核化后 k(xᵢ,xⱼ) 同前。
- 适用场景：连续值预测，希望输出稀疏、对小幅误差不敏感。
- 慎用情形/局限：需调 ε 与 C；本质上仍是无概率输出的回归。

### 核方法与表示定理
- 核心思想：表示定理表明，满足"单调递增正则项 + 任意损失"的优化问题，最优解总可写成核函数的线性组合，由此可将线性学习器核化为非线性，如核线性判别分析 KLDA。
- 数学形式/公式：表示定理——h*(x)=Σaᵢk(x,xᵢ)；KLDA 在特征空间中最大化类间/类内散度比，借助核矩阵 K 求解投影方向。
- 适用场景：想把任意线性算法拓展到非线性情形。
- 慎用情形/局限：性能仍由所选核函数决定；核选择未决。

## 4. 应用与决策框架
- 选线性还是非线性：若数据在原始空间近似线性可分，用线性核（文本等高位稀疏数据首选线性核，描述能力强足以"打散"）；若明显非线性、情况不明，先用高斯（RBF）核试探。
- 数据是否干净：噪声多/难完全可分 → 用软间隔（设 C）；几乎无噪声且严格可分 → 硬间隔即可。
- 任务类型：分类用 SVM；回归用 SVR（需设 ε）；多分类需对 SVM 专门推广（如一对多/一对一）。
- 规模考量：线性核可用 SVMperf、Pegasos、坐标下降等达近似线性复杂度；非线性核理论下限 O(m²)，需采样/CVM/低秩 Nyström/随机傅里叶特征等近似。
- 概率需求：若需概率输出，SVM/SVR 本身不提供，须用 Platt 缩放或等分回归校准；否则选对率回归更自然。
- 调参优先级：核函数类型 → 正则化常数 C（或高斯核带宽）→ 软间隔与损失选择。

## 6. 金句与重要结论
- 应取位于两类训练样本"正中间"的划分超平面，因其对局部扰动容忍最好、泛化最强。
- 支持向量机的重要性质：训练完成后大部分训练样本都不需保留，最终模型仅与支持向量有关。
- 间隔貌似仅与 w 有关，但 b 通过约束隐式影响 w，进而影响间隔。
- 核函数仅隐式定义特征空间，核函数选择是 SVM 的最大变数；选错则性能不佳。
- 对率回归与 SVM 优化目标相近、性能相当；区别在概率输出、多分类便利性与稀疏性。
- 使用 hinge 损失仍保持解的稀疏性；对率损失光滑、解依赖更多样本、预测开销更大。
- 正则化可理解为"罚函数法"：Ω(f) 提供模型先验，从贝叶斯估计角度看即先验概率。
- 表示定理表明：核函数的威力在于最优解总可写为核函数的线性组合，且对损失函数与正则项限制极宽。
- 替代损失的一致性：指数损失是 0/1 损失的一致替代（最小化它即最小化错误率）。
