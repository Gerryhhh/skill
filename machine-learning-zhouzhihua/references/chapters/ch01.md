# 第1章 绪论

## 1. 章节核心摘要
本章是全书导论，核心目标是厘清“机器学习是什么”以及“为什么需要机器学习”。机器学习是一门研究如何通过计算手段，利用经验（数据）来改善系统自身性能的学科；其核心产物是“模型”（学习算法的输出），模型能对未见的新样本做出判断。

全书围绕一组基本术语（数据集、示例/样本、属性/特征、标记、学习任务类型等）建立统一语言，并指出机器学习的根本追求是“泛化”能力——即在训练集之外的样本上也能表现良好。

在概念层面，本章把“从样例中学习”刻画为在“假设空间”中搜索与训练集一致的假设，多个一致的假设构成“版本空间”；学习算法必须有“归纳偏好”才能在多个等效假设中确定唯一模型。

最后，本章通过“没有免费的午餐”（NFL）定理郑重提醒：脱离具体问题的前提下，所有学习算法的期望性能相同。谈论算法优劣必须结合具体问题，归纳偏好与问题是否匹配决定了实际性能。

## 2. 关键术语表
- 机器学习（machine learning）— 研究如何通过计算的手段利用经验（数据）改善系统性能，主要内容是从数据中产生“模型”的“学习算法”。
- 模型（model）/学习器（learner） — 从数据中学得的结果；学习算法在给定数据和参数空间上的实例化。
- 数据集（data set） — 记录的集合；每条记录描述一个事件/对象。
- 示例（instance）/样本（sample） — 数据集中的一条记录；在属性空间中是一个“特征向量”。
- 属性（attribute）/特征（feature） — 描述对象某方面的事项（如色泽、根蒂、敲声）。
- 属性值（attribute value） — 属性上的取值（如青绿、乌黑）。
- 属性空间/样本空间/输入空间 — 属性张成的空间。
- 特征向量（feature vector） — 示例在属性空间中的坐标向量。
- 维数（dimensionality） — 描述示例所用的属性个数 d。
- 训练（training）/学习（learning） — 从数据中学得模型的过程。
- 训练集（training set）/训练样本 — 训练过程中使用的数据及其中每个样本。
- 假设（hypothesis） — 学得模型对应的关于数据潜在规律的猜测；潜在规律本身称“真相/真实”（ground-truth）。
- 标记（label） — 关于示例结果的信息（如“好瓜”）。
- 样例（example） — 拥有标记信息的示例，记为 (x, y)。
- 标记空间/输出空间 — 所有标记的集合。
- 分类（classification） — 预测离散值；二分类（正类/反类）、多分类。
- 回归（regression） — 预测连续值（标记空间为实数集）。
- 聚类（clustering） — 将样本分成若干组（簇），训练样本通常无标记。
- 监督学习（supervised learning） — 训练数据有标记（分类、回归）；亦称“有导师学习”。
- 无监督学习（unsupervised learning） — 训练数据无标记（聚类）；亦称“无导师学习”。
- 泛化（generalization） — 学得模型适用于新样本的能力。
- 分布（distribution）/独立同分布（i.i.d.） — 假设样本服从未知分布，且每个样本独立同分布采样。
- 归纳（induction）/演绎（deduction） — 特殊到一般的“泛化”过程 / 一般到特殊的“特化”过程。
- 归纳学习（inductive learning） — “从样例中学习”，属归纳过程；狭义指概念学习。
- 假设空间（hypothesis space） — 所有可能假设组成的空间；搜索目标为与训练集“匹配”的假设。
- 版本空间（version space） — 与训练集一致（对所有训练样本判断正确）的假设集合。
- 归纳偏好（inductive bias）/偏好 — 学习算法对学习过程中某种类型假设的偏好，使其能产生确定结果。
- 奥卡姆剃刀（Occam's razor） — “若有多个假设与观察一致，则选最简单的那个”。
- 没有免费的午餐定理（NFL 定理）— 在所有问题同等重要、机会相同的假设下，任意两学习算法的期望性能相同。
- 连接主义/符号主义/统计学习 — 三条主流技术路线（神经网络 / 决策树与逻辑 / SVM 与核方法）。

## 3. 关键模型与算法
### 假设空间搜索（概念学习）
- 核心思想：把学习看成在假设空间中搜索与训练集匹配的假设；假设表示一旦确定，假设空间及其规模就确定。以西瓜“好瓜”为例，假设形如“（色泽=?）∧（根蒂=?）∧（敲声=?）”，每个属性可取具体值、通配符“*”（任意值），以及极端假设“∅”（好瓜概念不成立）。
- 数学形式/公式：若三个属性分别有 3、3、3 种可能取值，则假设空间规模 = 4×4×4 + 1 = 65（每个属性“具体值数量+通配符”共4种选择，乘积累加后加 1 个 ∅ 假设）。搜索可自顶向下（从一般到特殊）或自底向上（从特殊到一般），过程中删除与正例不一致和/或与反例一致的假设。
- 适用场景：理解“从样例中学习”的基本机制、布尔概念学习。
- 慎用情形/局限：现实问题假设空间巨大，且基于有限训练样本常存在多个一致假设（版本空间），需归纳偏好才能确定模型；对含噪声数据，可能不存在与全部训练样本一致的假设。

### 归纳偏好（奥卡姆剃刀作为选择原则）
- 核心思想：当版本空间含多个与训练集一致的假设时，学习算法必须凭借自身偏好（如对“平滑曲线”“更特殊/更一般”的偏好）确定唯一模型。
- 数学形式/公式：无显式统一公式；作为启发式原则，奥卡姆剃刀主张选“描述最简单”的假设（如更平滑的曲线 A 比崎岖的曲线 B 更简单）。但“简单”的界定本身困难，且奥卡姆剃刀并非唯一可行原则（如伊壁鸠鲁“多释原则”保留所有一致假设，与集成学习更吻合）。
- 适用场景：在等效假设间做选择、为学习算法确立“价值观”。
- 慎用情形/局限：归纳偏好是否与问题本身匹配，在大多数情况下直接决定算法性能；脱离具体问题谈偏好优劣无意义。

### “没有免费的午餐”定理（NFL 定理）
- 核心思想：在所有问题同等重要、机会相同的假设下，无论算法多聪明，其期望性能与“随机胡猜”相同。
- 数学形式/公式（以二分类、分类错误率为性能度量、样本空间与假设空间均离散为例）：
  - 算法 a 基于训练数据 X 产生假设 h 的概率为 P(h|X, a)；a 在训练集外所有样本上的误差（式 1.1）为对各未见过样本 x 的指示函数 Ⅱ(h(x)≠f(x)) 在假设与数据上的期望求和。
  - 对所有可能的真实目标函数 f 按均匀分布求误差和（式 1.2），结果“与学习算法无关”。
  - 因此对任意两算法 a、b 均有：总误差期望相同，即 E_a = E_b。
- 适用场景：提醒研究者/实践者不能空泛地比较“哪个算法更好”。
- 慎用情形/局限：NFL 的前提是“所有问题机会均等、同等重要”，而现实中我们只关心手头具体问题；真实目标函数分布并非均匀，因此算法优劣必须针对具体问题评判。

## 4. 应用与决策框架
本章以“建立认知框架”为主，不直接给出选型算法，但可归纳为以下判断步骤：
1. 明确任务类型：根据预测输出是否为标记信息，区分监督学习（分类/回归）与无监督学习（聚类）。
2. 明确预测目标：离散值 → 分类（二分类/多分类）；连续值 → 回归；无标记的分组 → 聚类。
3. 意识到“泛化”是目标：所选方法与模型必须追求在新样本上的表现，而非仅拟合训练集。
4. 承认算法需要归纳偏好：选用或设计学习算法时，应使其归纳偏好与待解决问题的内在规律相匹配（这是后续各章模型设计的核心考量）。
5. 警惕“无免费午餐”：不要泛泛相信“某算法永远最优”，应在具体任务上通过实验评估来选型（评估方法见第2章）。

## 6. 金句与重要结论
- “机器学习正是这样一门学科，它致力于研究如何通过计算的手段，利用经验来改善系统自身的性能。”
- 机器学习的“经验”通常以“数据”形式存在；主要内容是“从数据中产生模型的算法”，即学习算法。
- 学习的目标是使学得的模型能很好地适用于“新样本”，这一能力称为“泛化”能力。
- 通常假设样本空间中全体样本服从一个未知“分布”，且“独立同分布”（i.i.d.）采样；训练样本越多，越可能获得强泛化能力的模型。
- “从样例中学习”显然是一个归纳过程，亦称“归纳学习”。
- 任何一个有效的机器学习算法必有其归纳偏好，否则无法产生确定的学习结果。
- “若有多个假设与观察一致，则选最简单的那个。”（奥卡姆剃刀）
- “没有免费的午餐”定理：无论学习算法 a 多聪明、b 多笨拙，它们的期望性能竟然相同。
- NFL 最重要的寓意：脱离具体问题空泛地谈论“什么学习算法更好”毫无意义；归纳偏好与问题是否相配，往往起决定性作用。
- 深度学习（狭义即“很多层的神经网络”）在“数据大了、计算能力强了”两个条件成熟时焕发活力。
