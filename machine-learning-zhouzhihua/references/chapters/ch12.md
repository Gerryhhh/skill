# 第12章 计算学习理论

## 1. 章节核心摘要

计算学习理论研究"通过计算得到学习"的理论基础，目标是分析学习任务的困难本质、为学习算法提供理论保证，并指导算法设计。本章聚焦二分类问题，假定样本独立同分布（i.i.d.）地从隐含未知分布 𝒟 上采样，核心关注经验误差与泛化误差之间的逼近程度。

主线是：先用 PAC（概率近似正确）框架抽象刻画"以较大概率学到误差满足预设上限的模型"这一机器学习能力，再分别研究有限假设空间和无限假设空间下"需要多少样本才能学好"这一样本复杂度问题。

最重要的方法论结论是：有限假设空间都是 PAC 可学习的；对无限假设空间，可用 VC 维度量其复杂度，且任何 VC 维有限的假设空间都是（不可知）PAC 可学习的；Rademacher 复杂度与稳定性分析提供了更紧、且与具体数据分布/算法相关的泛化误差界。

全章贯穿一个核心定量关系：学习算法的泛化能力由"假设空间复杂度 × 样本量"共同决定，误差界随样本量 m 以 O(1/√m) 的速率收敛到 0。

## 2. 关键术语表

- **计算学习理论（computational learning theory）**：研究机器学习理论基础的学科，分析学习任务困难本质并提供理论保证。
- **PAC 学习（Probably Approximately Correct）**：概率近似正确学习框架；"概率"指以较大置信度(1−δ)，"近似正确"指误差不超过预设上限 ε。
- **泛化误差 E(h; 𝒟)**：假设 h 在分布 𝒟 上的真实误分类概率，等于经验误差的期望。
- **经验误差 Ê(h; D)**：假设 h 在训练集 D 上的平均误分类率。
- **概念（concept）c**：从样本空间到标记空间的映射，决定示例真实标记；目标概念即真实映射。
- **概念类 C**：所有希望学得的目标概念构成的集合。
- **假设空间 ℋ**：学习算法考虑的所有可能概念的集合；假设 h 是其中元素。
- **可分 / 一致（separable / consistent）**：目标概念 c∈ℋ，存在假设能把所有示例完全分开。
- **不可分 / 不一致（non-separable）**：c∉ℋ，无任何假设能完全正确分开。
- **误差参数 ε**：预设的学得模型应满足的泛化误差上限。
- **置信度 1−δ**：对"学到误差≤ε 的模型"这一结论的把握程度。
- **样本复杂度（sample complexity）**：满足 PAC 学习所需的最少样例数 m。
- **恰 PAC 可学习（properly PAC learnable）**：假设空间与概念类完全相同，即 ℋ=C。
- **不可知学习（agnostic learning）**：目标概念 c∉ℋ 时，退而求 ℋ 中泛化误差最小假设的 ε-近似。
- **增长函数 Π_ℋ(m)**：假设空间 ℋ 对 m 个示例所能赋予标记的最大可能结果数，描述 ℋ 的表示能力。
- **对分（dichotomy）**：二分类问题中，ℋ 中假设对示例集赋予标记的一种可能结果。
- **打散（shattering）**：若 ℋ 能实现示例集 D 上的所有 2^|D| 种对分，则称 D 被 ℋ 打散。
- **VC 维（Vapnik-Chervonenkis dimension）**：能被 ℋ 打散的最大示例集的大小 d，记为 VC(ℋ)=d。
- **Sauer 引理**：若 VC 维为 d，则增长函数满足 Π_ℋ(m) ≤ Σ_{i=0}^{d} C(m,i)，当 m≥d 时上界约为 (em/d)^d。
- **Rademacher 复杂度**：以 Rademacher 随机变量（±1 等概率）度量假设空间与随机噪声的相关程度，刻画 ℋ 的表示能力。
- **经验 Rademacher 复杂度**：固定样本集 Z 上，ℋ 与随机噪声相关性的期望上确界。
- **稳定性（stability）**：算法输入（训练集）发生微小变化时，输出假设变化不大的性质。
- **β-均匀稳定性**：对任意单样本改变，学习算法的损失变化不超过 β。
- **ERM（经验风险最小化）原则**：学习算法输出经验误差（经验损失）最小的假设。
- **合（disagreement）**：两个映射在样本集上预测不一致的程度。

## 3. 关键模型与算法

### PAC 学习框架（定义12.1–12.4）

- **核心思想**：不以"精确学到目标概念"为目标，而是以较大概率学到"误差不超过 ε"的近似模型。分别定义 PAC 辨识、PAC 可学习、PAC 学习算法（运行时间也为多项式）、样本复杂度。
- **数学形式/公式**：对 0<ε,δ<1，所有 c∈C 与分布 𝒟，若存在学习算法 ℒ 使输出假设 h∈ℋ 满足 P(E(h)≤ε) ≥ 1−δ，则称 ℒ 能从 ℋ 中 PAC 辨识 C。概念类 C 是 PAC 可学习的，当存在多项式 poly(1/ε, 1/δ, size(x), size(c))，使任何 m≥该多项式时都能 PAC 辨识；若运行时间也是多项式则称高效 PAC 可学习。
- **适用场景**：作为抽象框架，用于讨论"某任务在什么条件下可学、需多少样本"。
- **慎用情形/局限**：PAC 框架仅给出存在性/上界，不直接给出具体算法的设计；对分布无关的分析往往偏松。

### 有限假设空间的泛化误差界（定理12.1）

- **核心思想**：对有限 ℋ，用 Hoeffding 不等式与并集界，说明"经验误差是泛化误差的好近似"。
- **数学形式/公式**：不可分情形（c∉ℋ），对任意 h∈ℋ，以至少 1−δ 概率有 E(h) ≤ Ê(h) + sqrt( (ln|ℋ| + ln(2/δ)) / (2m) )。可分情形（c∈ℋ）所需样例数约为 m ≥ (1/ε)(ln|ℋ| + ln(1/δ))，收敛速率 O(1/m)。
- **适用场景**：假设空间有限时直接估计所需样本量。
- **慎用情形/局限**：现实任务多为无限假设空间，无法直接套用；需借助 VC 维等工具。

### VC 维与基于 VC 维的泛化误差界（定理12.2、12.3）

- **核心思想**：用 VC 维度量无限假设空间的复杂度，得到分布无关、数据独立的泛化误差界。
- **数学形式/公式**：若 ℋ 的 VC 维为 d，对任意 m>d、0<δ<1、h∈ℋ，以至少 1−δ 概率有 E(h) ≤ Ê(h) + 上界项，其中上界项约为 sqrt( (d(ln(2m/d)+1) + ln(4/δ)) / m )。该界仅与 m、d、δ 有关，与分布 𝒟 和具体样本集 D 无关；收敛速率约 O(√(d/m))。
- **适用场景**：分析线性分类器、神经网络等无限假设空间的可学习性；如二维线性划分 VC 维=3、d 维线性超平面 VC 维=d+1。
- **慎用情形/局限**：界偏松（未考虑数据分布）；VC 维可能很大（决策树、最近邻分类器 VC 维可无穷大）。

### 不可知 PAC 可学习（定义12.5）

- **核心思想**：当 c∉ℋ 时，把目标改为输出 ℋ 中近似最优（泛化误差最小）假设。
- **数学形式/公式**：以至少 1−δ 概率输出 h 满足 E(h) ≤ min_{h'∈ℋ} E(h') + ε。定理12.4：任何 VC 维有限的 ℋ 都是不可知 PAC 可学习的（以 ERM 算法即可）。
- **适用场景**：现实中有偏假设空间下的学习保证。
- **慎用情形/局限**：同样依赖 VC 维有限这一前提。

### Rademacher 复杂度与泛化误差界（定理12.5、12.6、12.7）

- **核心思想**：用假设空间与随机噪声的相关性刻画复杂度，考虑了数据分布，通常得到比 VC 维更紧的界。
- **数学形式/公式**：经验 Rademacher 复杂度 R_m(ℋ) = E_σ[ sup_{h∈ℋ} (1/m) Σ_i σ_i h(x_i) ]，其中 σ_i 以 0.5 概率取 ±1。二分类下有以至少 1−δ 概率成立的界 E(h) ≤ Ê(h) + 2R_m(ℋ) + sqrt( ln(2/δ)/(2m) )。Rademacher 复杂度还与增长函数满足 R_m(ℋ) ≤ sqrt( (2ln(2Π_ℋ(m)))/m )，由此可推导出 VC 维界。
- **适用场景**：需要更紧误差界或分析具体数据分布相关的问题时。
- **慎用情形/局限**：计算/估计 Rademacher 复杂度本身并不容易；定理12.5 对实值函数空间 [0,1] 适用（回归），二分类用定理12.6。

### 稳定性分析与泛化误差界（定义12.10、定理12.8、12.9）

- **核心思想**：不依赖假设空间整体复杂度，而从"算法自身是否稳定"出发推导泛化界，可与具体算法挂钩。
- **数学形式/公式**：若算法满足 β-均匀稳定性且损失有界 M，则对任意 m≥1，以至少 1−δ 概率有 泛化损失 − 经验损失 ≤ 2β + (M/2)·sqrt( ln(1/δ)/m )（收敛速率 O(1/√m)）。定理12.9：若学习算法是 ERM 且稳定的，则假设空间可学习。
- **适用场景**：分析具体学习算法（而非整个假设空间）的泛化行为。
- **慎用情形/局限**：要求算法确实稳定（β→0）；并非所有算法都显然满足均匀稳定性。

## 4. 应用与决策框架

何时用本章哪种分析工具，可按如下决策步骤：

1. **判断假设空间是否有限**：
   - 有限 ℋ → 直接用定理12.1（基于 |ℋ| 的样本复杂度公式）估算所需样本量。
   - 无限 ℋ → 进入步骤 2。
2. **是否需要分布无关的普适保证**：
   - 是 → 计算 ℋ 的 VC 维，用定理12.3 的 VC 维泛化误差界（分布无关、偏松）。
   - 否，希望更紧的界 → 进入步骤 3。
3. **能否刻画具体数据分布**：
   - 能 → 估计 Rademacher 复杂度，用定理12.5/12.6（更紧、分布相关）。
   - 关注具体算法本身 → 进入步骤 4。
4. **分析具体学习算法**：
   - 验证算法是否满足 β-均匀稳定性 → 用定理12.8 的稳定性泛化界；若 ERM 且稳定则保证可学习（定理12.9）。

**对照表**

| 方法 | 依赖对象 | 是否依赖分布 | 误差界松紧 | 典型收敛率 |
|---|---|---|---|---|
| 有限 ℋ | |ℋ| | 否 | 中等 | O(1/m)（可分）|
| VC 维 | d=VC(ℋ) | 否（分布无关） | 偏松 | O(√(d/m)) |
| Rademacher | 数据分布 | 是 | 较紧 | O(1/√m) |
| 稳定性 | 算法 β | 否（对损失） | 较紧 | O(1/√m) |

## 5. 典型案例/例题要点

- **例12.1 实数域闭区间假设空间**：ℋ={h_{[a,b]}: a≤b}，即"落在某区间内判正、否则判负"。存在 2 个示例可被打散（VC 维至少为 2）；但任意 3 个示例 x3<x4<x5 无法实现 {+,−,+} 这种对分（被区间连续性限制），故 VC 维 = 2。
- **例12.2 二维实平面线性划分**：存在 3 个示例可被所有线性划分打散，但不存在 4 个示例能被打散（经典结论：d 维线性超平面 VC 维 = d+1），故二维线性划分 VC 维 = 3。
- **增长函数与 Sauer 引理**：VC 维 d 直接限制了 ℋ 对 m 个示例的标记能力，Π_ℋ(m) 当 m≥d 时上界约 (em/d)^d，是把 VC 维转化为泛化界的关键桥梁。
- **习题要点**：证明决策树、最近邻分类器 VC 维可为无穷大——说明这些强表达力模型需要其他手段（如正则化、稳定性）来控制泛化。

## 6. 金句与重要结论

- PAC 之名："概率"指以较大置信度学到模型，"近似正确"指误差不超过预设上限 ε——我们不追求精确学到目标概念，因为有限样本与采样偶然性使"等效假设"不可区分。
- 有限假设空间都是 PAC 可学习的，所需样例数随 |ℋ| 对数增长、随 1/ε 线性增长，泛化误差收敛速率为 O(1/m)。
- 任何 VC 维有限的假设空间都是（不可知）PAC 可学习的；VC 维是刻画无限假设空间复杂度的核心工具。
- 基于 VC 维的泛化误差界是分布无关、数据独立的，因此具有普适性但往往偏松。
- 基于 Rademacher 复杂度的泛化误差界与具体学习问题的数据分布相关，类似"量身定制"，通常比 VC 维界更紧；且可由它推导出 VC 维界。
- 经验误差是泛化误差的良好近似——样本越多，二者越接近（收敛速率均为 O(1/√m)）。
- 若学习算法是 ERM 且稳定的，则假设空间可学习：可学习性可由算法稳定性保证。
- 决策树、最近邻分类器等表达能力过强的模型 VC 维可为无穷大，需借助稳定性/正则化等手段控制泛化。
