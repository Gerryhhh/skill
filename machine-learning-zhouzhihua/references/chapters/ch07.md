# 第7章 贝叶斯分类器

## 1. 章节核心摘要
本章在概率框架下讨论分类决策。贝叶斯决策论指出：在已知所有相关概率的理想情形下，最优类别标记是使"条件风险"最小的那个，对应的分类器称为贝叶斯最优分类器，其风险（贝叶斯风险）是机器学习精度的理论上限。

核心难点是现实无法直得后验概率 P(c|x)。由此分两路：判别式模型直接建模 P(c|x)；生成式模型先建模联合 P(x,c) 再求后验。本章重点在生成式一路，用贝叶斯定理把问题化为估计类先验 P(c) 与类条件概率（似然）P(x|c)。

为绕过 P(x|c) 这个全属性联合概率在有限样本下无法估计的困境，引出属性条件独立性假设 → 朴素贝叶斯；放松该假设 → 半朴素贝叶斯（独依赖 ODE、TAN、AODE）；完全刻画属性依赖 → 贝叶斯网（结构与评分搜索、推断与吉布斯采样）；并在存在未观测变量时给出 EM 算法做参数与隐变量估计。

## 2. 关键术语表
- 贝叶斯决策论（Bayesian decision theory）— 概率框架下基于后验概率与误判损失选择最优类别的基本方法。
- 条件风险（conditional risk）R(c|x)— 把样本 x 判为 c 的期望损失；多分类下为对各类误判损失的加权和。
- 贝叶斯最优分类器（Bayes optimal classifier）— 每个样本选使条件风险最小的类别；总体风险称为贝叶斯风险。
- 风险（risk）/期望损失— 决策论中对"期望损失"的称呼；1−R(h*) 反映分类器可达的最好性能（精度理论上限）。
- 误判损失 λᵢⱼ— 把真实为 cⱼ 的样本错分为 cᵢ 所产生的损失。
- 判别式模型（discriminative models）— 直接建模 P(c|x) 预测类别，如决策树、BP 网络、SVM。
- 生成式模型（generative models）— 先建模联合 P(x,c) 再得后验，如朴素贝叶斯、贝叶斯网。
- 先验（prior）P(c)— 类"先验"概率，各类样本在空间中比例。
- 似然（likelihood）P(x|c)— 类条件概率，样本 x 相对于类 c 的条件概率。
- 证据（evidence）P(x)— 归一化因子，与类标记无关。
- 极大似然估计（MLE）— 频率主义学派方法：选使训练数据出现"可能性"最大的参数值。
- 属性条件独立性假设— 朴素贝叶斯的核心假设：已知类别时所有属性相互独立。
- 拉普拉斯修正（Laplacian correction）— 平滑技术，避免未观测属性值使概率估为 0；本质引入均匀先验。
- 半朴素贝叶斯分类器— 放松独立性假设、仅考虑部分属性依赖的方法族。
- 独依赖估计（ODE）— 假设每个属性在类别之外最多依赖一个其他属性（父属性）。
- SPODE / TAN / AODE— 独依赖分类器的代表：超父 ODE / 树增强贝叶斯 / 平均独依赖估计（集成式）。
- 贝叶斯网（Bayesian network）/信念网— 用有向无环图刻画属性依赖、用条件概率表描述联合分布的概率图模型。
- 有向分离（D-separation）/道德图（moral graph）/道德化— 分析有向图中条件独立性的工具；把 V 型结构的父节点相连、有向边改无向得到道德图。
- 最小描述长度（MDL）/ AIC / BIC— 贝叶斯网结构学习的评分函数（基于信息论编码长度）。
- 推断（inference）/证据（evidence）— 用已知变量观测值推测待查询变量；已知观测称证据。
- 精确推断 / 近似推断— 直接算后验（NP 难）vs 吉布斯采样等近似方法。
- 吉布斯采样（Gibbs sampling）— 在联合状态空间随机漫步、依平稳分布近似后验的马尔可夫链方法。
- 隐变量（latent variable）— 未观测到的变量；EM 算法用于含隐变量的参数估计。
- EM 算法（Expectation-Maximization）— 迭代：E 步算隐变量分布期望、M 步最大化期望似然，直至收敛。

## 3. 关键模型与算法
### 贝叶斯决策论与最优分类器
- 核心思想：以最小化总体风险为目标；每样本选条件风险最小的类。若最小化错误率（0/1 损失），最优分类器即选后验概率最大的类。
- 数学形式/公式：条件风险 R(c|x)=Σⱼ λᵢⱼ P(cⱼ|x)；贝叶斯判定准则 h*(x)=argmin_c R(c|x)。错误率目标下 λᵢⱼ=0(i=j) 否则 1，有 R(c|x)=1−P(c|x)，故 h*(x)=argmax_c P(c|x)。由贝叶斯定理 P(c|x)=P(x|c)P(c)/P(x)。
- 适用场景：概率已知时的理论最优决策；作为一切分类器的性能上界参考。
- 慎用情形/局限：现实往往拿不到真实后验；很多算法不需精确后验也能准确分类。

### 极大似然估计（MLE）
- 核心思想：频率主义视角，假定类条件概率有确定分布形式、由参数 θ_c 唯一确定，用训练数据估计 θ_c。
- 数学形式/公式：对数似然 LL(θ_c)=Σ_{x∈D_c} log P(x|θ_c)，取使 LL 最大的 θ_c。例：连续属性假定高斯分布时，均值估计=样本均值，方差估计=样本偏差平方均值（符合直觉）。
- 适用场景：参数化地估计类条件概率，分布形式已知或可信假设下。
- 慎用情形/局限：估计准确性严重依赖所假设的分布是否符合真实数据；猜错分布形式会误导。

### 朴素贝叶斯分类器
- 核心思想：用属性条件独立性假设把联合 P(x|c) 拆成各属性条件概率之积，从而可用有限样本估计。
- 数学形式/公式：P(c|x) ∝ P(c)·Π_{i=1}^d P(x_i|c)；判别 h(x)=argmax_c P(c)·Π_i P(x_i|c)。先验 P(c)=|D_c|/|D|；离散属性 P(x_i|c)=|D_{c,x_i}|/|D_c|；连续属性常假设高斯分布 p(x_i|c)~N(μ_{c,i},σ²_{c,i})。实践中常取对数把连乘转连加以防下溢。
- 适用场景：高维、尤其是文本分类；预测速度要求高时可将概率预计算"查表"。
- 慎用情形/局限：独立性假设常不成立；某属性值未在类中出现会使整项概率为 0、抹去其他属性信息——须用拉普拉斯修正：分子加 1、分母加类别数 N（及属性取值数 N_i）。

### 半朴素贝叶斯分类器（ODE / SPODE / TAN / AODE）
- 核心思想：放松独立性，假设每个属性最多依赖一个父属性（独依赖），既避免完全联合估计又保留较强依赖。
- 数学形式/公式：P(c|x) ∝ P(c)·Π_i P(x_i|c,pa_i)，pa_i 为父属性。SPODE 选单一超父（交叉验证定）；TAN 用最大带权生成树（边权=条件互信息 I(x_i,x_j|y)）约简为树形；AODE 把每个属性都当超父构建 SPODE 再集成：仅保留训练样本足够的 SPODE，形成基于集成机制的分类器。
- 适用场景：属性间存在部分相关、朴素贝叶斯假设偏差较大时，常能提升泛化。
- 慎用情形/局限：依赖关系需估计，k 阶依赖随 k 增大所需样本指数级增加，有限样本下高阶依赖反陷入估计泥沼。

### 贝叶斯网（结构与学习）
- 核心思想：用有向无环图表达属性依赖，每个结点条件依赖于其父结点集 π_i；联合分布 = Π_i P(x_i|π_i)。
- 数学形式/公式：B=(G,θ)；联合 P(x_1..x_d)=Π_i P(x_i|π_i)。条件独立性由结构决定，可用"有向分离/道德图"分析（同父、顺序、V 型三类典型结构）。学习用评分搜索：s(B|D)=f(θ)|B| − LL(B|D)，|B| 为参数个数、LL 为对数似然；f(θ)=1 得 AIC、f(θ)=½log m 得 BIC，f=0 退化为负对数似然（即极大似然）。结构搜索是 NP 难，常用贪心或加约束（如限定树形）。
- 适用场景：需可解释的概率依赖建模、不确定性推理。
- 慎用情形/局限：精确结构学习 NP 难；稠密网络推断 NP 难，需近似推断。

### 贝叶斯网推断与吉布斯采样
- 核心思想：训练好后用已知证据变量推测查询变量；精确推断 NP 难，常用吉布斯采样近似。
- 数学形式/公式：目标 P(Q=q|E=e)；吉布斯采样从与证据一致的一个样本出发，每步对非证据变量按当前其余变量状态的条件概率逐个重采样，经 T 步后近似 P(Q=q|E=e)≈ n_q/T（n_q 为与 q 一致的采样数）。马尔可夫链 t→∞ 收敛到平稳分布 P(Q|E=e)。
- 适用场景：网络结点多、连接稠密时求近似后验。
- 慎用情形/局限：收敛慢；若网络存在极端概率 0 或 1，马尔可夫链可能无平稳分布，给出错误估计。

### EM 算法
- 核心思想：含未观测（隐）变量时，交替进行 E 步（基于当前参数推断隐变量分布期望）与 M 步（最大化期望似然来更新参数），直至收敛到局部最优。
- 数学形式/公式：最大化边际对数似然 LL(θ|X)=log Σ_z P(X,z|θ)。E步：计算 Q(θ|θ^t)=E_{z|X,θ^t}[log P(X,z|θ)]；M步：θ^{t+1}=argmax_θ Q(θ|θ^t)。可视为坐标下降最大化对数似然下界。
- 适用场景：隐变量/不完整样本的参数估计，如高斯混合模型（GMM）、含缺失属性的贝叶斯网。
- 慎用情形/局限：只保证收敛到局部最优；梯度法因隐变量求和项指数级爆炸而难用，EM 是非梯度优化利器但起点敏感。

## 4. 应用与决策框架
- 选判别式还是生成式：若只需预测类别、且训练数据充分，决策树/BP/SVM 等判别式常更直接；若需建模数据生成机制、做推断或处理缺失/隐变量，选贝叶斯生成式路线。
- 属性依赖强弱：属性近乎独立 → 朴素贝叶斯（高效、文本常用）；依赖较强 → 半朴素（TAN/AODE）或贝叶斯网。
- 样本量：充足 → 可用高阶依赖；有限 → 止步于独依赖，避免联合概率稀疏。
- 零值/下溢处理：必须做拉普拉斯修正防概率为 0；高维时用对数概率防下溢。
- 预测效率：高实时要求可预计算概率查表；频繁更替数据用懒惰学习；流式数据用增量计数修正。
- 结构学习（贝叶斯网）：用 AIC/BIC/MDL 评分搜索，受 NP 难限制时采用贪心或限定结构（如树形）。
- 隐变量/缺失：用 EM 迭代估计；注意初始值与局部最优。

- 西瓜数据集3.0 朴素贝叶斯示例：测1（青绿、蜷缩、浊响、清晰、凹陷、硬滑、密度0.697、含糖0.460）下算 P(好瓜=是)×各条件概率 ≈0.063，P(好瓜=否)×… ≈6.8×10⁻⁵，判为"好瓜"。

## 6. 金句与重要结论
- 1−R(h*) 反映分类器所能达到的最好性能，即通过机器学习所产生的模型精度的理论上限。
- 很多机器学习技术无须准确估计出后验概率就能准确进行分类。
- 朴素贝叶斯分类器在很多情形下都能获得相当好的性能——只要各类别条件概率排序正确、或属性依赖影响可相互抵消，独立性假设就不会损害性能。
- 拉普拉斯修正本质假设了属性值与类别均匀分布，是在学习过程中额外引入的关于数据的先验。
- 贝叶斯分类器谱：朴素贝叶斯（无依赖）与贝叶斯网（任意依赖）位于两端，半朴素贝叶斯居中。
- 贝叶斯网结构学习是 NP 难；精确推断也是 NP 难，需近似推断。
- 贝叶斯分类器（最大后验单点估计）与"贝叶斯学习"（分布估计）有显著区别。
- EM 算法可看作用坐标下降法最大化对数似然下界，是非梯度优化方法。
- 朴素贝叶斯与 EM 算法均曾入选"数据挖掘十大算法"。
