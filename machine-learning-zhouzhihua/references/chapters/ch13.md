# 第13章 半监督学习

## 1. 章节核心摘要

半监督学习研究如何在不依赖外界交互的情况下，自动利用大量廉价"未标记样本"来提升学习性能——典型场景是"有标记数据少、未标记数据多"。核心前提：未标记样本与有标记样本须从同一数据源独立同分布采样，其所揭示的数据分布信息对建模有益。

主线是：利用未标记样本必须建立在"未标记数据分布与类别标记相联系"的假设上，最常用的是聚类假设（同簇同类别）与流形假设（流形上邻近样本输出相似），二者本质都是"相似样本拥有相似输出"。在此基础上，本章系统介绍四大范型：生成式方法、半监督 SVM、图半监督学习、基于分歧的方法，以及半监督聚类。

最重要结论是：未标记样本并非必然提升性能——生成式方法若模型假设不准、半监督 SVM 若陷入错误低密度划分，利用未标记数据反而会降低泛化；因此半监督学习的效果高度依赖假设的正确性。

## 2. 关键术语表

- **未标记样本（unlabeled）**：类别标记未知的样本，数量 u 远大于有标记样本数 l（l≪u）。
- **有标记样本（labeled）**：类别标记已知的样本，记作 D_l。
- **半监督学习（semi-supervised learning）**：利用未标记样本自动提升学习性能的学习范式。
- **主动学习（active learning）**：通过与专家交互，挑选"对改善模型最有帮助"的样本查询标记，用最少查询获最好性能（引入额外专家知识）。
- **聚类假设（cluster assumption）**：数据存在簇结构，同一簇的样本属于同一类别。
- **流形假设（manifold assumption）**：数据分布在一个流形结构上，邻近样本拥有相似输出；可看作聚类假设的推广，适用范围更广。
- **纯半监督学习（pure semi-supervised）**：假设未标记样本不是待预测数据，目标模型适用于训练时未观察到的数据（开放世界）。
- **直推学习（transductive learning）**：假设未标记样本恰是待预测数据，只求在这些样本上最优（封闭世界）。
- **生成式方法（generative methods）**：假设所有数据由同一潜在生成式模型产生，未标记数据的标记看作缺失参数，用 EM 算法求解。
- **低密度分隔（low-density separation）**：半监督 SVM 的基本假设——划分超平面应穿过数据低密度区域（聚类假设在线性划分上的推广）。
- **TSVM（Transductive SVM）**：最著名的半监督 SVM，针对二分类，对未标记样本尝试各种标记指派并最大化间隔。
- **伪标记（pseudo-label）**：未标记样本被算法赋予的临时标记，用于迭代训练。
- **图半监督学习**：把数据集映射为图，标记作为"颜色"在图上扩散/传播。
- **亲和矩阵（affinity matrix）W**：图的边权矩阵，常基于高斯函数 W_ij=exp(−‖x_i−x_j‖²/(2σ²)) 定义。
- **拉普拉斯矩阵（Laplacian matrix）Δ**：Δ=D−W，D 为度对角矩阵。
- **标记传播（label propagation）**：基于图的能量最小化/迭代传播，将已知标记扩散到未标记样本。
- **基于分歧的方法（disagreement-based methods）**：用多学习器，以学习器之间的"分歧"来利用未标记数据。
- **协同训练（co-training）**：多视图数据的代表方法，两个视图分别训练分类器、互相提供高置信度伪标记。
- **多视图（multi-view）**：一个对象拥有多个属性集（如电影的图像、声音视图），各视图具相容性与互补性。
- **充分且条件独立视图**：每个视图单独含足量信息，且在给定标记下两视图独立（协同训练强理论保证的前提）。
- **半监督聚类（semi-supervised clustering）**：利用少量监督信息（必连/勿连约束或有标记种子）改善聚类。
- **必连（must-link）/ 勿连（cannot-link）**：约束样本必属同簇 / 必不属同簇。
- **约束 k-means / 约束种子 k-means**：将监督信息融入 k 均值的半监督聚类算法。

## 3. 关键模型与算法

### 生成式半监督方法（13.2）

- **核心思想**：假定所有样本（含未标记）由同一生成式模型（如高斯混合模型）产生；未标记数据的标记视为缺失参数，用 EM 算法做极大似然估计。关键洞察：似然中含标记项只用到 D_l，而无标记项 D_u 两项都能用，u≫l 时整体估计更准。
- **数学形式/公式**：假设每个类别对应一个高斯混合成分，样本由混合密度 p(x)=Σ_i α_i·𝒩(x;μ_i,Σ_i) 生成，类别后验由最大化后验概率 f(x)=argmax_j P(y=j|x) 决定。对数似然由"基于 D_l 的监督项 + 基于 D_u 的无监督项"两部分组成；EM 迭代：E 步按当前参数算未标记样本 x_j 属各成分的概率，M 步据这些概率（连同有标记样本数 l_i）更新混合系数、均值、协方差，反复至收敛。
- **适用场景**：有标记数据极少、且对生成模型有充分可靠领域知识的情形；常比其他方法更好。
- **慎用情形/局限**：模型假设必须与真实分布吻合，否则利用未标记数据反而降低性能（Cozman & Cohen, 2002）；现实中难事先保证模型正确。

### 半监督 SVM / TSVM（13.3）

- **核心思想**：在 SVM 基础上，要求划分超平面既分开两类有标记样本，又穿过数据低密度区域；TSVM 对未标记样本尝试各种标记指派，选使全体样本（含标记指派）间隔最大化的超平面。
- **数学形式/公式**：目标是在 (w,b) 确定的超平面下，最小化含松弛向量的目标，其中 C_l 平衡有标记样本、C_u 平衡未标记样本（初始 C_u 小、逐渐增大至 C_l）；松弛向量分有标记与未标记两部分。TSVM 用局部搜索迭代近似：先用 D_l 训 SVM 给未标记数据赋伪标记 → 解标准 SVM → 找出标记指派异类且可能出错的样本对交换标记重解 → 重复并逐步增大 C_u 至 C_u=C_l。类别不平衡时把 C_u 项拆为对应正反例的两项并据伪标记数初始化。
- **适用场景**：二分类、未标记样本较多的情形；低密度分隔假设合理时。
- **慎用情形/局限**：目标函数非凸、优化开销大；若数据存在多个低密度划分，算法可能选错，导致性能下降。

### 图半监督学习 / 标记传播（13.4）

- **核心思想**：以样本为结点、相似度为边构建图，将半监督学习看作"颜色（标记）在图上扩散/传播"。基于能量最小化或迭代传播得到未标记样本的标记。
- **数学形式/公式**：二分类用能量函数 E(f)= (1/2)Σ_{i,j} W_ij (f(x_i)−f(x_j))² （f 在已标记上为真实标记、在未标记上满足 Δf=0，Δ=D−W 为拉普拉斯矩阵），解得未标记部分 f_u = P_uu⁻¹ P_ul f_l（其中 P=D⁻¹W 分块）。多分类用标记矩阵 F，迭代式 F(t+1)=α P F(t) + (1−α) Y（α∈(0,1) 折中传播项与初始标记，Y 为初始化标记矩阵），收敛解 F* 对应正则化框架 min_F Tr(Fᵀ(D−αW)F)+μ‖F−Y‖²。
- **适用场景**：中小规模数据、可清晰构图的任务；概念清晰、便于矩阵分析。
- **慎用情形/局限**：矩阵规模 O(m²)，难处理大规模数据；构图仅含训练样本，新样本需重构图或另训预测器（如再训一个 SVM）。

### 基于分歧的方法 / 协同训练（13.5）

- **核心思想**：使用多个学习器，借助学习器间的"分歧"利用未标记数据；协同训练利用多视图的相容互补性，各视图分类器互相提供高置信度伪标记。理论证明：若两视图充分且条件独立，可通过未标记样本把弱分类器性能提升到任意高。
- **数学形式/公式**：每个视图基于 D_l 训一个分类器 h_j，每轮各分类器挑自己"最有把握"的未标记样本赋伪标记提供给另一视图作新增有标记样本重训，迭代至稳定或达轮数上限（可用缓冲池降低开销、以置信度如后验概率/间隔衡量把握）。后续研究：单视图也可通过不同算法/采样/参数产生差异的学习器达到同样效果，核心是"显著分歧"。
- **适用场景**：拥有多视图数据，或能构造出有显著分歧且性能尚可的多个学习器时；理论基础坚实、适用范围广。
- **慎用情形/局限**：当 l 很少、尤其数据无多视图时，难以生成具显著分歧且性能尚可的多个学习器，需巧妙设计。

### 半监督聚类（13.6）

- **核心思想**：把少量监督信息融入聚类。两类监督信息：必连/勿连约束，或少量有标记种子样本。
- **数学形式/公式**：约束 k-means（Wagstaff et al., 2001）在 k 均值迭代中强制满足 M（必连集合）与 C（勿连集合），违规则报错；约束种子 k-means（Basu et al., 2002）用有标记样本作"种子"初始化 k 个簇中心，并固定其簇隶属关系不再变动。
- **适用场景**：有少量成对约束或少量已标注簇归属的样本时改善聚类。
- **慎用情形/局限**：约束若与数据真实结构冲突会致失败；种子选择影响结果。

## 4. 应用与决策框架

选择半监督方法的决策步骤：

1. **是否愿意与专家交互获取标记**？
   - 是 → 主动学习（挑选高价值样本查询），非半监督但可大幅降成本。
   - 否 → 进入 2。
2. **是否有可靠生成式模型假设（充分领域知识）**？
   - 是且 l 极少 → 生成式方法（GMM/朴素贝叶斯/混合专家 + EM）。
   - 否或不确定 → 进入 3。
3. **任务类型与数据规模**：
   - 二分类、希望低密度分隔 → 半监督 SVM / TSVM。
   - 中小规模、可构图、需可解释扩散过程 → 图半监督学习 / 标记传播。
   - 有多视图或能构造多个有分歧学习器 → 基于分歧的方法 / 协同训练（含 tri-training）。
4. **若是聚类任务且带少量监督信息** → 半监督聚类（约束 k-means / 约束种子 k-means）。

**范型对照表**

| 范型 | 基本假设 | 优点 | 主要风险 |
|---|---|---|---|
| 生成式 | 同生成模型 | l 极少时好、易实现 | 模型假设错则性能下降 |
| 半监督 SVM | 低密度分隔 | 理论清晰 | 非凸、优化贵、易选错划分 |
| 图方法 | 相似样本相似标记 | 概念清晰、可矩阵分析 | O(m²) 存储、难处理新样本 |
| 基于分歧 | 学习器显著分歧 | 理论坚实、广泛适用 | 难造多分歧学习器 |
| 半监督聚类 | 必连/勿连或种子 | 直接利用监督信息 | 约束冲突致失败 |

- **图13.1 未标记样本效用**：仅一个正例一个反例时待判样本居中只能随机猜；加入未标记样本后，待判样本经它们"撮合"与正例聚拢，可高把握判为正——直观说明未标记数据价值。
- **生成式方法的高斯混合推导**：式(13.4) 对数似然由监督项（仅 D_l）与无监督项（D_l∪D_u）组成；E/M 步迭代更新混合系数、均值、协方差，体现"未标记数据提升无监督项估计精度"。
- **TSVM 标记指派交换**：每轮找出"标记异类且松弛变量大（很可能错）"的未标记样本对交换重解，使目标函数下降；逐步增大 C_u 提升未标记样本影响。

## 6. 金句与重要结论

- 未标记样本虽无标记，但若与有标记样本同分布，其所含数据分布信息对建模大有裨益。
- 聚类假设与流形假设本质都是"相似样本拥有相似输出"。
- 纯半监督学习基于"开放世界"（模型适用于未观测数据），直推学习基于"封闭世界"（只预测所见未标记数据）。
- 生成式方法关键在模型假设准确：假设错则未标记数据反倒降低泛化性能（Cozman & Cohen, 2002）。
- 半监督 SVM 基于"低密度分隔"——划分超平面应穿过数据低密度区。
- 协同训练理论：若两视图充分且条件独立，可用未标记样本把弱分类器泛化性能提升到任意高（Blum & Mitchell, 1998）。
- 基于分歧的方法无需多视图，只需弱学习器间有显著分歧即可相互提供伪标记提升性能（周志华, 2013）。
- 利用未标记样本并非必然提升性能，甚至可能导致下降；"安全半监督学习"（确保不差于仅用有标记）仍是未决问题。
- 自训练（self-training）是原始半监督方法：用学得分类器给未标记数据赋伪标记后重训，缺陷在于错误伪标记会被放大累积。

## 7. 与其他章节的关联

- **第6章 支持向量机**：半监督 SVM / TSVM 是 SVM 的半监督推广，沿用间隔最大化与松弛向量思想；类别不平衡处理（3.6）用于改进 TSVM。
- **第7章 EM 算法 / 第9章 原型聚类**：生成式半监督方法直接基于 GMM 与 EM（7.6、9.4）；半监督聚类建立在 k 均值（9.4.1）之上。
- **第9章 聚类 / 第10章 降维与流形学习**：聚类假设、流形假设对应 10.5 流形学习；图半监督的构图借鉴 k 近邻图/ε 近邻图（10.5.1）。
- **第8章 集成学习**：基于分歧的方法（tri-training 等）把集成学习与半监督学习联系起来（周志华, 2009）；多学习器分歧思想相通。
- **第3章 线性模型 / 第12章 计算学习理论**：半监督 SVM 的非凸性优化、生成式方法的风险可用第12章稳定性/Rademacher 框架分析"安全"半监督。
- **第14章 概率图模型**：图半监督学习可视为在图上做标记传播推断；生成式方法本身即概率图模型思想。
