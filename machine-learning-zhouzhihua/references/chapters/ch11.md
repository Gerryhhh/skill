# 第11章 特征选择与稀疏学习

## 1. 章节核心摘要
- 特征选择是从给定特征集中挑出"相关特征"子集的过程，是关键的"数据预处理"步骤，与第10章降维并列为处理高维数据（维数灾难）的两大主流技术。另一动机是去除无关特征、降低学习难度。
- 特征选择需保证不丢失重要特征。特征分相关特征、无关特征（与当前任务无关）、冗余特征（信息可从其他特征推得，有时有益有时可去）。
- 特征选择的两大环节：子集搜索（如何生成候选子集）与子集评价（如何评价候选子集好坏）。搜索多为贪心（前向/后向/双向），评价可用信息增益等划分差异准则。方法分三类：过滤式、包裹式、嵌入式。
- 过滤式（如 Relief）与后续学习器无关，效率高；包裹式（如 LVW）以学习器性能为评价准则、为学习器"量身定做"，效果更好但开销大；嵌入式（如 LASSO）将特征选择融入训练过程，与 L1 正则化获得的稀疏解天然统一。
- 稀疏性还有另一层含义：将稠密数据转化为"稀疏表示"（字典学习/稀疏编码）。压缩感知则进一步利用信号本身的稀疏性，从少量观测中恢复完整信号，并延伸到矩阵补全（协同过滤、低秩恢复）。

## 2. 关键术语表
- 特征选择（feature selection）— 从特征集中选出相关特征子集的过程。
- 相关特征 / 无关特征 / 冗余特征 — 对任务有用 / 无用 / 信息可被其他特征推得的特征。
- 数据预处理（data preprocessing）— 获数据后先特征选择、再训学习器的环节。
- 子集搜索（subset search）— 生成候选特征子集的策略：前向（渐增）、后向（渐减）、双向。
- 子集评价（subset evaluation）— 评价候选子集好坏，如用信息增益衡量与标记划分的差异。
- 过滤式（filter）/ 包裹式（wrapper）/ 嵌入式（embedding）— 特征选择的三类方法（与学习器无关/以学习器性能为准则/与训练融为一体）。
- Relief — 著名的过滤式方法，用"相关统计量"度量特征重要性，靠猜中/猜错近邻更新。
- Relief-F — Relief 的多分类扩展。
- LVW（Las Vegas Wrapper）— 拉斯维加斯框架下的包裹式特征选择，以分类器误差为准则。
- 嵌入式选择与 L1 正则化 — 在训练同时做特征选择；L1 比 L2 更易得稀疏解。
- 岭回归（ridge regression）— L2 范数正则化的线性回归（Tikhonov 回归）。
- LASSO — L1 范数正则化的线性回归，可产生稀疏解、兼做特征选择。
- 稀疏（sparse）解 — 模型参数 w 中非零分量很少的解。
- 近端梯度下降（PGD）— 求解 L1 正则化（如 LASSO）的常用优化方法。
- 稀疏表示（sparse representation）/ 字典学习（dictionary learning）/ 稀疏编码（sparse coding）— 将稠密样本表示为"字典矩阵×稀疏系数"；学字典与求稀疏表达常同一过程完成。
- 压缩感知（compressed sensing）— 利用信号稀疏性，从少量观测恢复完整信号。
- 限定等距性（RIP）— 压缩感知中保证可由少量观测恢复稀疏信号的条件。
- 矩阵补全（matrix completion）/ 低秩矩阵恢复 — 由部分观测恢复完整低秩矩阵（如协同过滤），用核范数近似秩。
- 核范数（nuclear norm）/ 迹范数 — 矩阵奇异值之和，是秩的凸包近似。

## 3. 关键模型与算法

### 子集搜索与评价（特征选择框架）
- 核心思想：因遍历所有子集不可行，采用贪心搜索产生候选子集并评价。前向从空集渐增相关特征、后向从全集渐减无关特征、双向结合二者；评价用候选子集对数据集的划分与真实标记划分的差异（如信息增益）。
- 数学形式：对属性子集 A，按取值将 D 分为 V 个子集，信息增益 Gain(A) = Ent(D) − Σ_{v=1}^V (|D_v|/|D|) Ent(D_v)；Gain 越大，A 含分类信息越多。
- 适用场景：需从大量特征中筛出相关子集、作为学习器前处理。
- 慎用情形：贪心搜索无法避免局部最优（如第三轮选 a5 优于 a6，但第四轮 {a2,a4,a6,a8} 可能更优）；需以领域知识保不丢重要特征。

### 过滤式选择：Relief / Relief-F
- 核心思想：设计"相关统计量"向量（每分量对应一特征），用猜中近邻（同类最近邻）与猜错近邻（异类最近邻）在属性 j 上的距离差更新分量——猜中近、猜错远则该特征有益、增大分量。取超阈值或取最大的 k 个特征。
- 数学形式：对样本 x_i，分量 δ^j = Σ_i [ diff(x_i^j, x_{i,nh}^j) − diff(x_i^j, x_{i,nm}^j) ]（diff 对离散取0/1、对连续取规范化后的绝对差）；Relief-F 扩展为对每异类 l 取最近邻并乘类比例 p_l。
- 适用场景：二分类（Relief）或多分类（Relief-F），运行效率高的过滤式预筛选。
- 慎用情形：原始 Relief 仅适用于二分类；统计量本质含距离度量意味，依赖恰当的距离。

### 包裹式选择：LVW
- 核心思想：在拉斯维加斯方法（随机子集搜索）框架下，以最终学习器在特征子集 A' 上的交叉验证误差为评价准则；若误差更小或相当但特征更少则保留 A'；连续 T 轮未更新则停。
- 数学形式：评价准则 = 学习器在仅含特征 A' 的数据上的误差；目标为最小化该误差（或等价地、误差相同下最小化特征数）。
- 适用场景：为特定学习器"量身定做"特征子集、追求最终性能最优时。
- 慎用情形：每次评价都需训练学习器，计算开销远大于过滤式；随机搜索+LV 框架在特征多、T 大时可能长时间不收敛甚至给不出解（有运行时间限制时尤甚）。

### 嵌入式选择与 L1/L2 正则化（岭回归、LASSO）
- 核心思想：将特征选择融入训练。线性回归平方误差加正则化；L2（岭回归）降过拟合但不稀疏，L1（LASSO）除降过拟合外更易得稀疏解——w 仅少数非零，对应特征即被选入。
- 数学形式：
  - 岭回归 min_w Σ_i (y_i−wᵀx_i)² + λ‖w‖₂²（λ>0）；
  - LASSO min_w Σ_i (y_i−wᵀx_i)² + λ‖w‖₁（λ>0）；
  - 几何解释：L1 等值线（菱形）与平方误差等值线交点常在坐标轴上（得稀疏），L2 等值线（圆）交点常不在轴上（不稀疏）。
- 适用场景：特征多、样本少的线性回归场景，需同时降过拟合并自动选特征。
- 慎用情形：L0 范数最自然但非连续难优化，常以 L1 近似；LASSO 类因凸性不严格可能多解（弹性网可解）。

### 近端梯度下降（PGD）解 LASSO
- 核心思想：对可导且梯度满足 L-Lipschitz 的目标 f，每步在梯度下降迭代同时考虑 L1 范数最小化；对 LASSO 可逐分量求闭式解（软阈值）。
- 数学形式：迭代 x^{k+1} = argmin_x [ (1/2)‖x−z‖² + λ‖x‖₁ ]，其中 z = x^k − (1/L)∇f(x^k)；按分量闭式解为 x_i = sign(z_i)·max(|z_i|−λ/L, 0)（软阈值算子）。
- 适用场景：高效求解 LASSO 及其他 L1 最小化问题。
- 慎用情形：需 f 满足 Lipschitz 条件；L（步长相关常数）需合理设定。

### 字典学习 / 稀疏编码
- 核心思想：为稠密样本学一个"字典" B，使样本能表示为 B 与稀疏系数 a_i 的乘积，从而享有稀疏性好处（文本数据常因此线性可分）。
- 数学形式：min_{B,{a_i}} Σ_i ‖x_i − B a_i‖₂² + λ‖a_i‖₁；交替优化——固定 B 解各 a_i（类 LASSO），固定 A 更新 B（常用 KSVD 逐列更新，保持 A 稀疏性）。
- 适用场景：图像/文本等希望获得稀疏表达、降低模型复杂度与提高可解释性的任务。
- 慎用情形：字典词汇量 k 需用户设定，影响稀疏程度；"恰当稀疏"（不过度稀疏）才好；KSVD 更新需专门处理以保持稀疏。

### 压缩感知与矩阵补全
- 核心思想：若信号 x 经变换 Ψ 有稀疏表示 s（x=Ψs），则可由少量观测 y=Φx=As（n≪m）恢复 s 再得 x；恢复阶段靠 L1 最小化（基寻踪去噪），前提是测量矩阵 A 满足限定等距性（RIP）。矩阵补全将"部分观测"推广到低秩矩阵恢复（如协同过滤评分）。
- 数学形式：
  - 感知 y=Φx，恢复 min_s ‖s‖₀ s.t. y=As（NP难），转为 min_s ‖s‖₁（与 L0 在一定条件下共解）；
  - RIP：存在 δ∈(0,1) 使对任意 k-稀疏 s 有 (1−δ)‖s‖₂² ≤ ‖As‖₂² ≤ (1+δ)‖s‖₂²；
  - 矩阵补全 min_X rank(X) s.t. (X)_{ij}=(A)_{ij}, (i,j)∈Ω，近似为 min_X ‖X‖_* s.t. 约束（核范数=奇异值之和），可用半正定规划求解。
- 适用场景：信号欠采样恢复、协同过滤（读者-书籍评分矩阵补全）、低秩恢复。
- 慎用情形：须信号确有稀疏表示；观测数需满足一定条件（如矩阵补全需 o(mr log²m) 个观测）才能完美恢复；L0 直接最小化不可行，须转 L1。

## 4. 应用与决策框架
选择特征选择/稀疏方法：
1. 是否与后续学习器强相关、追求最终性能？
   - 是、且计算资源充足 → 包裹式（LVW），为学习器定制。
   - 否、追求效率 → 过滤式（Relief/Relief-F）。
   - 希望选择与训练一体、自动稀疏 → 嵌入式（LASSO 及 LARS、Group LASSO 等）。
2. 数据是稠密还是希望获得稀疏表达？
   - 仅想减特征维度 → 上述三类特征选择。
   - 想将稠密样本转稀疏表达 → 字典学习/稀疏编码。
3. 任务是否为"由部分信息恢复全部"？
   - 信号/矩阵恢复 → 压缩感知 / 矩阵补全，依赖信号稀疏性或低秩性。
4. 评估：过滤式看统计量/信息增益；包裹式看学习器性能；嵌入式看模型稀疏度与泛化；压缩感知看恢复误差与 RIP 条件。

## 5. 典型案例/例题要点
- 冗余特征示例：立方体已有"底面长""底面宽"，则"底面积"冗余；但若学习目标是估体积，底面积作为"中间概念"反而有益——说明冗余特征有时有用。
- Relief 演示：对样本 x_i 找同类最近邻（猜中）与异类最近邻（猜错），比较属性 j 上距离差更新统计量；只需在采样上估计，效率随采样与特征数线性增长。
- LASSO 几何（图11.2）：L1（菱形）等值线与平方误差等值线交点常在轴上→w1 或 w2 为 0（稀疏）；L2（圆）交点常在象限内→均非零（不稀疏）。
- 字典学习：固定 B 解 a_i（类 LASSO），再用 KSVD 逐列更新 B 并保持 A 稀疏；词汇量 k 控制稀疏程度。
- 压缩感知示例（表11.1 读者-书籍评分）：评分仅与题材有关，题材数远少于书数→信号稀疏，可用矩阵补全（核范数最小化）由部分评分恢复完整偏好矩阵，用于书籍推荐（协同过滤）。

## 6. 金句与重要结论
- 特征选择与降维动机相似，是处理高维数据（维数灾难）的两大主流技术；去除不相关特征还能降低学习难度，如侦探抽丝剥茧。
- 特征选择必须确保不丢失重要特征，否则后续学习因信息缺失而无法获得好性能。
- 前向/后向/双向搜索都是贪心的，无法避免局部最优（除非穷举，但组合爆炸不可行）。
- L1 正则化比 L2 更易获得稀疏解，故基于 L1 的学习方法天然是嵌入式特征选择。
- L0 范数最自然但非连续难优化，常以 L1 范数近似。
- 文本数据用字频表示后高度稀疏，使线性 SVM 等表现很好——稀疏性常让问题线性可分。
- 字典学习侧重"学字典"，稀疏编码侧重"求稀疏表达"，二者通常同一优化过程完成。
- 压缩感知精髓在"重构恢复"：利用信号稀疏性，从少量观测恢复完整信号；L1 最小化在一定条件下与 L0 最小化共解。
- 矩阵补全用核范数（奇异值之和）近似秩，在满足条件下只需观测 o(mr log²m) 个元素即可完美恢复。
