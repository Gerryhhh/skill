# 第3章 线性模型

## 1. 章节核心摘要

- 线性模型试图学得一个通过属性线性组合来进行预测的函数：f(x)=wᵀx+b。尽管形式简单，它却蕴涵了机器学习中若干重要思想——许多强大的非线性模型都可以在线性模型之上通过引入层级结构或高维映射得到；同时 w 直观表达了各属性在预测中的重要性，使模型具有很好的可解释性（comprehensibility）。
- 本章主线由“回归 → 二分类 → 多分类”展开：先用最小二乘法解决线性回归，再用广义线性模型的思路把线性回归预测值通过单调可微函数映射到分类标记，得到对数几率回归；然后又从“投影+散度”的角度提出线性判别分析（LDA）这一经典线性分类方法。
- 多分类学习本质上常“拆解”为多个二分类任务，本章给出三种经典拆分策略：一对一（OvO）、一对其余（OvR）、多对多（MvM，典型实现为 ECOC 纠错输出码）。
- 现实分类任务常面临类别不平衡，本章给出“再缩放”这一基本策略及其三类技术路线（欠采样、过采样、阈值移动），并指出它也是代价敏感学习的基础。
- 最重要结论：线性模型是几乎所有进阶模型（含神经网络、SVM、集成学习）的基石；当 XᵀX 不满秩（变量数多于样本数）时，需引入正则化来选定解；广义线性模型统一了回归、分类与指数族建模。

## 2. 关键术语表

- 线性模型（linear model）— 用属性线性组合 f(x)=wᵀx+b 进行预测的函数模型。
- 非线性模型（nonlinear model）— 在线性模型基础上引入层级结构或高维映射得到的更复杂模型。
- 可解释性 / 可理解性（comprehensibility）— 由 w 直观体现各属性重要程度的性质。
- 线性回归（linear regression）— 用线性模型尽可能准确预测实值输出标记。
- 均方误差 / 平方损失（square loss）— 回归任务中最常用的性能度量，对应欧氏距离，最小化它的方法即最小二乘法。
- 最小二乘法（least square method）— 基于均方误差最小化求解模型的方法；求最优解的过程称“参数估计”。
- 闭式解（closed-form）— 可直接由公式写出的最优解，如线性回归的正规方程解。
- 多元线性回归（multivariate linear regression）— 样本由 d 个属性描述的线性回归，又称“多变量线性回归”。
- 满秩矩阵 / 正定矩阵（full-rank / positive definite matrix）— XᵀX 可逆的前提；现实常不满秩。
- 正则化（regularization）— 在模型不满秩或防过拟合时引入约束项以选定/约束解。
- 对数线性回归（log-linear regression）— lny=wᵀx+b，形式上线性、实质是非线性映射，是广义线性模型的特例。
- 广义线性模型（generalized linear model）— y=g⁻¹(wᵀx+b)，g 称为“联系函数”（link function）。
- 对数几率回归 / 对率回归（logistic regression）— 用对数几率函数作联系函数，名字叫“回归”实为分类方法。
- 单位阶跃函数（unit-step function）— 理想但不连续的 0/1 映射；亦称 Heaviside 函数。
- 对数几率函数 / 对率函数（logistic function）— Sigmoid 函数代表，y=1/(1+e⁻ᶻ)，单调可微、任意阶可导。
- 几率（odds）/ 对数几率（log odds, logit）— 正例可能性与反例可能性之比，及其对数。
- 极大似然法（maximum likelihood method）— 令每个样本属于其真实标记的概率最大以估计参数。
- 梯度下降法 / 牛顿法（gradient descent / Newton method）— 求解凸目标最优解的经典数值优化算法。
- 线性判别分析（LDA, Fisher 判别分析）— 将样本投影到一条直线，使同类投影尽量接近、异类尽量远离的线性分类法。
- 类内散度矩阵（within-class scatter matrix, S_w）/ 类间散度矩阵（between-class scatter matrix, S_b）— LDA 目标中的两类散度。
- 广义瑞利商（generalized Rayleigh quotient）— LDA 最大化的目标形式 S_b w / S_w w。
- 多分类学习 / 拆解法 — 把多分类任务拆成若干二分类任务求解。
- 一对一（OvO, One vs. One）/ 一对其余（OvR, One vs. Rest）/ 多对多（MvM, Many vs. Many）— 三种经典拆分策略。
- 纠错输出码（ECOC）— 用编码矩阵拆分多分类、并在解码时具容错能力的 MvM 技术；含二元码、三元码。
- 类别不平衡（class-imbalance）— 不同类别训练样例数差别很大的情况。
- 再缩放（rescaling）/ 再平衡（rebalance）— 根据观测几率调整决策阈值的基本策略。
- 欠采样（undersampling, 下采样）/ 过采样（oversampling, 上采样）/ 阈值移动（threshold-moving）— 处理类别不平衡的三类技术。
- 代价敏感学习（cost-sensitive learning）— 在非均等误分类代价下学习；再缩放是其基础。
- 稀疏表示（sparse representation）/ 稀疏性（sparsity）— 仅少数系数为非零解的表示；LASSO 用 L1 范数近似 L0 以求得稀疏解。
- 多标记学习（multi-label learning）— 一个样本可同时拥有多个类别标记（区别于多分类）。

## 3. 关键模型与算法

### 线性回归（最小二乘法）
- 核心思想：用属性的线性组合 f(x)=wᵀx+b 预测实值标记，并让预测值与真实值之间的均方误差最小。
- 数学形式/公式：
  - 单变量：最小化 E(w,b)=Σᵢ(f(xᵢ)−yᵢ)²（均方误差）。偏导置零得闭式解：w = Σᵢ(xᵢ−均值x)(yᵢ−均值y) / Σᵢ(xᵢ−均值x)²，b = 均值y − w·均值x（其中“均值x/均值y”为样本均值）。
  - 多元：把 w 和 b 合并为增广向量、数据集写成 m×(d+1) 矩阵 X，最小化 (y−Xŵ)ᵀ(y−Xŵ)；当 XᵀX 满秩/正定时闭式解为 ŵ = (XᵀX)⁻¹Xᵀy。
  - 变化形式：对数线性回归 lny=wᵀx+b（让 e^{wᵀx+b} 逼近 y）；更一般广义线性模型 y=g⁻¹(wᵀx+b)，g 为联系函数。
- 适用场景：属性与输出近似线性关系的连续值预测；作为更复杂模型的基础组件。
- 慎用情形/局限：XᵀX 常不满秩（变量数多于样本数），会解出多个使均方误差最小的解，需靠归纳偏好或正则化选定；对强非线性关系需借助广义线性模型/高维映射。

### 对数几率回归（对率回归 / 逻辑回归）
- 核心思想：把线性回归预测值 z=wᵀx+b 经对数几率函数（Sigmoid）映射成接近 0/1 的值，用其逼近真实标记的对数几率，从而得到分类学习器。
- 数学形式/公式：y = 1/(1+e^{−(wᵀx+b)})（对率函数，Sigmoid）；可改写为 ln(y/(1−y)) = wᵀx+b，即线性回归预测值逼近“对数几率”。将 y 视为后验概率 p(y=1|x) 时，p(y=1|x)=y，p(y=0|x)=1−y。参数由极大似然法估计：最小化关于 β=(w;b) 的凸损失 Σᵢ[−yᵢ·ln(p₁)−(1−yᵢ)·ln(p₀)]，可用梯度下降或牛顿法求解（牛顿法更新依赖一阶、二阶梯度，目标为凸函数）。
- 适用场景：二分类；需要近似概率预测以辅助决策的任务；无需事先假设数据分布。
- 慎用情形/局限：本质是线性分类边界，对非线性可分数据有限；多分类需扩展（如 OvR/OvO 或多类对率）；类别不平衡时需配合再缩放/重采样。

### 线性判别分析（LDA / Fisher 判别分析）
- 核心思想：将样本投影到直线上，使同类样例投影点协方差尽可能小（类内紧凑）、异类样例中心距离尽可能大（类间远离）；新样本投影后按位置判定类别。
- 数学形式/公式：二分类最大化目标为类间散度与类内散度之比——分子为 (μ₀−μ₁)² 形式的距离，分母为两类投影协方差之和 wᵀΣ₀w+wᵀΣ₁w；定义类内散度矩阵 S_w=Σ₀+Σ₁、类间散度矩阵 S_b=(μ₀−μ₁)(μ₀−μ₁)ᵀ，目标即广义瑞利商 wᵀS_b w / wᵀS_w w。解为 w ∝ S_w⁻¹(μ₀−μ₁)（实践中对 S_w 做奇异值分解求逆以保证数值稳定）。多分类推广为 W 的广义特征值问题 S_b W = λ S_w W，投影到 d′≤N−1 维，可作监督降维。
- 适用场景：二分类、线性可分或近似线性可分数据；需要监督降维（投影到少于原属性数的空间）时。
- 慎用情形/局限：假定各类协方差相同（满秩）时理论最优；对非线性可分数据效果差（习题提示需改进）；仅当两类同先验、高斯同协方差时达到贝叶斯最优。

### 多分类拆分策略（OvO / OvR / MvM-ECOC）
- 核心思想：基本思路是“拆解法”——把 N 类多分类拆为若干个二分类任务，分别训练分类器再集成。
- 数学形式/公式：
  - OvO：两两配对，产生 N(N−1)/2 个二分类器，测试时投票决定最终类别。
  - OvR：每次取一类为正、其余为反，训练 N 个分类器；仅一个判正则取该类，多个判正则取置信度最大者。
  - MvM：若干类作正、若干类作反；典型实现 ECOC 用编码矩阵（二元码 / 三元码）指定划分，训练 M 个分类器，测试时把预测编码与各分类别编码比较、取距离最小者（常用欧氏距离）。
- 适用场景：手头只有二分类学习器时解决多分类；ECOC 在码较长时具更强纠错能力。
- 慎用情形/局限：OvO 存储与测试开销大于 OvR，但类别数很多时训练开销小于 OvR；码长超过一定范围失去意义，最优编码为 NP 难；OvR/OvM 拆分后可能产生类别不平衡（但可相互抵消，通常不需专门处理）。

### 类别不平衡处理（再缩放及其技术）
- 核心思想：当正/反例数目悬殊时，分类器决策阈值 0.5 默认假定两类先验相等，需用观测几率 m⁻/m⁺ 调整；基本策略是“再缩放”。
- 数学形式/公式：原决策规则 y/(1−y) > 1 判正；调整为 y/(1−y) > m⁻/m⁺ 判正，等价于把预测值乘以 m⁻/m⁺ 再与 1 比较。三类做法：①欠采样（去除部分反例使两类数接近）；②过采样（增加正例，代表性算法 SMOTE 通过插值产生额外正例，忌简单重复采样以免过拟合）；③阈值移动（基于原始集训练，预测时嵌入再缩放式）。
- 适用场景：正例稀少、反例众多的现实分类；代价敏感学习中以 cost⁺/cost⁻ 替代 m⁻/m⁺。
- 慎用情形/局限：“训练集是真实总体无偏采样”常不成立，使观测几率未必等于真实几率；随机欠采样可能丢失重要信息（EasyEnsemble 用集成缓解）；过采样开销大且易过拟合。

## 4. 应用与决策框架

选用本章方法时的决策步骤：

1. 明确任务类型：
   - 预测连续实值 → 线性回归（或广义线性模型，如输出在指数尺度用对数线性回归）。
   - 二分类且需概率输出 → 对数几率回归（首选，无需假设分布、可直接得近似概率）。
   - 二分类且强调类间可分/需监督降维 → LDA。
   - 多分类 → 基于二分类学习器用 OvO / OvR / ECOC 拆分。
2. 检查数据形态：
   - 自变量少、样本多且 XᵀX 满秩 → 直接闭式解（正规方程）。
   - 变量数 ≥ 样本数（如基因芯片）→ XᵀX 不满秩，必须引入正则化（见第 6、11 章 L1/L2 正则）。
3. 检查类别平衡：若严重不平衡，训练前决定欠采样 / 过采样 / 阈值移动；若使用 OvR 或 MvM，其不平衡影响相互抵消，通常不必专门处理。
4. 对照表：

| 需求 | 推荐方法 | 备注 |
|---|---|---|
| 实值预测 | 线性回归 / 广义线性模型 | 注意属性离散化方式（有序→连续值，无序→k 维向量） |
| 二分类 + 概率 | 对数几率回归 | 凸目标，梯度下降/牛顿法可解 |
| 二分类 + 降维 | LDA | 假定协方差相同 |
| 多分类 | OvR（简单）/ OvO（大类省时）/ ECOC（需容错） | 视类别数与纠错需求 |
| 不平衡数据 | 再缩放 / SMOTE / EasyEnsemble | 配合上述分类器 |

## 5. 典型案例/例题要点

- 西瓜问题示例：学得“f好瓜(x)=0.2·色泽 + 0.5·根蒂 + 0.3·敲声 + 1”，说明 w 的可解释性——根蒂最重要、敲声比色泽重要。
- 属性连续化：有序属性（身高“高/矮”→{1,0}，“高/中/低”→{1,0.5,0}）转化为连续值；无序属性（瓜类“西瓜/南瓜/黄瓜”）转化为 k 维 0/1 向量，避免引入虚假序关系。
- 最小二乘历史小故事：高斯 1809 年发表最小二乘法并含误差分析，用于据观测数据推算谷神星轨道；与勒让德发生优先权之争。
- 对数几率回归数值解：式（3.27）为关于 β 的高阶可导连续凸函数，牛顿法迭代更新依赖一阶、二阶导数（具体梯度形式见原书式 3.29–3.31）。
- LDA 贝叶斯最优性：当两类数据同先验、满足高斯分布且协方差相等时，LDA 可达最优分类（见习题 7.5）。
- 类别不平衡极端例：998 个反例、仅 2 个正例时，永远预测反例可得 99.8% 精度却无价值——说明需处理不平衡。

## 6. 金句与重要结论

- “线性模型形式简单、易于建模，但却蕴涵着机器学习中一些重要的基本思想。”
- “由于 w 直观表达了各属性在预测中的重要性，因此线性模型有很好的可解释性。”
- 许多功能更强大的非线性模型可在线性模型基础上通过引入层级结构或高维映射而得。
- 均方误差对应欧几里得距离；“基于均方误差最小化来进行模型求解的方法称为最小二乘法”。
- 对数几率回归“虽然它的名字是‘回归’，但实际却是一种分类学习方法”。
- 对率回归优点：直接对分类可能性建模、无需假设数据分布、可得近似概率预测、对率函数任意阶可导凸函数便于数值优化。
- LDA 在“两类同先验、满足高斯分布且协方差相等”时达到最优分类。
- “再缩放”是类别不平衡学习的基本策略，也是代价敏感学习的基础（用 cost⁺/cost⁻ 替代 m⁻/m⁺）。
- OvO 与 OvR 都是 ECOC 的特例；寻找最优离散编码矩阵是 NP 完全问题。
- LASSO 通过 L1 范数近似 L0 范数，是求取稀疏解的重要技术（L0 优化通常 NP 难）。

## 7. 与其他章节的关联

- 第1章：归纳偏好（为何在 XᵀX 不满秩时选定某一解）、假设空间等概念。
- 第2章：均方误差/性能度量（2.3）、代价敏感错误率与代价曲线（2.3.4）——再缩放是其基础。
- 第5章：对数几率函数（Sigmoid）是神经网络的典型激活函数；对率回归与神经元激活函数直接相通（见 5.2、5.3）。
- 第6章：正则化（软间隔与正则化）用于 XᵀX 不满秩与防过拟合；SVM 与引入正则化的神经网络思路相近。
- 第7章：极大似然估计（7.2）是对率回归参数估计的理论基础。
- 第8章：集成学习（如 EasyEnsemble 利用集成缓解欠采样信息丢失）；多分类器的结合策略。
- 第10章：LDA 可作监督降维技术，与降维/度量学习衔接。
- 第11章：特征选择与稀疏学习（LASSO、L1 正则化）是线性模型不满秩时的常用解法。
