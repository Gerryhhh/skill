# 第16章 强化学习

## 1. 章节核心摘要

强化学习研究智能体（机器）在环境 E 中通过不断尝试来学得一个"策略"，使得长期执行的累积奖赏最大化。它的典型特征是：没有监督学习那样的有标记样本（"示例-标记"对），只有多步决策后才能揭晓的最终奖赏，因此可看作具有"延迟标记信息"的监督学习。

本章主线由易到难：先从单步奖赏的简化情形——K-摇臂赌博机入手，引出"探索-利用窘境"及 ε-贪心、Softmax 两种折中策略；再进入多步任务，区分"模型已知"（有模型学习，用动态规划做策略评估、策略改进、策略迭代与值迭代）与"模型未知"（免模型学习，用蒙特卡罗、时序差分 Sarsa 与 Q-learning）；随后讨论连续/无穷状态空间下的"值函数近似"，以及借助人类范例的"模仿学习"（直接模仿与逆强化学习）。

最重要的结论是：模型已知时强化学习可归结为基于动态规划的寻优；模型未知时时序差分（TD）结合了动态规划与蒙特卡罗优点，Q-learning 作为异策略算法尤为经典；连续状态空间用值函数近似（线性或引入核/神经网络）；当奖赏函数难设计时，逆强化学习可从人类范例反推奖赏函数。强化学习在某种意义上就是具有"延迟标记信息"的监督学习。

## 2. 关键术语表

- **强化学习（reinforcement learning）** — 机器在环境中通过试错、以长期累积奖赏最大化为目标来学得策略的学习范式（亦称"再励学习"）。
- **马尔可夫决策过程（MDP）** — 强化学习任务的标准描述框架，对应四元组 E=〈X, A, P, R〉：状态空间、动作空间、状态转移概率、奖赏函数。
- **状态（state）/ 状态空间 X** — 机器感知到的环境描述。
- **动作（action）/ 动作空间 A** — 机器可采取的操作。
- **转移函数 P** — 在状态 x 执行动作 a 后转移到新状态的概率。
- **奖赏函数 R** — 状态转移时环境反馈给机器的即时奖赏；可写为 R: X×A×X→ℝ 或仅与状态有关 R: X×X→ℝ。
- **策略（policy）π** — 机器据以在状态 x 下选择动作的规则；确定性的 π: X→A，随机性的 π: X×A→[0,1]（满足 Σ_a π(x,a)=1）。
- **累积奖赏** — 长期执行策略得到的奖赏总和；常用"T 步累积奖赏"与"γ-折扣累积奖赏"（γ 为折扣因子）。
- **探索-利用窘境（Exploration-Exploitation dilemma）** — 估计摇臂优劣（探索）与选择当前最优（利用）的矛盾，二者权衡才能最大化累积奖赏。
- **K-摇臂赌博机（K-armed bandit）** — 单步强化学习的理论模型，有 K 个摇臂，目标最大化单步奖赏。
- **ε-贪心法** — 以 ε 概率均匀随机探索、以 1−ε 概率利用当前最优摇臂。
- **Softmax 算法** — 基于 Boltzmann 分布按各摇臂平均奖赏分配选取概率，温度 τ 控制探索/利用强度。
- **有模型学习（model-based learning）** — MDP 四元组均已知，机器已对环境建模。
- **免模型学习（model-free learning）** — 算法不依赖环境建模（转移概率、奖赏函数未知）。
- **状态值函数 V^π(x)** — 从状态 x 出发、用策略 π 的期望累积奖赏。
- **状态-动作值函数 Q^π(x,a)** — 从状态 x 执行动作 a 后再用策略 π 的期望累积奖赏。
- **Bellman 等式** — 值函数的递归等式（由 MDP 的马尔可夫性质得到）。
- **最优值函数 V\*** — 最优策略对应的值函数；最优 Bellman 等式唯一解即最优值函数。
- **策略评估** — 在模型已知时估计某策略的累积奖赏（值函数）。
- **策略改进** — 将策略选择的动作改为当前最优动作以提升累积奖赏。
- **策略迭代（policy iteration）** — 交替进行策略评估与策略改进直至收敛。
- **值迭代（value iteration）** — 直接将策略改进视为值函数改善，迭代更新值函数直至得到最优。
- **蒙特卡罗强化学习** — 免模型下通过多次采样轨迹求平均累积奖赏来近似值函数（适合 T 步累积奖赏）。
- **同策略（on-policy）** — 评估与改进的是同一个（如 ε-贪心）策略。
- **异策略（off-policy）** — 用一个策略（如行为策略）采样，评估/改进另一个策略（如目标策略）；基于重要性采样。
- **时序差分学习（TD）** — 结合动态规划与蒙特卡罗，每执行一步即增量更新值函数。
- **Sarsa** — 同策略 TD 算法，更新需"前状态、前动作、奖赏、新状态、新动作"五要素。
- **Q-learning** — 异策略 TD 算法，评估目标策略、执行 ε-贪心策略，是强化学习经典算法。
- **值函数近似（value function approximation）** — 连续/无穷状态空间下用参数化函数（如线性函数、核方法、神经网络）近似值函数。
- **模仿学习（imitation learning）** — 从人类专家决策范例中学习（亦称学徒学习、示范学习、观察学习）。
- **直接模仿学习** — 直接抽取"状态-动作对"用监督学习学得策略，作强化学习初始策略。
- **逆强化学习（inverse reinforcement learning）** — 从范例轨迹反推出使范例最优的奖赏函数，再据以训练策略。

## 3. 关键模型与算法

### K-摇臂赌博机与探索-利用折中（ε-贪心、Softmax）
- 核心思想：单步强化学习模型。最大化累积奖赏须同时"估计各动作奖赏"（探索）与"执行最优动作"（利用），二者矛盾，需在探索与利用间折中。
- 数学形式/公式：
  - 平均奖赏增量更新：Q_k(a) = Q_{k-1}(a) + (1/k)·(v_k − Q_{k-1}(a))，即每尝试一次用新奖赏 v 更新均值，只需记录已尝试次数与最近均值（高效增量式）。
  - ε-贪心：每次以 ε 概率均匀随机选摇臂（探索），以 1−ε 概率选当前平均奖赏最高者（利用）；ε 可随尝试次数增大而衰减。
  - Softmax（Boltzmann 分布）：选摇臂 a 的概率 ∝ exp(Q(a)/τ) / Σ_b exp(Q(b)/τ)，τ>0 为温度；τ→0 趋"仅利用"，τ→∞ 趋"仅探索"。
- 适用场景：单步决策、无标记反馈、需在线权衡探索与利用的情形（也作为多步任务每状态动作选择的组件）。
- 慎用情形/局限：单步模型忽略 MDP 结构；ε 与 τ 需调参；未考虑状态间的转移依赖。

### 有模型学习：策略评估与 Bellman 等式
- 核心思想：MDP 四元组已知时，可用全概率展开求任意策略的累积奖赏期望（值函数）。
- 数学形式/公式：
  - 状态值函数（T 步累积奖赏）递归式：V^π(x) = Σ_a π(x,a)·[ R(x,a,x′) 的即时项 + Σ_{x′} P(x′|x,a)·V^π_{T-1}(x′) ]，即 Bellman 等式。γ-折扣情形把步数项换为 γ·后续折扣累积。
  - 状态-动作值函数：Q^π(x,a) = 即时奖赏 + Σ_{x′} P(x′|x,a)·[ γ·Σ_{a′} π(x′,a′)·Q^π(x′,a′) ]。
  - 有了 V 可由 V 与转移/奖赏直接换算 Q。
  - 本质是动态规划：从初始值出发迭代 T 轮（T 步）或直到变化小于阈值 θ（折扣）即精确/近似求出值函数。
- 适用场景：环境模型（转移概率、奖赏）完全已知或可精确模拟的任务。
- 慎用情形/局限：现实中转移概率、奖赏常难获知，此时退化为免模型学习。

### 策略改进、策略迭代与值迭代
- 核心思想：评估策略后若非最优则改进——把策略所选动作改为当前最优动作（由最优 Bellman 等式，将动作求和改为取 max）。值函数对策略每点改进单调递增，直至策略不再变化即达最优。
- 数学形式/公式：
  - 最优值函数 V\*(x) = max_a [ 即时奖赏 + Σ_{x′} P(x′|x,a)·( γ·V\*(x′) ) ]；最优状态-动作值函数 Q\*(x,a) = 即时奖赏 + Σ_{x′} P(x′|x,a)·( γ·max_{a′} Q\*(x′,a′) )。
  - 策略改进：π′(x) = argmax_a Q^π(x,a)；当 Q^π(x,π′(x)) ≥ V^π(x) 对所有 x 成立时策略改进单调。
  - 策略迭代：初始（常随机）策略 → 策略评估 → 策略改进 → 重复至收敛。
  - 值迭代：直接迭代 V(x) ← max_a [ 即时奖赏 + γ·Σ_{x′} P(x′|x,a)·V(x′) ] 直至收敛，再据 Q 得最优策略。
- 适用场景：模型已知时求解最优策略的标准动态规划方法。
- 慎用情形/局限：策略迭代每轮都重做策略评估较耗时（故常值迭代）；均为表格法，状态有限。

### 免模型：蒙特卡罗强化学习（同策略 / 异策略）
- 核心思想：模型未知时无法全概率展开，只能通过在环境中执行动作观察转移与奖赏来学习。用多次采样轨迹求平均累积奖赏近似值函数（适合 T 步累积奖赏）；估计对象由 V 转为 Q（因模型未知时 V→Q 转换困难）；只能用从起始状态出发的探索发现状态。
- 数学形式/公式：
  - 采样轨迹：从起始状态用某策略执行 T 步得序列 ⟨x₀,a₀,r₁,…,x_{T-1},a_{T-1},r_T,x_T⟩；对轨迹中每对 (x,a) 记录其后奖赏之和作一次采样，多条轨迹平均得 Q 估计（均值用增量式更新）。
  - ε-贪心策略：π_ε 以 1−ε 选当前最优、以 ε/(|A|−1) 分给各非最优动作，保证各动作都可能被采样，产生不同轨迹。
  - 同策略（on-policy）：评估与改进同一 ε-贪心策略，最终产出 ε-贪心策略。
  - 异策略（off-policy）：用行为策略 π′（如 ε-贪心）采样、评估目标策略 π，基于重要性采样对累积奖赏加权：权重为两策略产生该轨迹概率之比 Π_t [π(a_t|x_t)/π′(a_t|x_t)]；实际只需策略概率比值，不依赖环境转移概率。
- 适用场景：环境模型未知、只能试错的多步任务；同策略简单直接，异策略可评估确定性目标策略。
- 慎用情形/局限：蒙特卡罗需完成整条轨迹才更新，效率低；异策略重要性采样加权可能因比值方差大而估计不稳。

### 时序差分学习：Sarsa 与 Q-learning
- 核心思想：结合动态规划（每步更新）与蒙特卡罗（采样）的优点，每执行一步即增量更新值函数，更高效地免模型学习。
- 数学形式/公式：
  - TD 增量更新（γ-折扣）：Q(x,a) ← Q(x,a) + α·[ r + γ·Q(x′,a′) − Q(x,a) ]，其中 x′ 为转移后状态、a′ 为策略在 x′ 上选的动作，α 为步长。
  - Sarsa（同策略）：更新用到 (x, a, r, x′, a′) 五要素（State, Action, Reward, State, Action 首字母），评估与执行均为 ε-贪心策略。
  - Q-learning（异策略）：评估目标策略、执行 ε-贪心策略；更新 Q(x,a) ← Q(x,a) + α·[ r + γ·max_{a′} Q(x′,a′) − Q(x,a) ]，即用下一状态的最大 Q 值（而非实际选的 a′）。
- 适用场景：免模型、需在线高效更新的多步任务；Q-learning 因异策略、可直接学最优动作值而广泛应用。
- 慎用情形/局限：步长 α 影响收敛与重要性加权；表格法仅适用于有限状态/动作空间。

### 值函数近似
- 核心思想：连续/无穷状态空间无法用表格值函数，直接对值函数做参数化近似（如线性函数），再用 TD 学习更新参数。
- 数学形式/公式：
  - 线性近似：V_θ(x) = θᵀx（x 为状态向量，θ 为参数）；近似误差用最小二乘 E[(V^π(x) − θᵀx)²] 度量。
  - 梯度下降更新：θ ← θ + α·(V^π(x) − θᵀx)·x；用 TD 估计目标 V^π(x) ≈ r + γ·V^π(x′) 代替真实值，得 θ ← θ + α·( r + γ·θᵀx′ − θᵀx )·x（对状态-动作值则将动作编码并入状态向量）。
  - 可替换为核方法（第6章）实现非线性近似，或结合神经网络（见习题 16.7）。
- 适用场景：状态空间连续或极大的现实任务。
- 慎用情形/局限：线性近似有较大误差（习题 16.6/16.7 指出现实误差常大），需更强国 approximator；近似可能破坏原有收敛保证。

### 模仿学习：直接模仿与逆强化学习
- 核心思想：当人类专家范例易得时，从范例学比仅靠累积奖赏搜索高效。
- 数学形式/公式：
  - 直接模仿学习：抽取所有范例轨迹的"状态-动作对"构成数据集 D={(x, a)}，用监督学习（离散动作分类、连续动作回归）学得策略，作为强化学习的初始策略再经环境反馈改进。
  - 逆强化学习（IRL）：假设奖赏 R(x)=wᵀx（线性），寻找使范例轨迹最优的奖赏权重 w（即对所有已学策略最小化 (wᵀ·特征期望差)）。迭代进行：从随机策略出发，求解更好的奖赏函数 → 基于奖赏学更好策略 → 直到最符合范例；范例轨迹可看作最优策略的蒙特卡罗采样来近似特征期望。
- 适用场景：奖赏函数难设计、但有专家示范的任务（如机器人控制）；直接模仿快速获得初始策略，IRL 反推奖赏以训练策略。
- 慎用情形/局限：直接模仿不同时刻数据分布可能不同（习题 16.10），需考虑分布变化；IRL 通常只求到与范例一致的解，未必唯一。

## 4. 应用与决策框架

按任务条件选择方法：

1. **只有单步决策、追求即时奖赏最大？** → K-摇臂赌博机：用 ε-贪心（简单、常用小常数 ε）或 Softmax（按奖励差异分配概率；奖励差异大时更偏向利用）。
2. **多步任务，环境模型（转移概率、奖赏）是否已知？**
   - 已知（有模型） → 动态规划：先策略评估（Bellman 迭代），再策略改进；追求简洁用值迭代，追求稳定收敛用策略迭代。
   - 未知（免模型） → 进入 3。
3. **免模型多步任务，如何更新？**
   - 可完整采样轨迹、用 T 步累积奖赏 → 蒙特卡罗（同策略简单；需评估确定性策略用异策略重要性采样）。
   - 需每步在线高效更新 → 时序差分：同策略用 Sarsa，异策略/直接学最优用 Q-learning（首选经典）。
4. **状态空间连续/无穷？** → 值函数近似：线性近似（高效）或引入核方法/神经网络（更强表达）。
5. **有人类专家范例？**
   - 要快速获得初始策略 → 直接模仿学习（监督学习学状态→动作）。
   - 奖赏函数难设计 → 逆强化学习（从范例反推奖赏再训练）。

对照表（简）：

| 条件 | 推荐方法 |
|---|---|
| 单步、探索-利用 | ε-贪心 / Softmax |
| 模型已知 | 策略迭代 / 值迭代 |
| 模型未知、轨迹采样 | 蒙特卡罗（同/异策略） |
| 模型未知、在线更新 | Sarsa（同策略）/ Q-learning（异策略） |
| 连续状态 | 值函数近似（线性/核/NN） |
| 有专家示范 | 直接模仿 / 逆强化学习 |

## 5. 典型案例/例题要点

- **种西瓜任务（强化学习隐喻）**：从选种、浇水、施肥到收获才知瓜好坏，中间动作只有当前反馈（瓜苗更健壮）。抽象为 MDP：状态=瓜苗长势，动作=浇水/施不同肥/用药，转移有概率，奖赏=健康+1、凋零−10、好瓜+100。说明强化学习是"延迟标记信息"的监督学习。
- **西瓜浇水 MDP（图16.2）**：四个状态（健康、缺水、溢水、凋亡）、两个动作（浇水、不浇水）。健康+1、缺水/溢水−1、凋亡−100 且不可逆。最优策略：健康→浇水、溢水→不浇水、缺水→浇水、凋亡→任意。直观展示状态转移、概率、奖赏与最优策略。
- **2-摇臂赌博机性能比较（图16.6）**：摇臂1 以 0.4 返 1、0.6 返 0；摇臂2 以 0.2 返 1、0.8 返 0。比较不同算法平均累积奖赏：Softmax(τ=0.01) 曲线几乎与"仅利用"重合，说明小温度时高度利用。
- **有模型策略评估（图16.7）**：基于 T 步累积奖赏的 Bellman 递归迭代 T 轮精确求值函数；γ-折扣情形替换第3行并设停止阈值 θ。
- **策略迭代（图16.8）与值迭代（图16.9）**：策略迭代在评估后改进策略；值迭代直接由最优 Bellman 更新值函数，再据 Q 得策略。
- **蒙特卡罗同/异策略（图16.10/16.11）**：同策略评估改进同一 ε-贪心策略；异策略用行为策略采样、目标策略评估，按策略概率比值作重要性采样加权。
- **Sarsa 与 Q-learning（图16.12/16.13）**：Sarsa 五要素 (s,a,r,s′,a′) 同策略更新；Q-learning 用 max_{a′}Q(s′,a′) 异策略更新，评估目标策略、执行 ε-贪心。
- **线性值函数近似 Sarsa（图16.14）**：以 θᵀx 替代表格 Q，用 TD 误差更新 θ，可推广到 Q-learning 与核/神经网络近似。

## 6. 金句与重要结论

- 强化学习可看作具有"延迟标记信息"的监督学习问题——没有"示例-标记"对，只有最终结果揭晓后才能"反思"之前动作。
- "探索"与"利用"矛盾：尝试次数有限，加强一方必削弱另一方，须在二者间达成较好折中（探索-利用窘境）。
- 若仅用"仅探索"或"仅利用"，都难以使最终累积奖赏最大化。
- 模型已知时，强化学习任务能归结为基于动态规划的寻优问题；与监督学习不同，这里不涉及泛化能力，而是为每个状态找最好动作。
- 值函数对策略的每一点改进都是单调递增的；改到策略不再变化即满足最优 Bellman 等式、找到最优策略。
- 蒙特卡罗强化学习效率低的主因是未充分利用 MDP 结构（批处理式更新）；时序差分（TD）结合动态规划与蒙特卡罗，做到每步高效更新。
- Sarsa 是同策略算法，Q-learning 是异策略算法；Q-learning 评估目标策略、执行 ε-贪心策略。
- 连续状态空间用离散化难在有效划分，故直接对值函数做近似（值函数近似）。
- 模仿学习是强化学习提速的重要手段；逆强化学习从范例反推奖赏函数，解决奖赏难设计的问题。
- 策略的优劣取决于长期执行后的累积奖赏；学习目的即最大化长期累积奖赏。
- 机器与环境界限：状态转移、奖赏返回不受机器控制，机器只能选动作并观察结果来感知环境。

## 7. 与其他章节的关联

- **第1章 发展历程 / 监督学习**：强化学习可视为"延迟标记信息"的监督学习（状态≈示例，动作≈标记，策略≈分类器/回归器）；与 1.5 节"示教学习"直接关联，模仿学习承接早期示教思想。
- **第2章 比较检验**：赌博机"悔界"（regret bound）分析与在线学习、对抗学习中的累积后悔评估相关。
- **第3章 / 类别不平衡**：重要性采样（异策略蒙特卡罗）是概率分布间期望估计的通用技术。
- **第6章 支持向量机（核方法）**：值函数近似中可用核方法实现非线性近似（16.5 明确引用第6章）。
- **第13章 半监督/第14章 概率图模型 / 阅读材料**：值函数近似中的线性模型、梯度下降与前面章节的机器学习基础一致；TD(λ)、资格迹等是 TD 的推广。
- **第15章 规则学习（本书前一章）**：两者均属符号/学习范式对照——规则学习强调可解释的逻辑规则，强化学习强调试错与累积奖赏；模仿学习把强化学习初始策略用监督学习（含决策树/规则）学得，与规则学习可衔接。
- **动态规划 / 优化（附录 B）**：有模型学习的策略评估、策略迭代、值迭代本质是动态规划；值函数近似用梯度下降（B.4）、坐标下降（B.5）等优化方法更新参数。
- **概率分布（附录 C）**：MDP 的转移概率、赌博机奖赏的概率分布、重要性采样均依赖概率论基础；Boltzmann 分布（Softmax）属指数族分布。
- **前向延伸**：本章 Q-learning、值函数近似、逆强化学习是现代深度强化学习（DQN、策略梯度、Actor-Critic 等）的基础；模仿学习与逆强化学习衔接机器人学、自动驾驶等应用领域。
