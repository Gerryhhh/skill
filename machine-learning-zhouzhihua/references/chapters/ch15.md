# 第15章 规则学习

## 1. 章节核心摘要

规则学习是从训练数据中学习出一组能用于对未见示例进行判别的逻辑规则（"若……，则……"形式的 if-then 规则）。与神经网络、支持向量机等"黑箱模型"相比，规则学习具有更好的可解释性，能自然地引入领域知识，并且在处理需要抽象推理的复杂 AI 任务（如问答系统）时有显著优势。

本章的主线是从简单到复杂地展开规则学习技术：先以"序贯覆盖"作为几乎所有规则学习算法的基本框架（逐条归纳、分治策略）；再用"剪枝"缓解贪心搜索带来的过拟合；随后将表达能力从命题规则提升到能描述对象间"关系"的一阶规则（FOIL 算法）；最后引入归纳逻辑程序设计（ILP），通过函数与逻辑表达式嵌套获得最强表达能力，核心技术为最小一般泛化（LGG）与逆归结。

最重要的结论是：规则学习是"符号主义学习"的主要代表，命题规则学习技术的高峰是 RIPPER，它融合了剪枝与后处理优化，在与决策树学习的长期竞争中首次占据上风（又快又好）；而一阶规则学习与 ILP 则是连接机器学习与知识工程（如 PROLOG 专家系统）的重要桥梁，并能通过逆归结自动发明新谓词，推动知识发现。

## 2. 关键术语表

- **规则（rule）** — 语义明确、可写成"若……则……"形式的逻辑规则，用于描述数据分布隐含的客观规律。
- **规则体（body）** — 逻辑蕴含符号"←"右侧部分，是规则的前提，由若干逻辑文字的合取式组成。
- **规则头（head）** — "←"左侧部分，是规则的结果，通常表示被判定的目标类别或概念（如"好瓜"）。
- **逻辑文字（literal）** — 规则体中对示例属性进行检验的布尔表达式，如"（色泽=乌黑）"或"¬（根蒂=硬挺）"。
- **规则的长度** — 规则体中逻辑文字的个数。
- **覆盖（cover）** — 一条规则能判定为符合其结论的样本，称为被该规则覆盖。
- **冲突（conflict）** — 同一示例被判别结果不同的多条规则覆盖。
- **冲突消解（conflict resolution）** — 解决冲突的策略，常用投票法、排序法、元规则法。
- **带序规则 / 优先级规则（ordered/priority rule）** — 在规则集合上定义顺序，冲突时取排序最前的规则（排序法）。
- **默认规则（default rule）** — 处理规则集未覆盖样本的规则。
- **命题规则（propositional rule）** — 由原子命题与"与/或/非/蕴含"连接词构成的简单陈述句。
- **一阶规则 / 关系型规则（first-order / relational rule）** — 基本成分是能描述属性或关系的原子公式（谓词、函数），可含逻辑变量与量词，能表达复杂关系与递归。
- **序贯覆盖（sequential covering）** — 逐条归纳：每学到一条规则就去除其覆盖的样本，再用剩余样本继续，亦称"分治"（separate-and-conquer）。
- **自顶向下（top-down）** — 从一般规则开始逐步添加文字使其特化（生成-测试法）。
- **自底向上（bottom-up）** — 从特殊规则开始逐步删除文字使其泛化（数据驱动法）。
- **集束搜索（beam search）** — 每轮保留最优的 b 个候选文字，缓解贪心陷入局部最优。
- **剪枝（pruning）** — 缓解规则过拟合的机制，分预剪枝与后剪枝。
- **似然率统计量（LRS）** — CN2 算法用于预剪枝的显著性检验指标，衡量规则覆盖分布与训练集经验分布的差别。
- **减错剪枝（REP）** — 用验证集对规则集穷举剪枝操作并保留最优。
- **IREP（增量式 REP）** — 在生成每条规则后立即对该单条规则剪枝，复杂度低于 REP。
- **RIPPER** — 结合 IREP* 剪枝与后处理（替换规则、修订规则）的著名命题规则学习算法。
- **关系数据（relational data）** — 直接描述样例之间关系的数据；由属性转化来的原子公式称"背景知识"。
- **FOIL** — 著名的一阶规则学习算法，遵循序贯覆盖、自顶向下，用 FOIL 增益选文字。
- **FOIL 增益** — FOIL 中选择文字的标准，仅考虑正例信息量，并以新规则覆盖的正例数加权。
- **归纳逻辑程序设计（ILP）** — 在一阶规则学习中引入函数与逻辑表达式嵌套，学得的规则可被 PROLOG 直接使用。
- **最小一般泛化（LGG）** — 将两个（或多个）一阶公式泛化为能特化为二者的最特殊的一般公式。
- **RLGG（相对最小一般泛化）** — 计算 LGG 时考虑所有背景知识，将样例初始规则定义为"样例←所有背景知识的合取"。
- **逆归结（inverse resolution）** — 基于已知归结项与某一子句反推另一归结商，从而"发明"新概念/新谓词。
- **置换（substitution） / 合一（unification）** — 用项替换变量 / 用一种置换令多个逻辑表达式相等；最一般合一置换（MGU）是 ILP 核心概念。
- **统计关系学习** — 将关系学习与统计学习结合的方向，代表含概率归纳逻辑程序设计、马尔可夫逻辑网等。

## 3. 关键模型与算法

### 序贯覆盖（Sequential Covering）
- 核心思想：逐条归纳生成规则。每学到一条规则，就将其覆盖的训练样本去除，再用剩余样本重复，直到覆盖足够多的样例。因每次只处理一部分数据，亦称"分治"策略。可推广到多分类（每类分别处理，把该类作正例、其余作反例）。
- 数学形式/公式：单条规则形如"⊕ ← f₁ ∧ f₂ ∧ … ∧ f_L"，其中 ⊕ 为目标类别（规则头），f_k 为候选逻辑文字（规则体），L 为规则长度。学习任务是基于候选文字集合，在给定正/反例下搜索最优规则体。单条规则生成中，评估标准常为：先准确率（覆盖正例数/覆盖样例总数），同则比覆盖样例数，再同则比属性次序。
- 适用场景：几乎所有规则学习算法的基本框架；属性与候选值适中、需可解释规则的监督/多分类任务。
- 慎用情形/局限：基于穷尽搜索时属性和候选值多会组合爆炸；纯粹的贪心逐条生成易陷入局部最优（需集束搜索等缓解）；每学一条规则就删去已覆盖样本，后续可参考样本越来越少（见习题 15.10）。

### 自顶向下 vs 自底向上规则生成
- 核心思想：自顶向下从空规则（最一般）开始逐步添加文字使其"特化"；自底向上从具体样例对应规则（最特殊）开始逐步删除文字使其"泛化"。
- 数学形式/公式：无显式统一公式。自顶向下每轮用评估标准（准确率/覆盖数/属性次序）挑选最优或集束（b 个）文字加入；自底向上用删除文字或对常量替换为变量来泛化。
- 适用场景：命题规则学习通常用自顶向下（对噪声更鲁棒、易得较好泛化）；自底向上更适合训练样本较少或假设空间极复杂（如一阶规则/ILP）的情形。
- 慎用情形/局限：自顶向下对噪声鲁棒但假设空间受限；自底向上泛化能力强但对噪声敏感、样本少时易过拟合。

### CN2 算法（基于 LRS 的预剪枝）
- 核心思想：采用集束搜索生成规则，并在预剪枝时用统计显著性检验控制规则生长，是最早考虑过拟合问题的规则学习算法。
- 数学形式/公式：似然率统计量 LRS = 2 ×（规则（集）覆盖样例的似然比统计量），用覆盖的正例数 m⁺、反例数 m⁻ 与训练集总正例数、总反例数计算，衡量规则覆盖分布与训练集经验（后验概率）分布的差别。LRS 越大，说明用规则预测与直接用训练集正反比例猜测差别越大、越可信；数据量大时通常设 LRS 很大（如 0.99 对应显著性水平）才停止生长。
- 适用场景：需要考虑过拟合、属性中等规模的命题规则学习。
- 慎用情形/局限：依赖显著性阈值设定；仅做预剪枝，不如结合后处理的 RIPPER 泛化好。

### 减错剪枝（REP）与 IREP
- 核心思想：将样本划分为训练集与验证集。REP 在训练集上学得规则集后多轮剪枝，每轮穷举删除某文字/尾部文字/整条规则等，用验证集选最优候选。IREP 在生成每条规则前先划分，对单条规则生成后立即在验证集上 REP 剪枝，再去掉其覆盖样本。
- 数学形式/公式：无统一闭式；以验证集错误率为剪枝准则。复杂度：REP 为 O(m⁴)（m 为样例数），IREP 降到 O(m log₂ m)。
- 适用场景：REP 适合规则集整体后剪枝；IREP 适合需高效、逐条处理的场景。
- 慎用情形/局限：REP 复杂度高；两者都需额外验证集。

### RIPPER 算法
- 核心思想：命题规则学习技术的高峰。先用 IREP*（以某种比率指标取代准确率作度量，删尾部多文字，最终再一次性 IREP 剪枝）生成规则集 ℛ；再对每条规则 r_i 产生"替换规则 r′_i"（基于 r_i 覆盖样本重生成）和"修订规则 r″_i"（对 r_i 增加文字特化后再 IREP* 剪枝），将二者分别与 ℛ 中其余规则组成候选集，选最优保留。本质是全局后处理优化缓解贪心局部性。
- 数学形式/公式：无统一闭式；关键是用"替换规则"与"修订规则"做全局重优化，选验证/整体性能最优的规则集。WEKA 中称 JRIP；重复 k 次即 RIPPERk（如 RIPPER5）。
- 适用场景：对泛化性能与速度都要求高的命题规则学习任务，常优于决策树（比 C4.5 又快又好）。
- 慎用情形/局限：仍是命题层次，无法处理对象间关系；后处理增加计算但总体仍高效。

### FOIL（一阶规则学习）
- 核心思想：著名的一阶规则学习算法，遵循序贯覆盖且自顶向下；因逻辑变量存在，生成时需考虑不同变量组合，新文字须含至少一个已出现变量。学完后可做后剪枝，允许目标谓词作候选可学递归规则，允许否定文字可得更简洁规则集。
- 数学形式/公式：FOIL 增益 = m⁺ ×（log₂((m⁺+1)/(m⁺ + m⁻ +1)) − log₂((m⁺′+1)/(m⁺′ + m⁻′ +1))），其中 m⁺、m⁻ 为加入候选文字前规则覆盖的正/反例数，m⁺′、m⁻′ 为加入后覆盖的正/反例数。该增益仅考虑正例信息量并以新规则覆盖正例数 m⁺ 加权（因关系数据中正例远少于反例，需更关注正例）。
- 适用场景：需表达对象间关系（如"瓜1 比瓜2 更好"）的任务；可看作命题规则学习与 ILP 之间的过渡。
- 慎用情形/局限：自顶向下过程不支持函数与逻辑表达式嵌套，表达能力仍不足；比一般 ILP 高效但比命题规则复杂。

### 最小一般泛化（LGG / RLGG）
- 核心思想：ILP 自底向上生成策略的基础。将一条或多条正例对应具体事实作初始规则，再逐步泛化（常量替换为变量、删除文字）以提升覆盖率。LGG 是能特化为给定公式的最特殊一般公式。
- 数学形式/公式：对两个一阶公式 r₁、r₂，LGG 先找出含相同谓词的文字，逐位置比较常量：若相同则保留，若不同则替换为同一新变量并推广到所有同位置；忽略不含共同谓词的文字（保证 LGG 能特化为任一条）。RLGG 在计算时纳入所有背景知识，将样例 e 的初始规则定义为 e ← K（K 为所有背景原子合取）。
- 适用场景：一阶规则/ILP 的初始规则构造，尤其当需从具体正例归纳一般关系规则时。
- 慎用情形/局限：仅基于正例；函数与嵌套引入后候选原子公式可能无穷多，单纯自底向上也面临困难。

### 逆归结（Inverse Resolution）
- 核心思想：归结原理是从 C₁=A∨L、C₂=B∨¬L 消去互补项 L 得归结项 C=A∨B（演绎）。逆归结则在已知 C 与某 C_i 时反推另一归结商 C_j，从而基于背景知识发明新概念/新谓词。一阶情形需借助"合一置换"搜索互补项。
- 数学形式/公式：命题归结写作 C = (C₁ − {L}) ∨ (C₂ − {¬L})，简记 C = C₁ ◦ C₂。逆归结定义归结商 C₁ = C / C₂、C₂ = C / C₁。一阶逆归结需找置换 θ 使 L₁θ = ¬L₂θ（MGU 最一般合一置换），再求归结商。逆归结能自动发明新谓词 q（如由"p←A∧B"与"p←A∧C"推出"p←A∧q"，并进一步学到"q←B""q←C"），对应原知识中未显式存在的新关系。
- 适用场景：ILP 中发明新谓词、发现新知识；连接机器学习与逻辑程序（PROLOG）。
- 慎用情形/局限：发明的新谓词语义需使用者结合领域理解才能明确；计算复杂，通常先自底向上生成规则再结合 LGG 与逆归结。

## 4. 应用与决策框架

何时选用本章哪种方法，可按以下决策步骤：

1. **任务只需可解释的分类/判别规则、且属性-值表示足够？**
   - 是 → 用命题规则学习（序贯覆盖为框架）。
     - 关注过拟合控制 → CN2（LRS 预剪枝）或 REP/IREP 后剪枝。
     - 追求最佳泛化与速度 → RIPPER（首选，常优于决策树）。
2. **任务涉及对象间关系、需比较/递归表达（如"X 比 Y 更好"）？**
   - 用一阶规则学习 → FOIL（效率高，表达中等）。
   - 还需函数/表达式嵌套、引入丰富领域知识、或要被 PROLOG 直接调用 → 归纳逻辑程序设计（ILP）：
     - 初始规则用 LGG/RLGG 自底向上构造；
     - 进一步发明新概念用逆归结。
3. **规则生成策略选择：**
   - 属性多、有噪声、要稳健泛化 → 自顶向下（命题规则标准做法）；
   - 样本少或假设空间极复杂 → 自底向上（ILP 常用）。
4. **缓解局部最优：** 单条规则生成用集束搜索（beam search，保留 b 个候选）。
5. **缓解过拟合：** 预剪枝（CN2 的 LRS）或后剪枝（REP→IREP→RIPPER 后处理）。

对照表（简）：

| 需求 | 推荐方法 |
|---|---|
| 快速、高泛化、可解释 | RIPPER |
| 控制过拟合、显著性检验 | CN2 |
| 表达对象间关系 | FOIL |
| 引入领域知识/递归/PROLOG可用 | ILP（LGG + 逆归结） |
| 样本少 | 自底向上生成 |

## 5. 典型案例/例题要点

- **西瓜数据集 2.0 的命题规则集 ℛ**：规则1"好瓜←（根蒂=蜷缩）∧（脐部=凹陷）"、规则2"¬好瓜←（纹理=模糊）"。说明"被规则1覆盖的样本是好瓜，但没被覆盖的未必不是好瓜"；只有被以"¬好瓜"为头的规则覆盖的才判为非好瓜。未覆盖样本用默认规则处理。
- **序贯覆盖自顶向下示例**：从空规则"好瓜←"开始，第一轮评估"色泽=乌黑""脐部=凹陷"均达 3/4 最高准确率；选"色泽=乌黑"加入，第二轮在覆盖样本上加"根蒂=蜷缩"得 100% 准确率，最终得"好瓜←（色泽=乌黑）∧（根蒂=蜷缩）"。
- **集束搜索（b=2）示例**：首轮保留两个 3/4 文字，第二轮可得"好瓜←（脐部=凹陷）∧（根蒂=蜷缩）"，同样 100% 但覆盖 3 个正例，比贪心单路更好。
- **西瓜数据集 5.0（关系数据）**：将原属性转为"色泽更深""根蒂更蜷"等背景知识，类别转为"更好/¬更好"。学出一阶规则"更好(X,Y) ← 根蒂更蜷(X,Y) ∧ 脐部更凹(X,Y)"，并能表达递归"更好(X,Y) ← 更好(X,Z) ∧ 更好(Z,Y)"。
- **FOIL 增益示例**：在西瓜数据集 5.0 上，给空规则加"色泽更深(X,Y)"或"脐部更凹(X,Y)"各覆盖 16 正例 2 反例，FOIL 增益约 13.28（取最大），例如得"更好(X,Y) ← 色泽更深(X,Y)"。
- **LGG 示例**：对"更好(1,10)"与"更好(1,15)"两条初始规则，比较常量（10≠15）替换为 Y，忽略仅一方有的"声音更沉(1,10)"，得"更好(1,Y) ← 根蒂更蜷(1,Y) ∧ 脐部更凹(1,Y) ∧ 触感更硬(1,Y)"；再与瓜2的初始规则求 LGG，最终得不含常量的一般规则"更好(X,Y₂) ← 根蒂更蜷(X,Y₂) ∧ 脐部更凹(X,Y₂) ∧ 触感更硬(X,Y₂)"。
- **逆归结发明谓词示例**：由"更好(1,X)←根蒂更蜷(1,X)∧纹理更清(1,X)"与"更好(1,Y)←根蒂更蜷(1,Y)∧敲声更沉(1,Y)"，用内构操作发明新二元谓词 q，得归结商"q(1,S)←纹理更清(1,S)"与"q(1,T)←敲声更沉(1,T)"，q 的语义需领域理解明确。

## 6. 金句与重要结论

- 规则学习中的"规则"是狭义的、约定俗成省略"逻辑"二字；它比黑箱模型有更好的可解释性。
- 数理逻辑具有极强表达能力，绝大多数人类知识都能通过数理逻辑简洁刻画；规则学习能更自然地引入领域知识。
- 几乎所有规则学习算法都以"序贯覆盖"为基本框架。
- 自顶向下（特化）通常比自底向上（泛化）对噪声更鲁棒、更易得较好泛化；自底向上更适合样本少或假设空间极复杂（如一阶规则）的任务。
- 仅用"仅探索"或"仅利用"都难以使累积奖赏最大化，必须在探索与利用间达成较好折中（集束搜索、ε-贪心等缓解贪心局部最优）。
- CN2 是最早考虑过拟合问题的规则学习算法；后剪枝（Fürnkranz, 1994）在缓解过拟合中优势明显。
- RIPPER 融合剪枝与后处理优化，使规则学习首次在"与决策树学习的长期竞争中占据上风"（比 C4.5 又快又好）。
- 命题规则是一阶规则的特例，一阶规则学习比命题规则复杂得多。
- FOIL 可看作命题规则学习与归纳逻辑程序设计之间的过渡。
- 归纳逻辑程序设计（ILP）学得的规则几乎能直接被 PROLOG 等逻辑程序解释器调用，是连接机器学习与知识工程的重要桥梁。
- 逆归结能自动"发明"新谓词，对知识发现与精化有重要意义；但新谓词的具体语义只能通过使用者对领域的进一步理解来明确。
- 将关系学习与统计学习相结合是机器学习发展的一大趋势，概率归纳逻辑程序设计（PILP）等"统计关系学习"是重要代表。

## 7. 与其他章节的关联

- **第4章 决策树**：规则学习与决策树学习对比密切——决策树每个叶结点对应一个等价类、试图划分不重叠等价类，而规则学习不强制这一点，模型复杂度常更低（PRISM 体现此优势）；决策树剪枝（4.3）思想是规则剪枝（预/后剪枝）的直接来源。
- **第2章 比较检验 / 统计显著性**：CN2 的 LRS 预剪枝基于似然率统计量，依赖统计显著性检验思想。
- **第3章 类别不平衡问题**：FOIL 增益仅关注正例信息量，本质上与类别不平衡相关（关系数据中正例远少于反例）。
- **第8章 集成学习**：规则集可看作多个子模型的集成；冲突消解中的"投票法"与集成学习思想相通。
- **第1章 归纳偏好 / 发展历程**：奥卡姆剃刀原则用于逆归结中选择更简洁的谓词发明；符号主义学习（规则学习）与 1.5 节知识工程、专家系统（PROLOG）发展直接相连。
- **第6章 支持向量机（核方法）**：值函数近似（第16章）与非线性规则表达中可引入核方法实现非线性近似。
- **第14章 概率图模型 / 阅读材料**：概率归纳逻辑程序设计、关系贝叶斯网、马尔可夫逻辑网等"统计关系学习"与概率模型结合，承接贝叶斯网、概率图模型思想。
- **前向铺垫**：本章一阶规则、ILP 的逻辑基础（置换、合一、归结）为后续"统计关系学习"与知识图谱推理提供基础。
