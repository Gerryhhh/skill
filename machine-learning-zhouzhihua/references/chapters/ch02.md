# 第2章 模型评估与选择

## 1. 章节核心摘要
本章解决的核心问题是：面对多种学习算法、同一算法不同参数配置所产生的多个模型，如何评估并选出泛化性能最优者。主线围绕“泛化误差不可直接获得”这一根本困难展开。

首先界定误差概念：训练集上的误差称“经验误差”，新样本上的误差称“泛化误差”；我们追求泛化误差小，但易陷入“过拟合”（把训练样本自身特点当作一般规律）这一机器学习的关键障碍，而过拟合无法彻底避免，只能缓解。

其次给出三类通过实验估计泛化误差的方法：留出法、交叉验证法（含特例留一法）、自助法，并讨论调参与最终模型的训练策略（用全部数据重训最终模型，区分验证集与测试集）。

接着系统介绍性能度量：错误率/精度、查准率/查全率与 F1、ROC 与 AUC、代价敏感错误率与代价曲线，强调“模型好坏是相对的，取决于任务需求”。

然后给出统计比较检验方法（假设检验、交叉验证 t 检验、McNemar 检验、Friedman 与 Nemenyi 检验），说明性能比较远比“比大小”复杂。

最后用“偏差-方差分解”从理论层面解释泛化误差来源，并引出“偏差-方差窘境”。

## 2. 关键术语表
- 错误率（error rate）— 分类错误样本数占样本总数比例 E = a/m。
- 精度（accuracy）— 1 − 错误率。
- 误差（error）— 学习器实际预测输出与样本真实输出之差（指误差期望）。
- 经验误差/训练误差（empirical/training error）— 学习器在训练集上的误差。
- 泛化误差（generalization error）— 学习器在新样本上的误差（我们真正关心的）。
- 过拟合（overfitting）/过配 — 学得“太好”，把训练样本自身特点当作一般性质，导致泛化性能下降。
- 欠拟合（underfitting）/欠配 — 对训练样本的一般性质尚未学好。
- 模型选择（model selection）— 选用哪种学习算法、哪种参数配置的问题。
- 测试集/测试误差 — 用于近似泛化误差的、与训练集互斥的数据集及其上的误差。
- 留出法（hold-out）— 直接将数据集划分为互斥的训练集 S 与测试集 T。
- 分层采样（stratified sampling）— 保持类别比例一致的采样方式。
- 交叉验证法（cross validation）/k 折交叉验证 — 将数据集划分为 k 个互斥子集，轮流用 k−1 个训练、1 个测试，取 k 次结果均值。
- 留一法（LOO, Leave-One-Out）— k=m 的交叉验证特例，每次留一个样本作测试。
- 自助法（bootstrapping）/自助采样 — 有放回采样 m 次得到 D′，D\D′ 作测试集；未出现的约 36.8%。
- 包外估计（out-of-bag estimate）— 自助法中用 D\D′ 作测试的结果。
- 调参（parameter tuning）/参数调节 — 设定算法参数（超参数）与模型参数。
- 验证集（validation set）— 模型评估与选择中用于调参/选模型的数据集（区别于最终使用的测试数据）。
- 性能度量（performance measure）— 衡量模型泛化能力的评价标准（好坏是相对的，取决于任务）。
- 查准率（precision）/准确率 — 预测为正例中真正正例的比例。
- 查全率（recall）/召回率 — 真正正例中被预测为正例的比例。
- 混淆矩阵（confusion matrix）— 以 TP/FP/TN/FN 表示四类分类结果的矩阵。
- P-R 曲线 — 以查准率为纵轴、查全率为横轴的曲线；下面积表征双高比例。
- 平衡点（BEP）— 查准率=查全率时的取值。
- F1 / Fβ — 查准率与查全率的调和平均；β 控制查全率相对查准率的重要性。
- 宏/微查准率、宏/微 F1（macro/micro）— 多混淆矩阵综合考察的两种平均方式。
- ROC 曲线 — 纵轴真正例率 TPR、横轴假正例率 FPR 的曲线；对角线为随机猜测。
- AUC（Area Under ROC Curve）— ROC 曲线下面积，衡量排序质量；AUC = 1 − ℓ_rank。
- 非均等代价（unequal cost）/代价矩阵 — 对不同类型错误赋予不同损失。
- 代价敏感错误率 — 在非均等代价下最小化总体代价的错误率。
- 代价曲线 — 横轴正例概率代价、纵轴归一化代价，反映期望总体代价。
- 假设检验（hypothesis test）— 基于统计检验推断泛化性能差异是否显著。
- 二项检验 / t 检验 — 单学习器泛化错误率检验方法。
- 交叉验证 t 检验 / 5×2 交叉验证 — 两学习器性能比较的成对检验。
- McNemar 检验 — 基于二分类列联表的卡方检验。
- Friedman 检验 / Nemenyi 后续检验 — 多数据集多算法比较的基于排序的检验。
- 偏差-方差分解（bias-variance decomposition）— 将期望泛化误差拆为偏差、方差、噪声之和。
- 偏差-方差窘境（bias-variance dilemma）— 偏差与方差通常冲突，训练不足偏差主导、训练充足方差主导。

## 3. 关键模型与算法
### 经验误差与过拟合
- 核心思想：以经验误差最小化为训练目标，但经验误差小不意味泛化好；学习能力过强易导致过拟合，学习能力低下导致欠拟合。
- 数学形式/公式：错误率 E = a/m（m 样本中有 a 个分类错误）；精度 = 1 − a/m。训练误差即经验误差，新样本误差即泛化误差。
- 适用场景：所有学习任务训练目标的设定与诊断。
- 慎用情形/局限：过拟合无法彻底避免（若可彻底避免则意味着 P=NP）；各类算法都须带缓解过拟合的措施，只能“缓解”其风险。

### 留出法（hold-out）
- 核心思想：直接将数据集 D 划分为互斥的训练集 S 与测试集 T（D=S∪T，S∩T=∅），用 T 上的测试误差估计泛化误差。
- 数学形式/公式：错误率估计 = (T 上分类错误样本数) / |T|；如 300 个测试样本错 90 个，则错误率 30%、精度 70%。常见做法将约 2/3~4/5 样本用于训练。
- 适用场景：快速、实现简单的评估；数据量充足时。
- 慎用情形/局限：单次划分结果不稳定，需多次随机划分取平均；训练/测试集比例影响估计偏差与方差（测试集小则方差大，训练集小则偏差大）。

### 交叉验证法（k 折）与留一法（LOO）
- 核心思想：将 D 划分为 k 个大小相似、分布一致（分层采样）的互斥子集，每次用 k−1 个训练、余下 1 个测试，重复 k 次取均值；k=m 时为留一法。
- 数学形式/公式：D = D₁∪…∪D_k，D_i∩D_j=∅；评估结果 = (k 次测试误差) 均值。常用 k=10（10 折），亦用 5、20；可重复 p 次取均值（如 10 次 10 折）。
- 适用场景：比留出法更稳定保真；留一法评估结果常较准确。
- 慎用情形/局限：留一法在数据集大时要计算 m 个模型，开销难忍；且“没有免费的午餐”定理对评估方法同样适用，留一法未必永远最优。

### 自助法（bootstrapping）
- 核心思想：有放回采样 m 次得到 D′（自助采样），D′ 作训练集，D\D′（约 36.8% 未出现样本）作测试集，结果称包外估计。
- 数学形式/公式：单样本在 m 次自助采样中始终不被采到的概率为 (1−1/m)^m，取极限 ≈ 1/e ≈ 36.8%，故约 36.8% 样本未进入 D′、可用于测试。
- 适用场景：数据集较小、难以有效划分训练/测试集时；能产生多个不同训练集，利于集成学习。
- 慎用情形/局限：自助采样改变了初始数据分布，引入估计偏差；数据量足够时留出法/交叉验证法更常用。

### 调参与最终模型
- 核心思想：算法参数（超参数，常 <10 个）与模型参数（可极多）均需设定；对每个参数选范围与步长产生候选值，评估后选定；模型选择完成后再用全部数据 D 重训最终模型。
- 数学形式/公式：如对参数在 [0,0.2] 以 0.05 为步长，候选值 5 个；3 个参数各 5 候选则需考察 5³=125 个模型。
- 适用场景：所有带参数的学习算法。
- 慎用情形/局限：候选值往往非“最佳”，是计算开销与性能估计的折中；调参工程量大，常对最终性能有决定性影响。

### 性能度量：查准率/查全率/F1
- 核心思想：错误率不足以刻画“挑出的好瓜中好瓜比例”“所有好瓜被挑出比例”等需求，改用查准率 P 与查全率 R；二者矛盾，用 F1（调和平均）或 Fβ 综合。
- 数学形式/公式（二分类，TP/FP/TN/FN 为对应样本数）：
  - P = TP / (TP + FP)；R = TP / (TP + FN)。
  - F1 = 2PR / (P + R) = 2TP / (样例总数 + TP − TN)（标准 F1）。
  - Fβ = (1+β²)·PR / (β²·P + R)，β>1 查全率更重要，β<1 查准率更重要，β=1 退化为 F1；调和平均更重视较小值。
  - 宏平均（先各矩阵算 P/R 再平均）与微平均（先平均 TP/FP/TN/FN 再算）。
- 适用场景：信息检索、推荐、医疗筛查等关注“正例质量/覆盖”的任务。
- 慎用情形/局限：P 与 R 矛盾，需依任务定夺侧重；仅二分类直接定义，多分类需扩展。

### 性能度量：ROC 与 AUC
- 核心思想：学习器输出实值/概率预测，按预测值排序后取不同截断点对应不同 P/R；ROC 曲线以 TPR 为纵轴、FPR 为横轴刻画“一般情况下”的泛化性能；AUC 为曲线下面积。
- 数学形式/公式：
  - TPR = TP / (TP + FN)；FPR = FP / (TN + FP)。
  - AUC 估计（近似）：对 ROC 曲线上相邻点 (x₁,y₁)…(x_m,y_m)（x₁=0, x_m=1）按梯形面积求和。
  - 排序损失 ℓ_rank：对每对正/反例，若正例预测值 < 反例记 1 罚分，相等记 0.5；有 AUC = 1 − ℓ_rank。
- 适用场景：需比较不同截断点下综合性能、重视排序质量的任务。
- 慎用情形/局限：ROC 曲线被包住才可断言优劣，交叉时只能比 AUC；有限测试样例只能绘近似 ROC。

### 代价敏感错误率与代价曲线
- 核心思想：不同类型错误代价不同（如误诊患者 vs 误诊健康人），引入非均等代价与代价矩阵，目标是最小化总体代价而非错误次数；代价曲线可反映期望总体代价。
- 数学形式/公式（二分类，第0类为正、第1类为反，D⁺/D⁻ 为正/反例子集）：
  - 代价敏感错误率 = (cost₀₁·FP + cost₁₀·FN) / (cost₀₁·(FP+TN) + cost₁₀·(TP+FN))。
  - 代价曲线横轴：正例概率代价 P(+)cost = p·cost₀₁ / (p·cost₀₁ + (1−p)·cost₁₀)；纵轴：归一化代价 cost_norm = FNR·p·cost₀₁/(...) + FPR·(1−p)·cost₁₀/(...)；将 ROC 每点转代价平面线段，取所有线段下界围成面积即期望总体代价。
- 适用场景：错误后果严重不对称的任务（医疗、安防、金融风控）。
- 慎用情形/局限：关键是代价比值而非绝对值；ROC 在非均等代价下不能直接反映期望总体代价，须用代价曲线。

### 统计比较检验
- 核心思想：测试性能受泛化误差、测试集选择、算法随机性影响，不能直接比大小；用假设检验判断性能差异是否统计显著。
- 数学形式/公式要点：
  - 二项检验：泛化错误率 ε 的学习器在 m 个样本上恰错 εm 个的概率服从二项分布；检验“ε ≤ ε₀”是否可在显著度 α 下不拒绝（置信度 1−α）。
  - t 检验：k 次测试错误率均值 μ、方差 σ²，变量 (√k·(μ−ε₀))/σ 服从自由度 k−1 的 t 分布，检验“μ=ε₀”。
  - 交叉验证 t 检验（成对）：两学习器 k 折误差差值的 t 检验；用 5×2 交叉验证缓解非独立问题。
  - McNemar 检验：二分类列联表 e₀₁/e₁₀，变量 (|e₀₁−e₁₀|−1)²/(e₀₁+e₁₀) 近似服从自由度 1 的 χ² 分布。
  - Friedman 检验：N 个数据集比较 k 个算法，按平均序值 r_i 构造统计量；原始式在 k 小时保守，常用改进式服从 F 分布；若拒绝“性能相同”则用 Nemenyi 后续检验，临界值域 CD = q_α·√(k(k+1)/(6N))。
- 适用场景：论文/工程中严谨比较多算法、多数据集性能。
- 慎用情形/局限：检验结果依赖显著度 α 与数据划分；交叉验证误差非独立会高估显著性，宜用 5×2 交叉验证。

### 偏差-方差分解
- 核心思想：对回归任务，将期望泛化误差拆解为偏差、方差与噪声三项之和，揭示泛化性能由算法能力、数据充分性、任务难度共同决定。
- 数学形式/公式（测试样本 x，y_D 为数据标记、y 为真实标记、f(x;D) 为模型预测，假定噪声期望为 0）：
  - 期望预测 f̄(x) = E_D[f(x;D)]。
  - 方差 var(x) = E_D[(f(x;D) − f̄(x))²]（同样大小训练集变动导致的性能变化）。
  - 噪声 ε² = E_D[(y_D − y)²]（任务本身难度下界）。
  - 偏差 bias²(x) = (f̄(x) − y)²（期望预测与真实标记偏离，刻画算法拟合能力）。
  - 期望泛化误差 = bias² + var + ε²。
- 适用场景：理论解释学习算法泛化行为、指导训练程度控制。
- 慎用情形/局限：该优美分解仅在基于均方误差的回归任务中严格成立；分类任务（0/1 损失）理论上难推导，需借实验估计。偏差与方差冲突（偏差-方差窘境）：训练不足偏差主导，训练充足方差主导，过拟合发生于方差主导阶段。

## 4. 应用与决策框架
如何选择“评估方法 + 性能度量 + 比较方式”，可按下表/步骤决策：

1. 选择评估方法（取决于数据规模与用途）：
   - 数据量充足 → 留出法（2/3~4/5 训练）或 k 折交叉验证（常用 10 折，重复 p 次）。
   - 数据量小、难划分 → 自助法（注意分布偏差）。
   - 追求最准确且数据不特大 → 留一法（但计算贵）。
   - 需产生多个训练集（如集成学习）→ 自助法。
2. 训练/测试集划分原则：互斥、保持分布一致（分层采样）、多次随机划分取平均；测试集至少约 30 个样例。
3. 选择性能度量（取决于任务需求）：
   - 一般分类好坏 → 错误率/精度。
   - 关注“挑出的正例有多准 / 正例被挑出多少” → 查准率、查全率、F1/Fβ、P-R 曲线、BEP。
   - 关注排序质量、不同截断点综合性能 → ROC 与 AUC。
   - 错误代价不对称 → 代价敏感错误率与代价曲线。
4. 模型选择完成后：用全部数据 D 重训最终模型；评估中用“验证集”调参，用“测试集”估计实际泛化能力。
5. 多算法/多数据集比较：先用假设检验（交叉验证 t 检验、McNemar、Friedman+Nemenyi）判断差异是否显著，勿直接比数值大小。
6. 诊断泛化问题：借偏差-方差视角——欠拟合（偏差大）增加模型复杂度/训练程度；过拟合（方差大）减小复杂度、加正则/更多数据。

- 偏差-方差窘境（图2.9）：训练不足偏差主导，加深训练方差渐主导，过拟合发生于训练充足后。

## 6. 金句与重要结论
- “我们事先并不知道新样本是什么样，实际能做的是努力使经验误差最小化”，但经验误差极小（甚至 0）的学习器多数情况下并不好。
- 过拟合是机器学习面临的关键障碍；过拟合无法彻底避免，只能“缓解”——若可彻底避免则意味着 P=NP。
- 测试集应尽量与训练集互斥；否则得到的是过于“乐观”的估计（如同用习题原题考试）。
- 自助采样中初始数据集约有 36.8% 的样本未出现在采样集中。
- 模型选择完成后，应“用数据集 D 重新训练模型”，这才是最终提交给用户的模型。
- 性能度量反映任务需求；“模型好坏是相对的，不仅取决于算法和数据，还决定于任务需求”。
- 查准率和查全率是一对矛盾的度量。
- AUC 考虑的是样本预测的排序质量，AUC = 1 − ℓ_rank。
- “没有免费的午餐”定理对实验评估方法同样适用（留一法未必永远最准）。
- 泛化误差可分解为偏差、方差与噪声之和；泛化性能由算法能力、数据充分性、任务难度共同决定。
- 偏差与方差通常有冲突，称“偏差-方差窘境”。
