# 《机器学习》术语表汇总

> 由 16 章「关键术语表」合并。查单章详见 references/chapters/chNN.md。

### 第1章 绪论

## 2. 关键术语表
- 机器学习（machine learning）— 研究如何通过计算的手段利用经验（数据）改善系统性能，主要内容是从数据中产生“模型”的“学习算法”。
- 模型（model）/学习器（learner） — 从数据中学得的结果；学习算法在给定数据和参数空间上的实例化。
- 数据集（data set） — 记录的集合；每条记录描述一个事件/对象。
- 示例（instance）/样本（sample） — 数据集中的一条记录；在属性空间中是一个“特征向量”。
- 属性（attribute）/特征（feature） — 描述对象某方面的事项（如色泽、根蒂、敲声）。
- 属性值（attribute value） — 属性上的取值（如青绿、乌黑）。
- 属性空间/样本空间/输入空间 — 属性张成的空间。
- 特征向量（feature vector） — 示例在属性空间中的坐标向量。
- 维数（dimensionality） — 描述示例所用的属性个数 d。
- 训练（training）/学习（learning） — 从数据中学得模型的过程。
- 训练集（training set）/训练样本 — 训练过程中使用的数据及其中每个样本。
- 假设（hypothesis） — 学得模型对应的关于数据潜在规律的猜测；潜在规律本身称“真相/真实”（ground-truth）。
- 标记（label） — 关于示例结果的信息（如“好瓜”）。
- 样例（example） — 拥有标记信息的示例，记为 (x, y)。
- 标记空间/输出空间 — 所有标记的集合。
- 分类（classification） — 预测离散值；二分类（正类/反类）、多分类。
- 回归（regression） — 预测连续值（标记空间为实数集）。
- 聚类（clustering） — 将样本分成若干组（簇），训练样本通常无标记。
- 监督学习（supervised learning） — 训练数据有标记（分类、回归）；亦称“有导师学习”。
- 无监督学习（unsupervised learning） — 训练数据无标记（聚类）；亦称“无导师学习”。
- 泛化（generalization） — 学得模型适用于新样本的能力。
- 分布（distribution）/独立同分布（i.i.d.） — 假设样本服从未知分布，且每个样本独立同分布采样。
- 归纳（induction）/演绎（deduction） — 特殊到一般的“泛化”过程 / 一般到特殊的“特化”过程。
- 归纳学习（inductive learning） — “从样例中学习”，属归纳过程；狭义指概念学习。
- 假设空间（hypothesis space） — 所有可能假设组成的空间；搜索目标为与训练集“匹配”的假设。
- 版本空间（version space） — 与训练集一致（对所有训练样本判断正确）的假设集合。
- 归纳偏好（inductive bias）/偏好 — 学习算法对学习过程中某种类型假设的偏好，使其能产生确定结果。
- 奥卡姆剃刀（Occam's razor） — “若有多个假设与观察一致，则选最简单的那个”。
- 没有免费的午餐定理（NFL 定理）— 在所有问题同等重要、机会相同的假设下，任意两学习算法的期望性能相同。
- 连接主义/符号主义/统计学习 — 三条主流技术路线（神经网络 / 决策树与逻辑 / SVM 与核方法）。


### 第2章 模型评估与选择

## 2. 关键术语表
- 错误率（error rate）— 分类错误样本数占样本总数比例 E = a/m。
- 精度（accuracy）— 1 − 错误率。
- 误差（error）— 学习器实际预测输出与样本真实输出之差（指误差期望）。
- 经验误差/训练误差（empirical/training error）— 学习器在训练集上的误差。
- 泛化误差（generalization error）— 学习器在新样本上的误差（我们真正关心的）。
- 过拟合（overfitting）/过配 — 学得“太好”，把训练样本自身特点当作一般性质，导致泛化性能下降。
- 欠拟合（underfitting）/欠配 — 对训练样本的一般性质尚未学好。
- 模型选择（model selection）— 选用哪种学习算法、哪种参数配置的问题。
- 测试集/测试误差 — 用于近似泛化误差的、与训练集互斥的数据集及其上的误差。
- 留出法（hold-out）— 直接将数据集划分为互斥的训练集 S 与测试集 T。
- 分层采样（stratified sampling）— 保持类别比例一致的采样方式。
- 交叉验证法（cross validation）/k 折交叉验证 — 将数据集划分为 k 个互斥子集，轮流用 k−1 个训练、1 个测试，取 k 次结果均值。
- 留一法（LOO, Leave-One-Out）— k=m 的交叉验证特例，每次留一个样本作测试。
- 自助法（bootstrapping）/自助采样 — 有放回采样 m 次得到 D′，D\D′ 作测试集；未出现的约 36.8%。
- 包外估计（out-of-bag estimate）— 自助法中用 D\D′ 作测试的结果。
- 调参（parameter tuning）/参数调节 — 设定算法参数（超参数）与模型参数。
- 验证集（validation set）— 模型评估与选择中用于调参/选模型的数据集（区别于最终使用的测试数据）。
- 性能度量（performance measure）— 衡量模型泛化能力的评价标准（好坏是相对的，取决于任务）。
- 查准率（precision）/准确率 — 预测为正例中真正正例的比例。
- 查全率（recall）/召回率 — 真正正例中被预测为正例的比例。
- 混淆矩阵（confusion matrix）— 以 TP/FP/TN/FN 表示四类分类结果的矩阵。
- P-R 曲线 — 以查准率为纵轴、查全率为横轴的曲线；下面积表征双高比例。
- 平衡点（BEP）— 查准率=查全率时的取值。
- F1 / Fβ — 查准率与查全率的调和平均；β 控制查全率相对查准率的重要性。
- 宏/微查准率、宏/微 F1（macro/micro）— 多混淆矩阵综合考察的两种平均方式。
- ROC 曲线 — 纵轴真正例率 TPR、横轴假正例率 FPR 的曲线；对角线为随机猜测。
- AUC（Area Under ROC Curve）— ROC 曲线下面积，衡量排序质量；AUC = 1 − ℓ_rank。
- 非均等代价（unequal cost）/代价矩阵 — 对不同类型错误赋予不同损失。
- 代价敏感错误率 — 在非均等代价下最小化总体代价的错误率。
- 代价曲线 — 横轴正例概率代价、纵轴归一化代价，反映期望总体代价。
- 假设检验（hypothesis test）— 基于统计检验推断泛化性能差异是否显著。
- 二项检验 / t 检验 — 单学习器泛化错误率检验方法。
- 交叉验证 t 检验 / 5×2 交叉验证 — 两学习器性能比较的成对检验。
- McNemar 检验 — 基于二分类列联表的卡方检验。
- Friedman 检验 / Nemenyi 后续检验 — 多数据集多算法比较的基于排序的检验。
- 偏差-方差分解（bias-variance decomposition）— 将期望泛化误差拆为偏差、方差、噪声之和。
- 偏差-方差窘境（bias-variance dilemma）— 偏差与方差通常冲突，训练不足偏差主导、训练充足方差主导。


### 第3章 线性模型

## 2. 关键术语表

- 线性模型（linear model）— 用属性线性组合 f(x)=wᵀx+b 进行预测的函数模型。
- 非线性模型（nonlinear model）— 在线性模型基础上引入层级结构或高维映射得到的更复杂模型。
- 可解释性 / 可理解性（comprehensibility）— 由 w 直观体现各属性重要程度的性质。
- 线性回归（linear regression）— 用线性模型尽可能准确预测实值输出标记。
- 均方误差 / 平方损失（square loss）— 回归任务中最常用的性能度量，对应欧氏距离，最小化它的方法即最小二乘法。
- 最小二乘法（least square method）— 基于均方误差最小化求解模型的方法；求最优解的过程称“参数估计”。
- 闭式解（closed-form）— 可直接由公式写出的最优解，如线性回归的正规方程解。
- 多元线性回归（multivariate linear regression）— 样本由 d 个属性描述的线性回归，又称“多变量线性回归”。
- 满秩矩阵 / 正定矩阵（full-rank / positive definite matrix）— XᵀX 可逆的前提；现实常不满秩。
- 正则化（regularization）— 在模型不满秩或防过拟合时引入约束项以选定/约束解。
- 对数线性回归（log-linear regression）— lny=wᵀx+b，形式上线性、实质是非线性映射，是广义线性模型的特例。
- 广义线性模型（generalized linear model）— y=g⁻¹(wᵀx+b)，g 称为“联系函数”（link function）。
- 对数几率回归 / 对率回归（logistic regression）— 用对数几率函数作联系函数，名字叫“回归”实为分类方法。
- 单位阶跃函数（unit-step function）— 理想但不连续的 0/1 映射；亦称 Heaviside 函数。
- 对数几率函数 / 对率函数（logistic function）— Sigmoid 函数代表，y=1/(1+e⁻ᶻ)，单调可微、任意阶可导。
- 几率（odds）/ 对数几率（log odds, logit）— 正例可能性与反例可能性之比，及其对数。
- 极大似然法（maximum likelihood method）— 令每个样本属于其真实标记的概率最大以估计参数。
- 梯度下降法 / 牛顿法（gradient descent / Newton method）— 求解凸目标最优解的经典数值优化算法。
- 线性判别分析（LDA, Fisher 判别分析）— 将样本投影到一条直线，使同类投影尽量接近、异类尽量远离的线性分类法。
- 类内散度矩阵（within-class scatter matrix, S_w）/ 类间散度矩阵（between-class scatter matrix, S_b）— LDA 目标中的两类散度。
- 广义瑞利商（generalized Rayleigh quotient）— LDA 最大化的目标形式 S_b w / S_w w。
- 多分类学习 / 拆解法 — 把多分类任务拆成若干二分类任务求解。
- 一对一（OvO, One vs. One）/ 一对其余（OvR, One vs. Rest）/ 多对多（MvM, Many vs. Many）— 三种经典拆分策略。
- 纠错输出码（ECOC）— 用编码矩阵拆分多分类、并在解码时具容错能力的 MvM 技术；含二元码、三元码。
- 类别不平衡（class-imbalance）— 不同类别训练样例数差别很大的情况。
- 再缩放（rescaling）/ 再平衡（rebalance）— 根据观测几率调整决策阈值的基本策略。
- 欠采样（undersampling, 下采样）/ 过采样（oversampling, 上采样）/ 阈值移动（threshold-moving）— 处理类别不平衡的三类技术。
- 代价敏感学习（cost-sensitive learning）— 在非均等误分类代价下学习；再缩放是其基础。
- 稀疏表示（sparse representation）/ 稀疏性（sparsity）— 仅少数系数为非零解的表示；LASSO 用 L1 范数近似 L0 以求得稀疏解。
- 多标记学习（multi-label learning）— 一个样本可同时拥有多个类别标记（区别于多分类）。


### 第4章 决策树

## 2. 关键术语表

- 决策树（decision tree）/ 判定树 — 基于树结构进行决策的模型；有时指学习方法，有时指学得的树。
- 分而治之（divide-and-conquer）— 决策树生成的基本递归策略：不断按属性划分样本子集。
- 纯度（purity）— 结点所包含样本属于同一类别的程度；划分过程使纯度越来越高。
- 信息熵（information entropy）— 度量样本集合纯度最常用的指标；值越小纯度越高。
- 信息增益（information gain）— 用某属性划分后纯度的提升量；ID3 选择信息增益最大的属性。
- 增益率（gain ratio）— C4.5 使用的准则，用“固有值”对信息增益做除数以抑制对多值属性的偏好。
- 固有值（intrinsic value）— 属性 a 的取值数目越多（V 越大）通常越大的量，用于修正信息增益。
- 基尼指数 / 基尼值（Gini index / Gini）— CART 使用的纯度度量，反映随机抽取两样本类别不一致的概率；越小纯度越高。
- 剪枝（pruning）— 对付过拟合的主要手段，去掉一些分支降低过拟合风险。
- 预剪枝（prepruning）— 生成过程中，划分前估计若不能提升泛化性能则停止划分并标记为叶结点。
- 后剪枝（postpruning）— 先生成完整树，再自底向上考察，若用叶结点替换子树能提升泛化则剪枝。
- 决策树桩（decision stump）— 仅有一层划分（一个划分结点）的决策树，是预剪枝常见结果。
- 连续值处理 / 二分法（bi-partition）— 对连续属性取相邻取值中点为候选划分点，进行二分。
- 缺失值处理 — 用样本权重机制处理属性值缺失下的划分选择与被划分问题。
- 轴平行（axis-parallel）— 标准决策树分类边界由若干与坐标轴平行的分段组成。
- 单变量决策树（univariate decision tree）— 每个非叶结点仅测试单个属性的传统决策树。
- 多变量决策树（multivariate decision tree）/ 斜决策树（oblique decision tree）— 非叶结点对属性线性组合进行测试，实现“斜划分”。
- 增量学习（incremental learning）— 接收新样本后仅局部调整模型而不重训全部；ID4/ID5R/ITI 等为代表。


### 第5章 神经网络

## 2. 关键术语表

- 神经网络（neural networks）/ 神经网络学习 — 由适应性简单单元并行互连组成的网络及其学习过程。
- 神经元（neuron）/ 单元（unit）— 网络最基本成分，即 M-P 模型中的“简单单元”。
- M-P 神经元模型 — 1943 年 McCulloch & Pitts 提出的模型：带权输入与阈值比较后经激活函数输出。
- 阈值（threshold）/ 偏差（bias）— 神经元激活的判断界限；常把阈值看作固定输入−1.0 的哑结点连接权。
- 激活函数（activation function）/ 响应函数 — 对神经元总输入做非线性变换产生输出；理想阶跃函数不连续，实际常用 Sigmoid。
- Sigmoid 函数 / 挤压函数（squashing function）— 把大范围输入挤压到 (0,1) 的单调可微函数；对数几率函数是其典型代表。
- 感知机（Perceptron）/ 阈值逻辑单元 — 两层神经元，输出层为 M-P 神经元；可学逻辑与/或/非。
- 线性可分（linearly separable）— 存在线性超平面能分开两类模式；感知机对此必收敛。
- 隐层 / 隐含层（hidden layer）— 输入层与输出层之间的层，其神经元拥有激活函数，是功能神经元。
- 多层前馈神经网络（multi-layer feedforward neural networks）/ 单隐层网络 — 层级全互连、无同层/跨层连接；含隐层即多层，“单隐层”指仅一个隐层。
- 连接权（connection weight）— 神经元之间的权重，是神经网络学习的核心参数。
- 误差逆传播（BP, error BackPropagation）/ 反向传播 — 训练多层网络最成功的算法，基于梯度下降。
- 标准 BP / 累积 BP（accumulated error backpropagation）— 前者逐样本更新，后者读完整个训练集后才更新参数。
- 早停（early stopping）/ 正则化（regularization）— 缓解 BP 过拟合的两类策略；正则化在误差目标中加连接权与阈值平方和项。
- 局部极小（local minimum）/ 全局最小（global minimum）— 参数空间中邻域/全体误差最小的解；全局最小必为局部极小，反之不然。
- 梯度下降（gradient descent）/ 随机梯度下降（SGD）— 沿负梯度方向寻优；SGD 在梯度中加随机性，有助跳出局部极小。
- 模拟退火（simulated annealing）— 以一定概率接受次优解以跳出局部极小的技术。
- 径向基函数网络（RBF 网络）— 单隐层前馈网络，隐层用径向基函数、输出层线性组合隐层输出。
- ART 网络 / 竞争型学习 / 胜者通吃（winner-take-all）— 识别层神经元竞争获胜、可增量/在线学习，缓解可塑性-稳定性窘境。
- SOM 网络 / 自组织映射（Self-Organizing Map）— 竞争型无监督网络，将高维数据映射到低维并保持拓扑结构。
- 级联相关网络（Cascade-Correlation）— 结构自适应网络，训练中新隐结点逐渐加入、输入端权冻结。
- 递归神经网络（recurrent neural networks）/ Elman 网络 — 允许环形连接、输出反馈作输入，可处理时序动态；Elman 是常用代表。
- Boltzmann 机 / 受限 Boltzmann 机（RBM）/ 能量模型 — 以“能量”定义网络状态，RBM 仅保留显层-隐层连接，用对比散度（CD）训练。
- 深度学习（deep learning）— 很深层的神经网络；通过增加隐层提升容量。
- 预训练（pre-training）/ 微调（fine-tuning）— 无监督逐层训练后再全局训练的多隐层训练策略。
- 权共享（weight sharing）/ 卷积神经网络（CNN）— 一组神经元用相同连接权；CNN 用卷积层+采样(汇合)层，大幅减少参数量。
- 特征学习 / 表示学习（feature learning / representation learning）— 深度学习通过多层加工把低层特征转化为高层特征，替代人工特征工程。
- 特征工程（feature engineering）— 由人类专家设计样本特征；深度学习旨在减少其依赖。


### 第6章 支持向量机

## 2. 关键术语表
- 划分超平面（separating hyperplane）— 在样本空间中将不同类别分开的线性方程 wᵀx + b = 0 所描述的平面；w 为法向量决定方向，b 为位移项决定与原点距离。
- 间隔（margin）— 两个异类支持向量到超平面距离之和，等于 2/‖w‖；最大化间隔是 SVM 的目标。
- 支持向量（support vector）— 距离超平面最近、使间隔约束等号成立的训练样本；最终模型仅由它们决定。
- 最大间隔（maximum margin）— 在正确分类约束下使间隔最大化的准则。
- 基本型（SVM 基本型）— 最小化 1/2‖w‖²、约束为 yᵢ(wᵀxᵢ+b)≥1 的凸二次规划问题。
- 对偶问题（dual problem）— 由拉格朗日乘子法从基本型导出的等价优化问题，变量为样本对应的乘子 aᵢ。
- KKT 条件— 带不等式约束优化问题取最优解需满足的互补松弛等条件；SVM 中体现为 aᵢ=0 或 yᵢf(xᵢ)=1。
- 核函数（kernel function）— 满足 k(xᵢ,xⱼ)=φ(xᵢ)ᵀφ(xⱼ) 的函数，隐式定义高维特征空间，免去直接计算高维内积。
- 核技巧（kernel trick）— 用核函数代替特征空间内积，使算法只需在原空间计算 k(·,·) 即可获得非线性能力。
- 再生核希尔伯特空间（RKHS）— 任一核函数隐式定义的特征空间。
- 半正定核矩阵（kernel matrix）— 以 k(xᵢ,xⱼ) 为元素的矩阵；定理6.1 要求它对任意数据都半正定，这样的对称函数才能作核函数。
- 硬间隔（hard margin）— 要求所有样本都被正确分类、满足间隔约束。
- 软间隔（soft margin）— 允许部分样本不满足间隔约束，以提升容错与泛化。
- 替代损失（surrogate loss）— 用凸、连续且是 0/1 损失上界的函数替代不可微的 0/1 损失，如 hinge、指数、对率损失。
- 松弛变量（slack variable）ξᵢ— 表征第 i 个样本不满足间隔约束程度的非负变量。
- 正则化（regularization）— 在经验风险之外加入结构风险项 Ω(f) 以控制模型复杂度、抑制过拟合；C 为正则化常数。
- 结构风险 / 经验风险— 描述模型性质的项 / 描述与训练数据契合程度的项。
- 支持向量回归（SVR）— 回归版 SVM，允许预测值与真实值有 ε 以内的偏差而不计损失。
- ε-不敏感损失（ε-insensitive loss）— SVR 的损失：仅当 |f(x)−y|>ε 时才计算损失，形成宽度为 2ε 的间隔带。
- 表示定理（representer theorem）— 一大类正则化风险最小化问题的最优解总可写为核函数的线性组合。
- 核方法（kernel methods）— 基于核函数的一系列学习方法统称；"核化"即引入核函数把线性学习器拓展为非线性。
- SMO（Sequential Minimal Optimization）— 高效求解 SVM 对偶的算法：每步只优化两个乘子，有闭式解。


### 第7章 贝叶斯分类器

## 2. 关键术语表
- 贝叶斯决策论（Bayesian decision theory）— 概率框架下基于后验概率与误判损失选择最优类别的基本方法。
- 条件风险（conditional risk）R(c|x)— 把样本 x 判为 c 的期望损失；多分类下为对各类误判损失的加权和。
- 贝叶斯最优分类器（Bayes optimal classifier）— 每个样本选使条件风险最小的类别；总体风险称为贝叶斯风险。
- 风险（risk）/期望损失— 决策论中对"期望损失"的称呼；1−R(h*) 反映分类器可达的最好性能（精度理论上限）。
- 误判损失 λᵢⱼ— 把真实为 cⱼ 的样本错分为 cᵢ 所产生的损失。
- 判别式模型（discriminative models）— 直接建模 P(c|x) 预测类别，如决策树、BP 网络、SVM。
- 生成式模型（generative models）— 先建模联合 P(x,c) 再得后验，如朴素贝叶斯、贝叶斯网。
- 先验（prior）P(c)— 类"先验"概率，各类样本在空间中比例。
- 似然（likelihood）P(x|c)— 类条件概率，样本 x 相对于类 c 的条件概率。
- 证据（evidence）P(x)— 归一化因子，与类标记无关。
- 极大似然估计（MLE）— 频率主义学派方法：选使训练数据出现"可能性"最大的参数值。
- 属性条件独立性假设— 朴素贝叶斯的核心假设：已知类别时所有属性相互独立。
- 拉普拉斯修正（Laplacian correction）— 平滑技术，避免未观测属性值使概率估为 0；本质引入均匀先验。
- 半朴素贝叶斯分类器— 放松独立性假设、仅考虑部分属性依赖的方法族。
- 独依赖估计（ODE）— 假设每个属性在类别之外最多依赖一个其他属性（父属性）。
- SPODE / TAN / AODE— 独依赖分类器的代表：超父 ODE / 树增强贝叶斯 / 平均独依赖估计（集成式）。
- 贝叶斯网（Bayesian network）/信念网— 用有向无环图刻画属性依赖、用条件概率表描述联合分布的概率图模型。
- 有向分离（D-separation）/道德图（moral graph）/道德化— 分析有向图中条件独立性的工具；把 V 型结构的父节点相连、有向边改无向得到道德图。
- 最小描述长度（MDL）/ AIC / BIC— 贝叶斯网结构学习的评分函数（基于信息论编码长度）。
- 推断（inference）/证据（evidence）— 用已知变量观测值推测待查询变量；已知观测称证据。
- 精确推断 / 近似推断— 直接算后验（NP 难）vs 吉布斯采样等近似方法。
- 吉布斯采样（Gibbs sampling）— 在联合状态空间随机漫步、依平稳分布近似后验的马尔可夫链方法。
- 隐变量（latent variable）— 未观测到的变量；EM 算法用于含隐变量的参数估计。
- EM 算法（Expectation-Maximization）— 迭代：E 步算隐变量分布期望、M 步最大化期望似然，直至收敛。


### 第8章 集成学习

## 2. 关键术语表
- 集成学习（ensemble learning）— 构建并结合多个学习器完成学习任务；亦称多分类器系统、基于委员会的学习。
- 个体学习器（individual learner）/基学习器（base learner）— 由单个学习算法从训练数据产生；同质集成的个体称基学习器。
- 基学习算法（base learning algorithm）/组件学习器（component learner）— 同质用基学习算法；异质集成中不同算法产生的个体称组件学习器。
- 同质（homogeneous）/异质（heterogeneous）— 集成中个体是否同为一种学习算法。
- 弱学习器（weak learner）— 泛化性能略优于随机猜测的学习器（如二分类精度略高于 50%）。
- 多样性（diversity）— 个体学习器间的差异；与"准确性"共同决定集成好坏。
- 好而不同— 集成对个体的核心要求：既准确又多样。
- Boosting— 串行、强依赖的集成族，将弱学习器提升为强学习器，关注降低偏差。
- Bagging— 基于自助采样（bootstrap）的并行集成代表，关注降低方差。
- 随机森林（Random Forest, RF）— Bagging 的扩展：在决策树训练中进一步引入随机属性选择。
- AdaBoost— Boosting 最著名代表；迭代调整样本分布、加权结合基分类器。
- 加性模型（additive model）— 基学习器的线性组合 H(x)=Σα_t h_t(x)，AdaBoost 可由此推导。
- 指数损失函数（exponential loss）— AdaBoost 优化的目标 ℓ_exp=exp(−f(x)H(x))，是 0/1 损失的一致替代。
- 重赋权法 / 重采样法— Boosting 中让基学习器关注不同数据分布的两种实现（权重 vs 重新采样）。
- 自助采样（bootstrap sampling）— 有放回采样 m 次，约 63.2% 样本被采中。
- 包外估计（out-of-bag estimate）— 用未被某基学习器采中的约 36.8% 样本估计其泛化误差。
- 结合策略— 把个体输出组合成集成输出的方法：平均法、投票法、学习法。
- 平均法（averaging）— 简单平均 / 加权平均（回归数值输出）。
- 投票法（voting）— 绝对多数/相对多数/加权投票（分类）；硬投票（类标记）/软投票（类概率）。
- Stacking（学习法）— 用次级学习器（元学习器）结合初级学习器输出；次级集由交叉验证生成防过拟合。
- 误差-分歧分解（error-ambiguity decomposition）— E = 加权平均误差 − 加权平均分歧，揭示准确性与多样性的权衡。
- 多样性度量（diversity measure）— 估算个体分类器多样化程度，如不合度量、相关系数、Q-统计量、κ-统计量。
- 多样性增强— 通过数据样本/输入属性/输出表示/算法参数扰动引入随机性。
- 稳定基学习器（stable base learner）— 对样本扰动不敏感的学习器（线性、SVM、朴素贝叶斯、k 近邻），需靠属性扰动等增强多样性。


### 第9章 聚类

## 2. 关键术语表
- 聚类（clustering）— 将无标记样本划分为若干不相交子集（簇）的无监督学习任务。
- 簇（cluster）— 聚类得到的样本子集，亦称"类"。
- 簇标记（cluster label）— 样本所属簇的编号 λ_j∈{1,…,k}。
- 性能度量 / 有效性指标（validity index）— 评估聚类结果好坏的指标，也可作为聚类过程的优化目标。
- 外部指标（external index）— 将聚类结果与参考模型（如专家划分）比较的指标。
- 内部指标（internal index）— 不依赖任何参考模型、直接考察聚类结果的指标。
- 簇内相似度 / 簇间相似度（intra-/inter-cluster similarity）— 同一簇内样本彼此相似、不同簇样本彼此相异的程度。
- 距离度量（distance measure）— 满足非负性、同一性、对称性、直递性（三角不等式）的函数。
- 闵可夫斯基距离（Minkowski distance）— 连续属性的通用距离 ‖x_i−x_j‖_p。
- 欧氏距离 / 曼哈顿距离 / 切比雪夫距离 — 闵氏距离在 p=2、p=1、p→∞ 时的特例。
- 有序属性（ordinal）/ 无序属性（non-ordinal）— 属性值是否定义了"序"关系，决定能否直接算距离。
- VDM（Value Difference Metric）— 针对无序离散属性的距离度量。
- 非度量距离（non-metric distance）— 不满足直递性的相似度距离（如"人""马"与"人马"的例子）。
- 距离度量学习（distance metric learning）— 基于数据样本学习合适的距离计算式。
- 原型聚类（prototype-based clustering）— 用一组"代表性点（原型）"刻画簇结构的聚类。
- k均值（k-means）— 最小化簇内平方误差的原型聚类，贪心迭代求解。
- 学习向量量化（LVQ）— 利用样本类别标记辅助学习的监督式原型聚类。
- 高斯混合聚类（Mixture-of-Gaussian）— 用 k 个高斯分布混合模型表达簇、借 EM 算法求解的原型聚类。
- 密度聚类（density-based clustering）— 从样本密度/可连接性出发的聚类，典型为 DBSCAN。
- 核心对象（core object）— ε-邻域内样本数不少于 MinPts 的样本。
- 密度直达 / 密度可达 / 密度相连 — DBSCAN 中描述样本可连接性的三种关系。
- 噪声 / 异常（noise/anomaly）— 不属于任何簇的样本。
- 层次聚类（hierarchical clustering）— 在不同层次做树形划分，可自底向上聚合或自顶向下分拆。
- AGNES — 自底向上聚合的层次聚类算法；按簇间距离计算方式分单链接、全链接、均链接。
- Voronoi 剖分 — 由一组原型向量定义的样本空间划分（每个样本归入最近原型）。


### 第10章 降维与度量学习

## 2. 关键术语表
- k近邻（kNN）— 基于距离找 k 个最近训练样本、用投票/平均预测的监督学习方法。
- 懒惰学习（lazy learning）/ 急切学习（eager learning）— kNN 仅保存样本、测试时才计算（前者）；训练阶段即学习模型（后者）。
- 密采样（dense sample）— 任意测试样本附近任意小范围内都能找到训练样本，是 kNN 良好性能的假设前提。
- 维数灾难（curse of dimensionality）— 高维下样本稀疏、距离计算困难的现象。
- 降维 / 维数约简（dimension reduction）— 将高维空间经变换映射到低维子空间。
- 嵌入（embedding）— 高维空间中与学习任务相关的低维分布结构。
- 子空间（subspace）— 降维后样本所处的低维空间。
- 多维缩放（MDS）— 保持原始空间样本距离的低维表示方法。
- 线性降维 — 符合 Z=WᵀX 的降维，W 为变换矩阵。
- 主成分分析（PCA）— 最常用的无监督线性降维，取方差最大方向。
- 最近重构性 / 最大可分性 — PCA 的两种等价优化视角（投影重构误差最小 / 投影后方差最大）。
- 核化（kernelized）— 借核技巧将线性降维推广到非线性（如 KPCA）。
- 本真（intrinsic）低维空间 — 样本最初被采样的低维空间（区别于降维后的空间）。
- 流形学习（manifold learning）— 借拓扑流形概念、保持局部结构做非线性降维。
- 等度量映射（Isomap）— 用近邻图上的最短路径逼近流形测地线距离再做 MDS。
- 局部线性嵌入（LLE）— 保持邻域内样本线性重构关系的非线性降维。
- 测地线距离（geodesic）— 流形表面上两点间的最短路径距离（本真距离）。
- 度量学习（metric learning）/ 距离度量学习 — 直接从数据学习合适的距离度量。
- 马氏距离（Mahalanobis distance）— 以半正定对称矩阵 M（度量矩阵）参数化的距离。
- 近邻成分分析（NCA）— 以最大化近邻分类器留一法正确率为目标的度量学习。
- 必连（must-link）/ 勿连（cannot-link）— 度量学习中"样本应相似/不相似"的约束。


### 第11章 特征选择与稀疏学习

## 2. 关键术语表
- 特征选择（feature selection）— 从特征集中选出相关特征子集的过程。
- 相关特征 / 无关特征 / 冗余特征 — 对任务有用 / 无用 / 信息可被其他特征推得的特征。
- 数据预处理（data preprocessing）— 获数据后先特征选择、再训学习器的环节。
- 子集搜索（subset search）— 生成候选特征子集的策略：前向（渐增）、后向（渐减）、双向。
- 子集评价（subset evaluation）— 评价候选子集好坏，如用信息增益衡量与标记划分的差异。
- 过滤式（filter）/ 包裹式（wrapper）/ 嵌入式（embedding）— 特征选择的三类方法（与学习器无关/以学习器性能为准则/与训练融为一体）。
- Relief — 著名的过滤式方法，用"相关统计量"度量特征重要性，靠猜中/猜错近邻更新。
- Relief-F — Relief 的多分类扩展。
- LVW（Las Vegas Wrapper）— 拉斯维加斯框架下的包裹式特征选择，以分类器误差为准则。
- 嵌入式选择与 L1 正则化 — 在训练同时做特征选择；L1 比 L2 更易得稀疏解。
- 岭回归（ridge regression）— L2 范数正则化的线性回归（Tikhonov 回归）。
- LASSO — L1 范数正则化的线性回归，可产生稀疏解、兼做特征选择。
- 稀疏（sparse）解 — 模型参数 w 中非零分量很少的解。
- 近端梯度下降（PGD）— 求解 L1 正则化（如 LASSO）的常用优化方法。
- 稀疏表示（sparse representation）/ 字典学习（dictionary learning）/ 稀疏编码（sparse coding）— 将稠密样本表示为"字典矩阵×稀疏系数"；学字典与求稀疏表达常同一过程完成。
- 压缩感知（compressed sensing）— 利用信号稀疏性，从少量观测恢复完整信号。
- 限定等距性（RIP）— 压缩感知中保证可由少量观测恢复稀疏信号的条件。
- 矩阵补全（matrix completion）/ 低秩矩阵恢复 — 由部分观测恢复完整低秩矩阵（如协同过滤），用核范数近似秩。
- 核范数（nuclear norm）/ 迹范数 — 矩阵奇异值之和，是秩的凸包近似。


### 第12章 计算学习理论

## 2. 关键术语表

- **计算学习理论（computational learning theory）**：研究机器学习理论基础的学科，分析学习任务困难本质并提供理论保证。
- **PAC 学习（Probably Approximately Correct）**：概率近似正确学习框架；"概率"指以较大置信度(1−δ)，"近似正确"指误差不超过预设上限 ε。
- **泛化误差 E(h; 𝒟)**：假设 h 在分布 𝒟 上的真实误分类概率，等于经验误差的期望。
- **经验误差 Ê(h; D)**：假设 h 在训练集 D 上的平均误分类率。
- **概念（concept）c**：从样本空间到标记空间的映射，决定示例真实标记；目标概念即真实映射。
- **概念类 C**：所有希望学得的目标概念构成的集合。
- **假设空间 ℋ**：学习算法考虑的所有可能概念的集合；假设 h 是其中元素。
- **可分 / 一致（separable / consistent）**：目标概念 c∈ℋ，存在假设能把所有示例完全分开。
- **不可分 / 不一致（non-separable）**：c∉ℋ，无任何假设能完全正确分开。
- **误差参数 ε**：预设的学得模型应满足的泛化误差上限。
- **置信度 1−δ**：对"学到误差≤ε 的模型"这一结论的把握程度。
- **样本复杂度（sample complexity）**：满足 PAC 学习所需的最少样例数 m。
- **恰 PAC 可学习（properly PAC learnable）**：假设空间与概念类完全相同，即 ℋ=C。
- **不可知学习（agnostic learning）**：目标概念 c∉ℋ 时，退而求 ℋ 中泛化误差最小假设的 ε-近似。
- **增长函数 Π_ℋ(m)**：假设空间 ℋ 对 m 个示例所能赋予标记的最大可能结果数，描述 ℋ 的表示能力。
- **对分（dichotomy）**：二分类问题中，ℋ 中假设对示例集赋予标记的一种可能结果。
- **打散（shattering）**：若 ℋ 能实现示例集 D 上的所有 2^|D| 种对分，则称 D 被 ℋ 打散。
- **VC 维（Vapnik-Chervonenkis dimension）**：能被 ℋ 打散的最大示例集的大小 d，记为 VC(ℋ)=d。
- **Sauer 引理**：若 VC 维为 d，则增长函数满足 Π_ℋ(m) ≤ Σ_{i=0}^{d} C(m,i)，当 m≥d 时上界约为 (em/d)^d。
- **Rademacher 复杂度**：以 Rademacher 随机变量（±1 等概率）度量假设空间与随机噪声的相关程度，刻画 ℋ 的表示能力。
- **经验 Rademacher 复杂度**：固定样本集 Z 上，ℋ 与随机噪声相关性的期望上确界。
- **稳定性（stability）**：算法输入（训练集）发生微小变化时，输出假设变化不大的性质。
- **β-均匀稳定性**：对任意单样本改变，学习算法的损失变化不超过 β。
- **ERM（经验风险最小化）原则**：学习算法输出经验误差（经验损失）最小的假设。
- **合（disagreement）**：两个映射在样本集上预测不一致的程度。


### 第13章 半监督学习

## 2. 关键术语表

- **未标记样本（unlabeled）**：类别标记未知的样本，数量 u 远大于有标记样本数 l（l≪u）。
- **有标记样本（labeled）**：类别标记已知的样本，记作 D_l。
- **半监督学习（semi-supervised learning）**：利用未标记样本自动提升学习性能的学习范式。
- **主动学习（active learning）**：通过与专家交互，挑选"对改善模型最有帮助"的样本查询标记，用最少查询获最好性能（引入额外专家知识）。
- **聚类假设（cluster assumption）**：数据存在簇结构，同一簇的样本属于同一类别。
- **流形假设（manifold assumption）**：数据分布在一个流形结构上，邻近样本拥有相似输出；可看作聚类假设的推广，适用范围更广。
- **纯半监督学习（pure semi-supervised）**：假设未标记样本不是待预测数据，目标模型适用于训练时未观察到的数据（开放世界）。
- **直推学习（transductive learning）**：假设未标记样本恰是待预测数据，只求在这些样本上最优（封闭世界）。
- **生成式方法（generative methods）**：假设所有数据由同一潜在生成式模型产生，未标记数据的标记看作缺失参数，用 EM 算法求解。
- **低密度分隔（low-density separation）**：半监督 SVM 的基本假设——划分超平面应穿过数据低密度区域（聚类假设在线性划分上的推广）。
- **TSVM（Transductive SVM）**：最著名的半监督 SVM，针对二分类，对未标记样本尝试各种标记指派并最大化间隔。
- **伪标记（pseudo-label）**：未标记样本被算法赋予的临时标记，用于迭代训练。
- **图半监督学习**：把数据集映射为图，标记作为"颜色"在图上扩散/传播。
- **亲和矩阵（affinity matrix）W**：图的边权矩阵，常基于高斯函数 W_ij=exp(−‖x_i−x_j‖²/(2σ²)) 定义。
- **拉普拉斯矩阵（Laplacian matrix）Δ**：Δ=D−W，D 为度对角矩阵。
- **标记传播（label propagation）**：基于图的能量最小化/迭代传播，将已知标记扩散到未标记样本。
- **基于分歧的方法（disagreement-based methods）**：用多学习器，以学习器之间的"分歧"来利用未标记数据。
- **协同训练（co-training）**：多视图数据的代表方法，两个视图分别训练分类器、互相提供高置信度伪标记。
- **多视图（multi-view）**：一个对象拥有多个属性集（如电影的图像、声音视图），各视图具相容性与互补性。
- **充分且条件独立视图**：每个视图单独含足量信息，且在给定标记下两视图独立（协同训练强理论保证的前提）。
- **半监督聚类（semi-supervised clustering）**：利用少量监督信息（必连/勿连约束或有标记种子）改善聚类。
- **必连（must-link）/ 勿连（cannot-link）**：约束样本必属同簇 / 必不属同簇。
- **约束 k-means / 约束种子 k-means**：将监督信息融入 k 均值的半监督聚类算法。


### 第14章 概率图模型

## 2. 关键术语表

- **概率模型（probabilistic model）**：把学习任务归结为计算变量概率分布的框架。
- **推断（inference）**：由可观测变量推测未知变量（含隐变量）的条件分布。
- **生成式模型**：对联合分布 P(Y,O,R) 建模。
- **判别式模型**：对条件分布 P(Y,R|O) 建模。
- **概率图模型（probabilistic graphical model）**：用图表达变量相关关系；分有向（贝叶斯网）与无向（马尔可夫网）。
- **隐马尔可夫模型（HMM）**：结构最简单的动态贝叶斯网，有向图，用于时序数据；含隐藏状态变量与观测变量。
- **状态变量 y_t / 观测变量 x_t**：HMM 中第 t 时刻的隐状态与可观测值。
- **马尔可夫链（Markov chain）**：下一时刻状态仅由当前状态决定，与以往无关。
- **状态转移概率矩阵 A**：a_ij 表示从状态 s_i 转移到 s_j 的概率。
- **输出观测概率矩阵 B**：b_ij 表示在状态 s_i 下观测到 o_j 的概率。
- **初始状态概率 π**：初始时刻各状态出现概率。
- **马尔可夫随机场（MRF）**：典型无向图模型；用势函数（因子）定义联合分布。
- **团（clique）/ 极大团（maximal clique）**：任意两结点有边相连的结点子集；极大团是不能再被包含的团。
- **势函数（potential function）/ 因子**：定义在团上的非负实函数，刻画变量间相关关系。
- **规范化因子 Z**：使联合分布为合法概率的归一化常数（常难精确计算）。
- **全局/局部/成对马尔可夫性**：给定分离集/邻接变量/其他所有变量时条件独立的三条性质。
- **马尔可夫毯（Markov blanket）**：某变量的所有邻接变量集合，给定它该变量条件独立于其余变量。
- **条件随机场（CRF）**：判别式无向图模型，对条件分布 P(y|x) 建模；链式 CRF 最常用。
- **特征函数（转移/状态）**：CRF 中刻画相邻标记关系、观测对标记影响的实值函数。
- **变量消去（variable elimination）**：精确推断，利用条件独立性按序求和消去变量（动态规划）。
- **信念传播（Belief Propagation）/ Sum-Product**：把变量消去看作消息传递，避免重复计算；无环图两趟完成。
- **近似推断**：采样（MCMC）与确定性近似（变分推断）两类。
- **MCMC（马尔可夫链蒙特卡罗）**：构造平稳分布为目标分布的马尔可夫链产生样本。
- **Metropolis-Hastings（MH）算法**：基于拒绝采样逼近平稳分布的 MCMC。
- **吉布斯采样（Gibbs sampling）**：MH 特例，逐变量按条件概率采样。
- **变分推断（variational inference）**：用简单分布逼近复杂后验，常结合平均场（mean field）假设。
- **盘式记法（plate notation）**：用方框表示由相同机制独立生成的重复变量，使图简洁。
- **话题模型（topic model）**：生成式有向图模型，处理离散数据（文本等）；代表为 LDA。
- **LDA（隐狄利克雷分配）**：每篇文档含多个话题、每个词来自某话题的词频分布。
- **词 / 文档 / 话题 / 词袋（bag-of-words）**：话题模型的基本概念。


### 第15章 规则学习

## 2. 关键术语表

- **规则（rule）** — 语义明确、可写成"若……则……"形式的逻辑规则，用于描述数据分布隐含的客观规律。
- **规则体（body）** — 逻辑蕴含符号"←"右侧部分，是规则的前提，由若干逻辑文字的合取式组成。
- **规则头（head）** — "←"左侧部分，是规则的结果，通常表示被判定的目标类别或概念（如"好瓜"）。
- **逻辑文字（literal）** — 规则体中对示例属性进行检验的布尔表达式，如"（色泽=乌黑）"或"¬（根蒂=硬挺）"。
- **规则的长度** — 规则体中逻辑文字的个数。
- **覆盖（cover）** — 一条规则能判定为符合其结论的样本，称为被该规则覆盖。
- **冲突（conflict）** — 同一示例被判别结果不同的多条规则覆盖。
- **冲突消解（conflict resolution）** — 解决冲突的策略，常用投票法、排序法、元规则法。
- **带序规则 / 优先级规则（ordered/priority rule）** — 在规则集合上定义顺序，冲突时取排序最前的规则（排序法）。
- **默认规则（default rule）** — 处理规则集未覆盖样本的规则。
- **命题规则（propositional rule）** — 由原子命题与"与/或/非/蕴含"连接词构成的简单陈述句。
- **一阶规则 / 关系型规则（first-order / relational rule）** — 基本成分是能描述属性或关系的原子公式（谓词、函数），可含逻辑变量与量词，能表达复杂关系与递归。
- **序贯覆盖（sequential covering）** — 逐条归纳：每学到一条规则就去除其覆盖的样本，再用剩余样本继续，亦称"分治"（separate-and-conquer）。
- **自顶向下（top-down）** — 从一般规则开始逐步添加文字使其特化（生成-测试法）。
- **自底向上（bottom-up）** — 从特殊规则开始逐步删除文字使其泛化（数据驱动法）。
- **集束搜索（beam search）** — 每轮保留最优的 b 个候选文字，缓解贪心陷入局部最优。
- **剪枝（pruning）** — 缓解规则过拟合的机制，分预剪枝与后剪枝。
- **似然率统计量（LRS）** — CN2 算法用于预剪枝的显著性检验指标，衡量规则覆盖分布与训练集经验分布的差别。
- **减错剪枝（REP）** — 用验证集对规则集穷举剪枝操作并保留最优。
- **IREP（增量式 REP）** — 在生成每条规则后立即对该单条规则剪枝，复杂度低于 REP。
- **RIPPER** — 结合 IREP* 剪枝与后处理（替换规则、修订规则）的著名命题规则学习算法。
- **关系数据（relational data）** — 直接描述样例之间关系的数据；由属性转化来的原子公式称"背景知识"。
- **FOIL** — 著名的一阶规则学习算法，遵循序贯覆盖、自顶向下，用 FOIL 增益选文字。
- **FOIL 增益** — FOIL 中选择文字的标准，仅考虑正例信息量，并以新规则覆盖的正例数加权。
- **归纳逻辑程序设计（ILP）** — 在一阶规则学习中引入函数与逻辑表达式嵌套，学得的规则可被 PROLOG 直接使用。
- **最小一般泛化（LGG）** — 将两个（或多个）一阶公式泛化为能特化为二者的最特殊的一般公式。
- **RLGG（相对最小一般泛化）** — 计算 LGG 时考虑所有背景知识，将样例初始规则定义为"样例←所有背景知识的合取"。
- **逆归结（inverse resolution）** — 基于已知归结项与某一子句反推另一归结商，从而"发明"新概念/新谓词。
- **置换（substitution） / 合一（unification）** — 用项替换变量 / 用一种置换令多个逻辑表达式相等；最一般合一置换（MGU）是 ILP 核心概念。
- **统计关系学习** — 将关系学习与统计学习结合的方向，代表含概率归纳逻辑程序设计、马尔可夫逻辑网等。


### 第16章 强化学习

## 2. 关键术语表

- **强化学习（reinforcement learning）** — 机器在环境中通过试错、以长期累积奖赏最大化为目标来学得策略的学习范式（亦称"再励学习"）。
- **马尔可夫决策过程（MDP）** — 强化学习任务的标准描述框架，对应四元组 E=〈X, A, P, R〉：状态空间、动作空间、状态转移概率、奖赏函数。
- **状态（state）/ 状态空间 X** — 机器感知到的环境描述。
- **动作（action）/ 动作空间 A** — 机器可采取的操作。
- **转移函数 P** — 在状态 x 执行动作 a 后转移到新状态的概率。
- **奖赏函数 R** — 状态转移时环境反馈给机器的即时奖赏；可写为 R: X×A×X→ℝ 或仅与状态有关 R: X×X→ℝ。
- **策略（policy）π** — 机器据以在状态 x 下选择动作的规则；确定性的 π: X→A，随机性的 π: X×A→[0,1]（满足 Σ_a π(x,a)=1）。
- **累积奖赏** — 长期执行策略得到的奖赏总和；常用"T 步累积奖赏"与"γ-折扣累积奖赏"（γ 为折扣因子）。
- **探索-利用窘境（Exploration-Exploitation dilemma）** — 估计摇臂优劣（探索）与选择当前最优（利用）的矛盾，二者权衡才能最大化累积奖赏。
- **K-摇臂赌博机（K-armed bandit）** — 单步强化学习的理论模型，有 K 个摇臂，目标最大化单步奖赏。
- **ε-贪心法** — 以 ε 概率均匀随机探索、以 1−ε 概率利用当前最优摇臂。
- **Softmax 算法** — 基于 Boltzmann 分布按各摇臂平均奖赏分配选取概率，温度 τ 控制探索/利用强度。
- **有模型学习（model-based learning）** — MDP 四元组均已知，机器已对环境建模。
- **免模型学习（model-free learning）** — 算法不依赖环境建模（转移概率、奖赏函数未知）。
- **状态值函数 V^π(x)** — 从状态 x 出发、用策略 π 的期望累积奖赏。
- **状态-动作值函数 Q^π(x,a)** — 从状态 x 执行动作 a 后再用策略 π 的期望累积奖赏。
- **Bellman 等式** — 值函数的递归等式（由 MDP 的马尔可夫性质得到）。
- **最优值函数 V\*** — 最优策略对应的值函数；最优 Bellman 等式唯一解即最优值函数。
- **策略评估** — 在模型已知时估计某策略的累积奖赏（值函数）。
- **策略改进** — 将策略选择的动作改为当前最优动作以提升累积奖赏。
- **策略迭代（policy iteration）** — 交替进行策略评估与策略改进直至收敛。
- **值迭代（value iteration）** — 直接将策略改进视为值函数改善，迭代更新值函数直至得到最优。
- **蒙特卡罗强化学习** — 免模型下通过多次采样轨迹求平均累积奖赏来近似值函数（适合 T 步累积奖赏）。
- **同策略（on-policy）** — 评估与改进的是同一个（如 ε-贪心）策略。
- **异策略（off-policy）** — 用一个策略（如行为策略）采样，评估/改进另一个策略（如目标策略）；基于重要性采样。
- **时序差分学习（TD）** — 结合动态规划与蒙特卡罗，每执行一步即增量更新值函数。
- **Sarsa** — 同策略 TD 算法，更新需"前状态、前动作、奖赏、新状态、新动作"五要素。
- **Q-learning** — 异策略 TD 算法，评估目标策略、执行 ε-贪心策略，是强化学习经典算法。
- **值函数近似（value function approximation）** — 连续/无穷状态空间下用参数化函数（如线性函数、核方法、神经网络）近似值函数。
- **模仿学习（imitation learning）** — 从人类专家决策范例中学习（亦称学徒学习、示范学习、观察学习）。
- **直接模仿学习** — 直接抽取"状态-动作对"用监督学习学得策略，作强化学习初始策略。
- **逆强化学习（inverse reinforcement learning）** — 从范例轨迹反推出使范例最优的奖赏函数，再据以训练策略。
