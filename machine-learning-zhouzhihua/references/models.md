# 《机器学习》关键模型与算法索引

> 按章归类，括号内为章号。查定义/公式/适用/慎用见对应 references/chapters/chNN.md 的「3. 关键模型与算法」。

## 第1章 绪论

- **假设空间搜索（概念学习）**（第1章） — 把学习看成在假设空间中搜索与训练集匹配的假设；假设表示一旦确定，假设空间及其规模就确定。以西瓜“好瓜”为例，假设形如“（色泽=?）∧（根蒂=?）∧（敲声=?）”，每个属性可取具体值、通配符“*”（任意值），以及极端假设“∅”（好瓜概念不成立）。
- **归纳偏好（奥卡姆剃刀作为选择原则）**（第1章） — 当版本空间含多个与训练集一致的假设时，学习算法必须凭借自身偏好（如对“平滑曲线”“更特殊/更一般”的偏好）确定唯一模型。
- **“没有免费的午餐”定理（NFL 定理）**（第1章） — 在所有问题同等重要、机会相同的假设下，无论算法多聪明，其期望性能与“随机胡猜”相同。

## 第2章 模型评估与选择

- **经验误差与过拟合**（第2章） — 以经验误差最小化为训练目标，但经验误差小不意味泛化好；学习能力过强易导致过拟合，学习能力低下导致欠拟合。
- **留出法（hold-out）**（第2章） — 直接将数据集 D 划分为互斥的训练集 S 与测试集 T（D=S∪T，S∩T=∅），用 T 上的测试误差估计泛化误差。
- **交叉验证法（k 折）与留一法（LOO）**（第2章） — 将 D 划分为 k 个大小相似、分布一致（分层采样）的互斥子集，每次用 k−1 个训练、余下 1 个测试，重复 k 次取均值；k=m 时为留一法。
- **自助法（bootstrapping）**（第2章） — 有放回采样 m 次得到 D′（自助采样），D′ 作训练集，D\D′（约 36.8% 未出现样本）作测试集，结果称包外估计。
- **调参与最终模型**（第2章） — 算法参数（超参数，常 <10 个）与模型参数（可极多）均需设定；对每个参数选范围与步长产生候选值，评估后选定；模型选择完成后再用全部数据 D 重训最终模型。
- **性能度量：查准率/查全率/F1**（第2章） — 错误率不足以刻画“挑出的好瓜中好瓜比例”“所有好瓜被挑出比例”等需求，改用查准率 P 与查全率 R；二者矛盾，用 F1（调和平均）或 Fβ 综合。
- **性能度量：ROC 与 AUC**（第2章） — 学习器输出实值/概率预测，按预测值排序后取不同截断点对应不同 P/R；ROC 曲线以 TPR 为纵轴、FPR 为横轴刻画“一般情况下”的泛化性能；AUC 为曲线下面积。
- **代价敏感错误率与代价曲线**（第2章） — 不同类型错误代价不同（如误诊患者 vs 误诊健康人），引入非均等代价与代价矩阵，目标是最小化总体代价而非错误次数；代价曲线可反映期望总体代价。
- **统计比较检验**（第2章） — 测试性能受泛化误差、测试集选择、算法随机性影响，不能直接比大小；用假设检验判断性能差异是否统计显著。
- **偏差-方差分解**（第2章） — 对回归任务，将期望泛化误差拆解为偏差、方差与噪声三项之和，揭示泛化性能由算法能力、数据充分性、任务难度共同决定。

## 第3章 线性模型

- **线性回归（最小二乘法）**（第3章） — 用属性的线性组合 f(x)=wᵀx+b 预测实值标记，并让预测值与真实值之间的均方误差最小。
- **对数几率回归（对率回归 / 逻辑回归）**（第3章） — 把线性回归预测值 z=wᵀx+b 经对数几率函数（Sigmoid）映射成接近 0/1 的值，用其逼近真实标记的对数几率，从而得到分类学习器。
- **线性判别分析（LDA / Fisher 判别分析）**（第3章） — 将样本投影到直线上，使同类样例投影点协方差尽可能小（类内紧凑）、异类样例中心距离尽可能大（类间远离）；新样本投影后按位置判定类别。
- **多分类拆分策略（OvO / OvR / MvM-ECOC）**（第3章） — 基本思路是“拆解法”——把 N 类多分类拆为若干个二分类任务，分别训练分类器再集成。
- **类别不平衡处理（再缩放及其技术）**（第3章） — 当正/反例数目悬殊时，分类器决策阈值 0.5 默认假定两类先验相等，需用观测几率 m⁻/m⁺ 调整；基本策略是“再缩放”。

## 第4章 决策树

- **决策树基本生成算法（分而治之）**（第4章） — 递归地选择最优划分属性，把结点样本集按属性测试划分到子结点，直到满足递归返回条件。
- **信息增益（ID3 准则）**（第4章） — 用属性划分后信息熵的加权平均下降量衡量“纯度提升”，选信息增益最大的属性。
- **增益率（C4.5 准则）**（第4章） — 用属性的“固有值”对信息增益做归一，减弱对多值属性的偏好；但增益率又偏好取值少的属性，故 C4.5 先筛选信息增益高于平均者，再从中选增益率最高。
- **基尼指数（CART 准则）**（第4章） — 用基尼值度量纯度，选划分后基尼指数最小的属性；CART 可用于分类与回归。
- **剪枝（预剪枝 / 后剪枝）**（第4章） — 主动去掉分支以降低过拟合风险；用留出法划分验证集评估泛化性能是否提升。
- **连续值与缺失值处理（C4.5 机制）**（第4章） — 连续属性用二分法找最优划分点；缺失值用样本权重同时解决“如何选属性”与“如何划分样本”。
- **多变量决策树（斜决策树）**（第4章） — 非叶结点不再测试单个属性，而是对属性的线性组合进行测试（形如 w₁a₁+…+w_d a_d ≤ t 的线性分类器），实现“斜划分”，简化复杂边界的模型。

## 第5章 神经网络

- **M-P 神经元与感知机**（第5章） — 神经元接收 n 个带权输入，总输入与阈值比较，经激活函数输出；感知机通过学习权重与阈值实现逻辑与/或/非。
- **多层前馈神经网络**（第5章） — 增加隐层使网络具备处理非线性可分问题的能力；每层与下层全互连、无同层/跨层连接，拓扑无环（前馈）。
- **误差逆传播算法（BP）**（第5章） — 基于梯度下降，信号从输入层逐层前传至输出，计算输出误差后逆向传播到隐层，据误差调整连接权与阈值；是训练多层前馈网络最成功的算法（也适用于递归网络）。
- **全局最小与跳出局部极小**（第5章） — 训练即参数寻优，希望找到全局最小；但误差函数常有多局部极小，基于梯度的方法易陷其中。
- **RBF 网络**（第5章） — 单隐层前馈网络，隐层用径向基函数（沿径向对称的标量函数，常以样本到中心的欧氏距离为自变量），输出层线性组合隐层输出。
- **ART / SOM / 级联相关 / Elman / Boltzmann-RBM**（第5章）
- **深度学习（DBN / CNN）**（第5章） — 增加隐层数提升模型容量；多隐层难直接用标准 BP（误差逆传发散），故用无监督逐层预训练+微调，或 CNN 权共享。

## 第6章 支持向量机

- **最大间隔划分超平面（硬间隔 SVM 基本型）**（第6章） — 在能正确分类的训练集中，找使两类支持向量到超平面距离之和（间隔）最大的超平面，等价于最小化 ‖w‖²。
- **对偶问题与支持向量**（第6章） — 对基本型每条约束加拉格朗日乘子 aᵢ≥0，令 L 对 w、b 偏导为零消去 w、b，得到仅含 aᵢ 的对偶问题。
- **SMO 算法**（第6章） — 固定除两个乘子 aᵢ、aⱼ 外的所有变量，因等式约束 aᵢ 可由 aⱼ 表出，该两变量优化有闭式解；反复选违背 KKT 最严重的变量对更新直至收敛。
- **核函数与核技巧**（第6章） — 把样本从原空间映射到高维特征空间使线性可分，但高维内积难算；核技巧用 k(xᵢ,xⱼ)=φ(xᵢ)ᵀφ(xⱼ) 在原空间直接算，模型变为 f(x)=Σaᵢyᵢk(xᵢ,x)+b（支持向量展式）。
- **软间隔支持向量机**（第6章） — 允许部分样本不满足硬间隔约束，在最大化间隔与最小化违例数之间用常数 C 折中，用替代损失代替 0/1 损失。
- **支持向量回归 SVR**（第6章） — 容忍预测值与真实值最多 ε 的偏差，仅当偏差超出 ε 才计损失，形成 2ε 宽的间隔带。
- **核方法与表示定理**（第6章） — 表示定理表明，满足"单调递增正则项 + 任意损失"的优化问题，最优解总可写成核函数的线性组合，由此可将线性学习器核化为非线性，如核线性判别分析 KLDA。

## 第7章 贝叶斯分类器

- **贝叶斯决策论与最优分类器**（第7章） — 以最小化总体风险为目标；每样本选条件风险最小的类。若最小化错误率（0/1 损失），最优分类器即选后验概率最大的类。
- **极大似然估计（MLE）**（第7章） — 频率主义视角，假定类条件概率有确定分布形式、由参数 θ_c 唯一确定，用训练数据估计 θ_c。
- **朴素贝叶斯分类器**（第7章） — 用属性条件独立性假设把联合 P(x|c) 拆成各属性条件概率之积，从而可用有限样本估计。
- **半朴素贝叶斯分类器（ODE / SPODE / TAN / AODE）**（第7章） — 放松独立性，假设每个属性最多依赖一个父属性（独依赖），既避免完全联合估计又保留较强依赖。
- **贝叶斯网（结构与学习）**（第7章） — 用有向无环图表达属性依赖，每个结点条件依赖于其父结点集 π_i；联合分布 = Π_i P(x_i|π_i)。
- **贝叶斯网推断与吉布斯采样**（第7章） — 训练好后用已知证据变量推测查询变量；精确推断 NP 难，常用吉布斯采样近似。
- **EM 算法**（第7章） — 含未观测（隐）变量时，交替进行 E 步（基于当前参数推断隐变量分布期望）与 M 步（最大化期望似然来更新参数），直至收敛到局部最优。

## 第8章 集成学习

- **集成学习的错误率分析（理论）**（第8章） — 二分类、基分类器错误率 ε 且相互独立时，简单投票集成的错误率随 T 指数级趋于 0。
- **AdaBoost（Boosting 代表）**（第8章） — 串行训练——每轮依样本分布训出基分类器，提高其前一集成犯错样本的权重，最终加权结合。基分类器权重由误差决定（误差越小权重越大）。
- **Bagging（并行集成代表）**（第8章） — 对训练集自助采样得 T 个有交叠子集，各训一个基学习器再结合；用自助采样制造差异，又保留足够样本保准确性。
- **随机森林（Random Forest）**（第8章） — 在 Bagging 的基础上，对每棵决策树每个结点的属性选择再做随机——仅从随机选择的大小为 k 的属性子集中挑最优属性。
- **结合策略：平均法 / 投票法 / 学习法**（第8章） — 把 T 个个体输出 h_i(x) 组合成最终输出。
- **误差-分歧分解与多样性增强**（第8章） — 理论证明集成泛化误差 = 个体加权误差均值 − 个体加权分歧均值；故个体越准、越多样越好。多样性可通过数据/属性/输出/参数四类扰动增强。

## 第9章 聚类

- **聚类性能度量（外部指标）**（第9章） — 将聚类结果 C 与参考划分 C* 比较，统计样本对（i<j）的归属情况，定义 a（两簇均同属）、b（C 同属、C* 异属）、c（C 异属、C* 同属）、d（两簇均异属），且 a+b+c+d = m(m−1)/2。
- **聚类性能度量（内部指标）**（第9章） — 直接考察聚类结果本身。定义簇内平均距离 avg(C)、簇内最远距离 diam(C)、簇间最近样本距离 d_min(C_i,C_j)、簇间中心点距离 d_cen(C_i,C_j)。
- **距离计算：闵可夫斯基与变体**（第9章） — 对有序/连续属性，以 ‖x_i−x_j‖_p 度量距离；p=2 为欧氏距离（最常用）、p=1 为曼哈顿距离（街区距离）、p→∞ 为切比雪夫距离。距离度量须满足非负性、同一性、对称性、直递性（三角不等式）。
- **距离计算：VDM 与混合/加权距离**（第9章） — 无序属性用 VDM 度量两个离散值的差异，再与闵氏距离结合处理混合属性；属性重要性不同则用加权距离（权重 w_t≥0）。
- **k均值算法（k-means）**（第9章） — 假设簇结构可由 k 个均值向量（原型）刻画，最小化所有样本到其所属簇均值向量的平方误差和；因最优解为 NP 难，采用贪心迭代：初始化均值向量→按最近均值划簇→重算均值→反复至不变。
- **学习向量量化（LVQ）**（第9章） — 与 k均值类似但利用样本类别标记（监督信息）。学一组原型向量 {p_1,…,p_q}，每轮取最近原型 p_{i*}，若与样本同类则令 p_{i*} 向样本靠拢（新向量 = p_{i*} + η(x_j−p_{i*})，η∈(0,1)），异类则推远；最终每个样本归入最近原型所在簇（Voronoi 剖分）。
- **高斯混合聚类（Mixture-of-Gaussian）**（第9章） — 以概率模型（k 个高斯分布混合）表达原型。样本由"先按混合系数 α_i 选成分、再按对应高斯密度采样"生成；用 EM 算法估计参数 {α_i, μ_i, Σ_i}，簇标记由后验概率最大者决定（x_j 归入使 γ_{ji}=p_M(z_j=i|x_j) 最大的成分）。
- **DBSCAN（密度聚类）**（第9章） — 基于邻域参数 (ε, MinPts) 刻画紧密程度。簇定义为"由密度可达关系导出的最大密度相连样本集合"。先找所有核心对象，再以任一核心对象为种子扩展出由其密度可达的所有样本构成簇，直至核心对象耗尽；未归入任何簇者为噪声。
- **AGNES（层次聚类）**（第9章） — 自底向上聚合——初始每样本一簇，每步合并距离最近的两个簇，直至达到预设簇数。簇间距离由集合距离决定，决定链接方式。

## 第10章 降维与度量学习

- **k近邻学习（kNN）**（第10章） — 给定测试样本，按距离找训练集中最近的 k 个邻居，分类用投票法（或距离加权投票）、回归用平均法（或加权平均）。
- **多维缩放（MDS）**（第10章） — 保持原始空间样本间距离，求低维表示 Z，使 ‖z_i−z_j‖ = dist_ij。
- **主成分分析（PCA）**（第10章） — 对中心化样本，找一组标准正交基，将维度降至 d' 时使"投影重构误差最小（最近重构性）"或"投影后方差最大（最大可分性）"，二者等价。
- **核主成分分析（KPCA）**（第10章） — 将样本经核映射 φ 投射到高维特征空间，再在该空间做 PCA；用核技巧避免显式写出 φ。
- **等度量映射（Isomap）**（第10章） — 流形上两点本真距离是测地线距离，高维直线距离有误导性。利用流形局部同胚欧氏空间，建近邻连接图，用 Dijkstra/Floyd 算法算图上最短路径逼近测地线，再对测地距离矩阵做 MDS。
- **局部线性嵌入（LLE）**（第10章） — 保持邻域内样本的线性重构关系。先为每个样本找邻域并用线性组合系数 w_i 重构它，再在低维空间保持 w_i 不变求坐标 z_i。
- **度量学习（马氏距离与 NCA）**（第10章） — 每个空间对应一个距离度量，寻找合适空间等价于学习合适距离。将平方欧氏距离推广到带权重 W=diag(w)（加权距离），再推广到半正定对称度量矩阵 M，得到马氏距离；M 可通过优化近邻分类器性能（如 NCA 最大化留一法正确率）或满足必连/勿连约束来学习。

## 第11章 特征选择与稀疏学习

- **子集搜索与评价（特征选择框架）**（第11章） — 因遍历所有子集不可行，采用贪心搜索产生候选子集并评价。前向从空集渐增相关特征、后向从全集渐减无关特征、双向结合二者；评价用候选子集对数据集的划分与真实标记划分的差异（如信息增益）。
- **过滤式选择：Relief / Relief-F**（第11章） — 设计"相关统计量"向量（每分量对应一特征），用猜中近邻（同类最近邻）与猜错近邻（异类最近邻）在属性 j 上的距离差更新分量——猜中近、猜错远则该特征有益、增大分量。取超阈值或取最大的 k 个特征。
- **包裹式选择：LVW**（第11章） — 在拉斯维加斯方法（随机子集搜索）框架下，以最终学习器在特征子集 A' 上的交叉验证误差为评价准则；若误差更小或相当但特征更少则保留 A'；连续 T 轮未更新则停。
- **嵌入式选择与 L1/L2 正则化（岭回归、LASSO）**（第11章） — 将特征选择融入训练。线性回归平方误差加正则化；L2（岭回归）降过拟合但不稀疏，L1（LASSO）除降过拟合外更易得稀疏解——w 仅少数非零，对应特征即被选入。
- **近端梯度下降（PGD）解 LASSO**（第11章） — 对可导且梯度满足 L-Lipschitz 的目标 f，每步在梯度下降迭代同时考虑 L1 范数最小化；对 LASSO 可逐分量求闭式解（软阈值）。
- **字典学习 / 稀疏编码**（第11章） — 为稠密样本学一个"字典" B，使样本能表示为 B 与稀疏系数 a_i 的乘积，从而享有稀疏性好处（文本数据常因此线性可分）。
- **压缩感知与矩阵补全**（第11章） — 若信号 x 经变换 Ψ 有稀疏表示 s（x=Ψs），则可由少量观测 y=Φx=As（n≪m）恢复 s 再得 x；恢复阶段靠 L1 最小化（基寻踪去噪），前提是测量矩阵 A 满足限定等距性（RIP）。矩阵补全将"部分观测"推广到低秩矩阵恢复（如协同过滤评分）。

## 第15章 规则学习

- **序贯覆盖（Sequential Covering）**（第15章） — 逐条归纳生成规则。每学到一条规则，就将其覆盖的训练样本去除，再用剩余样本重复，直到覆盖足够多的样例。因每次只处理一部分数据，亦称"分治"策略。可推广到多分类（每类分别处理，把该类作正例、其余作反例）。
- **自顶向下 vs 自底向上规则生成**（第15章） — 自顶向下从空规则（最一般）开始逐步添加文字使其"特化"；自底向上从具体样例对应规则（最特殊）开始逐步删除文字使其"泛化"。
- **CN2 算法（基于 LRS 的预剪枝）**（第15章） — 采用集束搜索生成规则，并在预剪枝时用统计显著性检验控制规则生长，是最早考虑过拟合问题的规则学习算法。
- **减错剪枝（REP）与 IREP**（第15章） — 将样本划分为训练集与验证集。REP 在训练集上学得规则集后多轮剪枝，每轮穷举删除某文字/尾部文字/整条规则等，用验证集选最优候选。IREP 在生成每条规则前先划分，对单条规则生成后立即在验证集上 REP 剪枝，再去掉其覆盖样本。
- **RIPPER 算法**（第15章） — 命题规则学习技术的高峰。先用 IREP*（以某种比率指标取代准确率作度量，删尾部多文字，最终再一次性 IREP 剪枝）生成规则集 ℛ；再对每条规则 r_i 产生"替换规则 r′_i"（基于 r_i 覆盖样本重生成）和"修订规则 r″_i"（对 r_i 增加文字特化后再 IREP* 剪枝），将二者分别与 ℛ 中其余规则组成候选集，选最优保留。本质是全局后处理优化缓解贪心局部性。
- **FOIL（一阶规则学习）**（第15章） — 著名的一阶规则学习算法，遵循序贯覆盖且自顶向下；因逻辑变量存在，生成时需考虑不同变量组合，新文字须含至少一个已出现变量。学完后可做后剪枝，允许目标谓词作候选可学递归规则，允许否定文字可得更简洁规则集。
- **最小一般泛化（LGG / RLGG）**（第15章） — ILP 自底向上生成策略的基础。将一条或多条正例对应具体事实作初始规则，再逐步泛化（常量替换为变量、删除文字）以提升覆盖率。LGG 是能特化为给定公式的最特殊一般公式。
- **逆归结（Inverse Resolution）**（第15章） — 归结原理是从 C₁=A∨L、C₂=B∨¬L 消去互补项 L 得归结项 C=A∨B（演绎）。逆归结则在已知 C 与某 C_i 时反推另一归结商 C_j，从而基于背景知识发明新概念/新谓词。一阶情形需借助"合一置换"搜索互补项。

## 第16章 强化学习

- **K-摇臂赌博机与探索-利用折中（ε-贪心、Softmax）**（第16章） — 单步强化学习模型。最大化累积奖赏须同时"估计各动作奖赏"（探索）与"执行最优动作"（利用），二者矛盾，需在探索与利用间折中。
- **有模型学习：策略评估与 Bellman 等式**（第16章） — MDP 四元组已知时，可用全概率展开求任意策略的累积奖赏期望（值函数）。
- **策略改进、策略迭代与值迭代**（第16章） — 评估策略后若非最优则改进——把策略所选动作改为当前最优动作（由最优 Bellman 等式，将动作求和改为取 max）。值函数对策略每点改进单调递增，直至策略不再变化即达最优。
- **免模型：蒙特卡罗强化学习（同策略 / 异策略）**（第16章） — 模型未知时无法全概率展开，只能通过在环境中执行动作观察转移与奖赏来学习。用多次采样轨迹求平均累积奖赏近似值函数（适合 T 步累积奖赏）；估计对象由 V 转为 Q（因模型未知时 V→Q 转换困难）；只能用从起始状态出发的探索发现状态。
- **时序差分学习：Sarsa 与 Q-learning**（第16章） — 结合动态规划（每步更新）与蒙特卡罗（采样）的优点，每执行一步即增量更新值函数，更高效地免模型学习。
- **值函数近似**（第16章） — 连续/无穷状态空间无法用表格值函数，直接对值函数做参数化近似（如线性函数），再用 TD 学习更新参数。
- **模仿学习：直接模仿与逆强化学习**（第16章） — 当人类专家范例易得时，从范例学比仅靠累积奖赏搜索高效。
