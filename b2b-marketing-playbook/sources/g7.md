# g7 · 第24–27课 提炼

## 第24课 B2B市场工作的绩效考核

**一句话主旨**：把市场部的投入换成"用工成本"、产出换成"工作项目的市场定价×职位加权"，市场部就能像独立经营单元一样按月算出盈亏，摆脱"产出是未知数X"的考核窘境。

**核心观点**：
- 市场部价值难衡量，是因为分母（市场费用）清楚、分子（产出）是个不可知的X，导致在老板、财务、董事会面前抬不起头（00:51）。
- 投入要重新定义：不只算市场费用，还要把每个市场人的工资、保险、福利、培训、体检、过节费用等用工成本一并计入（04:20）。
- 产出要重新定义：不再用销售额波动衡量，而把每项日常工作商品化，拿到市场上和代理商、agency 做同样工作比价估值（05:09）。
- 定价要按执行者职位等级加权：助理做的是可100%独立完成的细活，权重最高；职位越高，在基层单项工作上的加权值越小（09:11）。
- 有了分子分母，就能按月、按季、按年累计结算出每个成员的"收入−成本=盈亏"（06:30）。
- 方法落地有两个关键：项目定价要持续与第三方比价；要不断开发新的服务项目，否则每月产出恒定、失去经营意义（13:41）。

**方法论/模型**：
名称：**投入产出法（市场部内部经营核算）**。原文称"用我们的投入产出法来考核我们市场部每一个成员"（10:16）。

步骤：
1. **定分母（投入）**：市场部投入 = 工资 + 五险一金 + 各项福利（培训费、体检费、过节过年费用等）。原文口径为"部门的企业用工成本"（04:20）。
2. **建项目库**：把市场部所有日常工作"无论大小、事无巨细"全部列出，按类别归档（原文示例类别：市场活动、物料设计、新媒体推广）。
3. **定基本价**：每个项目参照市场上代理商/供应商的一般水平定"项目基本定价"（例：展会策划执行 1万元/次；catalog 设计 120元/页）。
4. **赋权重**：按执行者职位等级与实际承担比例加权。原文给出的取值：助理 = 1；专员、主管相应递减；职位越高，在基层单项工作上加权值越小。
5. **算单项加权收入**：加权收入 = 项目基本定价 × 权重。
6. **月结**：月度收入 = 各单项加权收入之和；月度盈亏 = 月度收入 − 月度成本；再按月/季/年累计，与投入项对比。

适用条件：
- 工作项可枚举、可被外部供应商报价锚定；
- 能持续获得第三方（公关/会务/设计/新媒体代理）的比价信息；
- 组织愿意把市场部当独立核算单元，而非纯费用中心。

原文案例（主管，月度）：
| 工作项 | 类别 | 项目收入 | 权重 | 加权收入 |
|---|---|---|---|---|
| 新产品应用手册制作 | 市场物料制作 | 2,400元（讲者推测为 200元/页 × 12页） | 1（无下属，独立完成） | 2,400元 |
| 产品发布会 | 市场活动 | 10,000元 | 0.8（需各部门通力合作） | 8,000元 |
| 公众号运营 | 新媒体运营 | 6,000元（按市面上初级/中级新媒体运营月薪计） | 0.8 | 4,800元 |
| **合计** | | | | **15,200元** |

本月成本 10,000 元（主管工资假设值）→ 本月盈亏 = 15,200 − 10,000 = **5,200元**（盈利）。

注：关于"与销售指标挂钩"——原文明确否定以销售额波动作为市场部产出（04:58–05:09），本课未提出任何与销售业绩挂钩的考核口径，**原文未详述**。

**可执行动作**：
- 盘点市场部近12个月全部工作项，按"活动/物料/新媒体/其他"分类建库。
- 向3家以上常用供应商索取分项报价，为每个工作项填"外部市价"作为基本定价。
- 为每个岗位设定加权系数表，并在每个项目上标注实际承担比例（独立完成/跨部门协作）。
- 建"市场部成员月度产出结算表"，字段：本月成本、项目清单、项目收入、权重、加权收入、本月收入、本月盈亏。
- 每月结一次账，每季/每年做累计对比，形成趋势而非单点数字。
- 每季度新增至少1个可对外定价的服务项目，避免产出曲线走平。
- 对难定价的项目（如与研发部共同做产品生命周期规划），用"第三方比价 + 内部实施经验"双轨定价。

**关键指标**：
- 投入口径：工资 + 五险一金 + 福利（培训、体检、过节费用）。
- 展会策划执行外部报价：10,000元/次。
- catalog 设计外部报价：120元/页（原文另提"或者150块钱"）。
- 新产品应用手册：2,400元（讲者推测 200元/页 × 12页，"可能是这样算出来的"）。
- 产品发布会：10,000元/次。
- 公众号运营：6,000元/月（按外雇初级或中级新媒体运营工资计）。
- 职位加权值：助理 = 1；专员、主管递减（原文未给出完整数值表，仅案例中主管取 1 与 0.8）。
- 主管月度成本 10,000元；月度收入 15,200元；月度盈亏 +5,200元。
- 考核周期：按月结算，按季、按年累计（06:30–06:33、10:23–10:27）。
- 市场费用见效周期：原文称可能"今后的三到五年之内才能看出一些端倪"（02:51）。

**原文金句**：
- "我们只有分母上的市场费用，而我们产出的价值，我们的分子却是一个不可知的一个X。"（00:54）
- "我们并不再去把它当作我们拿了工资、每天按部就班干的工作，而是把它给商品化。"（05:30）
- "让我们的B2B市场人从一个工作者到一个经营者完成这样的一个蜕变。"（15:21）
- "我们没有办法去压缩自己的投入……所以只有去努力的去开拓自己的产出。"（15:48）

**时效判断**：
- **仍有效**
  - 用外部 agency/供应商报价给内部工作定价——甲方 in-house 化越普遍，这套"内部比价"逻辑越有用。
  - 把市场部当独立核算单元、按月结盈亏——与今天阿米巴/内部结算制的做法一致。
- **需调整**
  - "新媒体推广 = 公众号运营"、按 6,000元/月外雇薪资计价——今天渠道已扩到视频号、抖音、小红书、直播，单一公众号口径覆盖不了实际工作项，薪资基数也要按城市重估。
  - "纸质 catalog 按 120元/页计价"——印刷物料在 B2B 物料盘子里占比大幅下降，应改为落地页、产品视频、案例集等数字物料的计价口径。
  - "展会策划执行 1万元/次"——线下展会仍是 B2B 主渠道，但这是原文当时的市场价，今天必须重新询价。
- **已过时**
  - 把"展会 + 产品发布会 + 公众号"当作市场部工作全集——今天还有线索运营、ABM、私域、直播、渠道市场，工作项清单需整体重建，否则核算表会漏掉大半产出。

**转写校订**：
- 投入最潮化 → 投入最小化
- roshow → roadshow（路演）
- 货录公司 → 会务/活动公司（原文如此，疑为转写误差）
- 无险一金 → 五险一金
- 产品的开设计 → 产品手册/catalog 设计（原文如此，疑为转写误差）
- 证文 → 正文
- 换一个比例的市值 → 换一个比例的方式
- 两千四加八千加四百八 → 两千四加八千加四千八（否则不等于15,200）
- 具理直气壮 → 理直气壮
- 结尾 [16:55–17:20] 乱码（"bütün石头都有 travaill进 Maggie"）→ 丢弃

## 第25课 玩转B2B产品定价

**一句话主旨**：定价是六步流程加3C导向的组合决策，其中客户导向决定三到五年的战略方向，成本与竞争导向只是短期数字技巧。

**核心观点**：
- 价格是影响品牌忠诚度最直接的因素，科特勒那句"没有降价两分钱抵消不了的品牌忠诚"虽夸张但点明了价格的杀伤力（01:47）。
- 定价有固定顺序：先定目标，再定需求、成本、竞争，最后才选方法与定价格，顺序不能倒（03:02）。
- 3C 不是三选一，实操中往往把两个甚至三个导向综合起来取平衡点（16:56）。
- 三种思维对应三种导向：成本导向是加法（成本+附加变量）、需求导向是减法（先定价格再反推成本）、竞争导向是等法（随行就市），无对错，按产品生命周期与营销策略选（15:04）。
- 客户导向的核心不是问客户"该卖多少钱"，而是让客户感知的利益不低于感知的价格，落在价值均衡线上或右下方的份额获取区（22:06）。
- 定价的本质不是标价加标准折扣，而是管理从研发设计到交付售后的整个交易活动（35:16）。

**方法论/模型**：

**模型一：产品定价六步流程**（03:02）
1. 确定价格服务的目标
2. 确定产品的价格需求
3. 明确产品成本
4. 分析市场竞争情况
5. 选择合适的定价方法与策略
6. 确定最终定价

其中 2、3、4 步即 3C 导向（Customer / Cost / Competition）。

**定价目标三分法**（05:12）：
- 利润目标：短期最高利润，还是拉长生命周期"细水长流"；
- 市场目标：拼销量抢占有率第一，还是"第一年5%、第二年7%、第三年9%"的慢速渗透；
- 竞争目标：做行业领先者、与寡头形成均衡、还是定位成薄利多销的中低端。
- 要求：目标必须与最高层/老板共同制定。原文案例：通用汽车（上世纪八九十年代）主要目标为 20% 资本回收率，附属目标为保持市场份额。

**模型二：3C 导向与三种思维**（15:04、17:39）
| 导向 | 思维 | 决策依据 | 定价起点 |
|---|---|---|---|
| 成本 Cost | 加法（正向） | 单位成本与预期利润的平衡 | 先定成本，再叠加利润 |
| 需求/客户 Customer | 减法（逆向） | 价格与客户利益的平衡 | 先从需求端找价格，再反推成本能否支撑 |
| 竞争 Competition | 等法 | 市场与对手的战略决策 | 随行就市，与对手保持同一水平 |

**模型三：客户感知价格—利益坐标图**（19:41）
- 纵轴：客户感知的价格；横轴：客户感知的利益。
- 中轴线为**价值均衡线**：感知利益 = 感知价格，即"物有所值"。
- 右下象限（感知利益 > 感知价格）：获取市场份额的厂商。
- 左上象限（感知价格 > 感知利益）：丢失市场份额的厂商。
- 原文案例：20元洗发水，用出100多元进口洗发水的效果 → 感知利益约100元，落在右下；若不如9.9元的好用 → 感知利益9.9元，落在左上。

三类厂商的调整路径：
- **价值劣势厂商（左上）回归均衡线，三条路**（24:29）：
  1. 价格不变，提高感知利益（产品改良、售后、公关、品牌营销）；
  2. 感知利益不变，直接降价（杀伤力最大，品牌档次降下去容易升上来难，原文不推荐）；
  3. 小幅降价 + 小幅提升感知利益（原文认为最折中、最易操作；例：50元卖、客户只感知30元 → 降到40元、同时把感知利益提到40元）。
- **价值优势厂商（右下），四条路**（29:06）：维持价格靠品牌/服务增值继续扩份额；价格不变但降低客户利益与相关成本（原文不推荐，例：进口发动机换国产）；维持感知利益直接提价；提价 + 把非核心部件换成有价格优势的供应商（原文称常用）。
- **均衡线上的厂商，两条路**（32:23）：提价 + 提感知利益走高端（高质高价）；降价 + 降感知利益走低端（物美价廉）。

每条路径都要评估四类因素：提供额外客户利益所需的成本、降价/提价对利润率和销售额的影响、竞争对手的预期反应、可 hold 住的市场规模与增长速度。

**本课未展开的部分**：十大定价方法、新产品定价、报价策略。原文明确"由于时间的原因，我们这节课不再去追溯这十大定价方法，将在下一节课介绍"（01:02）。**本课未提出报价策略**，仅指出"价格就两种：一个标价一个标准折扣"是错的（35:06）。

**可执行动作**：
- 开定价会前先写一页"价格服务目标"，明确利润/市场/竞争三类目标各自的取舍，并让最高层签字。
- 判定产品是价格敏感型还是不敏感型，再决定敢不敢动价（敏感型动价前先算销量弹性）。
- 拆成本为固定成本（厂房、设备、固定耗材）与变动成本（原材料、淡旺季人工、税收），并单独评估规模效应与经验效应。
- 列出主要竞品的成本、价格、以及未来一段时间可能的价格动作。
- 把自家产品画到"感知价格—感知利益"坐标图上，确认落在哪个象限。
- 按象限选路径，并同步评估额外利益成本、利润率影响、对手反应三项。
- 建立"不做什么"清单：不只按自身成本定价、不认为价格由市场单方面决定、不把价格等同于标价+标准折扣、不力争每一单。

**关键指标**：
- 定价目标示例：通用汽车 20% 资本回收率（上世纪八九十年代）。
- 市场目标示例：第一年 5%、第二年 7%、第三年 9%（慢速渗透）。
- 价格敏感型示例：地铁票价 4元 → 6元即引发客流转移。
- 价格不敏感型示例：名画拍卖 100万 与 150万 对收藏者差别不大。
- 感知价值示例：20元洗发水，感知利益 100元 / 9.9元。
- 回归均衡线示例：卖 50元、客户感知 30元 → 降到 40元、感知提到 40元。
- 二八原则：20% 的优质订单创造 80% 的利润。

**原文金句**：
- "没有降价两分钱抵消不了的品牌忠诚。"（01:47，原文引述菲利普·科特勒）
- "价格呢，其实也是能够很快的影响我们品牌忠诚度最直接的一个影响因素。"（02:46）
- "三种方法没有对错也没有好坏，这个是根据企业产品不同的一个生命周期阶段……来进行综合选择的。"（16:02）
- "定价，它背后的一个本质是管理我们的交易的活动。"（35:18）

**时效判断**：
- **仍有效**
  - 无印良品（中高端）与名创优品（亲民）的价格带对比——今天两者定位依旧，价格仍是分流顾客的第一道筛子。
  - 上海地铁用峰谷票价调节客流——今天仍在用价格杠杆做错峰。
- **需调整**
  - 通用汽车"20% 资本回收率"作为定价主目标——那是上世纪八九十年代美国车企的资本回报基准，今天行业结构与资本成本都变了，只能当历史参照，不能照抄比例。
  - "行业只有四五家寡头，一家调价就全行业洗牌"——逻辑仍成立，但今天还要叠加电商全网比价与招标平台透明化，传导速度快得多。
- **已过时**

## 第26课 B2B企业价格管理

**一句话主旨**：价格管理管的不是数字，而是整条利益链上的利润分配；用六大方向（对内制造/员工、渠道/终端、对外客户/对手）把定价权牢牢握在厂商手里。

**核心观点**：
- 渠道价格不是越高越好：过高会让产品脱离主流价位段、区域价差过大、渠道价差失控，渠道也会只顾眼前毛利不愿做大（07:04）。
- 也不是越低越好：过低同样引发窜货，渠道轮番降价，代理商不愿陈列甚至倒戈推竞品，品牌"未老先衰"（09:37）。
- 价格管理的本质是管理企业的利润分配，即在营销各环节的利益链上定一套大家都愿意服从的游戏规则（18:42）。
- 六大方向分三模块：对内（制造管理、员工管理）、渠道（渠道管理、终端管理）、对外（客户管理、对手管理）（22:09）。
- 渠道分层治理：大经销商固化利润、中等经销商用控价模式、终端给建议零售价（28:24）。
- 裸价模式把底牌暴露给渠道，控价模式用"统一面价 + 暗返 + 保证金"把定价主动权留在厂商手里（31:33）。
- 降价有六个原因、提价只有三个，所以提上去之后不到万不得已不要降回来（24:52）。

**方法论/模型**：

**模型一：六大价格管理方向**（42:02）
| 模块 | 方向 | 核心动作 |
|---|---|---|
| 对内 | 制造管理 | 定价（十大方法）+ 调价（降价6因/提价3因） |
| 对内 | 员工管理 | 以业绩为驱动，既考核成交量也考核成交质量；阶梯提成；体系一旦建立不许因裙带关系松动 |
| 渠道 | 渠道管理 | 大经销商固化利润、控供货价、控最低裸价；中等经销商推控价模式；合同明确费用分担 |
| 渠道 | 终端管理 | 控终端最低底价（裸价），给建议零售价并使其成为消费者看到的标志性价格 |
| 对外 | 客户管理 | 管客户感知利益，让感知利益与价格回到同一均衡点 |
| 对外 | 对手管理 | 预判对手反应（是否跟进、是否模仿、是否掀起全行业价格洗牌） |

**模型二：裸价模式 vs 控价模式**（31:33）
- **裸价模式**：底价与每一级价差完全透明。原文示例：出厂 60 → 经销商 70 → 分销商 80 → 终端 90，每级价差 10 元。缺点：厂商底牌暴露在复杂渠道中，对每一级的价格把控能力极差。
- **控价模式**：不亮底价，各层级**面价统一**，用返利/模糊返利在明面之下区分贡献，另收保证金做权利约束。
  - 原文简版示例：出厂 70 → 经销商与分销商同为 85 → 终端 90（终端 5 元加价可相对透明）。
  - 原文详版价格轴示例：出厂价 70（厂商底价）→ 要求经销商批发底价不低于 80 → 分销商从经销商拿货 80、批发 85 → 分销商到终端 93–98（业绩好返利 5 元则 93，业绩差则 97）→ 终端底价 85 以上 → 建议零售价 95 → 终端实际售价 95–108。
  - 注：简版（70/85/85/90）与详版（70/80/85/93–98/95–108）数字不一致，**原文如此**，两处均照录。

**模型三：降价六因 / 提价三因**（22:42、24:56）
- 降价：① 供大于求、产能过剩、库存积压（最主要）；② 维持或提高市场占有率；③ 生产成本下降（原材料降价）；④ 竞争产品降价（被动跟随寡头）；⑤ 宏观政治法律经济环境变化。原文口述编号为六条，但实际展开为以上五类（原文如此）。
- 提价：① 通货膨胀；② 产品供不应求；③ 配合竞争者涨价（被动）。

**模型四：新产品定价 = 按生命周期组合十大方法**（04:13）
原文不承认"新产品定价"是独立方法，主张用十大方法按阶段组合：
- 新产品阶段 → 用成本导向中的某一方法；
- 市场白热化阶段 → 用竞争导向的某一方法；
- 已成寡头或即将退市 → 用客户导向，从客户利益感知出发定价，在产品消亡前尽量多收回成本。

十大方法归属（02:28–04:11）：
- 成本导向（5）：成本加成法、目标收益法、盈亏平衡法、边际成本法、非标定制法；
- 竞争导向（2）：紧密跟随法、避谷扬峰法（避开不利规格型号，把优势型号利润做厚）；
- 客户导向（3）：感知利益法、促销折扣法、时间节点法。

**关于"折扣权限"与"价格审批"**：原文未给出分级折扣权限表，也未描述价格审批流程/审批节点，**原文未详述**。原文涉及的价格约束手段只有：最低底价（裸价）红线、返利/模糊返利、保证金、合同中的厂商费用分担条款、建议零售价。

**可执行动作**：
- 画出本品类的完整利益链（厂家→总代→一级分销→二级分销→终端→用户；工业品为厂家→设计方→监理方→工程方→安装方→最终用户），逐环标出现行价格。
- 选定裸价或控价模式；只要渠道层级超过两级，优先控价模式。
- 给每一级设"不得低于"的底价红线（如经销商批发不低于80），写进代理合同。
- 统一各层级面价，把层级差异改由返利/模糊返利体现。
- 与经销商签约时收保证金，并逐条写明厂商费用分担方式（你担什么、我担什么）。
- 给终端定建议零售价并对外公示，使其成为消费者看到的标准价格锚。
- 建调价触发清单：对照降价六因/提价三因逐条打勾，再决定动不动价。
- 销售考核同时看量与原：把"破成本价倾销"设为不合格项（原文例：年做5000万但单子全是破成本价，此人仍不合格）。
- 建窜货监控：按区域、按层级比对出货价与终端售价，价差异常即查。

**关键指标**：
- 价格带分层示例：0–70元 / 70–80元 / 80–100元（中高端）/ 100–200元以上（高端）。
- 渠道价差警戒示例：产品定 100元，若每级渠道价差达 10元或 20元，则价差过大、难以监管。
- 工业品项目降价效果：哪怕只有 3% 的降价，项目市场成功率就会大很多；此类项目金额"上亿或者几千万起码"。
- 销售考核反例：年 5000万 的单子若全是破成本价倾销，仍为不合格。
- 裸价模式：60 / 70 / 80 / 90，每级价差 10元。
- 控价模式（简版）：70 / 85 / 85 / 90，终端加价 5元。
- 控价模式（详版）：出厂 70；经销商批发底价 ≥80；分销商拿货 80、批发 85；到终端 93–98（返利 5元 → 93，业绩差 → 97）；终端底价 ≥85；建议零售 95；终端售价 95–108。
- 封闭式产品示例：投入 10万元理财，3年后收回本金与红利。
- 提价/降价原因数量：降价 6 条、提价 3 条。

## 第27课 用CLV法制定年度市场预算

**一句话主旨**：用客户终身价值（CLV）当预算的"临界线"——只要赢得一个客户的花费低于他的 CLV，这笔投入就值得，预算从"该花多少"变成"花多少才能挣更多"。

**核心观点**：
- B2B 预算难，是因为客户群窄、拓展依赖线下人员销售，钱少只能投在"不得不投"的展会、代理商会议、产品资料上，而这些动作给不出有效客户反馈（00:25）。
- 主流做法"销售额估算法"（去年销售涨了就追加、跌了就砍预算）错在假设投入与效果同步，实际营销效果需要数年积累才爆发（02:23）。
- CLV 是公司在客户保留期间从客户身上赚取、并最终可转化为净利润的值（03:15）。
- CLV 不直接告诉企业该花多少钱，而是告诉企业"花多少钱才能挣到更多的钱"，它表征的是一个差值，是二元双向指标（08:04）。
- 只要营销投入低于客户的平均价值，企业就能赚到钱，这个程度的投入就值得（06:35）。
- 快速增长策略的初期，新客增速赶不上预算消耗，此时硬套 CLV 会得出令人沮丧的结论，需要管理层扛住（10:37）。
- 必须做客户来源跟踪，否则只知道花了多少钱、不知道挣了多少钱，整套 CLV 体系就是空中楼阁（11:42）。

**方法论/模型**：
名称：**CLV 客户终身价值法**（原文全程口误/转写为"CRV"，实为 Customer Lifetime Value）。

**公式**（重要说明：原文口述为"公式的话我们就不再赘述了"，公式只在课件页上、未被念出。下式系按原文案例数值反推并验证，代入后与原文结果完全吻合，非原文口述）：

```
CLV = I × E × [1 − (1 + C)^(−N)] ÷ C
```

**变量定义与单位**：
| 变量 | 含义 | 单位 | 原文案例取值 |
|---|---|---|---|
| CLV | 客户终身价值：客户保留期内从客户身上赚取、最终可转化为净利润的总额 | 元 | 计算结果 402,259 元 |
| I | 企业针对每个客户的平均年收入，即某客户平均每年能和公司签多少额度的合同 | 元/年 | 400,000 元（原文区间 10万–200万，按客户重要性加权后取 40万） |
| E | 除去税收、利息、折旧、摊销和营销开支后的平均毛利润（毛利率） | %（无量纲比率） | 30% |
| C | 资金成本/资金使用成本：使用资金的企业支付给资金拥有方的报酬（如贷款利息、股东股利） | %/年 | 15% |
| N | 客户保持的平均年限：某客户能与公司维持多少年业务合作关系 | 年 | 5 年 |

反推验算：400,000 × 30% × [1 − 1.15^(−5)] ÷ 0.15 = 120,000 × 3.352155 ≈ **402,258.6 元**，原文给 **402,259 元**，吻合。

**原文未给出的参数**：
- 公式的具体形式（未口述）；
- 折现是按年末还是年初计（按年末年金反推才吻合，但原文未说明）；
- E 在公式中究竟以比率还是以金额代入（原文只给"平均毛利润为百分之三十"，按比率代入才与结果吻合，原文未明说）；
- 客户分层（大/中/小客户）是否分别计算 CLV（**原文未给出取值/口径**）。

**用 CLV 反推年度市场预算的步骤**：
1. **算 I**：统计客户合同额，按客户重要性加权，得出平均每客户年收入。
2. **算 E**：从财务取扣除税收、利息、折旧、摊销、营销开支后的毛利率。
3. **定 C**：取企业实际资金成本（原文案例取 15%，称其为"一般的中型非国有企业的资金使用率的平均值"）。
4. **定 N**：统计客户平均合作年限（B2B 战略客户可达十几年甚至二十几年，案例取 5 年）。
5. **算 CLV**：代入公式，得分层/平均 CLV。
6. **设预算上限**：某营销活动的总投入必须低于该活动带来的新增客户 CLV 之和；单客户获客成本必须低于单客户 CLV。
7. **算收支相抵临界点**：可容许获客数 = 活动总投入 ÷ 单客户 CLV；实际获客数高于此线即正向回报。
8. **复盘迭代**：按活动逐项结算"新增客户 CLV 总和 − 活动费用"，把结果回灌到下一年预算。

**原文案例**：
- 案例一（杂志封面广告）：某行业知名杂志隔月投放封面广告，全年广告费 30万元；年底带来 4 个新客户，单客户 CLV 40万元 → 4 × 40万 = 160万元；净收益 = 160万 − 30万 = **130万元**。
- 案例二（网站侧栏广告）：某知名网站每年 10万元、连续投放 3 年，合计 30万元；3 年只带来 1 个客户，CLV 仍为 40万元 → 40万 − 30万 = **10万元**，该营销计划仍算成功（收支相抵）。
- 案例基准（A公司）：I = 40万元、E = 30%、C = 15%、N = 5年 → CLV = 402,259 元。

**适用条件与边界**：
- 客户数量少而集中、可逐户统计合同额与保持年限（B2B 相对快消的优势）；
- 有财务数据支撑 E 与 C；
- **不适用于品牌快速扩张的初期**：此阶段新客增速赶不上预算消耗，CLV 会误判为负回报，需结合品牌战略判断（10:37）。

**可执行动作**：
- 拉近3年合同台账，按客户加权算出平均年合同额 I，并同时算出大/中/小客户三档的 I。
- 从财务取毛利率 E 与资金成本 C，不要用行业拍脑袋数。
- 统计客户流失年份，算出平均保持年限 N；战略客户单独算一档。
- 用公式算出分档 CLV，做成一张可复用的表。
- 给每类客户设"单客获客成本上限 = CLV"，写进投放审批规则。
- 每个营销项目结项时，用"新增客户数 × 单客 CLV − 项目费用"结算，正负都记录。
- 建客户来源跟踪机制：客户访谈 + 背景调查，确认每个新客户的首触品牌接触点。
- 在品牌快速扩张期，对 CLV 结论设"战略豁免"：明确哪些投入是品牌建设、不按当年 CLV 考核。

**关键指标**：
- I 区间：10万元–200万元/年（A公司客户年收入区间），加权平均取 40万元。
- E：30%（原文称"已经是一个非常高的水平"）。
- C：15%（原文称"一般的中型非国有企业的资金使用率的平均值"）。
- N：5年（原文另述战略合作客户可达十几年或二十几年）。
- CLV 结果：402,259 元。
- 案例一：广告费 30万元/年（隔月投放）、新增 4 客户、单客 CLV 40万元、CLV 合计 160万元、净收益 130万元。
- 案例二：10万元/年 × 3年 = 30万元、新增 1 客户、CLV 40万元、净收益 10万元。

**原文金句**：
- "营销效果的爆发往往需要数年的默默投入和量变的积累。"（02:36）
- "客户终身价值并不是直接告诉企业该花多少钱，而是告诉企业如何界定花多少钱才能挣到更多的钱。"（08:00）
- "只要营销投入低于这个客户的平均价值，企业就能赚到钱。"（06:35）
- "如果我们不知道我们的年度新增客户当中有多少是得益于我们的营销投入，我们也就没有办法计算出营销收益。"（12:05）

**时效判断**：
- **仍有效**
  - 用"获客成本 < 客户终身价值"作为投放止损线——今天就是 LTV/CAC 的同一逻辑，仍是投放决策的基本盘。
  - 客户来源跟踪（访谈、背景调查）——原则不变，今天可用 CRM、UTM、首触归因自动化，但归因本身仍要做。
- **需调整**
  - 行业杂志"隔月封面广告 30万元/年"——纸媒受众大幅萎缩，同样的钱今天应转向行业垂直媒体、搜索、内容与展会。
  - 网站"侧栏广告 10万元/年连投3年"——展示广告点击率早已崩塌，需换成搜索、内容营销、ABM。
  - "C 取 15%，为中型非国有企业资金使用率平均值"——融资成本区间已变，应按企业实际 WACC 取值，不能沿用这个数。
- **已过时**
  - 把纸媒封面广告当作 B2B 品牌曝光的主阵地——今天 B2B 决策人的信息入口已迁移到搜索、行业社群与线下展会，纸媒封面无法覆盖。

**转写校订**：
