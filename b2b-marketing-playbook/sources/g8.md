# 第28–30课 蒸馏（CMO 晋升 / CGO 与 CMO / 市场人自我提升）

## 第28课 B2B企业CMO的晋升之路

**一句话主旨**：成为 CMO 要先换"心智"（高度、广度、深度），再沿"大树模型"从动作层的执行力逐级长到愿景层的愿力，最终与老板成为利益共同体。

**核心观点**：
- 在中国企业环境下，市场基本是"吃青春饭"的行业，年龄增长、体力下降、家庭与健康重心偏移，会倒逼市场人尽早冲上 CMO 这个顶点（00:24）
- CMO 的职责边界三次扩张：传统环境只拿预算做活动、不为效果负责 → 品牌与效果营销（线索）都要负责 → 与 CEO、CFO 一起为企业各个方面的持续性增长负责（00:58）
- 调研几十家企业的 CEO，多数选择唐僧来领导市场部，理由是亲和力、带团队的公平性、良好的口才、取经路上的坚定信念、战略上的坚持和大局观的稳定，而不是个人技能最强或为人最圆滑（02:21）
- CMO 的心智分三维：高度看宏观、战略、长期；广度看整合企业营销资源、跨部门资源对接互换，以及是否有清晰可量化的考核标准作为互换筹码；深度看多层级管理与部门可持续发展规划（04:11）
- CMO 虽然只是一个部门的领导，但按心智、眼光和要考虑的内容，实际等于一个"小型企业的主管人"，要让部门自负盈亏并可持续运作（06:56）
- 晋升力随大树四层递进：动作层要执行力，任务层要领导力与协调力，战略层要"心力"（预见力、洞察力、把控力、鉴别力），愿景层要"愿力"（愿景力）（11:49）

**方法论/模型**：

1）**CMO 心智三维模型**
- 步骤：① 高度——站在企业战略发展的高度，审视市场战略是否与企业方向相符，关注宏观、战略、长期；② 广度——整合企业内外营销资源，做跨部门资源对接与互换，并建立清晰可量化的考核标准；③ 深度——建立多层级管理，只抓营销各节点的质量把控，把活动设计实施下放，同时规划部门明年的人、预算与工作范围。
- 适用条件：原文未详述（默认面向已带团队、准备或刚晋升市场部负责人的市场人）。
- 原文案例：无具体企业案例；以"唐僧被多数 CEO 选中"说明 CMO 靠的是信念、公平、大局观而非单点技能。

2）**大树模型（CMO 核心晋升力四层）**
- 步骤（自上而下）：
  - 树叶＝动作层：一线最基层的单点动作（写软文、做海报、联络客户），要求高度规范化与高效化，核心能力是**执行力**（07:49、11:49）
  - 树枝＝任务层：把一系列动作组合成一个任务，由主管级人员负责，要求把动作有机组合、让任务顺畅，核心能力是**领导力与协调力**（08:43、11:58）
  - 树干＝战略层：给上面的枝叶提供营养、决定长成什么样，由市场部经理级别以上负责，核心能力是**心力**——市场预见力、机会洞察力、热点把控力、对真假难辨的营销机会的鉴别力（10:05、12:06）
  - 树根＝愿景层：源源不断向战略层、任务层、动作层输送资源，只关注整棵树生长的大规划（从哪里吸取水分养分、如何向上输送），核心能力是**愿力/愿景力**——与老板成为忠实利益共同体，"忧老板之所忧，想老板之所想"（10:33、12:29）
- 适用条件：作为个人职业阶段自检与发展路径图；原文未给出行业、企业规模等限定。
- 原文案例：树叶对应"如何写好一篇软文、如何设计好一幅海报、如何去联络好一个客户"；树枝对应主管把各片树叶集合成一根树枝；树干对应经理级以上；树根对应与管理层一起做愿景层面规划。

**可执行动作**：
- 用高度／广度／深度三维给自己打分，找出最弱的一维作为本年补齐重点（04:11）
- 把自己的日常工作逐条映射到树叶、树枝、树干、树根四层，确认当前实际停在哪一层（07:49）
- 停止只交单点任务，主动承接"把多个动作组合成一个任务"的完整项目（11:58）
- 为市场部与其它部门的协作建立一套清晰可量化的考核标准，作为资源互换的筹码（05:30）
- 梳理团队分层，明确自己只抓各营销节点的质量把控，把活动设计、实施、参与下放给下属（06:06）
- 做一份部门年度规划，写清明年是否加人、是否向上要更多预算、是否扩充工作范围（06:23）
- 每月与老板对齐一次利益方向，用老板的可持续增长目标反推市场部议题（12:53）

**关键指标**：
- "年入百万的 CMO"（00:09）
- 调研样本："几十家企业的 CEO"（02:21）
- CMO 手下人数："少则十几人，多则几十人"（05:55）
- 战略层责任人门槛："市场部的经理级别以上"（10:27）
- 课程时长 13:59（片头信息）

**原文金句**：
- "我们想要改造自己的技能，首先要改造自己的脑袋。"（03:18）
- "他其实已经等于是一个小型企业的一个主管人。"（06:56）

- **仍有效**

## 第29课 CGO vs CMO，颠覆还是迭代？

**一句话主旨**：CGO 不是对 CMO 的颠覆，而是品效合一与增量增长要求下的迭代——CMO 解决业务结构里的单点，CGO 负责创建新结构并让结构上各部门协同运转。

**核心观点**：
- CGO 是当下营销对"品效合一"要求的产物，最早做这个改革的是可口可乐，其去年三月宣布取消 CMO、改设 CGO，此后各大企业纷纷撤销 CMO 设立 CGO（01:04）
- 各行业市场基本进入高度饱和阶段，智能手机拥有的人数处于平缓期，市场进入边界效益很低的阶段，企业不满足于存量市场的持续性增长，想在增量市场做颠覆性增长（01:47）
- 颠覆性增长仅凭一个部门一己之力难以做到，需要生产、研发、市场、财务以及企业内外各部门通力合作，CGO 就是把这些部门统一起来做有机整合、制定完整颠覆性增长方案的人（02:28）
- 本质区别：CGO 要创建一个新结构，并解决新结构上各部门协作运转的问题；市场部（含品牌、营销）目前更多是执行和迭代，解决的是业务结构中某一个环节的问题（03:07）
- 两者执行标准不同：市场部是单点标准或二维标准（与销售部目标相结合）；CGO 面对的是各部门担任节点要素的结构，是多维度标准的组合，维度越高结构变化程度越高（04:26）
- CGO 不必知道每个环节的具体业务标准（这不可能），但必须清楚每个部门在业务环节中的功用，以及对上下游业务点的责任（05:05）

**方法论/模型**：

**CMO → CGO 的三个转型方向**（原文称"三个非常有用的方向"，未命名）
- 步骤：
  1. 从 CEO 的忠实执行者，变为受 CEO 信任的顾问——不再只是拿老板给的钱做营销活动，而是与老板同等地位、共同为企业发展找出路（05:53）
  2. 从品牌的推广者，变为具有业务经验的品牌建设者——不再是把已经是"1"的品牌做成无穷大，而是和老板一起把从 0 开始的品牌建设到 1，做从无到有的新品牌（06:14）
  3. 从内部工作的协调者，变为内部利益的沟通者——不再只是协同，而要负责分配好各协作部门之间的利益，让每个部门在增长中利益最大化，合作才能高效长久（06:56）
- 适用条件：原文语境是"企业转向以增长为导向、设立 CGO"时，CMO 想保住位置或转型为 CGO；未给出企业规模、行业限定。
- 原文案例：某企业把原有线下业务网络化——若由 CGO 负责，则负责整个电商平台规划、交易闭环上各部门分工协作、对内对外推广引流、上下游供应商入驻整合、售前售后团队组建；市场部在其中只负责用市场传播的专业优势做推广引流（03:29）。另举例：CGO 不需精通产品设计部门的软件，也不需比物流部门更懂供应链，但必须精准把握产品设计质量与物流供应链系统效率（05:22）。

**可执行动作**：
- 先判断企业当前是在存量市场做迭代，还是要跳到增量市场做结构性增长，再决定设 CMO 还是 CGO（01:47）
- 用一句话自检岗位性质：我是在解决某个环节的单点问题，还是在创建一个新结构并让各节点协同（03:07）
- 把手上项目按"结构—节点—责任人—上下游责任"画一张图，标出每个部门在闭环中的功用（05:15）
- 主动争取新业务（线上化、新平台、新品牌）的整体规划权，而不是只领推广引流这一段（03:39）
- 把与各部门的协同关系升级为利益分配机制，明确各方在增长收益中的份额（07:13）
- 若目标是 CGO，先补业务经验：参与定价、供应链、售前售后、财务打通的讨论，而不只补传播技能（06:14）

**关键指标**：
- "去年三月"（可口可乐宣布取消 CMO、改设 CGO 的时间，相对本课讲授时点）（01:14）
- 课程定位："整个系列课的倒数第二节，也就是 29 节"（00:10）
- 转型方向数量：三个（05:50）
- 课程时长 08:43（片头信息）

**原文金句**：
- "CGO 它其实是目前的营销对于品效合一这样一个要求的产物。"（01:04）
- "CGO 呢，它是要创建一个新的结构。"（03:09）
- "CGO 一定要清楚每一个部门在这样的一个业务环节当中的一个功用，以及对上下游业务点的一个责任。"（05:15）
- "我们并不再是拿着一个已经是一的品牌把它变成无穷大，而是我们要和老板一起把一个从零开始的一个品牌把它建设到一。"（06:19）

**时效判断**：
本课唯一涉及"渠道"的是"线下业务线上化/自建电商平台"这一案例载体，原文未提具体平台或工具，故平台层条目有限。

- **仍有效**
  - 设增长负责人（CGO/增长VP）打通生产、研发、市场、财务的闭环——今天增长团队仍是主流组织解法（02:28）。
  - 用"是否创建新结构"而非"职级高低"区分 CGO 与 CMO——这个判据比头衔更可靠（03:07）。
- **需调整**
  - "CGO 比 CMO 高一个等级、取代 CMO"——实践中更多是 CGO 与 CMO 并存，或增长职能拆到增长团队/商业化团队（02:57）。
  - "线下业务搬到线上、自建电商平台"作为 CGO 的典型战场——今天更多是平台内经营、DTC 与渠道数字化，自建平台的优先级下降（03:31）。
- **已过时**
  - 以可口可乐"取消 CMO 改设 CGO"作为全行业风向标——后续企业岗位设置反复调整，该事件已不宜再当作"必然替代"的趋势证据（01:13）。

## 第30课 B2B市场人如何提升自我

**一句话主旨**：市场人靠"外部三条路（名校深造、名企锤炼、同行交流）+ 内部两条路（行业深耕、专业训练）"补硬软技能，再把碎片知识重组成系统，完成从单点执行到高维结构的升维。

**核心观点**：
- 市场人是职业圈层比较广泛的职位：有大量走出去的机会，参加研讨会、展会，与不同渠道不同媒体打交道，又是连接销售与内部职能部门的桥梁，因此更容易接触上下游产业链上的不同职位（02:02）
- 外部提升三条路：进名校做在职深造（MBA/EMBA/DBA）、进大企业市场部锤炼、主动增加与同行交流（03:10）
- 内部提升两条路：行业深耕、专业训练（13:26）
- 当下需要的是"碎片重组、系统学习"：把每天接收的碎片信息去伪存真、去粗取精，重组成自己的一套系统（20:40）
- 职场悖论：社会分工细化让岗位"一个萝卜一个坑，坑越来越小越来越深"，而飞速迭代的商业环境又要求能独立组建团队、独立运作项目的全才（24:33）
- 提升高维思维三步：掌握低维标准 → 争取从高维角度制定或参与制定结构的机会 → 清零心态、用新工具搭新结构并强化信息分析迭代（28:04）
- 运营部、CGO、全才型 CMO 本质相同：都是打破原来的单点结构、重建新商业结构，并解决结构中各环节各部门的协作运转（26:06）

**方法论/模型**：

1）**外部提升三途径**
- 步骤：① 名校在职深造——系统梳理零散实操知识点、补经典营销理论地基、收获高端商业人脉；② 进名企市场部——借成熟的市场运作模式、职能架构、岗位安排与帮带带教体系，以及充足预算和团队支援，快速练实操功底；③ 同行交流——在保证不泄露公司核心商业机密的前提下大方交流，换市场运作技巧、跨界营销思维、竞争对手情报，并寻找资源互换与异业合作。
- 适用条件：原文未设硬性条件；第②条明确"尤其是对一个新人来说"最合适（08:00）。
- 原文案例：机房布线企业——客户面窄、只讲布线内容单调，于是把机房建设中服务器、空调、地板、照明、安防等非同一产品线竞争对手的同行聚起来合办一场交流会，把机房建设各环节的最新热点一次性传达给客户，即此前课程讲过的跨界营销流量互换（11:45）。

2）**内部提升两途径**
