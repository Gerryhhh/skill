## 第19课 B2B企业如何应对危机公关

**一句话主旨**：自媒体时代负面信息传播快且不可控，B2B企业必须按危机性质先定性、再决定"快速认错"还是"沉默＋媒体工作"，并在态度、行为、情感三个层面同时修复用户心智。

**核心观点**：
- 传统媒体时代信息必须经过电视台、报纸等"中转站"筛选再传播，自媒体时代每个 C 端都带二次传播属性、都是小 B 端，信息无阻挡扩散，对用户心智的冲击被放大千百倍（01:05）。
- 危机公关不是发几条声明，而要沿"态度—行为—情感"三个层面层层递进，才可能扭转心智中的负面印象（03:05）。
- B2B 危机往往比 B2C 更致命：对手数量少、彼此高度了解，一旦被对手或舆论找到漏洞，这个漏洞基本已经坐实（09:30）。
- 四类高频危机各有不同处置路径：产品投诉先查证再表态，模式质疑先稳住媒体，CEO 丑闻少言慎言，对手攻击先沉默再探目的（09:53）。
- 快速反应不等于抢着发声；格力在骗补门中第一个回应，反而把全行业的火力集中到自己身上，成为"出头鸟"（21:47）。
- 当舆论覆盖全行业而非单家企业、且不涉及致命产品缺陷时，"沉默＋做媒体工作"优于解释和转移焦点（24:46）。

**方法论/模型**：

1）**危机定性四问**（原文未命名，据格力案例归纳：19:06–20:20）
- 步骤：① 是产品质量危机，还是品牌/企业形象危机？② 是否威胁公众人身安全与经济利益？③ 矛头指向一家，还是覆盖多家同业？④ 我方是否有白纸黑字的证据可反驳？
- 适用条件：任何危机在对外发声前的第一步，用于决定"说"还是"不说"。
- 原文案例：格力骗补门——空调品质本身没问题（属形象危机、不致命）；不威胁人身安全，消费者补贴已实际拿到（公众敏感度低）；审计署点名七家品牌（非独家）；审计署数据确凿（企业处于被动、无反驳证据）。四项均指向"不宜抢答"。

2）**危机处置主干流程**（原文散述，此处按顺序还原）
- 第一步 监测：持续收集各平台粉丝/用户信息发布，据此调整对外内容方向；发现负面第一时间与发布者互动，把负面消解在火苗放大之前（07:35）。
- 第二步 定性：按上述四问判断危机性质与自身证据强弱（19:06）。
- 第三步 选策略：证据确凿且属单点致命问题 → 快速认错＋整改；全行业波及、非致命、自身无有力证据 → 沉默＋媒体关系维护，等风口过去再动作（20:31、24:46）。
- 第四步 出态度：声明要"简单明确"，直接承认"这个责任是我们的"（海底捞，03:57）。
- 第五步 出方案：紧接着由总部发布详细整改方案，必须写清措施、时间节点、参与人员、监督的系统架构（04:12）。
- 第六步 补情感：明确责任归属在管理层而非一线员工，承诺"所有责任由公司和管理层承担"（04:42）。
- 适用条件：确有责任的产品/服务事故。
- 原文案例：海底捞后厨卫生事件三步走，负面事件反而提升了企业形象（05:13）；携程亲子园事件反向操作——先切割给第三方、全程推诿不认改、开除员工，口碑"一落千丈"（05:39–07:10）。

3）**四类危机分型处置**（原文明确分为四类，未命名）
- 产品投诉 → 先冷静排查是否属实（是质量问题、系统调试不当，还是客户操作不专业）→ 属实：出书面、专业、正式的官方道歉信，并给整改时间节点、措施、负责人、监督渠道 → 不属实：绝不自说自话，找第三方权威机构背书、出具检验或调试证明，过程透明公开（现场直播、在线报道）。适用条件：B2B 专业产品被质疑质量。原文案例：无具名案例，为通则式讲解（09:54–11:42）。
- 模式质疑 → 先与媒体保持友好沟通，争取客观公正平和的报道，避免被做成事件营销噱头 → 向媒体澄清未来规划 → 讲更有趣的故事转移关注。适用条件：质疑商业模式与背后商业流程、不涉及具体产品质量。原文案例：中兴芯片危机（11:45–12:41）。
- CEO 丑闻 → 少言慎言，除必要的信息声明与回馈外不多说 → 多谈产品、多谈企业规划 → 可用自我调侃等方式转移对个人的关注。适用条件：创始人/掌门人个人丑闻。原文案例：三星电子掌门人受惠丑闻（12:46–13:23）。
- 对手攻击 → 先不急着澄清、保持沉默 → 探查对手背后的深层商业目的（是否要用别的产品替代你、是否要在某个项目上取代你的赢家地位）→ 有理有据反击 → 全程不得伤害现有用户利益，也不能让用户觉得这个行业互相攻击、不团结。适用条件：同业公开攻击。原文案例：神州专车请吴秀波、海清拍"Beat U"海报攻击优步（13:28–15:11）。

4）**沉默决策模型**（原文称"沉默是金"，15:21–16:00、23:22–24:57）
- 步骤：先冷静 → 沉默观察 → 判断攻击背后是否有深层商业目的、被攻击点对用户的重要度、是否真正损害用户利益 → 期间做媒体工作（联系媒体不跟风、不炒作、不扩大事态）→ 风头过去再决定下一步。
- 适用条件：情况复杂、企业缺乏足够强有力的反驳证据；舆论覆盖全行业而非针对一家；不是致命的产品缺陷。
- 原文案例：2013 年 6 月审计署披露格力、美的、TCL、长虹等七家空调品牌骗补，格力以 2000 多万元居首并第一个发澄清说明（归因经销商填报数据不规范），被公众视为推卸责任、拉经销商做替罪羊；稍晚发声的长虹、美的反而未遭大规模批判（16:43–18:28）。

5）**5S 准则**：原文仅提及名称，未展开五项内容，本课未逐条讲解（07:29）。

**可执行动作**：
- 建立舆情监测日报：按平台收集用户/粉丝发布，标注负面苗头，发现当日即私信或评论互动，不等发酵（07:35）。
- 接到产品投诉先不回复结论，48 小时内完成"质量缺陷／调试不当／客户操作不当"三方排查，形成书面结论再对外（09:57）。
- 投诉属实时，出具书面、正式、带公章的官方道歉信，同步附整改表：措施、时间节点、负责人、监督渠道四列缺一不可（10:33）。
- 投诉不属实时，委托第三方权威机构检测并出具检验/调试证明，全程直播或在线公开，禁止用自家检测报告自证（11:09）。
- 每次危机先填"定性四问"表，再决定回应策略；四项均不利时选择沉默，不抢首发（19:06）。
- 沉默期同步约谈行业媒体，明确请求"只做客观事实描述、不做连续报道与专题深挖"（23:31）。
- 需要引导舆论时，联络行业媒体、专业机构、行业大 V、KOL 机构输出正向内容，把关注点转向企业可大书特书的一面或行业宏观动态（08:18）。
- 遭遇对手攻击时，先沉默 1 个观察周期，摸清对方是抢产品份额还是抢项目赢家地位，再组织有理有据的反击（14:16）。
- 反击全程设红线：不披露用户名单、不降价伤已签客户、不公开贬损整个行业（14:50）。
- CEO 丑闻期间只发必要声明，对外议题全部切到产品与规划，不补充个人细节（12:59）。
- 对外口径禁用三类表述：把责任推给经销商/第三方/一线员工；用"主动放弃申报"等无关事项抵消指控；在无证据时抢先"澄清"（17:38、21:40）。

**关键指标**：
- "树立一个良好的品牌声誉可能需要20年，而毁掉它却只需要5分钟"（02:12）
- 危机影响用户心智的三个层面：态度、行为、情感（02:59）

- 响应时限：原文只给"第一时间""快速反应"，未给具体小时数或分级时限（07:51、08:04）
- 危机分级：原文未给出"一级/二级/三级"式分级命名与对应时限，只给出四类分型与四项定性维度（09:53、19:06）

## 第23课 用户生命周期运营策略

**一句话主旨**：用户生命周期分获取、转化、提升、维护、流失后再营销五段，B2B 的运营重点是在每段与专业用户建立持续关联，把"峰值后一路下滑"的典型曲线尽量拉平、拉长。

**核心观点**：
- 用户生命周期有两条曲线：理想态是最佳客户生命周期曲线（Best Customer Life Circle），现实态是峰值后持续下滑的典型客户生命周期曲线（Typical Customer Life Circle），营销的所有动作都是为了延长后者（01:55）。
- 五阶段为获取、转化、提升、维护、流失后再营销，可归为初始期流量转化、中间会员服务、后期全网再营销三个模块（05:04）。
- 流量少、流量贵、流量造假，迫使企业不再只抢新客，而要在单个生命周期内做出最大成交（04:08）。
- 留住客户的关键不是搞几次活动，而是从初次接触就精密布局，在各阶段与用户建立紧密关联（04:28）。
- B2B 用户高度专业，最有效的粘性来源是把自己打造成行业意见领袖、专业领域风向标（10:10）。
- 维护忠诚度的根本是找到用户在商业角色之外的"第二重身份"，用新媒体建立社交联系、持续互动（13:19）。
- 开发一个新用户的成本是挽回一个老用户的 5 倍，因此再营销的"套路"要在第一次接触客户时就开始设计（16:52）。

**方法论/模型**：

1）**用户生命周期五阶段模型**（原文命名"用户生命周期模型"，05:04–05:22）
- 步骤/阶段：获取 → 转化 → 提升 → 维护 → 流失后再营销；对应三大模块：初始期流量转化、中间会员服务、后期全网再营销。
- 各阶段目标与动作：
  - 获取：把盘子做大。动作＝讲故事＋抬杠（05:29–09:52）。
  - 转化：完成首次成交（原文将"获取并有了最初的成交"连述，未单列转化动作）（09:52）。
  - 提升：提升粘性、延长停留。动作＝打造行业意见领袖/专业 IP、输出行业智库（10:00–12:49）。
  - 维护：维护忠诚度、延缓曲线下行。动作＝找第二重身份、建同因社群（13:14–16:32）。
  - 流失后再营销：挽回已流失用户。动作＝留存消费偏好数据、用成交频次/金额预警、用邮件再营销等工具触达（16:44–21:15）。
- 阶段迁移判断：原文未给出各阶段的量化阈值；仅给出流失前兆的监测口径——成交次数或成交金额锐减，且"频次锐减"与"金额锐减"指向不同的流失原因（18:58）。
- 适用条件：B2B 与 B2C 均适用，本课按 B2B 专业用户场景展开。
- 原文案例：苹果以 6、7、8、X 及 S/Plus 的高频出新持续刺激关注，把用户拴在品牌上；若半年不出新品，用户可能转投小米、华为（03:09–03:40）。

2）**获取用户两法：讲故事 + 抬杠**（05:47–09:51）
- 讲故事：设定几个精彩、抓眼球的品牌故事。可写题材＝创始人奋斗经历、企业知名人物的故事、企业重大事件、经典产品出炉过程、企业历史荣誉。三条要求＝真实不架空（否则互动中用户感到不真实、打不动情感）；让故事反复出现在营销人日常、销售随时可讲；向决策链上能构建品牌策略的关键人物讲，内部与外部持续传播。
- 抬杠：全行业笼罩在同一声音下时，勇于发出另外的真实声音，"与其更好，不如不同"。
- 适用条件：抬杠必须建立在对自家产品和服务有极大信心、且基于事实的基础上，为博眼球而抬杠是搬起石头砸自己的脚。
- 原文案例：董明珠"我要是做手机三年不用换""今年目标销量一亿部""开机画面必须是我""小米和美的两个骗子在一起就是小偷集团""你不买我的空调不是有病吗"；原文称这些反常规言论省掉格力市场部数亿元推广费（08:00–09:31）。

3）**行业意见领袖/专业 IP 打造**（10:10–12:49）

4）**第二重身份 + 同因社群**（13:19–16:32）
- 第二重身份：用户在商业环境之外的角色定位。例：电器设计师的第一重身份是设计院设计人员、项目决策链第一环节的决策者；第二重身份是黑科技爱好者、在自媒体分享科技产品心得。
- 作用：用户疏远时只会表现在第一重身份上（如产品不再上图），此时从第一重身份挽回往往无从下手；若在第二重身份上已有联系，可从侧面获得商业环境中拿不到的关键信息，多一条挽回渠道。
- 同因社群：相对于基于共同兴趣、非刚需、粘性与持久性都不长的兴趣社群，同因社群是为解决同一个困难而聚集（本课学员群即例）。打造方法＝线上引流、线下互动：用自媒体矩阵把线上专业用户引到线下活动，每月或每半个月做一次商业活动扫盲，或请客户到企业听产品与行业洞见，再让用户在各自自媒体矩阵二次传播。
- 适用条件：B2B 专业用户、决策链长、单客价值高的行业。
- 原文案例：无具名企业案例，以电器设计师与本课程社群举例（13:29–16:32）。
