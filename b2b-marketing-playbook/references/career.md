> 说明：本章讲"人怎么长"，不是业务打法。SKILL 不主动引导到这里，只有你明确问职业、晋升、转型、能力建设时才用。

## 什么时候翻这一章

- 觉得自己卡在专员/主管层，看不到往上的路
- 公司要设增长岗（CGO/增长 VP），担心自己被替代
- 刚带团队，发现"自己干得快、带人带不动"
- 想转销售、咨询、媒体、供应商或培训师，不知道代价
- 学习很碎片，看了很多课和书，但拼不成体系
- 要给自己或下属定一份能力成长计划

## 打法详解

### 五条转型路径

**它解决什么问题**：市场是"吃青春饭"的行业（00:15），加上普遍存在晋升天花板，只盯晋升一条路会走到死胡同。

| 路径 | 核心优势 | 主要代价 | 准备动作 |
|---|---|---|---|
| **销售** | 最便捷的职能转换；多年积累的客户与行业资源、对市场的把控、沟通能力、多任务承担能力 | 沉重业绩压力、冗长的 B2B 项目周期、对家庭的牺牲、业内潜规则；从甲方变乙方、从花钱变赚钱 | 培养"交易能力"：对外与供应商、对内跨部门争取资源时，衡量"我能给对方什么、对方能给我什么、如何在交易基础上双赢"（03:48） |
| **咨询顾问** | 职业素养高度一致：直穿表象看本质、高效分析、良好沟通、大胆假设；行业实战经验补咨询"只宽不深、纸上谈兵" | 工作强度只大不小、出差只多不少；每个项目都是全新挑战 | 研读 MBA 等学位；考含金量高的证书（原文举例：国家咨询师资格证）；参与企业内部管理项目的实施 |
| **媒体人**（行业内专业媒体） | 行业知识、市场敏感性、文字修养；能抓一般媒体人难以察觉的切入点 | 必须严守客观公正，克服对自家品牌的天然偏好 | 多写广告稿、新闻稿、新媒体内容；多参与行业论坛与展会；与行业/媒体伙伴持续互动 |
| **供应商** | 最懂甲方需求的 supplier：深知产品参数、应用范围、在系统中的核心地位 | 要从"接单执行"转为"主动发现需求" | 留意日常工作中的困难，从中察觉商机，转化为可交付的实物/服务 |
| **培训师** | 最能延续激情的方向：表达、形象、垂直专业资格、学习能力、逻辑梳理、体力 | 无名企/名校/高层背景者起步更难，需长期积累建立独到理论 | 见下方两步法 |

**原文金句**："不懂市场一定做不好销售，但是并不等于一个好的市场，它就一定能做成一个好销售。"（02:10）

**容易踩的坑**：把"市场转销售无缝衔接"当真——实际是从面到点、从幕后到前台、从甲方到乙方、从花钱到赚钱，四个维度同时翻转（02:10）。

**时效**：五条路径仍成立。需调整的是准备动作里的平台——微信/微博/百度百家/企鹅号/头条的组合已变（企鹅号基本退出，微博在 B2B 几乎失效），应换为视频号、行业垂直媒体、播客；"国家咨询师资格证"的认定已变更，改用市场认可度高的商业认证。

### 培训师两步法

**第一步：成为培训师（5 步）**
1. 下定决心——"我一定要成为培训师，我一定能够成功"
2. 找到行业内转型比较成功的前辈，看他当时是怎么转的
3. 找到自己的核心课程，进行刻意练习
4. 抓住企业内外各种培训机会，反复打磨课程
5. 把主打课程包装好，推向市场

**第二步：成为优秀培训师（5 条）**
1. 找准定位——不做万金油，在某个垂直细分领域做到"前几把交椅"，**宁精勿宽**
2. 专业包装——形象、课件、个人介绍、个人自媒体
3. 找强大机构做首期推广
4. 把自己打造成某个行业的知识 IP，持续输出原创内容
5. 注重团队协作——课件打磨、推广包装、讲课录课现场控制、杂事处理、甲乙双方沟通、行程安排

**原文金句**："宁精勿宽。"（14:19）

**时效**：方法论仍有效。个人包装主阵地需从"公众号、博客"改为视频号/短视频+私域社群+知识付费平台。

### CMO 心智三维 + 大树模型（第28课）

**它解决什么问题**：回答"我技能不差，为什么上不去"——因为卡住的不是技能，是心智。

**心智三维**：
- **高度**——站在企业战略高度审视市场战略是否与企业方向相符；关注宏观、战略、长期
- **广度**——整合企业内外营销资源，做跨部门资源对接与互换，并建立**清晰可量化的考核标准**作为互换筹码
- **深度**——建立多层级管理，只抓营销各节点的质量把控，把活动设计实施下放；同时规划部门明年的人、预算与工作范围

**大树模型**（自上而下）：

| 层 | 对应岗位 | 干什么 | 核心能力 |
|---|---|---|---|
| 树叶＝动作层 | 一线 | 写软文、做海报、联络客户 | **执行力**（高度规范化与高效化） |
| 树枝＝任务层 | 主管级 | 把一系列动作组合成一个任务，让任务顺畅 | **领导力与协调力** |
| 树干＝战略层 | 经理级以上 | 给枝叶提供营养、决定长成什么样 | **心力**：市场预见力、机会洞察力、热点把控力、对真假机会的鉴别力 |
| 树根＝愿景层 | 与管理层共事 | 向三层输送资源，只关注整棵树的大规划 | **愿力/愿景力**：与老板成为利益共同体 |

**原文金句**：
- "我们想要改造自己的技能，首先要改造自己的脑袋。"（03:18）
- "他其实已经等于是一个小型企业的一个主管人。"（06:56）
- "需要去忧老板之所忧，想老板之所想。"（12:53）

**容易踩的坑**：停在树叶层拼命优化动作（把软文写得更好、海报做得更美），误以为熟练就能晋升。原文的判断是：CMO 靠的是信念、公平、大局观，不是单点技能最强——调研几十家企业的 CEO，多数选唐僧来领导市场部（02:21）。

**时效**：仍有效，不依赖平台。

### 结构 vs 单点：CMO 与 CGO 的判据（第29课）

**它解决什么问题**：公司设增长岗时，判断自己是被迭代还是被替代。

**一句话判据**：**我是在解决业务结构里的某个单点，还是在创建一个新结构并让各节点协同运转？**（03:07）

- CMO/市场部：更多是执行和迭代，解决业务结构中某一个环节的问题；执行标准是单点标准或二维标准（与销售目标结合）
- CGO：创建新结构，并解决新结构上各部门协作运转的问题；面对的是多维度标准的组合
- CGO 不必知道每个环节的具体业务标准（这不可能），但必须清楚每个部门在业务环节中的功用，以及对上下游业务点的责任（05:15）

**CMO→CGO 三个转型方向**：
1. 从 CEO 的忠实执行者 → 受 CEO 信任的顾问（不再只是拿钱做活动，而是与老板同等地位共同找出路）
2. 从品牌的推广者 → 具有业务经验的品牌建设者（不是把已经是"1"的品牌做成无穷大，而是和老板一起把 0 做到 1）
3. 从内部工作的协调者 → 内部利益的沟通者（不只协同，要负责分配各协作部门的利益，让每个部门在增长中利益最大化）

**原文案例**：某企业把线下业务网络化——若由 CGO 负责，则负责整个电商平台规划、交易闭环上各部门分工协作、对内对外推广引流、上下游供应商入驻整合、售前售后团队组建；市场部在其中只负责用传播专业优势做推广引流（03:29）。

**容易踩的坑**：把 CGO 理解成"比 CMO 高一级的头衔"。原文的判据是结构，不是职级。

**时效**：判据仍有效。需调整的是"可口可乐取消 CMO 改设 CGO 是全行业风向标"——后续企业岗位设置反复调整，此事不宜再当作"必然替代"的证据；实践中更多是 CGO 与 CMO 并存。

### 外部三途径 + 内部两途径 + 高维思维三步（第30课）

**外部三途径**：
1. **名校在职深造**（MBA/EMBA/DBA）——系统梳理零散实操、补经典理论地基、收获高端人脉
2. **进名企市场部**——借成熟运作模式、职能架构、岗位安排、帮带带教体系、充足预算与团队支援，快速练实操（"尤其是对一个新人来说"最合适，08:00）
3. **同行交流**——在不泄露核心商业机密的前提下大方交流，换运作技巧、跨界思维、对手情报，寻找资源互换与异业合作

**内部两途径**：
1. **行业深耕**——吃透行业前世今生、竞争格局、未来技术/产品/市场趋势，建立"产品里最懂市场、市场里最懂技术、技术里最懂销售"的复合壁垒
2. **专业训练**——外语、PPT、演讲、虚拟项目综合管理，并坚持写作梳理系统理论

**高维思维三步**：
1. **掌握低维标准**——熟识业务流程三个关键点：各节点的工作内容、职能范围、如何考核。不必掌握旁部门技能，但必须清楚该部门在闭环上的功用及对上下游的责任（28:29）
2. **创造制定结构的机会**——"有机会要上，没有机会创造机会也要上"：新业务洽谈时争取跟老板和管理层一起拜访客户；多与业务关联部门负责人沟通；把外部新市场机会带进公司现有架构做业务升级模拟（29:56）
3. **清零心态 + 新工具**——用能维护节点联系、保持可变性与弹性的新工具搭新结构；把内外商业信息客观分析、结合企业实际修正后迭代（31:13）

**四个实用方法**：项目总结（每个项目结束当天记心得、成功与失误）｜ 换位思考（站到老板角度推演）｜ 自建营销自媒体并坚持更新（不必篇篇精品）｜ 大量阅读（每本书都是一个体系）

**原文金句**：
- "我们需要的是碎片重组系统学习。"（20:40）
- "位置决定想法。"（31:00）
- "今天你的同行可能就是明天你的同事。"（12:53）

**容易踩的坑**：只做外部输入（上课、看书）不做内部重组，结果是"知道很多点，拼不成体系"——这正是讲师说的"一筹莫展，因为没有人教过我们说零到一怎么办"（21:14）。

**时效**：内部两途径与四个方法不依赖平台，长期有效。需调整：在职学位的性价比要按当下学费与回报重算；"建立自媒体"必须落到具体阵地才有可执行性；"工业互联网"作为机会举例已转向 AI 与大模型。

## 动作清单

### 定位自己
- [ ] 用高度/广度/深度三维给自己打分，找出最弱一维作为本年补齐重点
- [ ] 把日常工作逐条映射到树叶/树枝/树干/树根，确认实际停在哪一层
- [ ] 用"结构 vs 单点"给自己岗位写一句话定性
- [ ] 每年做一次"第二战场"盘点，更新资源清单与可迁移能力清单

### 往上走
- [ ] 停止只交单点任务，主动承接"把多个动作组合成一个任务"的完整项目
- [ ] 为市场部与其它部门的协作建立可量化的考核标准，作为资源互换的筹码
- [ ] 梳理团队分层，只抓各节点质量把控，把活动设计实施下放
- [ ] 做部门年度规划：明年是否加人、是否要更多预算、是否扩工作范围
- [ ] 每月与老板对齐一次利益方向，用他的可持续增长目标反推市场部议题
- [ ] 画出自己业务的节点图，标注每个节点的工作内容、职能范围、考核方式
- [ ] 争取跟老板/管理层拜访客户、参与新业务洽谈，进入高维视角

### 转型准备
- [ ] 用五路径对照表打分：资源、能力、代价承受度各 1–5 分，先排除代价不可承受的
- [ ] 做三笔"内部交易"（向供应商要资源、向研发要排期、向财务要预算），记录交换条件与结果
- [ ] 跟销售跑满一个完整项目周期再决定是否转岗
- [ ] 为每个做过的项目建"效果量化表"，按月/季/年列可测指标
- [ ] 先定一个垂直细分方向，写出一门核心课程的目录与 3 个模块
- [ ] 在企业内部认领新员工/销售/经销商培训的授课机会，录一次完整授课视频
