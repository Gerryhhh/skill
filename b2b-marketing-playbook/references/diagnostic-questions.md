# 诊断问题库

> 用途：用户抛来一个模糊问题时，先别急着给方案。用这里的问题把"症状"变成"可判断的情形"，再决定翻哪一章。
> 原则：**一次只问一个问题**，最多追问三轮；三轮后仍不清楚，就先给一个"最小可行判断"，并说明缺哪项信息会影响结论。

---

## 第一步：先确认意图

用户说完问题后，用一句话确认他要什么。三种意图，对应三种交付：

| 意图 | 用户的话长什么样 | 你该怎么接 |
|---|---|---|
| **要方案** | "怎么办""怎么打""给我个思路" | 走诊断 → 出作战包 |
| **要判断** | "这样行不行""值不值得做""老板这个要求合理吗" | 给判断 + 依据 + 前提条件，不出动作清单 |
| **要查课** | "课程里怎么讲 XX""第几课说过" | 直接定位到 course-map，按课讲，不展开诊断 |

> 确认话术示例："先确认一下——你是要一套能落地的动作方案，还是想先判断这事值不值得做？"

## 问题组

### A1 线索

**问什么**（按顺序，问到能定位就停）：
1. 线索从哪几个渠道来？各占多少？（判断是"渠道少"还是"渠道错"）
2. 销售说"废"，具体是打不通、没需求，还是没预算没决策权？（判断是线索质量问题还是分级标准缺失）
3. 你们现在有没有线索分级？按什么分？（课程原文没有分级标准，这一问是为了确认要不要补建）
4. 一条线索从进来到销售首触，平均隔多久？（判断流失发生在交接环节还是开发环节）
5. 目标客户是"哪一类企业的哪一类角色"，能说出三层吗？（判断 ABM 能不能用）

**答案指向**：
- 渠道少 → 第9课双矩阵选平台、第16课跨界换流量
- 线索质量差 → 第15课 BANTIC 筛选、第11课线索真伪信号
- 交接断层 → 第6课补位三技巧（注意：原文没有 SLA，需明确告知）
- 说不清目标客户 → 第11课望闻问切 + ABM

### A2 投放

**问什么**：
1. 现在投在哪几个平台，各花了多少？（判断是"铺太散"还是"押错注"）
2. 投的时候，目标人群"此刻在干什么"能描述出来吗？（第3课场景投放的前提是掌握接触点）
3. 有没有算过一个有效线索的成本？（课程给了参照口径，见 foundations 指标表）
4. 落地页/物料上有几个联系入口？（第3课"加强互动"）
5. 品牌曝光和线索，这笔预算想各占多少？（判断是不是被"品效合一"这句话卡住了）

**答案指向**：第9课双矩阵、第3课效果营销三法、第12课三维媒体模型。

### A3 活动

**问什么**：
1. 办的是哪一类：代理商会、产品推广会，还是专业展会？（第10课三板斧，三类打法完全不同）
2. 办之前定的目标是什么——收名片、签单、还是建立关系？（目标错，后面全错）
3. 现场谁负责收线索、谁负责跟进？（判断有没有交接机制）
4. 活动结束后多久做第一次触达？（原文未给时限，但这是最常见的断点）
5. 花了多少钱、来了多少人、拿到多少有效线索？（没有这三个数就没法复盘）

**答案指向**：第10课三板斧与展会八要素、第6课"搭台—唱戏"分工。

**必须告知用户的缺口**：课程原文**没有**展前/展中/展后的完整流程，也**没有**线索分配与首触时限。这些要另行补齐，不能假装课程里有。

### B1 品牌

## 三轮追问规则

1. **第一轮**：问最能区分路径的那一个问题（通常是"目标是什么"或"现在卡在哪一环"）。
2. **第二轮**：问量级或范围（多少人、多少钱、多长时间），用来判断方案规模。
3. **第三轮**：问约束（预算、人手、老板的态度），用来砍掉不可行的选项。

三轮之后仍不清楚：
> "按目前信息，我给你一个最小可行判断：……。但结论会受两个变量影响——X 和 Y，你把这两个数补上，我再给你完整方案。"

**不要**在信息不足时硬凑一个"看起来很完整"的方案。B2B 营销的坑大多不是不知道打法，而是用错了情形。
