# 公司档案（可填可不填）

> 这份档案不是必填项。填了，建议会更贴合你的实际；不填，SKILL 会在需要时逐项问你。
> 原则：**只填你确定的事实，不确定的留空**。留空比填错好——填错的背景会带偏所有后续建议。

---

## 1. 公司与产品

| 项 | 填什么 | 为什么问 |
|---|---|---|
| 公司一句话介绍 | 你们做什么、卖给谁 | 决定用哪套打法 |
| 主要产品/服务线 | 列 3–5 条，标出主力 | 不同产品线的营销逻辑可能完全不同 |
| 单笔客单价区间 | 元 | 决定是直销还是渠道、决策链长短 |
| 平均成交周期 | 天/月 | 决定能不能用"短平快"打法 |
| 毛利率区间 | % | 决定能承受多高的获客成本 |

## 2. 目标客户

| 项 | 填什么 | 为什么问 |
|---|---|---|
| 目标行业 | 哪几个行业 | 决定内容与渠道选择 |
| 目标企业规模 | 营收/人数区间 | 决定触达方式 |
| 决策链角色 | 谁发起、谁评估、谁拍板、谁使用、谁付款 | 第2课的核心：B2B 决策链是营销设计的起点 |
| 客户最常见的三个顾虑 | 用客户原话写 | 决定文案与话术的切入点 |

## 3. 竞争

| 项 | 填什么 | 为什么问 |
|---|---|---|
| 主要对手 | 2–3 家 | 定价、定位都要对标 |
| 对手的价格带 | 公开报价区间 | 第25课定价的锚点 |
| 客户为什么选对手 | 你听到的真实理由 | 找出自己的差异点 |
| 你们的差异化 | 一句话，必须是"不同"而不是"更好" | 决定品牌与文案的核心 |

## 4. 现有资产与渠道

| 项 | 填什么 | 为什么问 |
|---|---|---|
| 官网 | 有无、月访问量（估） | 判断承接能力 |
| 新媒体阵地 | 开了哪些、粉丝量、更新频率 | 第12课要按属性分层，不是越多越好 |
| 私域/社群 | 有无、规模 | 第17/18课的前提 |
| 销售团队 | 人数、区域分布、是否代理 | 决定"搭台—唱戏"怎么分工 |
| 渠道体系 | 直销/代理/混合，几级 | 第26课价格管理的前提 |
| 老客户数量 | 大约多少家活跃 | 决定转介绍与生命周期的空间 |

## 5. 团队

| 项 | 填什么 | 为什么问 |
|---|---|---|
| 市场部人数 | 几人 | 决定方案规模 |
| 分工 | 谁负责品牌、内容、活动、渠道、产品 | 对照第4课五大职能看缺口 |
| 年度预算量级 | 万元（可给区间） | 决定打法轻重 |
| 汇报关系 | 向谁汇报 | 决定话语权与推进难度 |

## 6. 目标与约束

| 项 | 填什么 | 为什么问 |
|---|---|---|
| 今年最重要的一个目标 | 一句话，要可量化 | 所有建议都要服务于它 |
| 最大的卡点 | 一句话 | 诊断起点 |
| 硬约束 | 预算/人手/时间/老板态度 | 用来砍掉不可行选项 |
| 不能碰的红线 | 合规、品牌调性、竞业 | 避免给出不能执行的方案 |

## 填写示例（只示范颗粒度，不要照抄）

```
公司一句话：给汽车零部件厂做在线尺寸检测设备，客户主要是长三角的一级供应商
客单价：80–200 万
成交周期：6–12 个月
决策链：质量部发起 → 技术部评估 → 采购比价 → 厂长拍板
主要对手：两家外资 + 一家国产低价
差异化：换型时间比外资短一半，价格是外资的六成
市场部：3 人（1 内容、1 活动、1 设计），向销售副总汇报
今年目标：新增 15 家有效客户
最大卡点：展会收的名片销售不跟进
```
