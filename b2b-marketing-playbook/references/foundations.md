## 什么时候翻这一章

- 老板或跨部门同事问"市场部到底在干什么、产出是什么"，你答不出三句话时
- 要判断一门生意、一条新产品线值不值得投时
- 用 C 端那套裂变、社群打法做 B 端，发现完全跑不动时
- 市场部被当成"样本部""活动部"，要不到预算和人时
- 销售说市场部没用、活动不来人、线索不认账时
- 要带新人、给团队定能力标准时
- 预算要分"品牌"和"效果"，老板只认线索时

## 打法详解

### 四字拆解：市·场·赢·销

**它解决什么问题**：把"市场营销"从一句口号变成四个可以逐个回答的判断，避免一谈营销就只剩做品牌、做广告。

**怎么做**：
1. **市**——定义交易对象。不要写产品，写"产品需求 × 用户需求"的交集；再往下追问用户动机，因为真正被交易的是动机。
2. **场**——评估交易力。用交易频次、交易价格、交易利润三个指标两两组合，判断这门生意好不好卖。
3. **赢**——逐条搭壁垒。内部：技术、规模、成本、管理、人才；外部：品牌、价格、渠道、持续占领心智的传播功力。
4. **销**——把每个市场动作折算成"占领了用户心智的哪一点"，答不出的动作砍掉或重做。

**适用条件**：新产品上马、开拓新商业路线、判断市场动作有没有商业含量。

**原文案例**：
- 钉子：用户要的不是钉子，是挂画、挂窗帘——交易对象是动机（02:25）
- 四档饮用水：农夫山泉 2 元、昆仑山 5 元、依云 10 元、VOSS 25 元——同一件商品在不同场景下交易的东西完全不同（03:34）
- 格力：空调行业没有技术门槛，"大"就是壁垒——极大规模＋极低利润，让"有钱没规模"或"有规模没钱"的对手都撼不动（09:50）
- 小米：壁垒不是饥饿营销或情怀，是覆盖手机、净化器、盒子、风扇、背包、路由器、音箱的生态链＋极致性价比（10:50）

**容易踩的坑**：把产品参数当卖点（"市"这一格填成了产品说明书）；把"我们质量好"当壁垒（对手用资本可以把这个优势放大十倍百倍，11:41）。

**时效**：仍有效。四字框架不依赖任何平台。唯一需要补的是外部壁垒清单——今天还要算上数据资产、私域/客户关系资产、供应链响应速度。

### 交易力三指标矩阵

**它解决什么问题**：判断一个产品落在什么行业象限、这个象限的宿命是什么，从而知道该不该投入。

**怎么做**：给产品在频次、价格、利润三个维度分别打高/低，两两组合。

| 组合 | 原文判定 | 原文举例 |
|---|---|---|
| 频次高 + 价格高 + 利润低 | 工业品 | — |
| 频次高 + 利润高 + 价格低 | 快消品 | 麦当劳（几乎看不到关店） |
| 价格高 + 利润高 + 频次低 | 奢侈品、汽车、房地产 | 米其林餐厅 |
| 三高 | 石油、电力、矿产、大宗（国家命脉资源，中小公司很难介入） | — |
| 频次高 + 价格低 + 利润低 | 极难持续经营 | 小吃店（招牌频繁更换） |

**适用条件**：新产品上马或开新业务线之前做合格性判断（08:30）。

**原文案例**：小吃店 vs 麦当劳 vs 米其林餐厅的对比（07:41）。

**容易踩的坑**：只算价格和利润、漏掉频次；把"三高"当成理想生意，忽略准入壁垒。

**时效**：方法论仍有效。"三高"里的石油、电力、矿产作为商业机会样本已不具参考价值（准入与监管环境完全不同）。

### B2B 三大特点

**它解决什么问题**：解释为什么 B 端跑不动 C 端那套打法，以及营销难度到底来自哪里。

**怎么做**：
1. 判断产品专业度，以及是否必须匹配系统运作（参数进入不同系统会衍生千变万化）
2. 数客户群体——窄到什么程度（"全中国只有那么几十家"，04:44）
3. 画决策链——链上每个有决策权的人都是理性商业人

**原文案例**：化工冷门原材料、大工业系统里的零配件，客户群体极窄；决策链角色依次为设计方、评估方、掏钱的甲方、安装方、施工方、监理方、验收方、最终用户端（05:38）。项目周期"短的两三个月，长的拉长到好几年"（05:23）。

**容易踩的坑**：把"客户少"理解为"不用做营销"，实际是"每一个都要精耕"。

**时效**：仍有效。需放宽的一点是"社群、裂变、跨界在 B 端无处发力"——今天视频号、行业社群、私域在 B 端能跑通，只是玩法从"拉新裂变"变成"长周期培育"。

### B2B vs B2C 的 4P 对照

**它解决什么问题**：把"B2B 不一样"这句空话，拆成四个具体差异，避免照搬 C 端经验。

| P | B2B | B2C |
|---|---|---|
| 产品 | "填坑"——需求先于产品存在，向下挖掘填补空白（建高铁必然需要钢筋水泥、列车、电器、通风照明安防） | "堆山"——在既有需求上拔高、锦上添花 |
| 价格 | 看市场与对手，对标领军企业/主要对手的价格水平并兼顾利润 | 看客户感知（飘柔初入中国时因"进口=昂贵"卖得贵，今天 9 块 9、十几块） |
| 渠道 | 大客户直接销售为主（产品专业、沟通成本高、行业重"成一单是一单"的口碑） | 铺渠道，要求又广又深 |
| 促销 | 以销售成交为主 | "空军"，以品牌拉动为主 |

**容易踩的坑**：四大误区——无本土化成型的 B2B 理论、重销售轻市场、关系营销主导、专业知识壁垒严重（13:51）。原文对关系营销的判断很直接："靠关系搞定有话语权的人，见效非常快，但它并不是一个长久持续发展的路子"（15:29）。

**时效**：渠道与定价逻辑仍有效。飘柔案例的"进口=高端"认知前提已消失，只能作历史说明；"铺渠道要深到三四线农村"需换成全渠道触达。

### 效果营销三法

**它解决什么问题**：B2B 决策链长、一次曝光促不成单，钱怎么花才有线索。

**怎么做**：
1. **场景投放**——在目标人群出没的地点、扣住其当下需求投放；前提是先掌握"品牌接触点"
2. **简单直接**——用非专业人士也能一眼抓住的硬朗话语，并在不同场景重复同一句
3. **加强互动**——每版物料都放尽可能多的联系入口

**原文案例**：
- 机场与高速路旁的大牌广告，看似传统甚至"有点土"，但精准命中"飞往各地谈项目的负责人下飞机/跑城市时看到建材、零部件广告"的场景，记忆度高于互联网投放（08:19）
- 冷水机组广告语"少即是多"——四字硬朗，用极少部件达到高性价比工况，引发专业与非专业用户的好奇（09:54）
- 互动入口清单：客服电话、二维码、搜索关键词、社群名称、天猫/京东旗舰店名（10:46）

**时效**：三法全部仍有效。需要调整的是入口载体——电商旗舰店在工业品与 SaaS 里更多是信任背书，主战场已转向官网/垂直平台；"农村刷墙"已彻底过时。

### 流量流转拓循环

**它解决什么问题**：流量"少、贵、假"，怎么用存量带增量。

**怎么做**：
1. 整合传播（以新媒体为主）把客人从各渠道引到自有平台
2. 线上线下整合活动（最常用场景营销）留存用户并促成交
3. 对成交用户做整合服务（订单查询、新品播报、售后响应）
4. 服务满意触发"再拓展"——决策链上理性、生活中感性的人，在社交圈向同领域用户转介绍
5. 转介绍用户重新进入整合服务，形成循环
6. 全程用整合数据监督、改进、迭代

**原文案例**：行业用户关注公众号 → 得知某场线下活动 → 到场接触营销人员与产品 → 购买 → 服务中体验订单查询/新品播报/售后响应 → 转发朋友圈 → 朋友圈里的同行业专业用户关注公众号，形成新循环（16:02）。

**容易踩的坑**：把"流转拓"做成单向漏斗，只引流不服务，第 4 步断掉，循环就变成一次性买卖。

**时效**：循环逻辑仍有效（B2B 转介绍至今是最高质量线索来源）。承接主阵地需从"单一公众号"改为"公众号＋视频号＋企微＋行业社群"组合。

### 播种—收割

**它解决什么问题**：终结"市场部领导销售部还是销售部指引市场部"这种鸡生蛋式争论。

**怎么做**（原文的农作六步）：
1. 找一块适合耕种的肥沃土地——找目标市场
2. 翻犁、浇水、除虫——培育市场环境
3. 播种——找到适合该市场的产品
4. 除草、施肥、灌溉——制定产品发展规划与生命周期、调动资源推动产品下线
5. 销售用工具收割
6. 收割所得反哺下一季度，去挑更肥沃的土地、试更多作物

**原文金句**："市场部播种，销售部收割。"（03:40）

**容易踩的坑**：市场部越界去收割（抢单），或销售部要求市场部直接给订单——两边都会退回"市场部没用"的结论。

**时效**：仍有效，是 B2B 组织分工的主流共识。

### 四种组织设置

| 设置 | 常见于 | 已知弊端（原文） | 出处 |
|---|---|---|---|
| 市场部＝销售部（营销部） | 大部分初创与中小企业 | 此阶段"先活下去、有更多种子用户进来"最重要，专业分工不足 | 04:19 |
| 市场部隶属销售部 | 销售导向的 B2B，如软件、服务行业 | 市场动作被短期业绩绑架 | 05:03 |
| 市场部独立于销售部 | 外企 | 预算、营收、资源完全独立，可按自己节奏规划；但脱离一线，信息多为二手 | 05:51 |
| 互为支持与管理 | 大型成熟工业品及 B2B 企业 | 职责交叠处容易扯皮 | 06:47 |

**怎么用**：先判断自己属于哪一种，再写出这一种的已知弊端和补救动作——不要试图直接跳到"最理想"的那种。

### 五大职能 + 军事编成

| 职能 | 管什么 | 军事类比 |
|---|---|---|
| 产品市场 | 新产品开发、上市定价与推广、产品生命周期管理、内外沟通资料 | 特种部队（攻特定项目/特定应用） |
| 传讯市场（MarCom） | 内外沟通政策与流程、市场活动、政府事务与公共关系、危机公关 | 空军（从上到下鸟瞰式传播） |
| 渠道市场 | 渠道推广计划、渠道开发/建设/管理、代理商管理 | 总参谋部（与渠道、应用、战略同属"需创市场"） |
| 应用市场 | 特定产品/系统在某一细分市场（民用机场、核电核能、数据中心、医疗净化）的应用拓展 | 总参谋部 |
| 战略市场 | 进管理层，与核心管理群体共定中长期市场规划 | 总参谋部 |

**关键概念**：渠道、应用、战略三者统称**"需创市场"（demand creating）**——本质都是为企业创造新需求、找颠覆性增长的新路子（07:26）。战略市场只在企业足够大、方向选择比具体实施更重要时才有存在必要（10:21）。

**容易踩的坑**：把销售事务（报价、跟单、催款）塞进市场部，导致市场部永远在救火，没有余力做"需创"。

**时效**：职能划分仍有效。传讯需补自有媒体矩阵与内容/搜索运营；渠道需补线上渠道与渠道数据化；"弹药"要从纸质册子换成可在线分发、可追踪阅读的数字化内容包。

### 四技能框架 + 三个具体方法组

**它解决什么问题**：给"B2B 市场人该会什么"一个可考核的口径，而不是泛泛的"综合素质"。

**专业知识**——深度标尺是一句话：**比销售更懂产品，比研发更懂市场**（03:10）。四步：了解本公司产品特点与技术特色 → 掌握行业基础知识 → 确保工作方向与公司品牌战略一致 → 在销售与研发之间承担信息沟通职能。

**市场敏感度三法**：
1. **囫囵吞枣法**——进入陌生市场先大量翻第三方资料与报告，先记框架不求甚解：市场规模、主要品牌划分、各品牌份额、主打产品、我方优劣势、当地与今后几年发展势头；框架进脑后，日常工作中逐格填细节（04:43）
2. **追本溯源法**——看不懂的信号向上游追。原文例：发现铜价波动，追问是国际期货变动，还是国内进入用铜产品销售高发期导致供不应求（05:29）
3. **名师引路法**——向同行前辈、企业内部在市场竞争上做得出色的同事请教（06:14）

**创造力三法**：
1. **跨越**——跨行业、跨部门、跨群体；看别的行业怎么占领心智，判断能否为我所用，不能用的找出隔阂在哪
2. **Plan B**——任何方案都备替代案，用"必须有备份"强迫自己开拓眼界
3. **开放的心态**——重视团队每个人的想法，当下不合适的可能成为后续点睛元素

**工具三件套**（各有明确掌握口径）：
- **财务统计**：看得懂报表，做得了预算。场景：看对手财报备战 PK、算非标产品不含税毛利率判断报价会不会输、判断项目 ROI 过低是否要重研产品（09:33）
- **专业软件**：看得懂图纸，讲得了产品。原文列举 AutoCAD、Pro/E 及选型软件；场景为 presentation、讲标书、带客户参观工厂与测试（10:33）
- **PPT**：市场人的看家工具，原文列举的场景几乎覆盖全部营销环节（11:21）

**原文金句**："很多 B2B 企业的市场部，尤其是负责传讯的部门，往往会被大家戏称为样本部、活动部。"（02:47）

**时效**：能力要求仍有效。PPT 的应用场景清单需更新——公众号编辑、小程序开发在 B2B 营销中已边缘化，重心转向视频号/短视频/直播与私域；付费行业报告可大量用公开财报、招投标公告、AI 检索替代，只买稀缺数据。

### 五维职能对照 + 三个补位技巧（第6课）

**它解决什么问题**：跟销售吵架之前，先看清矛盾的结构性来源——不是谁态度不好，是职能设计本来就错位。

| 维度 | 市场部 | 销售部 |
|---|---|---|
| 业务设计面 | 多维立体：看市场前后发展、区域整体情况 | 点状：拿下这个单、搞定这个客户、完成今年指标 |
| 业务环节位置 | 成交的**前期与后方**：签单前找市场、开拓、联系客户、做品牌灌输；成交后做客情维护、服务、案例配置 | 链条**中间最核心**：具体负责成交 |
| 销售工具 | 制作方 + 支援方 | 使用方 |
| 品牌推广 | 搭台：会场、会址、邀请函、物料；邀请对象偏行业组织与专家 | 唱戏：负责把真正的客户请到现场 |
| 财务角色 | 花钱部门，成本中心 | 挣钱部门，利润中心 |

**为什么市场部尴尬**（利益链条三段）：内部利益相关方（CEO、CFO）→ 中间层（CMO/市场部，把战略拆成战术）→ 外部（销售、代理商、渠道、最终用户）。市场部卡在中间，进不了内部核心圈，也进不了外部利益循环，所以被销售视为"可有可无甚至多余"（06:41）。

**三个补位技巧**（这是本章最实操的部分）：

1. **说销售不便说的话**
   - 机制：销售口才"不排第一起码进 top3"，但再能干的销售，对内对外总有"不方便说、不敢说、不能说"的话。市场部用自己的发声功能替他说。
   - 原文案例（完整）：某公司因产品货期延误甲方工期，客户甩下"今后再也不与你们公司做生意了"。销售继续公关必然吃闭门羹，市场部转而抓一切接触机会重塑形象——展会上热情寒暄并馈赠纪念品、逢年过节登门送贴心礼品、新产品出炉把新宣传册"热气腾腾"亲自送到用户手上、办大型活动提前登门诚意邀请（08:41–09:31）。
   - 底层逻辑："人非草木，攻心为上"；做的是 B2B 生意，最终要打动的是 B 端里有决策话语权的那个 C（09:31）。

2. **做销售不便做的事**
   - 机制：B2B 销售是"跑项目"，"跑"字很传神——埋头于几个核心客户，必然对宏观形势不敏感。原文对照：地区销售负责人谈当地销售状况"能和你说上三天三夜"，但问他明年该地区产业形势对主要对手有什么影响、公司该怎么应对，就"不会那么得心应手"（10:18）。
   - 具体动作（原文完整链路）：每年买精良行业报告 → 报告不能看一遍就尘封 → 提炼成"迷你版"（本公司产品市场份额、竞争地位、对手动态、全行业大环境）→ 发给各地销售团队 → 免掉销售阅读总结理解的麻烦，同时给一线前瞻指导（11:04）。

3. **扛销售不愿意干的活**
   - 机制：销售背年度指标、本能求稳，只要现有市场没饱和就不会主动开拓。两类市场没人愿碰：进入难度太大的、公司从未涉足的。
   - 成功标准（原文口径，非常低）：从零开始，只要"开拓了几个意向用户"或"做成一到两个哪怕非常小的样板工程"，就是市场部巨大的成功（12:25）。
   - 附加收益：借试水向企业上下展示市场部的工作方式，完成"战略旁观者 → 营销战略参与者 → 营销战略支持者"的蜕变（12:54）。

**原文金句**："我们虽然做的是 B2B 的生意，但是我们最终要打动的还是那个 B 端里面有决策话语权的那个 C。"（09:33）

**容易踩的坑**：把"补位"做成"抢位"——直接去抢销售的客户和提成，会立刻失去所有协作空间。

**时效**：三技巧全部仍有效，因为逻辑不依赖具体渠道。需调整的是载体：公众号已不足以承担内容交付（应转视频号/直播/垂直社群+销售朋友圈分发）；纸质样本与礼品可保留但权重下降，让位于案例内容、行业数据服务、客户参访。

## 原文缺口

实操时绕不开、但课程**没有讲**的环节。遇到这些，本手册只能给框架，具体做法需另行补齐：

1. **市场部 KPI 的权重设计**——第6课只说"有共同指标"，没给权重、双算规则、互评机制
2. **线索交接规则**——没有 MQL/SQL 定义、线索评分、交接时点、退回机制
3. **SLA 时限**——全文未出现响应时限、跟进时限、线索有效期
4. **内部争议处理流程**——只有"换位思考、少抱怨"的态度层表述，没有仲裁与升级机制
5. **B2B 营销的本土化理论**——第2课明确说国内没有成型理论，本手册的框架全部来自讲师个人实践总结，不是学术模型
6. **各职能的人员配比**——五大职能该配几个人、什么规模配什么职能，原文未给
7. **预算分配比例**——品牌与效果各占多少、渠道之间怎么分，原文未给基准
